## Phase 5 · Critiques

### CC-01 · MorphoJIT · 864

Joint screws and validated graph tables make first execution of an unseen topology a data update. Keep one rigid-tree interpreter with a CPU oracle and promote a specialization only when it pays for itself. E003 supports the ABA reference, and `fs-tilelang` supports a restricted scalar/lane pattern. Neither supplies the two GPU backends or host-to-device semantic parity. A `PFAFF` or `LOOP` row names a constraint. It takes a coupled solver to satisfy it. Twist exponentials need a well-conditioned zero-angular limit and admitted precision. Same topology makes opcode control uniform, while contacts and reset work remain divergent. In the all-small case the two 4090s see only 512 launched warps across 256 SMs. A cache-sized table also leaves bandwidth and occupancy unmeasured. E024’s e-graph is a stub, and a warp cannot select a new compiled pipeline by swapping a hash alone. Use acknowledged dispatch boundaries and versioned state maps for promotions. [Ada tuning guide](https://docs.nvidia.com/cuda/archive/13.4.2/ada-tuning-guide/index.html)

**Decisive gate.** Time novel structural edit to accepted rollout against warm graph buckets and a ragged operator scheduler. Match contacts and task work. A repeated CUDA Graph launch does not pay a fixed host launch cost for each node, so the 8–20× projection cannot be taken from that multiplication. DoF-normalized throughput alone can hide the cost of difficult contacts. [CUDA Graph launch measurements](https://developer.nvidia.com/blog/constant-time-launch-for-straight-line-cuda-graphs-and-other-performance-enhancements)

### CC-02 · Equivariant Gait Atlas · 842

Generate candidate phase patterns and continue verified periodic solutions as geometry changes. This is a concrete alternative to retraining on every edit, and E021 already analyzes a supplied monodromy. H/K enumerates admissible symmetry types of an equivariant system. It does not prove that each phase pattern is realized on the prescribed robot. The whole twisted boundary action, including the generator of $H/K$, must be a symmetry of the actual controller, guard/reset and terrain. A restricted orbit can hide unstable transverse multipliers. Adding a leg changes state dimension and needs a new seed or justified embedding. Periodic LQR needs stabilizability and feasible actuation. An envelope-gradient error of $O(\|\nabla_\phi J\|)$ also needs local regularity and an error bound linking residual to optimizer distance. [Buono–Golubitsky](https://www.asc.ohio-state.edu/golubitsky.4/reprintweb-0.5/output/papers/buonoI.pdf), [Saltation matrices](https://arxiv.org/abs/2306.06862)

**Decisive gate.** Start on the rimless wheel and one real catalog gait chart. Check full return-map derivatives and symmetry-breaking perturbations, then time accepted continuation edits against warm shooting, Drake trajectory optimization and tuned RL where applicable. The 9.2B lane-step count is plausible bookkeeping. NEON’s rigid primal step rate is no measurement of coupled tangent sweeps, solves, or branch recovery.

### CC-03 · Falsify → shrink → attribute → repair · 820

The valuable output is a small versioned world edit plus an independently replayable failure and repair. E003 topology admits geometric candidates. An oracle using stronger hardware establishes feasibility for its own robot. Require a witness with the **candidate body, controls and mission constraints**. If it uses privileged sensing, label the result as plant-model feasibility and test information feasibility separately. `ddmin` is 1-minimal under the tested edit relation and failure predicate. Noisy tests and nonmonotone continuous failure sets invalidate a simple claim of the globally closest boundary. Frozen fresh confirmation matters after adaptive search and cause selection. Shapley scores alone cannot establish necessary causes or disambiguate redundant causes.

**Decisive gate.** Compare independently accepted failure repairs per hour against tuned cross-entropy search and incumbent reset/replay tooling. CC’s projected 6.0M search + 9.2M shrink + 0.41M autopsy steps gives a roughly **6.4×** work ratio against its 100M random-search baseline, before extra confirmation and parity. The assumed five cross-entropy levels have no universal rare-event guarantee. Make seeded `.fmcw` output useful before requiring 4,096 simultaneous branches or the planned WebGPU exporter.

### CC-04 · Complete-solution mechanism synthesis · 713

Parameter homotopy from a certified generic instance is a real addition beyond E023’s bounded RUR. It can make a linkage designer choose across entire branch families. A checked α-test establishes a nearby nonsingular root under its hypotheses. Distinctness and reality require additional witnesses. An unexplained path loss, positive-dimensional component, or singular endpoint blocks a complete result. A finite-field count also needs justified transfer to characteristic zero and matching saturation/projective-chart conventions. The 99.9% certification gate cannot support saying every root was certified. E023 caps RUR at eight variables, 4,096-bit coefficients and zero-dimensional inputs, and its univariate integer bridge cannot project general α-inequalities. E024’s `norm_num` is a stub. [Nine-point four-bar primary study](https://academicweb.nd.edu/~cwample1/Preprints/Ninepoint_JMD1992.pdf), [alphaCertified](https://arxiv.org/abs/1011.1091)

**Decisive gate.** Lock a small planar family and compare certified, continuously traversable geometries/hour with optimized CPU parameter continuation or exact construction. Count generic startup, rejected paths, singular endgames and checking. The 0.14 s 4090 estimate omits the item’s own 1–2 s checking estimate and mixed-precision divergence. Metal needs checked double-float or CPU recovery. Ship the Rust CPU checker before porting the difficult endgames.

### CC-05 · Breadth/depth dual silicon · 683

The strongest part is a compact, verified world recipe with independent rollout shards. A seed can recreate a deterministic procedural output when the generator, numerical choices and immutable assets are pinned. A reconstructed scan or recipe dependency still needs a content-addressed transfer on a cache miss. Resident 200 GB process memory does not establish an admissible Metal working set or useful locality. E025 requires new leases and synchronization. The assumed 40 MB/generation hits 1 GB/hour at 25 generations before retries or assets. The stated diversity budget is 5× versus both 4090s sharded, not 10×. A static max-plus cycle mean applies to an appropriately modeled event graph. Variable queue/compile times and resource contention need measured feedback. Live `fs-tropical::critical_circuit` enumerates simple cycles, unlike its Karp mean routine. [FrankenSim max-plus source](../../../frankensim/crates/fs-tropical/src/lib.rs), [Apple working-set guidance](https://developer.apple.com/documentation/metal/mtldevice/recommendedmaxworkingsetsize)

**Decisive gate.** Compare equal scene distributions, cold asset traffic and accepted campaigns against strong tiled caching and a simple work-conserving scheduler. Separately measure the generalization effect of additional worlds. The 1.7× fleet gate could justify the architecture without constituting a 10× workflow result.

### CC-06 · Proof-carrying fused shields · 515

A fixed-point shield with model-scoped proof and independently checked lowering would beat a penalty workaround. CC improves the order of control and disturbance quantifiers over AGY #3. The cone shortcut still fails as written. For an **infimum over possible contact forces**, replacing a larger cone with a smaller one can only increase the infimum. One may use a smaller cone for conservative *controlled* force feasibility when enforceability is proved. The stated single-row projection also ignores box constraints. With $R=I$, $u_\pi=(1,0)$, box $[0,1]^2$ and $u_1+u_2\ge1.5$, it yields $(1.25,0.25)$ instead of $(1,0.5)$. Box faces invalidate the 64-set count unless eliminated by a separate bounded method. The 4k FLOPs are 20% of the quoted 20k low-end step. E023/E024 do not provide the proposed multivariate SOS bridge or rewrite witness. A buffer on $h$ alone cannot handle all actuation, coefficient, timing and reset error.

**Decisive gate.** Build a two-mode sampled-data template with a shared feasible action, a certified backup domain and a direct checker for the actual fixed-point kernel. Include box-saturating, rank-deficient and out-of-model cases. Compare at equal coverage with an optimized robust filter. E026 supports firmware test practice, while MCU WCET and field calibration require their own receipts.

### CC-07 · Operadic robot algebra · 782

Composable open modules can carry a durable port contract, local code and proven obligations into the next design. This is a stronger agent interface than regenerating XML. It builds on E021 and real `fs-ports`, `fs-system` and `fs-couple` code. Their current manifests directly depend on `fs-qty`, so this is a lift/toolchain project. Continuous lossless interconnection leaves initialization, discretization and global compatibility to prove. A wreath-product factor survives only if component symmetries preserve exposed ports and the hub action preserves the decorated interfaces. A shared moving base can make Delassus dense across leaves even when the kinematic wiring is a tree. And for the stated 10 types on six indistinguishable dihedral slots, exact Burnside gives 86,185 orbits, not 83,333. Count only automorphisms admitted by the physical configuration and task. [FrankenSim port composition](../../../frankensim/crates/fs-couple/src/lib.rs)

**Decisive gate.** Mirror-swap one limb and change one shared bus. Test that powered interface obligations are reused exactly where valid and centrally coupled ones invalidate. Compare accepted edits/hour with memoized assembly and monolithic checking, including Drake-style composed systems as a reference. A 20× certificate-composition gain is plausible for hot leaves, while time-to-qualified design has a larger denominator.

### CC-08 · Causal tribology and local multiphysics · 735

Wheel pickup and redeposition make one robot alter the traction faced by the next. That creates a distinct decision problem that static friction randomization cannot express. CC’s transport term puts the contact indicator outside the divergence, which can introduce a spurious source at the contact boundary. Use conservative face fluxes with the support mask inside the flux and balance film carried by the wheel. The given $\eta v/p$ has units of length and needs an explicit characteristic length or a calibrated dimensional law. A wet friction lookup alone cannot predict hydrodynamic lift. E022 supplies candidates for both laws, while coupled finite-volume/LBM phases need separate admission. At two water subcycles, full-grid film traffic goes from about 177 to **354 GB/s** before halos. In the 5 mm LBM cube, two population buffers take about **1.22 GB/env**, or **156 GB** at 128 envs before other allocations. A continuous Dirac identity supplies no asynchronous discrete energy guarantee. [Genesis coupled fluid models](https://genesis-world.readthedocs.io/en/latest/user_guide/theory/coupling/index.html)

**Decisive gate.** Start with one wet patch, one trailing wheel and instrumented spread/friction data. Compare design rankings against static maps and an eligible Genesis or Isaac fluid reference at matched measured error. Require mass and discrete work residual checks. A 10× result would be accepted causal-spill evaluations per hour. Rank agreement and held-out physical calibration have separate denominators.

### CC-09 · Lifecycle compression · 715

Updating age, then re-solving the operating cycle, can capture feedback that a detached wear spreadsheet misses. The 1,800× **substep-count** reduction follows from the stated windows and horizon. It is evidence for an experiment, with runtime and field life still open. Floquet multipliers separated from the unit circle help bound relaxation, while transient amplification, competing attractors and load excursions can invalidate short windows. Step doubling can agree on a biased window estimate. E022’s rainflow implementation retains residual cycles, so passing only a histogram between windows can change fatigue damage. Archard, Miner and battery fade need calibrated regime and history state. A 100 h, 64-world reference is 23.04B substeps, not a timing result on a 4090.

**Decisive gate.** One component, periodic load, known answer, plus rare overload and planted regime switch. Compare against direct integration and a competent duty-cycle model, charging micro-window burn-in and retries. Validate ranking on held-out wear trials. Compression of simulated age earns no clock-to-failure claim outside those data.

### CC-10 · Spec-to-silicon · 686

The typed mission and replayable package are strong product ideas. Normalize predicate margins before using the min/max robustness as an objective across mixed units. Exact sampled robustness can decide a completed trace. Future STL operators require buffering or an explicit delayed verdict, and smoothing or reward shaping can change satisfaction decisions near zero. A 600 s future window at 50 Hz can require 30,000 samples in a worst-case streaming deque even when work per sample is modest. E024’s executable e-graph and E008’s WebGPU packager are absent at the cited revisions. E026 supports a test-harness precedent. Instruction counts alone do not bound MCU WCET across memory stalls, buses and interrupts. A million trace matches give numerical evidence for those vectors. They leave universal lowering equivalence to prove. [FrankenThreeD workspace](../../../franken_threed/Cargo.toml)

**Decisive gate.** Deliver one typed mission and a closed catalog BOM/wiring packet, with independent reviewer acceptance and tested sampled monitors. Compare prompt-to-accepted-packet time against scripted export plus the same review. Add one no-alloc firmware target only after linked size, stack and real-board timing receipts exist. Charge sensor and HAL behavior in the 1 ms budget, and collision/assembly and connector constraints in the harness review.

### TA-P1 · Algebra quotients campaign work · 804

This is the right unit of comparison. A0/A1/A2/A3 can distinguish deleting work from accelerating work, and the quality controls make the speed claim falsifiable. At the stated costs, A2 gives $32/(3+0.27)\approx9.8\times$ before extra confirmation. The 24× A3 projection assumes the same speedup on atlas, PPO and other work. Those fractions need independent timings. The periodic atlas is a **screen**, so it can discard a superior staircase policy. A winning e-value between the eighth and ninth retained designs says nothing about discarded designs without a selection-valid audit. The assumption of 15 GPU-min on all 128 also needs comparison to tuned early stopping and warm starts.

**Exclusion test.** Add a blinded, stratified audit of discarded designs and a planted winner whose gait chart is poorly represented. Freeze a common definition of the reference top eight and the multiple-comparison error budget. Give credit for fewer equal-quality decisions, including failures and all confirmation. Keep the exact isomorphism quotient only where the observation, control, world and mission share it.

### TA-P2 · Warp diversity and race annealing · 763

This is stronger than a blanket warp-lock pitch because it allows per-family supersets to win. The modular rotation balances the initial cohort and covers all 64 worlds over 64 epochs. Different morphology residues visit the same world at **different epochs**. Seeding by (world, epoch) therefore does not pair those runs. Use world/replicate keys and rebalance after pruning. With balanced dual shards, 512 32-lane warps average two per SM, not four. Two worlds per warp also permit different traversal and contact paths. Recent CUDA straight-line graphs show near-constant repeat host overhead on tested configurations, so charge measured node execution, launch and concurrency separately. A 5% population share is a trigger candidate. Remaining useful work, compile completion and publication cost decide promotion. [CUDA Graph launch measurements](https://developer.nvidia.com/blog/constant-time-launch-for-straight-line-cuda-graphs-and-other-performance-enhancements), [Ada occupancy](https://docs.nvidia.com/cuda/archive/13.4.2/ada-tuning-guide/index.html)

**Exclusion test.** Add ragged per-operation batching and an 8-episode sparse tail to the warm-graph and superset arms. Score measured edit-to-result cadence, legal topology coverage, and campaign wall time after asynchronous promotion. Qualification comparisons must use an estimand that remains valid across the annealing schedule.

### TA-P3 · Contract-stratified certificates · 621

Keep the typed product of conditional theorem, monitor evidence and empirical residual. Fix its probability semantics. $\delta_1$ must be a conditional miss probability under a declared breach-event sampling law for the rate-times-miss multiplication. An unconditional joint probability cannot be multiplied again by breach rate. A sound episode bound can sum expected counts of missed breaches and failed alarms plus the probability of a model-gap event, provided every violation is covered by those events. Silent breaches cannot be labeled by the same monitor that misses them, and InEKF covariance is not a pointwise error bound. Shift can change both rates and conditional errors. Four independent open/stick/slip contact statuses under the stated free $V_4$ action yield $(3^4+3\cdot3^2)/4=27$ orbits before impact ordering. The 14 certificates cover only a model with an explicitly coarser flag.

**Exclusion test.** Use independent hidden-state breach labels, an identically sampled shifted-world baseline, and simultaneous confidence bounds. Challenge mode ambiguity, latency and silent breaches. A contract theorem survives in its proved domain. The empirical bound needs evidence under the target distribution or a separate transport assumption. CC-06’s force-quantifier and backup gaps remain prerequisites.

## Phase 6.75 · Steelman of CC-01 MorphoJIT

MorphoJIT makes the structural research loop usable before the compiler is clever. An agent that adds a fifth leg or reconnects a drive should receive a type-checked graph and a first valid rollout on the same resident execution substrate. A researcher should be able to compare that candidate with its parent immediately, along with hundreds of other short-lived experiments. Rigid-tree ABA, finite screw operands and versioned tables are sufficient for an early demonstration. The interpreter supplies a stable reference for specialized code, with an independent CPU oracle checking both. A cohort that survives long enough pays for partial evaluation from its own measured remaining work, while new and rejected candidates spend nothing on shader generation. That decouples evolutionary exploration from compiler backlog, gives both hardware backends an ordinary path for unseen inputs, and puts a reversible fallback behind every optimization. If novel edits are common and each gets only a thin rollout budget, this can eliminate the dominant cost of the campaign. The smallest serious test is edit-to-first-accepted-result with warmed incumbents and matched contacts, which can establish the value before anyone builds proof synthesis or universal RL.

## Phase 6.9 · Blind spots across all three slates

The overlap check included the appendices and Brenner alternatives. Three proposals below target gaps in the *scope of admissible evidence or control*, with a bounded artifact and a cheap falsifier for each. [COD slate](WIZARD_IDEAS_COD.md), [AGY slate](WIZARD_IDEAS_AGY.md), [CC slate](WIZARD_IDEAS_CC.md)

### 1. Reject an embodiment with an observation-alias witness

The slates optimize observability, transfer actions between bodies, and protect a state estimate. Add `frob-preflight::observation_conflict` to show that **every policy using the specified information interface fails a worst-case mission at a particular decision history**. On a small tray-cart fixture, build two admitted hidden-world prefixes yielding the same quantized observation/action transcript up to a deadline. Use `fs-ivl` and exact bounds to produce *necessary outer sets* of next actions compatible with eventual mission completion in each world. Have Lean check their disjointness and emit the two traces and separating inequality. A common policy input gives one shared action, and under an equal prior on such a deterministic pair even a randomized policy can succeed on at most half. Synthesize the cheapest extra sensor, changed sample time or allowed probe that separates the witnessed pair. The claim is conditional on the admitted history. A mission-wide impossibility claim additionally needs coverage of earlier probing actions.

**Breakpoint and gate.** With 64 equally trained layouts at 12 GPU-min and six survivors, 4 min of screening plus 72 min of training gives $768/76=10.1\times$. That needs 58 valid exclusions and a strong warm-start comparison. Use a blinded fixture with a certified common action and another with an in-time probe as negative controls. One false impossibility witness kills the rule. M5 checks certificates and the 4090s test survivors and search for counterexamples.

### 2. Check temporal contracts across event orderings

The slates test physical trajectories, scheduler throughput and firmware values. They leave the ordering of sensor capture, packet delivery, estimator reads, watchdog expiry and actuator commit largely implicit. Add `frob-runtime::schedule_check` with typed discrete events, clock/latency bounds and conservative read/write/effect footprints. Explore a representative of each partial-order class only when swaps preserve enabledness, timestamps, observations and monitor results. Use `asupersync` for the bounded replay harness and E026’s trace pattern for firmware parity. A late sample or zero-order hold at a contact boundary can then become a small timing counterexample with the exact offending order. This concerns control and perception events inside one trace. COD’s interaction calendar schedules independent physics work. [Dynamic partial-order reduction](https://doi.org/10.1145/1040305.1040315)

**Breakpoint and gate.** In an admitted equal-time fixture with six events and just three independent conflicting pairs, there are 720 permutations but only eight conflict orientations. That is a 90× reduction in replay count before commutativity checks. Compare real completed qualification time with a strong memoized schedule oracle, and exhaust the 720 cases to verify every class. Plant reordering-sensitive stale reads and a watchdog/commit race. A missed observable event kills the reduction. Dense conflicts should naturally approach exhaustive cost.

### 3. Spend statistical evidence as an explicit campaign resource

All three slates use held-out suites, e-racing or causal replay. None specifies who owns confirmation data after an agent has queried it, or which error budget is shared across adaptive restarts. Add `frob-ledger::qualification` with a discovery lane and a separate confirmation runner. An evaluation request binds candidate, baseline, mission, metrics and world population before receiving fresh independent **world clusters**. Commit releases and failures to a spend ledger. Retain only the authorized decision and aggregate receipt in the agent-facing view until the campaign closes. For request $i$, use a valid paired e-process under its declared null, fresh conditional data and $\alpha_i=\alpha/[i(i+1)]$. The total error spend is bounded by $\alpha$. Offline replay uses a different grant so a failed confirmation cannot silently become the next tuning suite. E003 supplies `fs-eproc`, and E009 supplies the ledger and task transport. [Adaptive data analysis](https://arxiv.org/abs/1411.2664)

**Breakpoint and gate.** Plant a no-signal world family and let agents adaptively select, retry and tune hundreds of candidates. Require calibrated campaign-level false promotions and preserved power on a planted real improvement. In an illustrative regime with 512 candidates at 50 costly cluster pairs, eight finalists at the same powered requirement plus 1,000 discovery pairs reduce the bill from 25,600 to 1,400, or 18.3×. This is conditional on screening recall and measured power at the spent α. If a tuned one-shot blinded finalist baseline matches valid claims per cluster, the 10× claim dies. The remaining value is a qualification receipt that survives adaptive agent work.
