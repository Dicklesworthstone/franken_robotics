## Background

Construction C-16 (hybrid gait orbits; core in bead SPEC-C-16) ends with a rule that reaches far beyond gaits:
**every derivative that leaves a kernel or an analysis carries exactly one validity label**, and a derivative
that does not exist is refused by name. This is doctrine rule D-15, which extends D-8 (every domain ships its
adjoint or its excuse). The reason: a contact-rich simulator can always return *some* matrix when asked for a
derivative, and an optimizer cannot tell a valid gradient from one taken across a mode change. A label makes the
derivative something an optimizer can trust because it says when it cannot be trusted. Tier: Frontier [F]
(with the rest of C-16). Crate: `frob-dyn` declares the label type; every producer of derivatives uses it
(`frob-gait`, the paired finite-difference gradients of the families crate, the step adjoints).

Terms. *Transversality number*: D_t g + D_x g·f⁻, the rate at which a trajectory crosses a guard g (D_x g its
gradient, D_t g its explicit time derivative, f⁻ the flow before the event). *Grazing*: the trajectory touches
the guard surface without crossing; the transversality number is zero. *Active set*: the set of constraints
(contacts, limits) currently active. *Frictional degeneracy*: a contact exactly on the boundary between stick
and slip. *Saltation matrix* Ξ: the first-order map of perturbations across one isolated transverse event
(SPEC-C-16).

Rejected alternatives: one Boolean "valid" flag (it cannot say *which* conditional derivative was returned); a
silent fallback to finite differences (the caller would not know the estimator changed); returning a matrix
near grazing with a warning (the counterexample below: a warning is ignored and the matrix is wrong).

## Technical approach

### 1. The nine labels (statement C-16.S10: every exported derivative carries exactly one; class `Tested`)

| Label | Meaning | Carries |
|---|---|---|
| `smooth` | No event in the interval; chart regular | Chart identity |
| `saltation` | Isolated transverse events composed by Ξ | Event identities, guard margins, transversality numbers |
| `discrete-step` | Derivative of the time-stepping map with the active set unchanged in each step | Count of active-set changes |
| `fixed-mode` | Mode sequence held fixed by fiat; a conditional derivative | The frozen sequence |
| `one-sided` | Directional derivative on one side of a guard | Side and direction |
| `generalized` | One selection of a piecewise-smooth map | Number of selections and which one |
| `smoothed` | Derivative of a declared smoothed surrogate | Smoothing parameter |
| `finite-difference` | Central difference with events re-located on both sides | Step size, events matched |
| `refused` | No derivative is returned | Offending state and perturbation directions |

How producers map onto the set (consistency requirement for the mechanism beads): a derivative with no event in
the stride is `smooth`; compliant-tier Jacobians with an unchanged active set are `discrete-step`;
event-located ones on the referee are `saltation`; an estimate on one side of a guard is `one-sided`; a
set-valued result that carries several selection Jacobians is `generalized`; a declared surrogate is `smoothed`;
central differences are `finite-difference`. No producer defines a label of its own.

### 2. Refusal (statement C-16.S11; class `Tested`): FROB-REF-263

A derivative query is refused with FROB-REF-263 in four cases:

1. **Grazing.** The transversality number, normalized by the guard's declared scale and the model's time scale,
   is below a threshold: ν = |D_t g + D_x g·f⁻|·t_scale/g_scale < ν_min. g_scale has the dimension of g and is
   declared with the guard; t_scale is the model's time scale (the canonical t₀ = √(ℓ₀/g) of the design); ν is
   dimensionless, so one threshold serves every guard.
2. **Ambiguous event order.** Two events not tied by a symmetry of the nominal state fall within the event-time
   resolution of each other.
3. **Active-set change.** The active set changes under the requested perturbation.
4. **Frictional degeneracy.** A contact sits on the stick–slip boundary.

Exception (statement C-16.S12): simultaneous events that are tied by a symmetry, as in a trot, are **not**
refused. The derivative is ordinary on the symmetric subspace and `generalized` off it.

The reply carries the offending state and the perturbation directions. Registry record (the code is listed in
the Lemma chapter's refusal table; the conditions are this construction's):

| Field | Value |
|---|---|
| Code | FROB-REF-263 |
| Meaning | A derivative is requested near grazing, at an ambiguous event order, across a change of active set or at frictional degeneracy |
| Payload | `cause` (one of the four), offending state, perturbation directions, ν and ν_min for cause 1, the two event keys and their time gap for cause 2 |
| Ranked repairs (DESIGN) | (1) ask for a `one-sided` derivative on a named side; (2) ask for `finite-difference` with events re-located on both sides; (3) ask for a `smoothed` surrogate with a declared parameter; (4) move the nominal state or the section away from the guard; (5) use derivative-free search for this orbit (the retirement rule of C-16) |
| Retry | `after-change` |
| Exit code | 3 (refused input or question) |

**The threshold ν_min.** OPEN in the source text: the normalization is fixed and the number is not. Fail-closed
default (DESIGN): ν_min = 1/16 until the pilot N10b-03 has run; the pilot then fixes the value so that all of
its 20 grazing and unstable controls are refused, and the value with its justification is written into the
contract. A change of ν_min is a recorded event with a new contract version.

### 3. Type sketch (DESIGN: fixes intent, not signatures)

```rust
pub enum DerivativeLabel {
    Smooth { chart: ChartId },
    Saltation { events: Vec<EventKey>, guard_margins: Vec<Qty>, transversality: Vec<f64> },
    DiscreteStep { active_set_changes: u32 },
    FixedMode { frozen: ModeSequence },
    OneSided { side: Side, direction: DirectionId },
    Generalized { selections: u32, which: u32 },
    Smoothed { parameter: Qty },
    FiniteDifference { step: Qty, events_matched: bool },
    Refused { cause: RefusalCause, state: StateRef, directions: Vec<DirectionId> },
}
pub struct Labeled<D> { pub value: Option<D>, pub label: DerivativeLabel }   // value is None iff Refused
```

`Labeled<D>` has no constructor that pairs `Refused` with a value or any other label with `None`. The type is
declared once, in `frob-dyn` (the lowest crate named for C-16); if a lower crate must name it the declaration
moves to the core crate by architecture decision, and the law tests bind by path alias so the move does not
touch them. Evidence class of a labeled derivative: `Tested`; determinism class that of the producing kernel.

### 4. Validation of `saltation` derivatives (statement C-16.S13; class `Tested`)

Every `saltation` derivative is validated by perturbing the initial state and re-locating events on both
sides (central difference with matched events). The pilot's TARGET is a gradient cosine of at least 0.95 in at
least 72 of 80 regular cases, with each of 20 grazing or unstable controls refused.

### 5. Law-suite layout (DESIGN)

`crates/frob-dyn/tests/laws_c16_labels.rs`, generic over
`C16LabelSubject { fn derivative(&self, q: &DerivQuery) -> Labeled<Mat> }`; reference model
`tests/support/c16_labels_ref.rs` (the bouncing ball with a ceiling, exact rationals; two balls for
simultaneity); mutants in `tests/support/c16_labels_mutants.rs` under the feature `controls`. Each test emits
one structured line through the STD-TEST helper.

## Test plan

### Unit tests

- `s10_exactly_one_label`: 500 seeded queries on the reference model; each result has exactly one label and
  `value.is_none()` exactly when the label is `Refused`.
- `s10_payload_complete`: one query per label; the payload fields of the table are present and non-empty (for
  `saltation`: one event key, one guard margin and one transversality number per event).
- `s11_grazing_refused` (KA-095): a ball thrown upward at 3 m/s from y = 0 under g = 981/100 m/s² with a ceiling
  at its apex height H = 9/(2·981/100) = 150/327 m; guard H − y; at the apex v = 0, so the transversality number
  is 0 and ν = 0 < ν_min. Expected: `Refused { cause: Grazing }`.
- `s11_near_grazing_threshold`: the same ball with the ceiling lowered so that ν is just above and just below
  ν_min (ν_min·(1 ± 1/8)); expected `saltation` above, `Refused` below.
- `s11_ambiguous_order`: two balls with different restitutions (r_L = 4/5, r_R = 3/5) hitting within the
  event-time resolution: `Refused { cause: AmbiguousOrder }` with both event keys.
- `s12_symmetric_tie_not_refused`: two identical balls (r = 4/5) hitting at the same instant: a derivative is
  returned; for a perturbation that keeps both states equal the label is `saltation`; for one that separates
  them it is `generalized` with `selections = 2`.
- `s11_active_set_change`: a perturbation large enough to add a bounce inside the horizon: `Refused`.
- `s13_saltation_validated`: for 80 seeded regular ball cases, the cosine between the `saltation` gradient of
  the final height and the re-located central difference is at least 0.95 (expected 1 − 10⁻⁶ on this fixture).
- `controls_are_caught`.

Further controls (mutants): a producer that labels everything `smooth`; one that refuses symmetric ties (the
trot would be unanalysable); one that returns `saltation` when the active set changed; one that normalizes ν
without the guard scale, so that a guard in millimetres and the same guard in metres disagree. Metamorphic
relation: rescaling the guard function by a positive constant, with its declared scale, changes no label.
Determinism: twice on one machine, debug and release, identical output lines (class D0 on the reference model).

## Considerations

- The label set is closed. A tenth label needs an architecture decision; producers never invent one.
- Composition beyond what the table states (which label a product of differently labeled factors carries) is
  not fixed by the construction. Fail-closed rule until the mechanism bead decides it: a composite never
  carries a label that claims more than its weakest factor, and a composite containing `refused` is `refused`.
- The gait verbs have their own refusal code for a derivative at grazing or at a fold (FROB-REF-431); it is the
  gait-level statement of causes 1 here and of the fold of statement C-16.S7. Both codes exit with 3.
- Gradients through the contact solve itself are deferred to a later milestone; until then fixed-mode
  derivatives on smooth kernels, return-map derivatives and paired finite differences are the admitted kinds,
  each with its label.
- Risk: a threshold set too low admits wrong derivatives; too high refuses useful ones. The pilot measures
  both sides (controls refused, regular cases admitted).
