## Background

The mission-observable projection quotient (specified by N10b-12, part of construction C-22) merges designs
whose compiled models are equal in everything the mission reads, and evaluates each class once. The claim
"equal projections give identical trajectories" is a statement about the simulator that no proof checker
decides; it is a structural rule and the only evidence for it is replay. Before campaign quotienting by digest
is funded, a paper-scale pilot must show, end to end on a fixture built to have many merges, that **no merged
pair replays differently in any bit**. One such pair falsifies the mechanism. This bead is that pilot.

Terms. *Ballast fixture*: eight identical slugs in 8 of 24 collinear slots on a rigid carrier mounted on a
robot; the placement enters rigid-body dynamics only through the count, Σx and Σx², so the 735,471 placements
fall into 24,546 classes. *Merged pair*: two different placements with equal (Σx, Σx²), hence equal digest.
*Replay*: running the same episode (same task, scene, policy, tier, world address) for each design and
comparing the chain of state digests. *World address*: (run seed, world, episode); random streams are keyed by
it.

## Scope

In: the frozen protocol; the falsifier evaluation; the ceiling; the record `PILOT-C-22`.

Out: the digest and `phylum.quotient` as product features (BD-285); the gate GATE-PHYLUM-01, which repeats a
test of this shape on 10⁴ sampled class pairs at M3; orbit deduplication, which is Solid and needs no pilot.

## Technical approach

**Protocol (frozen before execution).**

1. *Host robot and task.* DESIGN: a wheeled reference archetype carrying the ballast rail along its
   longitudinal axis, driving a fixed 10 s velocity profile with one turn and one braking event on flat ground,
   so that mass, first moment and second moment all matter. Slug mass 3/10 kg, slot pitch 1/40 m, rational
   parameters throughout.
2. *Pairs.* By a keyed draw before any run: 200 merged pairs (equal (Σx, Σx²), different placements), spread
   over small and large classes; 50 control pairs with equal Σx and different Σx² (the {1, 4} against {2, 3}
   pattern embedded in otherwise equal placements); 20 identical pairs (the same placement twice: an A/A arm).
3. *Runs.* Each design of each pair runs the episode on each tier available at the time (`batch-cpu` in `f64`
   and `f32`; the referee; a GPU tier if present), solo and inside a mixed batch with random co-tenants. Digest
   chains are recorded per step.
4. *Arms.* The mechanism (evaluate one member per class and reuse); the conventional alternative (memoize on
   full model identity only, which evaluates every placement); the fallback (orbit deduplication only).
5. *Measures.* For merged pairs: the first step at which digests differ, if any. For control pairs: whether the
   digests differ (they must). For A/A pairs: zero differences. Dispatches saved on the pair set.

**Falsifier.** One merged pair whose replays differ in any bit.

**Ceiling (stated before the run).** Fixture-dependent, and 1 in general. On this fixture the class count gives
a factor of 30.0 on dispatches (735,471/24,546); on a campaign corpus the factor is whatever the corpus has,
and the kill gate requires at least 5% of dispatches saved. Exact reuse after edits that change dynamics is at
most about a tenth of compute (FACT, source register, to be re-read).

**Fallback and kill gate.** Orbit deduplication only. Kill gate KILL-QUOTIENT (decided at M3): one false
quotient survives a repair cycle, or digest classes save less than 5% of dispatches on the campaign corpus;
then the digest is kept as a cache key with no claim.

**The six parts of a method experiment.** Ceiling (above); competing arms (above); potency control (a planted
digest that omits the second moment must merge the 50 control pairs, and their replays must then differ: the
pilot must report those as false quotients; the A/A arm must report none); paired comparison (pairs by design
pair, tier and world address; the reported quantity is a count of differing pairs, exact); pre-declared
fallback (above); reachability (a single differing merged pair falsifies; both verdicts are reachable).

**Record.** `PILOT-C-22` in `frob-conformance/registry/pilots.toml`: protocol hash, falsifier, ceiling,
fallback, kill gate, cost (CPU core-hours; about 540 design-episodes per tier), tools and pins, then the
result. Evidence class `Tested`, determinism class as measured per tier.

## Acceptance criteria

- [ ] The record's protocol, falsifier, ceiling and fallback are committed before its result.
- [ ] 200 merged pairs, 50 control pairs and 20 A/A pairs ran on every available tier, solo and in a mixed
      batch; the pair list and its draw key are in the record.
- [ ] Merged pairs with any differing digest: 0 (TARGET). Any other value records the verdict `fallback`, with
      the first differing step and state component.
- [ ] All 50 control pairs differ in digest; all 20 A/A pairs are identical.
- [ ] The planted digest without the second moment is reported as producing false quotients.
- [ ] Campaign quotienting by digest does not start before the record has a result (GATE-GAUNT-08).

## Test plan

### Unit tests

In the pilot's harness (`crates/frob-conformance/tests/pilot_c22.rs`):
- `pair_draw_is_keyed`: the same key gives the same 270 pairs; merged pairs have equal (Σx, Σx²) and different
  slot sets; control pairs have equal Σx and unequal Σx².
- `first_divergence_search`: on two synthetic digest chains (labelled `synthetic`) that differ from step 37 on,
  the search returns 37.
- `falsifier_evaluator`: zero differing merged pairs → `funded`; one → `fallback`.
- `lowered_tables_bit_equal`: for each merged pair the lowered pseudo-inertia is bit-equal before any run (a
  pair that fails here is a lowering defect, reported separately from a replay difference).

### End-to-end script and logging

`scripts/e2e/pilot_c22.sh` (idempotent; draw key printed; refuses to overwrite a record with a result): for
each design `frob --json sim run --tier <tier>` with the fixed task and world address, then
`frob --json sim replay` on each design and the harness's own first-divergence search over the two digest
chains (the verb `frob --json telemetry divergence` is used in addition where it exists); validates the record. Sources the
STD-E2E helper; writes `target/e2e-logs/pilot_c22/<utc>.ndjson` and a transcript; one `metric` line per (pair,
tier, co-tenancy) with both final digests and the first divergent step or `none`; `assert` lines for the three
pair kinds and the potency control; each line has `ts`, `script`, `bead` (`N10b-13`), `step`, `event`, the
exact command line, exit code, wall time and the envelope's evidence block (claim Known answer, class Tested,
tier, determinism class, design and episode identities, seed); on failure the first differing merged pair with
the step, the state component and the two values. Final `summary`: counts per pair kind, verdict, gate
GATE-GAUNT-08.

### Known answers and negative controls

Known answer: KA-127 (735,471 placements, 24,546 classes; merged members replay bit-identically; slots {1, 4}
and {2, 3} have Σx = 5 and Σx² = 17 and 13 and must not merge). Negative controls: the digest without the
second moment; a roll-up that sums rounded terms in placement order (it makes merged pairs lower to different
bits); a reduction tree shaped by batch capacity (it makes a design's digests depend on its co-tenants).
Determinism lanes: each design twice on one machine; solo against mixed batch; debug and release on the CPU
tiers; across tiers each against its own determinism class (bit equality is required within a tier, never
across tiers).

## Considerations

- A difference traced to batch composition or reduction order is a defect of the determinism lane, not of the
  quotient; the pilot separates the two by running solo first.
- The pilot does not show the quotient is useful, only that it is safe on a fixture rich in merges.
  Usefulness is the 5% clause of the kill gate, measured on the campaign corpus.
- If only one tier exists when the pilot runs, it runs there and the record lists the tiers still owed.
