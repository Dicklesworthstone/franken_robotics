## Background

Construction C-31 separates safety into three tiers; bead SPEC-C-31 holds the separation and tier 1. This bead
specifies tier 2: tube inclusion for small subsystems, realized as reachable-set tables. Tier Moonshot [M], at
M8, off the critical path. Owner: the Reflex subsystem, crate `frob-shield`. The bead extends `docs/math/C-31.md`
(part C) created by SPEC-C-31, which is why it depends on it.

The problem: some safety questions hinge on a guard whose side cannot be known in time: a wheel at a threshold, a
tray about to tip, braking across two floor materials, a door pinch zone. For such a subsystem, reduced to at most
four states, one can tabulate cells of measured state, each with one common safe action that works whichever
simultaneously enabled guard fires, under bounded sensing error and bounded disturbance. At run time the whole
belief set is looked up, and the answer is covered or uncovered. This is abstraction-based reachability.

What is assumed and not proved: that the four-state reduction represents the robot. It was considered as a theorem
card and rejected as an assumption about model order; it is a monitored assumption, watched by the tier-3
assumption monitors. Rejected shortcut, with its hand-checkable refutation below: eroding the target cell by the
error set E instead of by −E, which is correct only for a centrally symmetric error set.

Terms. *Mode* m: a discrete state of the subsystem (which surface, which contact state). *Cell* K_m: a set of
measured reduced states in mode m. *Guard* G_mn: the set where a transition from m to n may fire. *Reset* R_mn:
the state map of that transition, with disturbance d ∈ D. *Sensing-error set* E: true state = measured state + e,
e ∈ E. A ⊕ B is the Minkowski sum; A ⊖ B = {x : x + B ⊆ A} is the erosion. Proof classes: Proved, Certified
(re-checked by the offline auditor `frob-verify`), Tested, Estimated; status HYPOTHESIS.

## Technical approach

### 1. Statements

| Id | Statement | Class |
|---|---|---|
| C1 | Inclusion, cells of measured states: a cell K_m keeps a common safe action only if R_mn((K_m ⊕ E) ∩ G_mn, D) ⊆ K_n ⊖ (−E) for every guard G_mn that may be enabled. | Certified per table (proof kind `tube-inclusion`, re-checked for every cell and enabled guard); Tested on the fixtures here |
| C2 | The erosion is by −E, which equals E only for a centrally symmetric error set. | Tested (the one-sided example) |
| C3 | Variant, cells of true states where the whole belief set must stay in one cell: R_mn(K_m ∩ G_mn, D) ⊆ K_n ⊖ (E ⊕ (−E)). | Tested |
| C4 | The successor set accounts for inter-sample sweep (every state visited during a sample period, not only the endpoint), actuation latency (the action in force is the one decided a latency earlier) and chatter; every kept cell lies in the declared domain of the backup controller. | Tested on the fixture; a contract clause for the builder |
| C5 | Run-time answer: the whole belief set is looked up; if it is covered by cells that share the cell's safe action the answer is `covered`; otherwise `uncovered`, and the backup domain applies. | Tested |
| C6 | The reduction of a robot to at most four states is a monitored assumption; no bundle presents it as Proved or Certified. | Non-claim, recorded |

### 2. Construction of a table (carried so the mechanism matches the contract)

Size cap: at most 8 modes × 16,384 cells. Backward viability pruning:
1. Start with every cell of every mode marked kept, each with its candidate action set.
2. For each kept cell and each candidate action, compute the within-mode successor set (with sweep and latency)
   and, for every guard that may be enabled, the reset image R_mn((K_m ⊕ E) ∩ G_mn, D).
3. Remove an action if any successor set leaves the kept cells of its mode, or any reset image is not inside the
   erosion K_n ⊖ (−E) of kept cells of the target mode. Remove a cell with no action left.
4. Repeat steps 2 and 3 until nothing changes. The kept cells with one remaining common action each are the table.

The table is a payload of the shield record and has no file format of its own.

### 3. Hand-checkable erosion case

One dimension. A target cell [0, 1] of measured states. True state = measured + e with e in [0, 0.1]. A true
successor x is admissible when every measurement consistent with it, [x − 0.1, x], lies in the cell: x in
[0.1, 1.0], which is [0, 1] ⊖ (−E). Erosion by E gives [0, 0.9]: it admits 0.05, whose measurement can be −0.05,
and rejects 0.95, whose measurements lie in [0.85, 0.95].

### 4. Law-test layout, registry, implementers and gate

`crates/frob-shield/tests/laws_c31_tube.rs` with `tests/support/c31c_ref.rs`: interval boxes in exact rationals
with ⊕, ⊖ and reflection; the inclusion check; the pruning loop on a *synthetic* two-mode one-dimensional system
(mode 1 contracts x to x/2 per tick; guard [0.4, 0.6]; reset x + d with d in [−0.05, 0.05]; E = [0, 0.1]). Generic
over a trait `C31TubeSubject`; mutants in `tests/support/c31c_mutants.rs`. Registry: the erosion row with a
derivation file; the mutants as controls of GATE-SHIELD-05.

Implementer: `frob-shield` (BD-440). Pilot named by the plan: braking across two floor materials, two states and a
mode. Gate: GATE-SHIELD-05 at M8 (zero false admissions in 5,000 in-envelope episodes on the braking fixture;
`uncovered` outside the table). Kill gate KILL-TUBE (M8); fallback: reduced-order barriers of tier 3.

## Test plan

### Unit tests

- `erosion_one_sided`: with K = [0, 1] and E = [0, 0.1], K ⊖ (−E) = [0.1, 1.0] and K ⊖ E = [0, 0.9]; the point
  0.05 is rejected and 0.95 admitted by the correct erosion.
- `erosion_symmetric_sets_agree`: for E = [−0.05, 0.05] the two erosions are equal.
- `erosion_adjoint_property`: 10⁴ seeded boxes in up to four dimensions: x ∈ A ⊖ B exactly when {x} ⊕ B ⊆ A.
- `inclusion_holds_and_fails`: source cell [0.4, 0.5]: (K ⊕ E) ∩ G = [0.4, 0.6], reset image [0.35, 0.65]. Target
  cell [0.2, 0.9] erodes to [0.3, 0.9]: included. Target cell [0.3, 0.9] erodes to [0.4, 0.9]: 0.35 is outside, so
  the action is removed.
- `true_state_variant`: with cells of true states the target [0.3, 0.9] erodes by E ⊕ (−E) = [−0.1, 0.1] to
  [0.4, 0.8].
- `pruning_reaches_fixpoint`: on the synthetic system the loop ends, the result is the same from two different
  cell orders, and every kept cell passes the inclusion against the kept set.
- `sweep_matters`: a tick whose endpoint is inside a kept cell and whose path leaves it is rejected.
- `belief_lookup`: a belief set straddling a kept and a removed cell answers `uncovered`.
- `size_cap`: 9 modes or 16,385 cells are refused.

  the regression suite for the erosion rule.
