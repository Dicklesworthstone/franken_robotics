## Background

Construction C-32 has two halves. Bead SPEC-C-32 specifies the dual witnesses and the stance family. This bead
specifies the other half: the region certificate, an outward-rounded enclosure that decides one constraint on a
box of design parameters, and the rule by which per-constraint certificates are assembled into a family answer
without paving the joint design box. Tier Frontier [F]. Owner: the Augur subsystem, crates `frob-mission` and
`frob-cert`. It extends `docs/math/C-32.md` (part C).

Why it is built this way. A region certificate is a statement about every as-built unit inside a box: it gives
evidence quality and robustness to tolerances. It is not a speed lever, and deciding volume is not the same as
saving simulations: pointwise static checks give the same pruning for the designs an agent actually proposes. The
decisive arithmetic is the limit on paving: 10⁴ boxes are 13 bisections, which in 20 dimensions is less than one
cut per axis, so a uniform box keeps about 0.64 of each side (0.41 in 10 dimensions), and a constraint surface
that depends on most parameters crosses nearly every box. FACT (source register, to be re-read): interval design
of parallel robots is described by its practitioners as exponential branch and bound suited to small and medium
problems, with a worked example of five design parameters; a three-dimensional workspace paving took about five
hours and left an error bound of up to a third of the certified volume; Taylor models move the barrier very
little. Hence certificates are issued per constraint, on the parameters that constraint reads, bisected along at
most about six of them.

Forms that were killed and are not built: sampling only inside a certified inner ellipsoid (it cuts off the
feasibility boundary, where optima sit, and misses disconnected islands); a logarithmic change of variables to
linearize posynomial constraints (the logarithm of a posynomial is a convex log-sum-exp, neither linear nor
polynomial); cylindrical algebraic decomposition for reachable sets (doubly exponential beyond four or five
variables).

Terms. *Box* B: a product of closed intervals of design parameters. *Enclosure* [c](B): an interval guaranteed to
contain every value c(θ) for θ in B, with endpoints rounded outward. *Split set*: the parameters of one constraint
along which bisection is allowed. *Cylinder* over a set in the coordinates S_k: all designs whose S_k-coordinates
lie in the set. Proof classes: Proved, Certified (re-checked by the offline auditor in integer-based interval
arithmetic), Tested, Estimated; status HYPOTHESIS.

## Technical approach

### 1. Statements

| Id | Statement | Class |
|---|---|---|
| R1 | A region certificate for one constraint c(θ) ≤ 0 on a box B is an outward-rounded enclosure [c](B) = [lo, hi]. If hi ≤ 0 the box is feasible for that constraint; if lo > 0 the box is infeasible; otherwise it is undecided and is bisected. | Certified per box (proof kinds `interval-box`, `taylor-box`) |
| R2 | Enclosures come from interval, affine or Taylor-model arithmetic. Where c is monotone in a parameter, evaluation at the corners in that parameter is exact. | Tested (soundness against exact rational evaluation) |
| R3 | Certificates are issued per constraint, with bisection confined to a split set of about six parameters; the remaining parameters of the constraint are enclosed at full range. | Rule; the cap is the fail-closed default of an open question |
| R4 | A family answer is assembled from per-constraint certificates by products, monotonicity and witnesses, not by paving the joint box: a design is in the inner set when it lies in every cylinder over the per-constraint inner sets I_k, and outside the outer set when it lies outside some cylinder over O_k. The joint set is represented implicitly by k membership tests and is never enumerated; its volume, when wanted, is an Estimated quantity from sampling. | Tested |
| R5 | Monotone bounds first: a bound that is monotone in one parameter removes its half space with one `monotone-transport` certificate and no bisection. | Tested |
| R6 | Where a static condition is a linear or second-order-cone feasibility problem, the exclusion is a dual witness (bead SPEC-C-32); a parametric dual with a sign proof covers a whole cell, which is why linear static families need no paving. | Cross-reference to part A |
| R7 | Paving arithmetic: after k bisections in n dimensions a uniform box keeps 2^(−k/n) of each side. 10⁴ boxes are 13 bisections (2¹³ = 8,192): 2^(−13/20) = 0.637 in 20 dimensions and 2^(−13/10) = 0.406 in 10. | Arithmetic, Tested |
| R8 | Scope: a region certificate covers the static rigid model named in its bundle. It certifies neither run-up nor landing nor recovery, nor any dynamic performance. | Non-claim, recorded |

### 2. The procedure (numbered, for the contract)

1. List, for each lowered constraint g_k, the parameters S_k it reads (the constraint-to-parameter graph).
2. Apply every monotone bound first (R5).
3. For each g_k, choose a split set of at most six parameters of S_k; enclose the others at full range.
4. Bisect the split set; classify each box by R1; attach an `interval-box` or `taylor-box` certificate to each
   decided box; stop at the box budget.
5. Combine by cylinders (R4). Report undecided volume per constraint; never report a joint volume as certified.

### 3. Conventions, failure cases and non-claims

- An undecided box is `unresolved`, never feasible. An infeasible sample point does not eliminate its box.
- A request to bisect more than six parameters of one constraint, or to pave a joint box, is refused; that is the
  fail-closed default of OPEN-AUGUR-3 (the measured sparsity of the constraint-to-parameter graph, owner the
  Augur lead).
- The printed figure "0.64 of each side" is 0.637 for 13 bisections and 0.631 for exactly 10⁴ boxes; the row
  carries the printed figure and the derivation file states both.
- Foundations (FACT, FrankenSim `483d09c682f2`, observed 2026-11-21): `fs-ivl` has outward-rounded intervals,
  affine forms, multivariate Taylor models with subdivision, and interval Newton and Krawczyk operators; it has no
  paving driver and no contractors, so the driver is this project's.

### 4. Law-test layout, registry, pilot and gate

`crates/frob-mission/tests/laws_c32_region.rs` with `tests/support/c32c_ref.rs`: interval and affine arithmetic
over exact rationals with outward rounding to binary endpoints, exact range evaluation for small polynomials, a
bisection driver and the cylinder combination. Generic over a trait `C32RegionSubject`; mutants in
`tests/support/c32c_mutants.rs`. Registry: two appended known-answer rows (three-way verdict; paving arithmetic)
with derivation files; the control seeded from CX-080.

Pilot (BD-289): a 12-parameter quadruped box (three link lengths, two hip offsets, three masses, gear ratio, motor
mass, body length and width) with static joint torque in three stance postures, reach to a foothold set and
self-clearance, paved with 10⁴ boxes in four arms: plain intervals, affine forms, contractors, per-constraint
decomposition. Kill (TARGET): the best arm leaves more than 90% of the volume undecided, or more than 95% of the
decided volume falls to a single monotone bound. Ceiling: evidence quality and robustness to tolerances; no speed
is claimed. Fallback: pointwise checks at proposed designs. Cost: about two engineer-days and CPU minutes (TARGET).
Gate GATE-AUGUR-09 (pilot at M3, gate at M4): the per-constraint arm decides at least 50% of each constraint's
sub-box volume within 10⁴ boxes; no single monotone bound gives more than 95% of decided volume; zero certified
boxes contradicted by 10⁶ point evaluations. Kill gate KILL-AUGUR-REGION (M3): on firing, region certificates are
removed and family answers use dual witnesses, monotone bounds and pointwise static analyses, with untested
regions reported as sample coverage, Estimated.

## Test plan

### Unit tests

- `three_way_verdict`: c(θ) = θ₁ + θ₂ − 1. On [0, 0.4]² the enclosure is [−1, −0.2]: feasible. On [0.6, 1]² it is
  [0.2, 1]: infeasible. On [0.4, 0.6]² it is [−0.2, 0.2]: undecided, bisected.
- `enclosure_soundness_property`: 10⁴ seeded polynomial constraints of degree at most 3 in at most 4 variables
  with rational coefficients over random boxes: the enclosure contains the exact values at every corner and at
  10² rational sample points, and its binary endpoints bracket the rational endpoints.
- `monotone_corner_exact`: c = θ₁·θ₂ − 1/2 on [1/2, 1]² has exact range [−1/4, 1/2] from two corners.
- `affine_beats_interval_on_dependency`: c = θ − θ on [0, 1] is [−1, 1] in plain intervals and exactly 0 in
  affine forms.
- `no_decided_box_contradicted`: c = θ₁² + θ₂² − 1 on [0, 2]², bisected to 4,096 boxes: no feasible box contains a
  sampled point with c > 0 and no infeasible box a point with c ≤ 0, over 10⁴ points.
- `rounding_never_decides_a_tie`: c = θ − 1/3 on [1/3 − 2⁻⁶⁰, 1/3] is undecided.
- `cylinder_combination`: constraints on S₁ = {θ₁} and S₂ = {θ₂} with I₁ = [0, 3/10], I₂ = [1/2, 1]: the design
  (1/5, 7/10, x) is inner for every x; (2/5, 7/10, x) is not inner; no joint cell list is built.
- `monotone_first`: a mass bound monotone in one parameter is decided with one certificate and zero bisections.
- `split_set_cap`: a seven-parameter split set is refused.
- `paving_arithmetic`: 2¹³ ≤ 10⁴ < 2¹⁴; 2^(−13/20) rounds to 0.637 and 2^(−13/10) to 0.406; (10⁴)^(−1/20) rounds
  to 0.631.
- `sampled_volume_is_estimated`: a volume report carries class Estimated.

### End-to-end script and logging

`scripts/e2e/spec_c32_region.sh`: `frob --json doctor`; `cargo test -p frob-mission --test laws_c32_region`; the
two appended conformance rows by registry id; file and registry checks. Log to
`target/e2e-logs/spec_c32_region/<utc>.ndjson` with a transcript; each line has `ts`, `script`, `bead`, `step`,
`event`, command line, exit code, wall time, the evidence block (claim Known answer, class Tested, tier G1 host,
determinism D0, seed), interval endpoints as rationals against expected, decided-volume fractions, and on failure
the first box with its bounds. The `summary` line counts assertions and names GATE-AUGUR-09.

Other mutants: `inward_rounding`; `corner_evaluation_without_monotonicity` (uses corners for a non-monotone
constraint such as θ·(1 − θ) on [0, 1], whose corner values are both 0 while the range reaches 1/4);
`sample_point_excludes_box`. Counterexample carried: CX-080 (a region certificate cannot be had by paving the whole
design box). Determinism: exact arithmetic, twice on one machine; binary endpoints identical across platforms.

## Considerations

- The kill gate may remove the mechanism at M3; this contract then documents a removed mechanism and the law
  tests remain for the enclosure arithmetic used elsewhere (clearance enclosures, interval checks of tolerances).
- Performance envelope: none is claimed; the pilot costs CPU minutes.
- Closure constraints of linkage legs raise the coupled dimension above the sparse three to six parameters per leg
  (HYPOTHESIS until OPEN-AUGUR-3 is measured).
- Interaction: the enclosure arithmetic must agree with the auditor's integer-based intervals on a shared corpus;
  the auditor does not link the sibling library.
