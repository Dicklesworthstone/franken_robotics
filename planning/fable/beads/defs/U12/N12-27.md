## Background

A reflected instance is proved by the Lean kernel evaluating a closed term `check x` to `true`. The kernel is not
an optimized evaluator: it reduces terms, and rational arithmetic in a kernel means reducing integer operations
and normalizations on literals step by step. Every cost of kernel evaluation on large rationals is a HYPOTHESIS
until it has been measured. OPEN-LEMMA-3 is the question: what does kernel evaluation cost on exact rationals at
specimen size? Fail-closed default: reflection is limited to specimens that fit the budget. It blocks
GATE-LEMMA-05, whose threshold is that each reflector proves its specimen by kernel evaluation within 60 s
(TARGET).

The pilot (BD-382) answers the question at exactly two points: the Farkas reflector on the stance exclusion (a
7×8 system with small rationals) and the rational LDLᵀ reflector on one 4×4 pseudo-inertia with 64-bit
numerators. Two points do not make a budget. The verb `prove.reflect` needs to know, for an arbitrary instance,
whether to accept the job or refuse it and leave the certificate `Certified`. This bead measures the cost surface
around the specimens and turns it into a table the verb consults. It runs after the pilot's reflectors exist and
before reflection is offered beyond the specimens.

## Scope

In: a sweep of kernel-evaluation time and memory over instance size for the two reflectors, under stock Lean's
kernel and under `fln`; the fitted budget table; its registration; the answer to OPEN-LEMMA-3.
Out: the reflectors and their proofs (BD-382); admission logic in the verb (N12-28 uses the table); the kill
decision (N12-32).

## Technical approach

1. Instances (synthetic, generated deterministically from a seed, all with a known true answer so that every
   evaluation should return `true`):
   - Farkas: systems with (m, n) ∈ {(3, 4), (7, 8), (12, 16), (20, 32), (40, 64)} and numerator and denominator
     bit sizes b ∈ {8, 16, 32, 64, 128}; each is an infeasible system built from a planted dual vector.
   - LDLᵀ: symmetric positive-definite matrices of dimension n ∈ {2, 4, 6, 8, 12, 16} with entry numerators of
     b ∈ {16, 32, 64, 128, 256} bits, built as LᵀDL from planted rational factors (4×4 is a pseudo-inertia; 6×6
     and above stand for composite inertias and Gram matrices).
2. For each instance: generate the instance file with the literals and `example : check x = true := by decide`;
   measure wall time and peak memory of (a) stock Lean's kernel checking the file and (b) `fln` re-checking the
   compiled declaration; three repetitions; a hard stop at 600 s recorded as `timeout`.
3. Record intermediate growth: exact LDLᵀ over ℚ grows entry sizes with elimination depth (the pivots are ratios
   of leading minors), so the measured time is reported against both input bits and the bit size of the largest
   intermediate, computed by an independent exact run outside Lean.
4. Budget table (DESIGN): for each reflector, the largest (size, bits) cells whose worst repetition under `fln`
   is within the evaluation budget (default 60 s, the gate's figure) with a safety factor of 2; the table is
   written to `registries/reflection-budget.toml` with the host fingerprint and the pins, and is valid only for
   that pin (a Lean or `fln` upgrade requires a re-run).
5. Answer to OPEN-LEMMA-3: the measured cost at specimen size (both specimens), the scaling exponents observed in
   size and in bits, and the table. If even the specimens exceed 60 s under `fln`, the answer feeds KILL-REFLECT
   directly.
6. Diagnostics worth recording because they change the design: whether representing rationals as normalized
   pairs or as unnormalized pairs with one final comparison is cheaper in the kernel; whether binary natural
   literals are reduced by the kernel's accelerated arithmetic in both checkers (stock Lean has built-in
   acceleration for natural-number literals; whether `fln` implements the same reduction is observed, not
   assumed).

## Acceptance criteria

- [ ] The sweep ran on the Linux host for both reflectors over the grids above, three repetitions per cell,
      under stock Lean and under `fln`, with timeouts recorded as such.
- [ ] The two pilot specimens' evaluation times are restated from this harness and agree with BD-382's record
      within the repetition spread.
- [ ] `registries/reflection-budget.toml` exists, schema-valid, with pins and host fingerprint.
- [ ] OPEN-LEMMA-3 is closed in the open-question register with the measured figures and the scaling summary.
- [ ] Negative control: an instance built to be false (a perturbed dual vector; a matrix with a negative pivot)
      evaluates to `false` and its `example` fails to check, at every grid size tried; a planted cell that sleeps
      past the limit is recorded `timeout`, not as a pass.

## Test plan

### Unit tests

`tools/pilots/reflect_cost/tests/`: `instances_are_true_by_construction` (the planted dual satisfies the Farkas
conditions in an independent exact evaluator; the planted factors give positive pivots);
`false_instances_are_false`; `intermediate_bits_reported`; `table_cells_within_budget_with_factor_2`;
`table_invalid_on_pin_change` (changing the recorded `fln` build marks the table stale).

### End-to-end script and logging

`scripts/e2e/lemma_reflect.sh` (bead N12-38) reads the table and logs, for both specimens, the measured time
against 60 s and the table cell they fall in; the sweep itself is `scripts/e2e/pilot_reflect_cost.sh`, logging
one `metric` line per cell (size, bits, checker, time, memory, timeout flag) and a `summary` with the largest
admissible cells.

### Known answers and negative controls

KA-227 (each specimen's `check x` evaluates to `true` within 60 s, TARGET). Negative controls: the false
instances and the planted timeout. Determinism: instance generation is seed-explicit; timings are per host and
reported with their spread.

## Considerations

- The ceiling of reflection is small by design: it relabels a few instance certificates from `Certified` to
  `Proved`. A budget table that admits only small instances is an acceptable outcome.
- Memory can be the binding limit before time (large intermediate literals); both are recorded.
- The table must never be used to claim performance; it is an admission rule.
