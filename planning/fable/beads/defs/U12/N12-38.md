## Background

GATE-LEMMA-05 (M5, claim Proof): the Farkas and rational LDLᵀ reflectors have soundness theorems compiled by
stock Lean and re-checked by `fln`, and each proves its specimen by kernel evaluation within 60 s. A reflector is
a checker function defined in Lean with a soundness theorem; an instance is proved by the kernel evaluating the
function on literals, with no tactic at checking time and no compiled evaluator. The verb is `prove.reflect`
(kind `run`, first milestone M5: promote an instance certificate through a reflected checker). The two specimens:
the Farkas reflector on the stance exclusion at half-width 1/5 m, and the LDLᵀ reflector on one 4×4
pseudo-inertia with 64-bit numerators.

This bead is the end-to-end script for that capability: it runs the verb as a user would, waits on the job,
checks both capsules from an empty environment, times the kernel evaluation, exercises the negative controls and
records the gate, whose result the kill-gate decision KILL-REFLECT (N12-32) reads.

## Scope

In: `scripts/e2e/lemma_reflect.sh` (phase 1: the two pilot reflectors; phase 2, enabled when N12-28 lands: the
other two and the admission cases); the gate record. Out: the reflectors and the verb (BD-382, N12-28); the cost
sweep (N12-27); the decision (N12-32).

## Technical approach

Steps, phase 1 (plain shell on the Linux host, sources the STD-E2E helper, idempotent, explicit idempotency
keys):
1. `start`: commit, host fingerprint, Lean version, Mathlib commit, `fln` build.
2. Soundness theorems: build `farkas_sound` and `ldltPos_sound` with stock Lean; `fln check-olean`; seal; verify
   each capsule from an empty container; log closure module counts and the blocked intersection (threshold 0),
   wall time and peak memory of the re-check; assert no `sorry`, no axiom outside the whitelist, no
   `native_decide`, and that each theorem is bound to its registered statement.
3. Obtain the two instance certificates through the product: the stance exclusion bundle (kind `lp-farkas`) from
   the mission slice fixture and a `rational-ldlt` bundle for the pseudo-inertia fixture; assert `frob-verify`
   accepts both.
4. `frob prove reflect --certificate <hash> --reflector farkas --json --idempotency-key …` and the same with
   `ldlt-pos`: the verb returns a job handle with exit code 8 while running; `frob job wait` until done; assert
   the result has class `Proved`, both capsule hashes (soundness and instance), both checker identities, and the
   three flags false.
5. Timing: assert the recorded kernel evaluation time of each specimen is at most 60 s (TARGET) under `fln`, and
   log the time under stock Lean beside it.
6. Verify the instance capsules from an empty container; assert the instance file's literals equal the bundle's
   rationals (the standard-form system for the stance exclusion: Σ f = 400; f₁ + f₂ − f₃ − f₄ = 180;
   f₁ − f₂ + f₃ − f₄ = 150; fᵢ + sᵢ = 160; witness y = (0, −½, −½, 1, 0, 0, 0) with rᵀy = −5).
7. Negative controls: a perturbed Farkas witness (y = (0, −½, −⅓, 1, 0, 0, 0), rᵀy = 20) is refused before or
   during the job with no `Proved` evidence produced; a matrix with a non-positive pivot likewise; a certificate
   the auditor rejects is refused by the verb; repeating step 4 with the same idempotency key returns the same
   job and result; cancelling a running job (request, drain, finalize) leaves no process and no partial capsule.
8. Trigger read-out for KILL-REFLECT: print both halves of the trigger from the measurements.
9. `summary`: reflectors sealed (2), specimens proved within 60 s (2), negative controls refused, gates touched;
   write the gate record.

Phase 2 adds: `poly-eq` and `replay` specimens; an over-budget instance refused before any job starts with the
table cell it missed; a timeout reported as `unknown`.

Logging: newline-delimited JSON under `target/e2e-logs/lemma_reflect/<utc-timestamp>.ndjson` with a transcript;
each line has `ts`, `script`, `bead` (`N12-38`), `step`, `event`, the command line, exit code, wall time, the
`evidence` block of each verb response, measured values with their thresholds (60 s), digests and capsule
hashes, and on failure the first differing value and artifact paths.

## Acceptance criteria

- [ ] The script exits 0 on the Linux host when all assertions hold and non-zero otherwise; without the Lean
      toolchain it reports the gate `not run`.
- [ ] GATE-LEMMA-05 (TARGET, M5): both reflectors' soundness theorems compiled by stock Lean and re-checked by
      `fln`; each specimen proved by kernel evaluation within 60 s. Recorded with times, closures and memory.
- [ ] The negative controls produce no `Proved` evidence; idempotency and cancellation behave as stated.
- [ ] Under the parked configuration (KILL-REFLECT fired) the script asserts that `frob prove reflect` is refused
      and that the theorem-card listing shows the reflection card as `parked`.
- [ ] The log validates against the shared schema and ends with a `summary` naming GATE-LEMMA-05 and
      KILL-REFLECT.

## Test plan

### Unit tests

Script self-tests under `scripts/e2e/tests/`: `reflect_selftest_slow_specimen.sh` (a fixture reflector that
sleeps past 60 s makes the timing assertion fail and logs the measured time); `reflect_selftest_compiled_evaluator.sh`
(an instance file that uses `native_decide` is refused at sealing and the script fails at step 6).

### End-to-end script and logging

This bead is the script; steps and logging as above.

### Known answers and negative controls

KA-227 (each `check x` evaluates to `true` in the kernel, with no tactic at checking time and no compiled
evaluator; within 60 s per specimen, TARGET; a closure that cannot avoid a blocked module, or a specimen not
evaluated within 60 s, falsifies the pilot), KA-208. The perturbed witness, the non-positive pivot and the two
self-tests are the negative controls. Determinism: capsule hashes identical across two runs on the pins; timings
logged with three repetitions.

## Considerations

- Timing depends on the host; the gate's record names the host fingerprint, and the threshold is a TARGET until a
  measurement is on file.
- The script must not use a compiled evaluator anywhere in the instance path; `#eval` is allowed only in the
  development-time differential test, which is not part of this script.
- Reflection is never on the critical path; a `not run` here blocks nothing except the reflection work itself.
