## Background

Several theorem cards have two routes: an instance route that is Solid (a certificate about this kernel or this
grid of cases, class `Certified`) and a general route that is Frontier (the statement for all inputs, proved in
Lean, class `Proved`). The instance halves are delivered early by the card beads. The general halves need the
Lean lane (the project under `lean/`, the capsule pipeline, the binding of statements) and would otherwise belong
to no bead. Two of them are sealed as the first capsules (T-15 the gear law, T-26 the level series, with T-12
Kleene iteration, in BD-381), and one is the soundness theorem of the first reflector (T-21 Farkas, in BD-382).
This bead carries the rest:

- T-01 general: for skew-symmetric Ω, cay(Ω)ᵀ·cay(Ω) = I and det cay(Ω) = 1, with cay(x) = (I − x/2)⁻¹·(I + x/2).
- T-03 general: the quaternion update preserves the norm, ‖q·c‖² = ‖q‖²·‖c‖², through `Mathlib.Algebra.Quaternion`
  (an accepted module).
- T-23 general: the docking family: for U ∈ [½, 1] a robust causal policy exists if and only if the packet is on
  time and ε < (U + ½)/4 (linear arithmetic over ℚ).
- T-24 general, conditionally: the orbit-counting lemma is cited from Mathlib only if its closure re-checks
  (OPEN-LEMMA-6, experiment N12-25); otherwise the count stays `Tested` or instance-certified and nothing is
  proved here.

Tier: Frontier. Lean is a second opinion: stock Lean compiles, FrankenLean re-checks, and only closures that avoid
the blocked modules can be sealed. Ceiling: these capsules raise four cards from `Certified` to `Proved`; no
design decision depends on it.

## Scope

In: the registered `Statement` definitions and the proofs for T-01, T-03, T-23; for T-24 the bridge lemma and
the citation if admitted; sealing through the pipeline; registry updates.
Out: the pipeline (BD-381); binding (N12-24); the instance certificates (the card beads); analytic statements
about exp and log (not attempted; the modules are blocked).

## Technical approach

```lean
-- DESIGN: statements fix intent, not signatures. No `sorry`, no added axiom, no `native_decide`.

/-- T-01, general. Stated over a commutative ring in which 2 is invertible, with invertibility of I − Ω/2 as a
    hypothesis so that the closure stays inside algebra. -/
theorem cayley_orthogonal {n : ℕ} {R : Type} [CommRing R] [Invertible (2 : R)]
    (Ω : Matrix (Fin n) (Fin n) R) (hΩ : Ωᵀ = -Ω) (hU : IsUnit (1 - (⅟2 : R) • Ω)) :
    let C := (1 - (⅟2 : R) • Ω)⁻¹ * (1 + (⅟2 : R) • Ω)
    Cᵀ * C = 1 ∧ C.det = 1 := …

/-- Companion: over a linearly ordered field, I − Ω/2 is invertible for every skew-symmetric Ω,
    because xᵀ·(I − Ω/2)·x = xᵀ·x. -/
theorem skew_shift_isUnit {n : ℕ} {K : Type} [LinearOrderedField K]
    (Ω : Matrix (Fin n) (Fin n) K) (hΩ : Ωᵀ = -Ω) : IsUnit (1 - (2 : K)⁻¹ • Ω) := …

/-- T-03, general. -/
theorem quaternion_normSq_mul {R : Type} [CommRing R] (q c : Quaternion R) :
    Quaternion.normSq (q * c) = Quaternion.normSq q * Quaternion.normSq c := …

/-- T-23, general, packet on time. Unit mass, three unit ticks, acceleration g·u with g ∈ {1, 2} hidden,
    first command p, reading r = g·p + e with |e| ≤ ε, later commands chosen from the reading. -/
theorem docking_on_time (U ε : ℚ) (hU : 1/2 ≤ U ∧ U ≤ 1) (hε : 0 ≤ ε) :
    (∃ p : ℚ, ∃ π : ℚ → ℚ × ℚ, |p| ≤ U ∧ ∀ g ∈ ({1, 2} : Finset ℚ), ∀ e : ℚ, |e| ≤ ε →
        let u := π (g * p + e)
        |u.1| ≤ U ∧ |u.2| ≤ U ∧ g * (p + u.1 + u.2) = 0 ∧ g * (5/2 * p + 3/2 * u.1 + 1/2 * u.2) = 1)
      ↔ ε < (U + 1/2) / 4 := …

/-- T-23, general, packet late: the later commands cannot depend on the reading. -/
theorem docking_late (U : ℚ) :
    ¬ ∃ p u₁ u₂ : ℚ, ∀ g ∈ ({1, 2} : Finset ℚ),
        g * (p + u₁ + u₂) = 0 ∧ g * (5/2 * p + 3/2 * u₁ + 1/2 * u₂) = 1 := …
```

1. T-01 proof route: I + Ω/2 and I − Ω/2 commute; transposition exchanges them (Ω is skew); hence
   Cᵀ·C = (I − Ω/2)·(I + Ω/2)⁻¹·(I − Ω/2)⁻¹·(I + Ω/2) = I after commuting; and det(I + Ω/2) = det((I + Ω/2)ᵀ) =
   det(I − Ω/2), so det C = 1. The SO(3) closed form R = I + 4/(4 + ‖ω‖²)·(ω̂ + ω̂²/2) is the instance the
   certificate covers; the general theorem covers every dimension.
2. T-03 proof route: the norm-squared map of a quaternion algebra over a commutative ring is multiplicative; in
   Mathlib it is packaged as a monoid-with-zero homomorphism, so the statement is its `map_mul`. The closure must
   stay in `Mathlib.Algebra.Quaternion` and avoid `Analysis.Quaternion`.
3. T-23 terminal conditions, derived by hand and encoded above: with velocities v₁ = g·p, v₂ = v₁ + g·u₁,
   v₃ = v₂ + g·u₂ and unit ticks, the final velocity is g·(p + u₁ + u₂) and the final position is
   g·(5/2·p + 3/2·u₁ + 1/2·u₂); they force u₁ = 1/g − 2p and u₂ = p − 1/g. Bounds for both gains hold exactly when
   1 − U ≤ p ≤ (U + ½)/2; the readings of the two gains are centred at p and 2p and must be disjoint, which gives
   ε < p/2 and hence ε < (U + ½)/4, equality excluded. The proof is case analysis and linear arithmetic over ℚ.
4. T-24, only if N12-25 answered `yes`: cite the Mathlib orbit-counting lemma; prove the bridge "the number of
   assignments of k types to the slots fixed by a permutation g is k^c(g)"; conclude the formula
   |Γ|⁻¹·Σ_g k^c(g) for the number of orbits. If the answer was `no`, this part is closed as not built and the
   registry route is `parked` with the blocking module.
5. Each theorem proves its registered `Statement` constant (binding rule), goes through the capsule pipeline, and
   updates its card's registry row with the capsule hash and both checker identities.

      with ≤ in place of < fails to compile (at U = ¾, ε = 5/16 both gains can report 15/16 while needing −¼ and

      check.
- [ ] The instance certificates remain valid and unchanged; the two routes are listed side by side.

## Considerations

- OPEN-LEMMA-1: the closure of each theorem is measured before it is counted (N12-23); the matrix theorems pull
  in the linear-algebra hierarchy, which is the largest closure in this bead.
- The hypothesis `IsUnit (1 − Ω/2)` is deliberate: over an arbitrary ring it can fail; over an ordered field the
  companion lemma discharges it.
- Upstream item FD-FLN-01 would later allow statements through the matrix exponential; none is attempted here.
