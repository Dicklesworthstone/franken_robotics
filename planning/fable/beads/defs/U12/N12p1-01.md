## Background

In the continuation lane of linkage synthesis (C-34 lane 2, a Moonshot mechanism) mechanism families whose
synthesis or kinematics systems exceed the exact caps (four- and six-bar path synthesis, Stewart–Gough forward
kinematics, 6R inverse kinematics, parallel ankles) are solved by a parameter homotopy
H(z, t) = F(z; (1 − t)·p₀ + t·p₁) tracked in double precision on the CPU. Each claimed root is then certified
outside any proof kernel by Smale's α-test. For a square polynomial system f: ℂⁿ → ℂⁿ and a point z define

- β(f, z) = ‖Df(z)⁻¹·f(z)‖, the length of the Newton step from z;
- γ(f, z) = sup_{k ≥ 2} ‖Df(z)⁻¹·Dᵏf(z)/k!‖^(1/(k−1)), with Dᵏf the k-th derivative as a k-linear map and the
  operator norm;
- α(f, z) = β(f, z)·γ(f, z).

Smale's theorem: if α(f, z) < α₀ = (13 − 3√17)/4 ≈ 0.157671 (KA-167), Newton's iteration from z converges
quadratically to a root ζ of f with ‖z − ζ‖ ≤ 2·β(f, z). Distinctness of several certified roots follows from
disjoint balls B(zᵢ, 2βᵢ); non-reality of a root of a real system follows from disjointness of B(z, 2β) with the
conjugate ball B(z̄, 2β); reality follows from the robust test α(f, z) < 0.03 with ‖z − Re z‖ < 1/(20·γ(f, z)).

The proof kind `alpha-root` of the closed registry `frob.cert.kinds/1` lets such a certificate travel in a bundle:
the offline auditor `frob-verify` recomputes "the α bound of a rational point, with Smale's theorem as a named
assumption" (card T-34). The theorem itself is an assumption of the bundle and is printed in the trusted-base
block of every report; it is not re-proved. An α-test proves a nearby nonsingular root and nothing about roots
that were not found (CX-083: a run that certifies fewer than the 40 Stewart–Gough solutions, or loses a path, has
not found them all).

The row is listed in the registry from the start with status `not-implemented` (dispatching to `unsupported`), so
the registry is complete; the checker is built only if the continuation lane is funded after its pilot (N25d-21,
Stewart–Gough forward kinematics by parameter homotopy, 40 certified roots on ten parameter sets). Tier: Moonshot.
Ceiling: evidence quality for one mechanism family; not on the critical path. Rejected alternative: checking α in
floating point (the threshold comparison is a strict decision and is made exactly). This bead was split from
N12-19, which keeps the unrelated `tube-inclusion` checker of the shield's reachable-set tables, so that each
checker waits only for its own pilot.

## Technical approach

1. Payload (DESIGN): the polynomial system f with rational coefficients (n equations in n unknowns, as sparse
   monomial lists with integer exponents), the degree bound d (largest total degree), and a list of claimed
   roots. Each root carries: the point z with real and imaginary parts as reduced rationals; a rational complex
   matrix B claimed to approximate Df(z)⁻¹; rational bounds β̄ and γ̄; the claimed label `real`, `non-real` or
   `unlabelled`. The bundle's `assumptions` list must contain `smale-alpha-theorem`. The claim carries the
   certified count and, separately and unchecked, the producer's completeness label.
2. Checks per root, all in exact rationals over ℚ(i) with squared norms so that no square root is taken, in this
   order, naming the first failing rule and the root index:
   a. `alpha.eval`: evaluate f(z) and Df(z) exactly.
   b. `alpha.inverse`: R = I − B·Df(z); require ‖R‖_F² < 1 (Frobenius norm, exact). Then Df(z) is invertible and
      ‖Df(z)⁻¹·v‖ ≤ ‖B·v‖/(1 − ‖R‖_F) for every v. Where a norm enters a sum, the checker uses a rational upper
      bound s̄ of √s for the exact squared norm s, verified by s̄ ≥ 0 and s̄² ≥ s (computed by rational Newton
      iteration from above for a fixed number of steps; no floating point). A claimed bound ‖Df(z)⁻¹·v‖ ≤ c is
      accepted when ρ̄ < 1 and b̄ ≤ c·(1 − ρ̄), with ρ̄ the verified upper bound of ‖R‖_F and b̄ that of ‖B·v‖.
   c. `alpha.beta`: β̄ ≥ ‖Df(z)⁻¹·f(z)‖, by step b with v = f(z).
   d. `alpha.gamma`: for each k from 2 to d, γ̄^(k−1) ≥ ‖Df(z)⁻¹·Dᵏf(z)/k!‖, with the k-linear operator norm
      bounded from above by the Frobenius-type norm (the square root of the sum of squared moduli of all tensor
      entries), computed exactly in squared form and combined with step b. A loose bound only makes the test
      conservative; the checker never needs a tight one.
   e. `alpha.threshold`: ᾱ = β̄·γ̄, and ᾱ < (13 − 3√17)/4 decided exactly as 13 − 4·ᾱ > 0 and
      (13 − 4·ᾱ)² > 153 (since 9·17 = 153). A comparison at exactly the bound is rejected.
   f. `alpha.real`: for label `real`, the robust test ᾱ < 3/100 and ‖z − Re z‖² < 1/(400·γ̄²).
   g. `alpha.nonreal`: for label `non-real` (only for a system with real coefficients), the ball B(z, 2β̄) is
      disjoint from its conjugate: ‖Im z‖² > 4·β̄².
3. Checks over the list: `alpha.distinct`: for every pair i < j, ‖zᵢ − zⱼ‖² > (2β̄ᵢ + 2β̄ⱼ)², so the certified
   roots are distinct and the certified count is a true lower bound on the number of roots.
4. `alpha.assumption`: a bundle whose `assumptions` do not list `smale-alpha-theorem` is rejected as a missing
   side condition (FROB-REF-829). The usual generic rules apply first (schema, flags FROB-REF-833, unknown kind
   FROB-REF-823, query match FROB-REF-826).
5. Class: `Certified` for "the listed roots exist, are distinct, and carry the stated reality labels", relative to
   the named assumption. Completeness is outside the kind: a result is `Complete` only when the certified count
   equals an independent generic count from a trace test with no lost path and no positive-dimensional
   component; that comparison is the producer's and is reported, never certified here. A `Partial` result can
   support inclusion of the designs it found and can never support an exclusion; a bundle that offers an
   `alpha-root` certificate as the basis of an exclusion is rejected (`alpha.scope`).
6. Caps (DESIGN): n ≤ 16 unknowns, d ≤ 16, at most 4,096 roots per bundle (the nine-point four-bar problem has
   4,326 solutions and ships as two bundles under one Merkle root), coefficient bit sizes declared in the
   registry row; beyond them the bundle is refused (`unsupported`), never approximated.
7. Report: the trusted-base block names the binary, the Rust standard library and compiler, and the assumption
   "Smale's α-theorem (not re-proved)"; per root the measured ᾱ as an exact fraction and its decimal value.

## Test plan

### Unit tests

`crates/frob-cert/tests/kind_alpha_root.rs`:
- `unfunded_kind_is_unsupported`.
- `alpha_sqrt2_at_17_over_12_accepts` (ᾱ = 1/1156; Newton's next iterate 577/408; √2 within 2·(1/408) of z).
- `alpha_at_1_rejects` (ᾱ = 1/4).
- `alpha_threshold_exact_square_test`: the comparison (13 − 4·ᾱ)² > 153 agrees with a 200-digit decimal
  evaluation of (13 − 3√17)/4 on 1,000 random rationals within 10⁻¹² of the threshold, and ᾱ equal to a rational
  just above α₀ is rejected.
- `alpha_gamma_below_true_rejects` (γ̄ = 1/3 < 6/17 at z = 17/12).
- `alpha_missing_assumption_rejects`.
- `alpha_reality_robust_test` (z = 17/12 + i/10⁶ labelled `real`: ‖Im z‖² = 10⁻¹² < 1/(400·(6/17)²) accepted;
  z = 17/12 + i/10 labelled `real` rejected at `alpha.real`, since there ᾱ ≈ 0.0351 ≥ 3/100).
- `alpha_nonreal_conjugate_balls` (x² + 1 at i·101/100: β ≈ 0.00995, ‖Im z‖² ≈ 1.02 > 4β̄², accepted).
- `alpha_distinct_balls` (±17/12 accepted; 17/12 and 577/408 rejected: their distance is 1/408, below
  2·(1/408) + 2·β̄ at 577/408, where β = 204/(166464·577) ≈ 2.1·10⁻⁶).
- `alpha_inverse_defect_too_large_rejects` (B = 0 gives ‖R‖_F² = 1).
- `alpha_exclusion_scope_rejects` (an exclusion argued from a `Partial` count).
- `alpha_caps_refused` (n = 17).
- `alpha_seeded_fault_campaign` (200 mutated bundles, seed recorded: a coordinate of z moved, γ̄ or β̄ lowered,
  B perturbed so that ‖R‖_F² ≥ 1, a reality label flipped, two roots moved within each other's balls, the
  assumption dropped; zero accepted).
- `alpha_unsupported_before_enable` (the auditor at the revision before `alpha-root-enable` returns
  `unsupported` for the accepted specimen).
- Property test: for 1,000 random univariate quadratics with rational roots r and points z = r + ε, the checker
  accepts exactly when an independent high-precision evaluation of α is below α₀ by a margin, and never accepts
  when it is above.

### End-to-end script and logging

The corpus directory `crates/frob-cert/tests/specimens/alpha-root/` (accept and reject files with
`expected.toml`) is run by `scripts/e2e/lemma_auditor_mutations.sh` (bead N12-34, a dependency), which asserts
`unsupported` for the kind while it is `not-implemented` and afterwards one accept and at least three rejects. Its
NDJSON lines for this kind (STD-E2E helper, `target/e2e-logs/lemma_auditor_mutations/<utc>.ndjson` with a
transcript) carry `ts`, `script`, `bead` (`N12p1-01`), `step` (`alpha-root/<specimen-or-mutation>`), `event`, the
exact command line (`frob-verify` and `frob prove verify --json` on the specimen file), exit code, wall time, the
registry status of the kind, per root ᾱ as an exact fraction against α₀ with β̄ and γ̄, the label tested, the
expected and observed verdict, the bundle's BLAKE3, and on a mismatch the first failing rule and root index with
the path to reproduce. On the funded branch the gate script of the continuation lane (N25d-24, GATE-AUGUR-22: 40
certified Stewart–Gough roots on ten parameter sets), which depends on this bead, sends its real bundles through
this checker and logs the certified count, the distinctness check and the reality labels; that run is N25d-24's.

√2 lies within twice the Newton step 1/408 of z. CX-083 (α-certified is not complete). Known counts the producer

## Considerations

- Kill gate named in advance by the owning mechanism: KILL-SYNTH-CONT (M8; fallback: the exact lane with
  multi-start). If it fires, this kind stays `not-implemented` permanently.
- Smale's theorem is an assumption of the bundle, printed in the trusted-base block; re-proving it inside a proof
  kernel is out of scope and has no basis at this tier.
- Tensor norm bounds for γ can be loose, which only makes the test conservative; a system whose roots fail only
  because of loose γ̄ is reported with the measured ᾱ so the producer can refine z by more Newton steps.
- Exact arithmetic on high-degree systems can grow large integers; the caps bound it, and a refused bundle is
  `unsupported`, never `accept`.
- The auditor's 12,000-line cap: this checker is complex-rational arithmetic, a monomial evaluator and a few
  comparisons, a few hundred lines; it shares the polynomial evaluator with `interval-root` (N12-16).
