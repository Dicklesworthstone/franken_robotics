## Background
Construction C-01: a floating-base robot's configuration space is the Lie group Q = SE(3) × G₁ × … × Gₙ, and joint j contributes the map θ ↦ ∏ₖ exp(θₖ·Sₖ) for screws Sₖ ∈ 𝔰𝔢(3). When span{Sₖ} is closed under the Lie bracket the joint is a connected subgroup of SE(3), and such subgroups fall into twelve conjugacy classes (Hervé). A joint whose basis is not closed (a universal joint) is not a subgroup; it is a product of one-parameter subgroups. This replaces `enum JointKind` with one hand-written code path per case. FACT (FrankenSim at `483d09c682f2`): `fs-mbd` has `JointKind = Fixed | Revolute | Prismatic | Helical` only, with no spherical, universal or planar joints; `fs-ga` has `Twist::bracket` and `Twist::ad`; the joint catalog crate `fs-kinematics` proposed by FrankenSim's charter does not exist. So the classification and the generated maps are new code here.

Payoff: one kernel generator parameterized by a screw basis covers every joint, and the model compiler (BD-061) can check that a declared joint class agrees with its screw basis. Theorem card T-11 states the obligation: a joint's screw basis is, or is not, closed under the bracket, and its Hervé class is as reported; route: exact rational linear algebra. Bracket closure and Hervé class are therefore `Exact` predicates (integers and rationals on the host, class D0): a rank decided in floating point would misclassify a helical joint of pitch 10⁻⁹ m/rad as revolute. Tier: Solid. The use of the subgroup lattice for mobility analysis is Frontier and is N13-28.

## Scope
In: `ScrewBasis`, `HerveClass`, `JointSubgroup`; the exact closure test and classification with normal-form data; the report for non-closed bases; the generated joint transform and motion subspace; the Subgroups law.
Out: intersections and products of subgroups for mobility (N13-28); the joint catalog of the design language and the port-type refusal (frob-design, frob-model); kernels (frob-kir).

## Technical approach
**Types (DESIGN).**
```rust
pub struct ScrewBasis { screws: Vec<[Rational; 6]> }           // each (ω, v), angular first, not normalized
pub enum HerveClass { Identity, LineTranslation, Rotation, Helical { pitch: Rational },
    PlanarTranslation, Cylindrical, SpatialTranslation, PlanarGliding, Spherical,
    TranslatingScrew { pitch: Rational }, Schoenflies, Se3 }
pub struct JointSubgroup { class: HerveClass, screws: ScrewBasis, closed_under_bracket: bool,
    normal_form: NormalForm /* axis line, plane normal or centre, exact */ }
```
Screw entries are exact rationals taken from the design's exact decimals and rational turns; directions need not be unit vectors (every test below is scale-free). `Rational` and exact rank, solve and nullspace come from N13-10.

**The twelve classes** (dimension; description):
| Class | dim | Motion |
|---|---|---|
| Identity | 0 | none |
| Line translation | 1 | along one direction (prismatic pair) |
| Rotation | 1 | about one axis (revolute pair) |
| Helical, pitch p | 1 | screw about an axis (helical pair) |
| Planar translation | 2 | in a plane |
| Cylindrical | 2 | rotation about and translation along one axis (cylindrical pair) |
| Spatial translation | 3 | all translations |
| Planar gliding SE(2) | 3 | planar rigid motion (planar pair) |
| Spherical SO(3) | 3 | rotations about one point (spherical pair) |
| Translating screw, pitch p | 3 | planar translation with a screw along the plane's normal |
| Schönflies | 4 | all translations with rotation about one direction |
| SE(3) | 6 | everything |
The six lower pairs are the revolute, prismatic, helical, cylindrical, planar and spherical classes.

**Classification algorithm** (all in exact rationals):
1. Rank. Row-reduce the basis; d = rank. If d is less than the number of screws, return `Degenerate { rank: d }` with the dependent screws named.
2. Closure. For every pair i < j compute [Sᵢ, Sⱼ] = (ωᵢ × ωⱼ, ωᵢ × vⱼ − ωⱼ × vᵢ) and test membership in the span by rank. If every bracket is in the span, `closed_under_bracket = true`.
3. Not closed: report the joint as a product of one-parameter subgroups, giving each factor's class by step 4 on the single screw (Rotation, Line translation or Helical with its pitch) in declared order; also compute the generated algebra by adding brackets until the rank stops growing (at most six) and report its class as information. Example: two rotations about perpendicular axes through one point span a 2-dimensional non-closed space; the report is the product Rotation·Rotation, generated algebra Spherical.
4. Closed: let r be the rank of the angular parts and t = d − r the dimension of the translation subalgebra T = {(0, v)}.
   - d = 0: Identity.
   - d = 1: r = 0 → Line translation. r = 1 → pitch p = (ω·v)/(ω·ω); p = 0 → Rotation, else Helical{p}.
   - d = 2: r = 0 → Planar translation; r = 1 → Cylindrical.
   - d = 3: r = 0 → Spatial translation. r = 1 (t = 2): take any element with ω ≠ 0 and p = (ω·v)/(ω·ω) (unchanged by adding elements of T, because closure forces T ⟂ ω); p = 0 → Planar gliding, else Translating screw{p}. r = 3 (t = 0) → Spherical, with the centre c solving vᵢ = c × ωᵢ for all i.
   - d = 4: r = 1, t = 3 → Schönflies.
   - d = 6 → SE(3).
   - Any other (d, r) for a closed basis (r = 2, or d = 5) contradicts the classification theorem and is an internal error, asserted.
5. Normal form. Axis line for Rotation, Helical, Cylindrical: direction ω and point c = (ω × v)/(ω·ω). Plane normal for Planar translation, Planar gliding, Translating screw. Centre for Spherical. Direction for Schönflies. All exact.
The result carries a D0 digest of (class, canonical reduced basis), so equal joints written differently hash equally.

**Generated joint maps.** For coordinates θ ∈ ℝᵈ: `joint_transform(θ) = exp(θ₁·S₁)·…·exp(θ_d·S_d)` (product of exponentials in declared order, floating point, using BD-011) and the body-frame motion subspace, column k = Ad_{(exp(θ_{k+1}·S_{k+1})·…·exp(θ_d·S_d))⁻¹}·Sₖ. A revolute factor uses the unit-complex coordinate of BD-012 in place of θₖ. A Cayley-stepped variant `joint_step(θ̇, h)` composes cay(h·θ̇ₖ·Sₖ) for the batched tiers, under the Cayley bound. These functions are the algebraic description that `frob-kir` lowers into one generated kernel family.

**Laws (the Subgroups row).** (a) A classified basis is bracket-closed: exact. (b) The generated joint map composes like its subgroup: for a closed basis, log(joint_transform(θ)·joint_transform(φ)) lies in span{Sₖ} (residual of the projection onto the orthogonal complement at most 64 ulp at the element's scale, 10⁶ cases); for the abelian classes joint_transform(θ)·joint_transform(φ) = joint_transform(θ + φ). (c) The motion subspace equals the dual-number derivative of the joint transform.

**Determinism and evidence.** Classification is D0 and `Exact`; when the T-11 certificate is emitted for a model (by frob-lemma) the class is `Certified`, otherwise `Tested`. The maps are D2 host code.

## Acceptance criteria
- [ ] Each of the twelve classes is recognized from a screw basis given in a non-canonical pose (conjugated by a rational rigid transform) and in a non-reduced basis (random invertible rational recombination); 1,000 random instances per class, zero errors (the seed bead's done-condition).
- [ ] A non-closed basis is reported as a product with its factor classes, in order, and with the class of its generated algebra (the seed bead's done-condition); the universal joint reports Rotation·Rotation, generated Spherical.
- [ ] A helical basis with pitch 10⁻⁹ m/rad is classified Helical with that exact pitch, not Rotation.
- [ ] The Subgroups law passes on 10⁶ cases; rows appended to the GATE-MARROW-01 ledger.
- [ ] Negative controls caught: (i) the bracket's arguments exchanged fails the second-order composition fixture; (ii) a floating-point rank with tolerance 10⁻⁶ misclassifies the tiny-pitch case and is rejected by the test; (iii) a basis for Planar gliding with one translation tilted out of the plane by 1/1000 is reported not closed.
- [ ] An oversized rational (above the declared budget of N13-10) returns FROB-REF-215, not a wrong class.

## Test plan
### Unit tests
- `herve_twelve_classes_canonical`: canonical bases, e.g. Rotation {(e_z, 0)}; Helical {(e_z, p·e_z)}, p = 1/200; Cylindrical {(e_z, 0), (0, e_z)}; Planar gliding {(e_z, 0), (0, e_x), (0, e_y)}; Translating screw {(e_z, p·e_z), (0, e_x), (0, e_y)}; Spherical {(e_x, 0), (e_y, 0), (e_z, 0)}; Schönflies {(e_z, 0), (0, e_x), (0, e_y), (0, e_z)}; SE(3) the six unit screws.
- `herve_twelve_classes_conjugated`: each basis moved by g = (cay of a rational Ω, rational p) through exact Ad_g and recombined; class and invariants (pitch) unchanged.
- `spherical_centre_recovered`: rotations about the point c = (1/3, −2, 5/7) return that centre exactly.
- `universal_joint_is_product`: {(e_x, 0), (e_y, 0)} → not closed; factors Rotation, Rotation; generated Spherical.
- `rotation_plus_perpendicular_translation_not_closed`: {(e_z, 0), (0, e_x)} → not closed; generated Planar gliding.
- `tiny_pitch_exact`: pitch 10⁻⁹ kept.
- `bch_second_order_sign`: log(exp(a·S₁)·exp(b·S₂)) − (a·S₁ + b·S₂) ≈ ½·a·b·[S₁, S₂] for a = b = 10⁻³ on the Spherical basis; the exchanged-argument mutant has the opposite sign.
- `abelian_map_adds`, `closed_map_stays_in_span`, `motion_subspace_matches_duals`.

KA-247 (Subgroups law). Controls as listed, registered for the Subgroups row. ## Considerations
- Mobility by intersections and products in the subgroup lattice (Sarrus returns 1; Bennett returns `undecided`) is Frontier and depends on its pilot (N13-27, N13-28); here the lattice is not consulted.
- Joint limits cut a subset out of the subgroup and do not change its class; loop closures and singular poses belong to the mobility analysis (A-01).
- Irrational directions (a 45° axis) are handled by scale-free tests on rational direction vectors such as (1, 1, 0); a design that can only state an axis by a floating number is classified by tolerance, labelled `Tested`, with the tolerance recorded.
