## Background
A rotation is stored as a unit quaternion, and q and −q are the same rotation (the double cover of SO(3)). Open question OPEN-MARROW-1 asks whether stored state should be forced to one representative (for example scalar part non-negative). The question is owned by the Marrow lead, it is listed as blocking GATE-MARROW-01, and it is to be decided at that gate. This bead records the decision as an ADR and makes the default testable until then.

The two options and their consequences:
- **Do not canonicalize (the default, fail-closed).** State stays continuous in time: a body rotating through a half turn has a quaternion that moves smoothly from q to −q. Consumers that need a sign-free quantity use sign-invariant features, such as projected gravity (the gravity direction in the body frame, which is quadratic in q), rotation matrices, or the group action itself. Cost: two bit-different states can denote one physical state, so equality of rotations must be tested as "q = ±q′", and a digest of raw state distinguishes them.
- **Canonicalize.** One physical state has one bit pattern, which simplifies digests and equality. Cost: the stored state jumps by a sign flip when the scalar part crosses zero; any consumer that interpolates, differentiates or feeds raw quaternion components to a policy sees a discontinuity of size 2 with no physical event behind it, and a flip that happens on one backend one step earlier than on another creates a bitwise divergence that is not a physical divergence.

Reason for the default: a discontinuity injected into state is a worse failure than a redundant representation, because it is silent and it depends on rounding. The conventions table already says the double cover is resolved by a deterministic sign rule at the boundary where a representative is needed, not in state.

## Scope
In: the decision record; the tests that make the default binding until it is decided; the list of consumers the decision touches.
Out: implementing canonicalization if the decision goes the other way (a new bead would be opened; nothing downstream assumes it).

## Technical approach
1. Fail-closed default in force from M0: stored rotation state is whatever the group update produces; no kernel or host function flips a quaternion's sign. A canonical representative (first non-zero stored component positive) is produced only by an explicit `canonical_representative()` call at an observation or comparison boundary.
2. Evidence to gather before GATE-MARROW-01 is recorded (from BD-010's fixture and the probe below; the probe composes increments through the `fs-ga`-backed exponential that BD-010 forwards, and is repeated with the Cayley update when BD-011 lands): (a) from the PO-MARROW-01 fixture, what `fs-ga` itself does on compose and normalize (FACT to record: whether it ever flips sign); (b) a continuity probe: a body spun through 4π in 10⁴ group-update steps; the stored quaternion's componentwise step-to-step change must stay below 2·sin(h‖ω‖/2) + 4 ulp at every step, which a canonicalizing update violates twice; (c) a list of every place that hashes or compares raw rotation state (state digests, snapshots, the first-divergence search), with a statement of whether "q against −q" can occur there between two runs that are physically equal. Under the default it cannot within one deterministic run, because the same arithmetic produces the same sign.
3. Decision record: an ADR in `docs/adr/` titled by the question, with the option chosen, the evidence above, the consumers affected (observation terms in the task language, policy inputs, digests, replay comparison, the invariant filter) and the date; the open-question row is then marked decided. The decision is made by the Marrow lead; if the lead proposes canonicalization, the owner signs, because it changes every stored state and every digest.
4. Downstream if "no" is confirmed: nothing changes. Downstream if "yes": a canonicalization select is added after the per-step normalization in the group-update kernel (a `Guarded` predicate on the sign of the scalar part, because the branch changes stored state discretely), digests change, and policies must still never read raw components.

## Acceptance criteria
- [ ] An ADR exists with the decision, the evidence (a), (b), (c) and the affected consumers; the open-question table row for OPEN-MARROW-1 points to it.
- [ ] Until the ADR exists, `no_sign_flip_in_state` passes and is listed as a blocking test of GATE-MARROW-01.
- [ ] The observation path offers at least one sign-invariant rotation feature (projected gravity) and a compile-time or lint barrier against exposing raw quaternion components as an observation term without `canonical_representative()`.
- [ ] The negative control is caught: a planted canonicalizing update fails `no_sign_flip_in_state`.

## Test plan
### Unit tests
- `no_sign_flip_in_state`: spin about a fixed axis through 4π in 10⁴ steps of g ← g·exp(h·ω) (and of the Cayley update once it exists); assert the maximum componentwise change between consecutive stored quaternions is below 2·sin(h‖ω‖/2) + 4 ulp; with canonicalization planted the change reaches about 2 at two steps.
- `rotation_equality_is_sign_free`: `same_rotation(q, −q)` is true; `canonical_representative(q) == canonical_representative(−q)` bit for bit.
- `projected_gravity_sign_invariant`: the feature computed from q and from −q is bit-equal.
### End-to-end script and logging
`scripts/e2e/marrow_laws.sh` (shared) runs these tests in its `open-marrow-1` step and logs, per `STD-E2E`, the measured maximum component change against its bound, the seed, the commit, and whether the ADR file exists (an `assert` event that fails the M0 exit if the gate is being recorded without it). NDJSON under `target/e2e-logs/marrow_laws/`.
### Known answers and negative controls
Known answer: 2·sin(h‖ω‖/2) for the step change of a unit quaternion under a rotation by h‖ω‖ (exactly: |q₊ − q| = 2·sin(Δθ/4) for a rotation by Δθ, since the quaternion angle is half the rotation angle; the bound above is deliberately loose by the factor between Δθ/4 and Δθ/2). Negative control: the planted canonicalizing update. Determinism lanes: the continuity probe gives identical bytes twice on one machine and in debug and release.

## Considerations
- This is a decision bead: it blocks the recording of GATE-MARROW-01 (BD-011 at M0, N13-19 at M1) only in the sense that the gate record must cite the ADR; the fail-closed default lets all implementation proceed.
- If a later tier shows digests diverging between backends solely by quaternion sign (possible only if two backends are not bit-equal and one crosses zero in the scalar part a step earlier, with a normalization that is sign-sensitive), that is evidence to revisit, and it goes to the divergence ledger first.
- The same question does not arise for the planar coordinate (a unit complex number has no double cover) or for dual-quaternion storage (not used).
