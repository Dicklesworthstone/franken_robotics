## Background
Every Frontier mechanism needs a paper-scale pilot with a falsifier before it is funded. A pilot is small enough to run on a CPU in a day, uses exact or hand-checkable arithmetic where it can, is registered before it runs, and has an outcome that is not taken for granted; its result, including a negative one, is recorded in the review log and the mechanism's tier and scope are revised to match. A pilot that cannot fail is not a pilot.

The Frontier item here is "irreducible blocks for equivariant policies" (mechanism bead BD-325): parameterizing equivariant linear maps by real and complex irreducible blocks so that optimization runs on exactly the free parameters. Its registered pilot: by hand for C₃, C₂ × C₂ and D₆, commutant dimensions from the formula against the exact rank of the Reynolds projection. Falsifier: any mismatch. Kill gate and fallback of the mechanism: KILL-MARROW-BLOCKS (Reynolds projection in `f64`, classed `Tested`).

Ceiling of the benefit, stated before any measurement: a factor equal to the order of Γ_obs in free parameters per layer and in trajectories per rollout: 2 for a robot with a forward sensor suite, 4 for a blind fore-aft-symmetric quadruped, 12 for a blind radial hexapod. Augmentation already recovers much of this, so the gain over augmentation may be nil (HYPOTHESIS, settled by the learning chapter's three-arm experiment, not by this pilot). This pilot tests only whether the counting rule (one real parameter per pair of copies for a real-type constituent, two for a complex-type constituent) is the rule the Reynolds projection obeys on the three groups that matter first.

## Scope
In: the registration, the hand derivations, an independent exact computation of the Reynolds rank, the comparison, the record.
Out: any production code; any learning experiment; groups beyond the three named (the gate GATE-MARROW-04 covers the families).

## Technical approach
**Registration (before running).** An entry `PILOT-MARROW-01` in the pilot register `crates/frob-conformance/registry/pilots.toml` (schema `frob.gauntlet.pilot/1`, record form and funding rule of N38a-09): mechanism "irreducible blocks for equivariant policies", tier `F`, owner §13.5, bead N13-23, work package of BD-325, `gated_beads = ["BD-325"]`; `protocol` = { path `docs/delivery/pilots/marrow-blocks.md`, `blake3`, `frozen` (the freeze date), `ledger_seq` }; falsifier "any mismatch between a predicted commutant dimension and the exact Reynolds rank, on the six cases below" (six exact counts); `ceiling` = { statement "free parameters per layer reduced by a factor equal to |Γ_obs|", value "2, 4 or 12", basis "the order of Γ_obs for a forward sensor suite, a blind fore-aft-symmetric quadruped and a blind radial hexapod" }; `fallback` = { ships "Reynolds projection in `f64` classed `Tested`", kill_gate `KILL-MARROW-BLOCKS` }; `cost` = { cpu_core_h under 0.02 (one core-minute), gpu_h "0", wall_h under 0.02, envelope "default" }; `tool` = { name the exact script below, pin its digest, site `host` }; status `registered`. The protocol document states the question, the three groups and the representations below, the predicted numbers from the formula, who runs it, and the date. Entry and document are committed before the computation is run; the result is appended as a `[[pilot.result]]` with the observed ranks and the verdict.
**Formula under test.** dim Hom_Γ(V_in, V_out) = Σᵢ cᵢ·mᵢ^out·mᵢ^in, cᵢ = 1 for a real-type irreducible and 2 for a complex-type pair, with the type read from the Frobenius–Schur indicator ι(χ) = |Γ|⁻¹·Σ_g χ(g²).
**Cases and predictions (by hand).**
1. C₃ acting on ℝ³ by cyclic permutation (three legs). Characters: trivial (ι = 1) and the conjugate pair χ₁, χ₂ (ι = 0), each once. Prediction 1·1·1 + 2·1·1 = 3. The equivariant maps are the circulants a·I + b·S + c·S², three parameters; the D₃-equivariant ones are the symmetric circulants (b = c), two parameters. The map x ↦ (x₂ − x₃, x₃ − x₁, x₁ − x₂) is a circulant with (a, b, c) = (0, 1, −1) and must lie in the Reynolds image under C₃ and outside it under D₃.
2. C₂ × C₂ acting on ℝ⁴ by its regular representation (four legs of a quadruped permuted by the fore-aft mirror, the left-right mirror and the half-turn). Four real characters, each once: prediction 4. With k copies in and l copies out: 4·k·l; for k = l = 64: 16,384, against 65,536 unconstrained.
3. D₆ acting on ℝ⁶ by permuting six radial legs. The permutation character is (6, 0, 0, 0, 2, 0) on the classes (identity; rotations by ±60°; by ±120°; half-turn; reflections through opposite legs; reflections through opposite gaps), which decomposes into four distinct real irreducibles, each once (two of degree one, two of degree two): prediction 4. Cross-check: the equivariant maps are the "distance-class" matrices W_{ij} = w(|i − j| mod 6 folded to 0, 1, 2, 3), four parameters.
4. D₆ regular representation (ℝ¹²): prediction Σ d² = 1 + 1 + 1 + 1 + 4 + 4 = 12.
5. A signed case: C₂ × C₂ acting on four roll joints (permutation with signs −1 under each mirror and +1 under the half-turn). Prediction from the formula: computed by hand from the signed permutation character (4, 0, 0, 0): again four real characters once each: 4. Because no element fixes a joint, this character equals the unsigned one, so this case checks the bookkeeping of signs (the Reynolds image must contain only sign-consistent maps) but cannot tell a dropped sign by its rank; case 6 can.
6. A parity case that discriminates: C₂ × C₂ (body frame x forward, y left, z up; left-right mirror P = diag(1, −1, 1), fore-aft mirror P = diag(−1, 1, 1), half-turn about z P = diag(−1, −1, 1)) mapping the base angular velocity, an axial vector transformed by det(P)·P, to the base linear velocity, a polar vector transformed by P. Characters on (e, left-right, fore-aft, half-turn): polar (3, 1, 1, −1), axial (3, −1, −1, −1). Prediction: dim Hom = (1/4)·(9 − 1 − 1 + 1) = 2 (the maps ω_x ↦ v_y and ω_y ↦ v_x, each with one free scalar; ω_z maps to nothing). A reading that drops the parity factor treats both as polar and predicts (1/4)·(9 + 1 + 1 + 1) = 3 (the diagonal maps).
**Independent exact computation.** `tools/pilots/marrow_blocks/` holds a small script (development-time only, not part of the build graph, not linking `frob-algebra`) that builds each representation as explicit rational matrices, forms the Reynolds operator on the d_out·d_in-dimensional space of matrices as a rational matrix, and computes its rank by exact Gaussian elimination. It prints the rank for each case, a basis of the image for case 1, and membership tests for the antisymmetric circulant under C₃ and under D₃.
**Decision rule.** All ranks equal the predictions and the two membership tests come out as stated: the pilot passes and BD-325 may be funded as specified. Any mismatch: the pilot fails; the record states which reading of the type rule failed; BD-325 is revised (or reduced to the Reynolds fallback) before any work on it starts.
**Record.** The `[[pilot.result]]` of `PILOT-MARROW-01` carries the date, the protocol hash, the commands, the six observed ranks against the predictions as exact values, the verdict (`falsifier-rejected` when all agree, `falsifier-holds` otherwise) and the receipt; the outcome, the script's digest and output, and the hand derivations are also appended to the review log under `docs/delivery/`; the mechanism's tier line is updated to cite the pilot.

## Acceptance criteria
- [ ] The `PILOT-MARROW-01` entry, with the protocol document's hash, is committed before the computation's output; the commit order is visible in history, and the register's completeness check (N38a-09) accepts the entry.
- [ ] Exact ranks: case 1 → 3; case 2 → 4 (and 16,384 for 64 copies, by the multiplicative rule checked at k = l = 2, giving 16); case 3 → 4; case 4 → 12; case 5 → 4; case 6 → 2.
- [ ] The antisymmetric circulant is in the Reynolds image under C₃ and not under D₃.
- [ ] A planted wrong rule (complex-type block counted once) predicts 2 for case 1 and is shown to disagree with the exact rank 3: the pilot's falsifier is exercised and seen to bite.
- [ ] A planted parity error (axial vectors transformed by P instead of det(P)·P) predicts 3 for case 6 and is shown to disagree with the exact rank 2; the Reynolds image of case 6 is spanned by the two maps ω_x ↦ v_y and ω_y ↦ v_x.
- [ ] The result is recorded in the review log with the script digest; BD-325's dependency on this bead is then satisfied.

## Test plan
### Unit tests
The pilot script's own checks: `reynolds_is_idempotent_exact` (R² = R as rational matrices for every case); `rank_cases` (the six ranks); `membership_c3_vs_d3`; `wrong_rule_disagrees` (the planted rule's prediction differs from the rank in case 1 and agrees in cases 2 to 6, which shows why C₃ is the discriminating case for types); `parity_rule_discriminates` (with the axial representation built as P instead of det(P)·P the rank of case 6 becomes 3 and differs from the prediction 2; the correct build gives 2 and its image basis is ω_x ↦ v_y, ω_y ↦ v_x).
### End-to-end script and logging
`scripts/e2e/pilot_marrow_blocks.sh` runs the pilot script and compares its output with the registered predictions; it has no `frob` command to drive because the pilot precedes the mechanism, and it says so in its first log line. It then runs the register's own checks in their example form, `cargo run -p frob-conformance --example pilots -- complete --json` (the entry is accepted and names the mechanism) and `cargo run -p frob-conformance --example pilots -- fundable --bead BD-325 --json` (`Blocked` while the record is `registered`, `Fundable` once the result with verdict `falsifier-rejected` is appended), and logs both answers. Logging follows the `STD-E2E` format so pilot evidence is uniform: NDJSON at `target/e2e-logs/pilot_marrow_blocks/<utc>.ndjson` with a transcript; `metric` lines per case (predicted, exact rank), `assert` lines for the membership tests and for the two planted wrong rules (type and parity), the script digest, wall time; summary with pass or fail of the pilot.
### Known answers and negative controls
KA-231 (C₃: 3, antisymmetric circulant representable), KA-232 (16,384); CX-122; CX-124 (an axial vector mapped by P instead of det(P)·P). Negative controls: the planted single-scalar rule for complex blocks (case 1: 2 against 3); the planted parity error (case 6: 3 against 2). Determinism: exact arithmetic; identical output on every machine.

## Considerations
- Representation theory guarantees the formula in general; what the pilot can falsify is this project's concrete reading of it (types, pairing of conjugates, signed permutations, the parity rule for axial vectors). That is why the signed cases and the D₃ contrast are included; of the signed cases only case 6 changes its rank when a sign is dropped, because only there an element fixes a coordinate.
- The pilot says nothing about whether tying pays in learning; the ceiling above is at most the group order and may be fully recovered by augmentation.
- No compute beyond one core for seconds; no envelope approval needed.
