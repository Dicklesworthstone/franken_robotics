## Background

A three-phase motor driven from a bus can only be given a voltage vector inside the inverter's hexagon, and its
back-EMF grows with speed. In power-invariant dq coordinates, with electrical speed ω_e = p·ω for p pole pairs:

  v_d = R·i_d − ω_e·L_q·i_q,   v_q = R·i_q + ω_e·(L_d·i_d + λ),   τ = p·[λ·i_q + (L_d − L_q)·i_d·i_q],

subject to v_d² + v_q² ≤ V_lim² and i_d² + i_q² ≤ I_max². Above base speed the voltage limit binds, and negative
d-axis current (field weakening) trades torque for speed. A model that omits this errs in one direction or the
other: with no limit it offers stall torque at any speed (the actuator family's rejection fixture, "stall torque
available indefinitely at high speed"); with a limit and no field weakening it offers no torque above the no-load
speed, where a real drive still delivers 59% of peak at 1.5 times base speed on the illustrative card.

This bead puts the limit into the running L2 model and exposes the static envelope as a verb, so that a design
whose required operating points lie outside the envelope is refused before any simulation is spent on it. The
closed forms and the maximum-torque solve are in the library bead N15a-16.

FACT: the referee's limit follows FrankenSim's controller, which enforces the exact voltage hexagon
(`frankensim/crates/fs-control/src/synchronous.rs`, power-invariant normalization). DESIGN: the batched tiers use
the circle inscribed in the hexagon, radius V_bus/√2, conservative by at most 1 − √3/2 = 13.4% of voltage at a
hexagon vertex; reason: the circle needs no electrical angle and no branch on the hexagon sector, so it is one
straight-line kernel. Rejected: the circumscribed circle (admits voltages the inverter cannot produce).

## Technical approach

1. **Limit shapes.** `LimitShape::Hexagon` on the referee: the voltage vector in the stationary frame is clamped to
   the hexagon with vertices at √(2/3)·V_bus, by the same rule as FrankenSim's controller, reached through the
   airlock. `LimitShape::InscribedCircle` elsewhere: the dq voltage vector is scaled back to radius V_bus/√2. For a
   DC machine V_lim = V_bus. V_bus is the bus voltage of the current step, so a sagging bus shrinks the envelope
   in the same step.
2. **Reference currents each step (DESIGN).** Given the torque request τ*, the speed ω, the temperatures and
   V_bus: (a) the minimum-current operating point that produces τ* is computed (for a non-salient machine
   i_q = τ*/(p·λ(T_m)), i_d = 0); (b) if its required voltage exceeds V_lim, i_d is moved negative along the
   constant-torque curve until the voltage constraint holds (non-salient, neglecting R:
   i_d = (−λ + √((V_lim/ω_e)² − (L·i_q)²))/L when the square root is real); (c) if the current circle is then
   violated, the point is moved to the intersection of the two limits and the torque is what that point gives,
   less than τ*. The general salient, resistive case calls the boundary solve of N15a-16. The clipped case raises
   a `speed-saturation` episode event (voltage-limited) or `torque-saturation` (current-limited) on telemetry
   level T1, with the joint named and the shortfall τ* − τ recorded.
3. **Voltage application.** The current loop of the L2 model then commands (v_d, v_q); the command is clamped by
   the limit shape, and the loop's integrators are held while clamped (no wind-up), so recovery after saturation
   is not delayed by the model.
4. **Verb `actuator.envelope` (kind `read`, M1).**
   `frob actuator envelope <card|design:joint> [--t-winding T] [--t-magnet T] [--v-bus V] [--speeds a:b:n]
   [--at joint|motor] [--shape circle|hexagon] [--point τ,ω [--require]] --json`.
   `--shape` defaults by the card's `modulation` (DESIGN, reason: the default is the conservative shape of the
   batched tiers wherever it exists, and it is the shape of the gate's closed forms): `svm-linear` → `circle`
   (V_lim = V_bus/√2); `six-step` → `hexagon`, answered with the flag `six-step: hexagon only`, since no inscribed
   radius is on file for it (N15a-02); `dc` → neither, V_lim = V_bus and the option is ignored with a warning. An
   explicit `--shape circle` on a `six-step` card refuses with FROB-REF-136 (item 5). Without `--require` a
   `--point` outside the envelope is a finding, exit 2, carrying the boundary at that speed.
   Result (`frob.actuator.envelope.out/1`, input `frob.actuator.envelope.in/1`, named as the verb registry
   VERBS-actuator names every verb's schemas): the boundary of the feasible set as torque against speed for both signs of
   torque, each point with (i_d, i_q) and which limit binds; base speed, no-load speed and top speed (or
   `unbounded`); V_lim and the limit shape; the stated winding temperature, magnet temperature and bus voltage;
   with `--at joint`, the boundary reflected through the bound transmission with its four-quadrant efficiency
   (N15a-17); flags (`l1-reactive-drop-not-negligible` from N15a-04; `six-step: hexagon only`). For a coupled
   transmission the result carries the generators of the feasible joint-torque set instead of per-joint limits:
   the object `joint_torque_set`, added to this schema by N15b-10; until that bead lands a coupled transmission
   is answered per motor with the flag `coupled: joint set not computed`, never with per-joint limits.
   Evidence: class `Estimated` unless every card field read has provenance `measured` (card values are
   `Estimated` unless calibrated), then `Tested`; `evidence.weakest` names the field that set the class; tier
   `static`; determinism D2; the `CardId` or `ModelId`.
5. **Refusal FROB-REF-131.** "A required operating point outside the torque, speed and voltage envelope." Raised
   for `--point … --require`, and from stage 6 and A-11 for the standing, crouching, stepping-up and nominal-gait
   points of a design. Returned with it: the point, the envelope boundary, and the gear-ratio or card edit that
   admits it. The repair search: scan the ratio lever's admissible values for those that place the joint-side
   point inside the motor envelope (edit `regear`); otherwise the smallest catalog class that admits it (edit
   `swap-actuator`); otherwise report that no single edit admits it. Exit code 3, `retry: after-change`.
   **Refusal FROB-REF-136** ("a row option the requested tier does not carry"; N15-REF's row), the verb's second
   chapter refusal: an explicit `--shape circle` on a card with `modulation: six-step`. The rule is N15a-02's
   (`v_lim(SixStep)` refuses on the circle path) and is raised through the static library N15a-16; this verb
   passes it on with the tiers that carry the option (`referee`, whose exact hexagon serves the card) and the
   repairs `--shape hexagon` or the card option `svm-linear`. Exit code 3, `retry: after-change`.
6. **Gate measurement.** GATE-SINEW-06 (claim Known answer, earliest M1): the five closed forms within 0.5%; over
   10⁴ random operating points the inscribed-circle envelope never exceeds the hexagon envelope. The closed forms
   are measured twice: from the verb, and from the running L2 model on the referee (a speed sweep under a torque
   request above the envelope, reading the delivered torque and currents). The second clause compares, at 10⁴
   random (speed, electrical angle, torque request, V_bus), the torque the circle shape admits with the torque the
   hexagon shape admits.

## Acceptance criteria

- [ ] On the illustrative card (λ = 0.010 V·s, L = 100 µH, I_max = 40 A, V_bus = 48 V, non-salient, R = 0) the
      verb returns V_lim 33.9 V, base speed 3,151 rad/s, no-load speed 3,394 rad/s, i_d = −32.2 A and i_q = 23.7 A
      at 1.5 times base speed (59% of peak torque), and top speed 5,657 rad/s, each within 0.5%.
- [ ] The running L2 model on the referee, swept in speed with a saturating torque request, delivers the same
      boundary within 0.5% at the five reference points.
- [ ] Circle against hexagon: 0 violations in 10⁴ points; the largest conservatism observed is at most 13.4%.
- [ ] With field weakening disabled by a test switch, delivered torque at 1.5 times base speed is zero.
- [ ] `--point` outside the envelope with `--require` refuses with FROB-REF-131, returning the point, the boundary
      and a `regear` or `swap-actuator` edit that admits it when one exists.
- [ ] `--shape` defaults to `circle` on an `svm-linear` card and to `hexagon` (flagged) on a `six-step` card; an
      explicit `--shape circle` on a `six-step` card refuses with FROB-REF-136 naming `referee` (the CLI
      assertion of the code is N15b-38's).
- [ ] The rejection fixture "stall torque available indefinitely at high speed" (KA-280): its required
      high-speed stall point is refused by `actuator.envelope --point … --require` with FROB-REF-131, the verdict
      stage 6 reuses; the stage-6 refusal of the whole design is measured by N15b-34 (seeds BD-103, BD-110), which
      depend on this bead.
- [ ] A bus sag from 48 V to 40 V within a run lowers the delivered torque above base speed in the same step and
      raises a `speed-saturation` event.
- [ ] The verb is reachable through `frob --json` with schema and refusals registered; the unit tests write the
      measured values of every row above to their output. The gate itself has one recorder: N15a-26 records
      GATE-SINEW-06 with `cargo run -p frob-conformance --example record_gate -- --gate GATE-SINEW-06 --receipt
      <g0 hash> --receipt <g1 hash>` from the two tier receipts its script produces (KA-319 in `g0_laws`, KA-314
      to KA-318 in `g1_known_answers`), once N15a-24's referee script has passed the speed sweep from the user's
      side; both scripts depend on this bead.

## Test plan

### Unit tests
- `reference_currents_below_base`: τ* inside the envelope at 1,000 rad/s electrical gives i_d = 0 and
  i_q = τ*/(p·λ).
- `reference_currents_field_weakening`: at ω_e = 4,727 rad/s with a saturating request the reference is
  (−32.2 A, 23.7 A); with a request of half that torque the i_d needed is smaller in magnitude and the voltage
  constraint holds with equality.
- `clamp_hexagon_vs_circle`: a commanded vector at a vertex angle with magnitude 0.80·V_bus is admitted by the
  hexagon and scaled to 0.7071·V_bus by the circle; at an edge-midpoint angle both give 0.7071·V_bus.
- `no_windup_while_clamped`: integrator state is unchanged across 100 clamped steps.
- `saturation_events`: voltage-limited and current-limited clips emit the two event kinds with the shortfall.
- `refusal_131_payload`: a joint-side point (30 N·m, 25 rad/s) outside a card's envelope at N = 9 returns the
  ratio interval that admits it, or the next card class.
- `bus_sag_shrinks_envelope`: base speed scales with V_bus (3,151 → 2,626 rad/s at 40 V).
- `shape_default_and_six_step`: the illustrative card (`svm-linear`) with no `--shape` answers V_lim 33.9 V and
  `limit_shape: circle`; the same card marked `six-step` with no `--shape` answers `limit_shape: hexagon` with the
  flag `six-step: hexagon only`; with `--shape circle` it refuses with FROB-REF-136, `tiers: ["referee"]`, first
  repair `--shape hexagon`; a `--point` outside the envelope without `--require` exits 2 with the boundary.
- `d4_voltage_limit_oracle`, in `crates/frob-conformance/tests/sinew_envelope_d4_oracle.rs` (in the conformance
  crate, so that `frob-actuate` takes no dependency on it; oracle values are read from the compendium library
  N12-44, `frob_conformance::compendium::d4`, and never regenerated here): on the illustrative card the verb's
  V_lim = V_bus/√2, base speed V_lim/√(λ² + (L·I_max)²) and top speed V_lim/(λ − L·I_max) agree with the
  voltage-limit row to 10⁻¹² relative; at base speed with (0, I_max) and at top speed with (−I_max, 0) the limit
  holds with equality; the circle's largest shortfall equals the row's 1 − √3/2 ≈ 0.134. Negative control, the
  row's own: a card with λ ≤ L·I_max, for which the oracle and the verb both report no finite top speed
  (`unbounded`).

## Considerations

- The L1 level has no dq limit; cards flagged by the L1 screen (L_q·I_max above one tenth of the flux linkage) get
  their envelope claims from this bead's L2 computation (N15a-04).
- Resistance and saliency move every closed-form figure; the gate's closed forms are for the lossless non-salient
  case only, and the verb prints the assumptions beside them.
- Interaction with the bus: field weakening draws current that produces no torque; the bus ceiling check of the
  other Sinew unit sees that power, which is one reason the bus analysis is run in full.
