## Background

Sinew's static functions exist so that a design is refused before any simulation is spent on it. Two read verbs
expose them, first milestone M1: `actuator.thermal` (the thermal steady state and runaway) and `actuator.envelope`
(the torque–speed envelope). An agent sizing a knee actuator asks them two questions: will this current hold for a
shift, and is this torque available at this speed? This bead is the end-to-end script that asks those questions of
the real binary on the two worked cards of the plan and checks every published number, and that records the static
rows of two gates:

- **GATE-SINEW-05** (Known answer, M1): equilibrium, time constant, critical current and time to limit within 0.5%
  of the closed forms; the two-node condition; the tangency under torque holding within 1%; the worked card's 20 A
  point admitted by the constant-resistance check and refused by the corrected one.
- **GATE-SINEW-06** (Known answer, M1): the five closed forms within 0.5%; over 10⁴ random operating points the
  inscribed-circle envelope never exceeds the hexagon envelope.

The dynamic rows of the same gates (the stepped L2 model reproducing the closed forms) are measured by the referee
script of N15a-24; a gate is recorded as passed only when both scripts pass.

## Scope

In: the two worked cards as fixtures; the script; assertions on every tabulated value; the refusals; the gate
records for the static rows. Out: the verbs and libraries (BD-072, BD-073, N15a-14, N15a-16); `actuator.bus` (the
other Sinew unit's verb, with its own script); the A-11 analysis and stage 6 of `design.check` (their own beads),
although one step runs `design.check` on a planted undersized design to see the same refusals arrive through it.

## Technical approach

1. **Fixtures** (synthetic; illustrative numbers derived for the plan, none measured; all fields `assumed`):
   - `thermal_worked.fcard`: R₀ = 0.20 Ω at 25 °C, α = 0.00393 K⁻¹, G = 0.80 W/K, C = 120 J/K, winding limit
     155 °C; a second variant with `alpha_flux` = −0.0011 K⁻¹; a two-node variant with G_wh and G_ha whose series
     conductance is 0.80 W/K.
   - `envelope_worked.fcard`: λ = 0.010 V·s, L_d = L_q = 100 µH, I_max = 40 A, R = 0, `modulation: svm-linear`,
     evaluated at V_bus = 48 V.
2. **Thermal steps** (`frob actuator thermal thermal_worked … --ambient 25degC --json`), tolerance 0.5% unless
   stated:

   | Request | Expected in the result |
   |---|---|
   | `--current 20A --start cold` | stable; rise 164.7 K (190 °C); time constant 247 s; loss at equilibrium 132 W; time to 155 °C: 385 s; constant-resistance comparison 125 °C, 150 s, never |
   | `--current 35A --start cold` | not stable; growth rate 0.00136 s⁻¹; time to limit 61 s; constant-resistance comparison: equilibrium 306 K above ambient, 83 s |
   | any | `i_crit` 31.9 A; `i_continuous` 18.6 A (constant-resistance comparison 22.8 A) |
   | `--torque … --hold torque` on the flux variant | limit current 15.9 A cold-equivalent; tangency 16.5 A (1%); the slope estimate 25.5 A reported as non-conservative; margin to tangency about 4% |
   | two-node variant at 20 A | the condition s < G_wh·G_ha/(G_wh + G_ha) reported true; with the series conductance lowered below s = 0.314 W/K, reported false and not stable |
   | `--current 20A --require` | exit 3, FROB-REF-132; payload: equilibrium 190 °C, largest sustainable load 18.6 A, ranked repairs |
   | `--current 20A --require --model constant-resistance` (comparison switch) | exit 0: the wrong model admits the point; the result is labelled as the comparison model |
3. **Envelope steps** (`frob actuator envelope envelope_worked --v-bus 48V --json`), tolerance 0.5%:
   V_lim 33.9 V; base speed 3,151 rad/s electrical; no-load speed 3,394 rad/s; at 1.5 times base speed
   i_d = −32.2 A and i_q = 23.7 A, 59% of peak torque; top speed 5,657 rad/s. Then
   `--point <full torque>,<1.5 × base speed> --require`: exit 3, FROB-REF-131, with the point, the boundary and an
   admitting edit. Then the property run: `--shape circle` against `--shape hexagon` at 10⁴ seeded random
   (speed, angle, torque) points; the circle's admitted torque never exceeds the hexagon's.
4. **Through the preflight.** `frob design check <undersized-knee design> --json`: stops at stage 6 with
   FROB-REF-131 or FROB-REF-132 for the knee, with typed-edit repairs (`swap-actuator`, `regear`) as
   `next_actions`.
5. **Gate records.** Static rows of GATE-SINEW-05 and GATE-SINEW-06 in `registries/gates.toml` with the measured
   values, commit, seed (for the property run) and hardware fingerprint, by a fresh-context session.

## Acceptance criteria

- [ ] Every value of the two tables is returned within its tolerance; the JSON carries units on every quantity.
- [ ] The seed bead's condition for thermal: the 20 A point is admitted by the constant-resistance comparison and
      refused by the corrected law with FROB-REF-132.
- [ ] The envelope refusal carries FROB-REF-131 with the point, the boundary and an edit.
- [ ] Circle against hexagon: 0 violations in 10⁴ points; the seed and the count are logged.
- [ ] The preflight step returns the same refusal codes with repairs as typed edits.
- [ ] Results carry evidence class `Estimated` (the fixture cards are `assumed`), tier `static`, and the `CardId`.
- [ ] The script exits non-zero on any failed assertion and is idempotent.

## Test plan

### Unit tests
None of its own beyond shell-lint and the fixture–table agreement test (every row of the tables has an assertion
in the script and vice versa).

### End-to-end script and logging
`scripts/e2e/sinew_static_sizing.sh`. It sources the shared end-to-end helper and writes newline-delimited JSON to
`target/e2e-logs/sinew_static_sizing/<utc-timestamp>.ndjson` with a transcript beside it. Each line: `ts`,
`script`, `bead` (BD-072, BD-073, N15a-14 or N15a-16 according to the assertion), `step`, `event`, the exact
command line, exit code, wall time, the envelope's evidence block (claim, class, tier, determinism, `CardId`,
seed). `metric` lines give each measured value with its unit, the closed-form value, the relative error and the
threshold (`0.005`, or `0.01` for the tangency); `refusal` lines give code, pointer, observed, required and the
first repair; the property run logs the point count, violations and the largest observed conservatism (at most
13.4%). On failure: the first differing value and the paths of the card and the envelope. The `summary` line
counts assertions and lists `GATE-SINEW-05` and `GATE-SINEW-06`.

### Known answers and negative controls
KA-304 to KA-313 (thermal; KA-313 is the verdict flip) and KA-314 to KA-319 (envelope), with the values in the
tables above. CX-136, CX-137, CX-139. Negative controls run by the script under the conformance mutants: the
constant-resistance law as the checked model (the 20 A refusal disappears: the assertion must fail); the slope
estimate in place of the tangency (16.5 A becomes 25.5 A); the envelope without the voltage ellipse (the 1.5 times
base-speed point is admitted); the circumscribed circle (the property finds violations). Determinism: the verbs'
output is byte-identical across two runs and in debug and release; the property run is seed-explicit.

## Considerations

- The worked cards are illustrative and are labelled so in the fixtures; the script tests the arithmetic and the
  refusals, not any real part.
- The comparison switch that evaluates the constant-resistance model exists only so that the difference can be
  shown and tested; its results are labelled and can never be cited for a verdict.
