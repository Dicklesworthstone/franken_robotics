## Background

Backlash needs the rotor as its own coordinate: inside the gap the rotor and the link move independently.
Twelve backlash joints would raise the velocity count of a quadruped from 18 to 30, and the fast tiers
factor a dense matrix per world per Newton iteration, so a naive treatment would cost about (30/18)³ ≈ 4.6
times the factorization work. It does not have to. Under the usual flexible-joint simplification, in which
a rotor's kinetic energy is that of its own spin, the rotor block of the system matrix is diagonal and each
backlash or motor-side stiction row couples one rotor to one joint. The rotor block is then eliminated in
closed form: its Schur complement changes only diagonal entries of the link block, at a cost linear in the
number of rotors. The dense factorization keeps the size it has with no backlash joints. Tier: Solid [S].
Crate `frob-actuate` for the algebra; the kernels of BD-155 call it.

The statement to verify is proof obligation PO-SINEW-02: **the rotor-eliminated solve equals the full
solve**, by exact rational comparison on small cases and round-off comparison on 10⁴ random cases. The gate
is GATE-SINEW-09 (M2): PO-SINEW-02 holds, and with twelve backlash joints the dense factorization has the
size it has with none.

## Scope

In: the block structure; the elimination formulas for the diagonal case and for a rotor behind a coupling;
back-substitution; a host reference in `f64` and in exact rationals; the PO-SINEW-02 tests; the comparison
against the referee's full coupling for the gyroscopic hypothesis. Out: the row potentials and their
curvatures (BD-155); the batched Cholesky (`K-chol`, BD-156); the rigid pull-back of rotor inertia for
transmissions without backlash (N15b-11); the referee's own solve (BD-084).

## Technical approach

**Setting.** A convex-tier step minimizes over the next velocity v = (q̇, θ̇), with q̇ ∈ ℝⁿ the joint and base
rates and θ̇ ∈ ℝᵐ the rotor rates:

  Φ(v) = ½·(v − v*)ᵀ·A·(v − v*) + Σ_rows ℓ_r(a_rᵀ·v),

A positive definite, each ℓ_r convex. A Newton iteration solves H·Δv = r with H = A + Σ a_r·g_r·a_rᵀ, g_r ≥ 0
the row curvature. Flexible-joint simplification: A = blockdiag(A_ll, D) with D = diag(J_r,i + h·b_i)
(rotor inertia plus implicit rotor damping).

**Rows that touch rotor i** (driving joint j = j(i) through ratio N_i):
- backlash, argument θ̇_i/N_i − q̇_j, total curvature g_i of its two rows: a = (−e_j, e_i/N_i);
- motor-side stiction, argument θ̇_i, curvature s_i: a = (0, e_i).

**Blocks.** H_rr = diag(d_i) with d_i = J_r,i + h·b_i + g_i/N_i² + s_i. H_rl has one entry per rotor,
(H_rl)_{i,j} = −g_i/N_i. H_ll = A_ll + (contact, limit and output-side rows) + Σ_i g_i·e_j·e_jᵀ.

**Elimination (diagonal case), cost O(m).**
1. For each rotor i: c_i = (g_i/N_i)/d_i.
2. Reduced matrix: S = H_ll − Σ_i (g_i/N_i)·c_i·e_j·e_jᵀ. Only the diagonal entry (j, j) changes; the net
   contribution of rotor i to that entry is g_i·(J_r,i + h·b_i + s_i)/d_i, which is nonnegative, so S stays
   positive definite.
3. Reduced right-hand side: r̃_l = r_l + Σ_i c_i·r_r,i·e_j.
4. Factor S (dense, size n) and solve S·Δq̇ = r̃_l.
5. Back-substitute: Δθ̇_i = (r_r,i + (g_i/N_i)·Δq̇_j)/d_i.
The line search evaluates Φ on the full v, so rotor velocities remain variables; only the linear solve is
reduced. Limit check: as g_i → ∞ (gap closed and stiff) the diagonal contribution tends to N_i²·(J_r,i +
h·b_i + s_i), the familiar reflected inertia.

**A rotor behind a coupling transmission.** The row argument is θ̇_k − C_k·q̇ with C_k the rotor's row of the
coupling map, so H_rl row k is −g_k·C_k and the complement subtracts (g_k²/d_k)·C_kᵀ·C_k: a block over the
joints the rotor drives, with off-diagonal entries. In the rigid limit it is the block C_kᵀ·J_r·C_k, which is
added once, in the lowering (N15b-11), and never again. This case costs O(m·w²) for couplings of width w.

**What the simplification neglects.** The gyroscopic torque J_r·N·q̇·Ω of a spinning rotor carried by a link
turning at Ω: with J_r = 10⁻⁴ kg·m², N = 9, q̇ = 20 rad/s, Ω = 5 rad/s it is 0.09 N·m (illustrative), under
one percent of the joint torques of such an actuator. HYPOTHESIS: negligible for the cards on file. Test:
the referee with full coupling (BD-084) against the reduced model on the standard battery, recorded as a
row of the fidelity ledger with its envelope.

**Regularization.** Rotor rows have tiny diagonal entries (J_r of order 10⁻⁴ kg·m²) next to base rows of
order 10 kg; any regularization is stated in the scaled variables of the solver's diagonal scaling, never as
a uniform shift, and elimination happens before scaling so that d_i is never perturbed by a shift sized for
a base row.

**Reference implementations.** `eliminate_rotors_f64` and `eliminate_rotors_rational` in
`crates/frob-actuate/src/rows/eliminate.rs`, the second over exact rationals for the proof-obligation test.

## Acceptance criteria

- [ ] PO-SINEW-02, exact: on 10³ random rational systems with n ≤ 6 and m ≤ 6 the eliminated solution (Δq̇,
  Δθ̇) equals the solution of the full (n + m) system exactly.
- [ ] PO-SINEW-02, round-off: on 10⁴ random double-precision systems the relative difference is at most
  10⁻¹² (tolerance to be set at the gate; this value is the proposal).
- [ ] GATE-SINEW-09 (TARGET): with twelve backlash joints on the reference quadruped the dense factorization
  has size 18, the size it has with none; recorded from the step plan's shape class.
- [ ] The coupled case reproduces the block C_kᵀ·J_r·C_k in the rigid limit to 10⁻¹².
- [ ] The fidelity-ledger row "rotor gyroscopic coupling neglected" exists with its measured disagreement
  against the referee, and the hypothesis is recorded as held or refuted.
- [ ] S is positive definite whenever H is (property test).

## Test plan

### Unit tests
`crates/frob-actuate/tests/rotor_elimination.rs`:
- `one_rotor_hand_case`: n = 1, m = 1, A_ll = 0.02, J_r = 10⁻⁴, N = 9, g = 50, s = 0, h·b = 0: d = 10⁻⁴ +
  50/81 = 0.617384; diagonal contribution g·J_r/d = 0.0080987; S = 0.0280987. Solving with r = (1, 0)
  reproduces the full 2 × 2 solve exactly in rationals.
- `rigid_limit_is_reflected_inertia`: g = 10¹², contribution → N²·J_r = 0.0081 within 10⁻⁹.
- `exact_rational_equivalence` (10³ cases), `roundoff_equivalence` (10⁴ cases).
- `diagonal_only_changes`: off-diagonal entries of S equal those of H_ll bit for bit in the diagonal case.
- `coupled_rotor_block`: the one-rotor coupling C = [10, 10] with J_r = 0.01 gives [[1, 1], [1, 1]] in the
  rigid limit.
- `factor_size_quadruped`: twelve backlash joints, n = 18.
- `spd_preserved` (property).

### End-to-end script and logging
`scripts/e2e/sinew_joint_rows.sh` (bead N15b-37) runs the twelve-backlash quadruped on `batch-cpu` with
`frob sim run --profile lockstep --json`, reads the shape class and the solve-stage record from the receipt,
asserts factor size 18, and compares the episode against the referee through `frob fidelity ledger`. Lines
log the factor size, the equivalence residuals with thresholds and the ledger row.

### Known answers and negative controls
KA-303 (the rotor-eliminated solve equals the full solve; 18 velocities in the factor, not 30). Negative
controls: `mutant-eliminate-drop-rhs` (step 3 omitted) must fail the exact equivalence; `mutant-rotor-
diagonal` on the coupled case must fail `coupled_rotor_block`. Metamorphic: permuting rotor order leaves S
bit-identical (sums into one diagonal entry are taken in rotor-index order). Determinism: D0 for the
rational path; D2 for the `f64` path.

## Considerations

- If the gyroscopic hypothesis is refuted for some card class, that class runs with explicit rotor
  coordinates in the dense block on the fast tiers (larger factor, flagged), and the referee is unaffected.
- A motor-side stiction row with zero curvature outside its kink leaves d_i = J_r,i + g_i/N_i², still
  positive.
- KILL-SINEW-ROWS, if it fires, removes these rows from throughput tiers; the elimination then serves only
  the `strict` profile.
