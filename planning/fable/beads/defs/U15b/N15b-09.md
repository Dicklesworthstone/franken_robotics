## Background

Every actuator element is written in port-Hamiltonian form: ẋ = (J(x) − R(x))·∇H(x) + G(x)·u with output
y = G(x)ᵀ·∇H(x), where J is skew-symmetric and R is positive semidefinite. Then Ḣ = uᵀy − ∇Hᵀ·R·∇H: stored
energy changes by the power at the ports minus what the element dissipates, and dissipation is never
negative. Elements are joined by power-conserving junctions, so the property survives composition. This is
what makes the energy checks of the chapter statements about structure instead of bookkeeping: if J is skew
and R is semidefinite, the element cannot create energy at any state, whatever the numbers.

Proof obligation PO-SINEW-01 states it: **the composite of passive elements through power-conserving
junctions is passive**, verified structurally by checking skew-symmetry of J and semidefiniteness of R per
element, exactly, on the rationals of the card; the plan also names it a candidate theorem card for the
proof subsystem. FACT: the sibling foundation implements this form (`frankensim/crates/fs-phs`) but has no
passivity proof generator and defers constrained Dirac structures, so the check is built here. It
complements the random-point battery of GATE-SINEW-08 (N15a-23): the battery samples operating points, this
bead certifies structure for every card. Invariant INV-SINEW-01 is the per-element form: every element is
passive, its dissipation nonnegative in all four quadrants of every port. Tier: Solid [S].

## Scope

In: a structural descriptor (J, R, G as exact rational matrices, or a monotone relation) for each element
kind the element bead does not already cover (thermal node, battery, bus, stiction, backlash, coupling
transmission, series spring, the gear's loss element), reusing the per-element check and `StructureRecord`
that N15a-05 writes for the winding, gyrator, rotor, ideal gear and driver; the composite assembly through
the junction incidence of N15b-01; instance certificates of the two existing proof kinds; integration into
`actuator.check`; the proposal text for the candidate theorem card. This is the bead that discharges
PO-SINEW-01 for composites. Out, with the bead that has each: the element definitions (N15a-05, N15a-06,
N15a-08, N15a-09, N15a-17, N15b-03, BD-074, BD-075); the general theorem in a proof assistant (Frontier,

user's side (N15b-32); the ideal gear law PO-SINEW-03 as a test (N15a-18); the per-step numeric balance
(N15b-05, BD-076).

## Technical approach

**Element descriptors.** Each element kind implements `fn structure(&self, card: &CardRationals, x: &State)
-> Structure`, exact over ℚ (card quantities are exact decimals; temperature-dependent values are rational
functions of the state).

| Element | State and stored energy H | J (structure) | R (dissipation) | Check |
|---|---|---|---|---|
| Winding | Flux linkage φ = L·i per axis; φ²/(2L) | 0 | R_w(T) ≥ 0 | sign of a rational |
| Electromechanical conversion | none | Gyrator of modulus k: τ = k·i, e = k·ω | 0 | power identity e·i − τ·ω = 0 |
| Rotor | Angular momentum p = J_r·ω; p²/(2J_r) | 0 | viscous b ≥ 0 | sign |
| Motor axis (winding + gyrator + rotor) | (φ, p) | [[0, −k], [k, 0]] | diag(R_w, b) | J + Jᵀ = 0; R diagonal nonnegative |
| Gear | none | Transformer of modulus N | loss element in series, nonnegative in four quadrants | identity; quadrant signs |
| Coupling transmission | none | Matrix transformer T (or C): q̇ = T·θ̇, τ_actuator = Tᵀ·τ_joint | per-motor loss | τ_jointᵀ·q̇ − τ_actuatorᵀ·θ̇ = 0 identically |
| Stiction | none | — | A monotone set-valued relation between torque and speed | monotonicity: (τ₁ − τ₂)·(v₁ − v₂) ≥ 0 |
| Backlash | Relative angle δ; zero inside the gap, ½·k_tooth·e² beyond on compliant tiers | 0 | tooth damping ≥ 0; an impact law with restitution in [0, 1] on the referee | sign; restitution range |
| Series spring | Deflection; ½·k_s·δ² | canonical | internal damping ≥ 0 | sign |
| Thermal node | U = C·(T − T_ref) | 0 | conductance matrix to neighbours and ambient, symmetric positive semidefinite | exact LDLᵀ |
| Battery | q, q₁, q₂; ∫OCV dq + q₁²/(2C₁) + q₂²/(2C₂) | 0 | R₀, R₁, R₂ ≥ 0 | signs |
| Bus | Capacitor charge; q_b²/(2C_b) | Node: equal voltages, currents sum to zero | harness resistance ≥ 0 | incidence identity |
| Driver | Controller states are signals | Modulation as a lossless transformer of duty | switching loss as a resistance ≥ 0 | identity; sign |

**Checks.**
1. Skew-symmetry: J + Jᵀ = 0 entry by entry in ℚ.
2. Semidefiniteness: R symmetric; exact rational LDLᵀ with symmetric pivoting; every pivot nonnegative and
   every zero pivot has a zero remaining row (the semidefinite acceptance condition).
3. Lossless two-ports: the power form vanishes as a polynomial identity in the port variables (the gear law
   e₁·f₁ + e₂·f₂ = 0 from f₂ = r·f₁ and e₁ = −r·e₂).
4. Storage: each quadratic H has a positive coefficient (L, J_r, C₁, C₂, C_b, k_s, C all positive), so H is
   bounded below.
5. Composite: with the junction incidence of N15b-01 the composite has J_c = blockdiag(J_i) plus the
   junction's skew coupling and R_c = blockdiag(R_i); run 1 and 2 on J_c and R_c. The composite storage is
   Σ H_i. Then Ḣ_c ≤ (external port power), which is passivity.
6. A failing check refuses with FROB-REF-130 and names the element, the entry and, for a loss, the quadrant
   and the power created at a witness point.

**Certificates.** For each admitted card the check emits instance certificates of the kinds the offline
auditor already checks: `poly-identity` for steps 1 and 3, `rational-ldlt` for step 2. They are stored with
the card version and listed among a module's local certificates ("passivity of every element"). A result
that relies on them may cite class Certified for the structural statement only; numeric results stay
Tested or Estimated.

**Candidate theorem card (proposal text).** "For port-Hamiltonian components with J_i skew-symmetric, R_i
positive semidefinite and H_i bounded below, interconnected by a power-conserving relation with no
algebraic loop, the composite satisfies Ḣ ≤ u_extᵀ·y_ext with H = Σ H_i." Evidence proposed: instance-level
exact check [S] (this bead); general statement in a proof assistant [F]. The proposal is filed with the
proof subsystem; adopting it as a numbered card is that subsystem's decision.

## Acceptance criteria

- [ ] `crates/frob-actuate/src/passivity/structure.rs` has a descriptor for every element kind in the table.
- [ ] Every card in the starter catalog passes the exact checks (a row of GATE-SINEW-08: every card in the

- [ ] The composite of a full leg (three L2 actuators, gears, the bus, the battery, thermal nodes) passes
  step 5 exactly.
- [ ] Planted defects are refused: a gyrator with unequal moduli on its two sides; a negative conductance; a
  negated copper loss in a braking mode; a transmission efficiency of 1.05.
- [ ] `actuator.check` runs these checks at admission and at binding.
- [ ] The theorem-card proposal is filed and its identifier or its rejection is recorded.

## Test plan

### Unit tests
`crates/frob-actuate/tests/passivity_structure.rs`:
- `motor_axis_structure`: k = 1/20, R_w = 1/2, b = 1/1000: J + Jᵀ = 0; R = diag(1/2, 1/1000) passes.
- `gyrator_mismatch_refused`: k_t = 1/20 and k_e = 1/18 make J = [[0, −1/18], [1/20, 0]], not skew: refused
  with FROB-REF-130 (the card-level symptom is torque and back-EMF constants that disagree).
- `thermal_conductance_psd`: G_wh = 2, G_ha = 4/5: the 2 × 2 conductance matrix [[2, −2], [−2, 14/5]] has
  pivots 2 and 4/5.
- `negative_conductance_refused`.
- `semidefinite_accepts_zero_pivot`: a lossless rotor (b = 0) passes; a matrix [[0, 1], [1, 0]] fails.
- `gear_identity`: polynomial identity for symbolic r.
- `stiction_monotone` (property, 10⁵ random pairs).
- `composite_leg_passes`; `composite_with_reversed_sign_fails` (a junction with a reversed port breaks skew
  symmetry of J_c).
- `certificates_round_trip`: emitted certificates are accepted by the checker and a one-coefficient change
  is rejected.

### End-to-end script and logging
`scripts/e2e/sinew_passivity.sh` (bead N15b-32) calls `frob actuator check <card> --json` for every catalog
card and the four planted defects, asserts exit 0 or 3 with FROB-REF-130, then runs `frob-verify` on the
emitted certificate bundle. Lines log the card hash, the check names, the certificate hashes and the
refusal payload.

### Known answers and negative controls
KA-293 (the motor-axis structure and its Ḣ, an exact polynomial identity), KA-323 (ideal gear law), KA-294
(every card in the catalog passes). Negative controls: the four planted defects; `mutant-psd-skip-zero-row`
(accepting an indefinite matrix with a zero pivot) is caught by `semidefinite_accepts_zero_pivot`.
Determinism: D0; certificate bytes identical on a second machine.

## Considerations

- The check certifies structure, not parameter truth: a passive card can still be a wrong card.
- State-dependent R (temperature) is checked as a rational function inequality over the card's declared
  temperature range, by its sign at the range ends and monotonicity of the linear law.
- Interconnections with algebraic constraints are deferred in the foundation; a wiring with an algebraic
  loop never reaches this check because the junction step refuses it.
