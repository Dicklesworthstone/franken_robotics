## Background

GATE-SINEW-01 is the first known-answer gate of the actuator subsystem (milestone M1, claim kind Known
answer): **known answers within 1%: stall torque, no-load speed, electrical and mechanical time constants
of a DC motor step, thermal steady-state rise ΔT = P·R_th.** Two mechanism beads supply the models: levels
L0 and L1 (BD-070, which owns the stall-torque, no-load-speed and mechanical-time-constant rows) and level
L2 (BD-071, the electrical time constant and the thermal rise). This bead is the user-side measurement: a
shell script that drives the real `frob` binary on the referee tier, compares each measured value with its
closed form, and writes the gate receipt. A gate is passed only with measured values in a receipt that names
the commit, the hardware fingerprint and the seed; a gate that nothing can fail validates nothing, so the
script also runs the planted defects.

The closed forms, with N the gear ratio, k_t and k_e the torque and back-EMF constants (equal in
power-invariant coordinates), R winding resistance, L inductance, J rotor inertia, η motoring efficiency,
I_max current limit, V_lim voltage limit, P loss power, G thermal conductance (R_th = 1/G):

| Known answer | Closed form |
|---|---|
| Stall torque | η·N·k_t·min(I_max, V_lim/R) |
| No-load speed (joint side) | V_lim/(k_e·N) |
| Electrical time constant | L/R |
| Mechanical time constant | J·R/(k_t·k_e) |
| Constant-resistance thermal rise | P/G |

## Scope

In: the fixtures, the script, the mutant runs, the receipt. Out: the models; the other Sinew gates.

## Technical approach

**Fixtures** (`synthetic`, under `assets/fixtures/sinew/ladder/`, registered so `frob task fixture` can run
them):
- `dc-ref-a`: one revolute joint with card k_t = k_e = 0.05, R = 0.5 Ω, L = 1 mH, J_rotor = 1.0 × 10⁻⁴
  kg·m², N = 10, η = 0.9, I_max = 40 A, V_lim = 24 V, `current_convention: dc`, latency 0, no friction.
  Expected: stall 18.0 N·m; no-load 48 rad/s; electrical 2 ms; mechanical 20 ms (bare rotor).
- `dc-ref-a-12v`: the same with V_lim = 12 V: stall 0.9·10·0.05·24 = 10.8 N·m (voltage-limited).
- `locked-rotor`: R = 1 Ω, L = 10 mH: current rises as (V/R)·(1 − e^(−t/τ)) with τ = 10 ms.
- `thermal-const-r`: single thermal node, α = 0, P = 80 W, G = 0.80 W/K: rise 100 K.

**Script `scripts/e2e/sinew_ladder_referee.sh`** (plain shell, idempotent, seed-explicit, sources the
shared helper of STD-E2E):
1. `frob doctor --json`: record toolchain, pins and the hardware fingerprint.
2. `frob task fixture dc-ref-a --tier referee --actuator-level L1 --measure stall-torque --seed 7 --json`:
   assert 18.0 N·m within 1%.
3. Same fixture, `--measure no-load-speed`: assert 48 rad/s within 1%.
4. Same fixture, `--measure mechanical-time-constant` (a 2 V step, 4 A, below the limit): assert the 63.2%
   time is 20 ms within 1%.
5. `dc-ref-a-12v`, stall: 10.8 N·m within 1%.
6. `frob task fixture dc-ref-a --actuator-level L2 --measure electrical-time-constant`: 2 ms within 1%;
   `locked-rotor`: 10 ms within 1%.
7. `frob task fixture thermal-const-r --actuator-level L2 --measure thermal-rise`: 100 K within 1%.
8. `frob sim run --tier referee dc-ref-a --actuator-level L2 --seed 7 --json` twice: assert identical
   episode digests (determinism lane).
9. Mutants through the conformance harness: `mutant-l1-no-backemf` must fail step 3; `mutant-l2-const-r`
   is inert for step 7 (the fixture has α = 0) and must fail the cold-start row of BD-071 instead, which the
   script calls to prove the control has teeth.
10. Write `target/gates/GATE-SINEW-01.json` with all measured values, thresholds, commit, fingerprint, seed.

**Logging.** NDJSON to `target/e2e-logs/sinew_ladder_referee/<utc-timestamp>.ndjson` and a transcript
beside it. Each line: `ts`, `script`, `bead` ("N15b-29"), `step`, `event` (`start`, `cmd`, `assert`,
`metric`, `refusal`, `end`), the exact command, exit code, wall time, the envelope's `evidence` block
(claim, class, tier, determinism, identities, seed), the measured value with unit and its threshold, digests
where state is compared, and on failure the first differing value and the artifact paths. A final `summary`
line gives assertions passed and failed and names GATE-SINEW-01. Fixtures are synthetic; no private data.

## Acceptance criteria

- [ ] The script exits zero on a clean tree; each of the five known answers is inside 1% and recorded with
  its measured value.
- [ ] The receipt exists and carries measured values, not targets.
- [ ] The two episode digests of step 8 are equal.
- [ ] Each planted mutant is caught and the log shows its first failing assertion.
- [ ] The gate is registered in the conformance registry with its negative controls.
- [ ] The envelope of every step carries class Estimated (generic synthetic card) with the weakest input
  named, tier `referee`, and `reality: no-claim`.

within 1%. Negative controls as in step 9. Determinism lanes: twice on one machine; debug and release

## Considerations

- The mechanical time constant is measured on the bare rotor; with a load inertia J_load the constant
  becomes (J + J_load/N²)·R/(k_t·k_e), and the fixture states which it uses.
- A first-order delay in the driver would bias the time-constant rows; the fixture sets latency to zero and
  a separate unit test covers the delay.
- The script needs only the CPU and belongs to the `smoke` battery.
