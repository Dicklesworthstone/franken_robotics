## Background

After an agent edits a design it needs to know what the edit cost in evidence before it spends compute: which
analyses, kernels, scorecards and episodes of the previous version are still valid, and which must be redone. The
rule that answers this is Phylum's invalidation contract (bead BD-286): a memoized result is reused exactly when the
digest of the fields it read is unchanged, and results are transported along orbits of the observation-preserving
symmetry group. `phylum.reuse` is the read verb that reports the contract's verdict for a given edit: for an edit,
which cached results survive, which are invalidated, and the field that forced each invalidation. It is one of the
seven verbs of the `phylum` cluster, first available at milestone M3.

Why a verb and not a log line: the answer is evidence about evidence. An agent that sees "everything invalidated,
forced by `power_bus.battery`" learns that its edit was global; one that sees "siblings' analyses survive" learns
that a module swap was leaf-local. The verb makes the reason inspectable, in the same envelope as any other answer.

## Scope

In: the verb's input and output schemas, its two modes (preview of an edit not yet applied; report between two
versions), totals, the reuse-ledger figure, refusals, and the end-to-end script of the reuse capability.
Out: the decision procedure and the gate (BD-286); calibration and quarantine (N17b-13); `result.revalidate`, which
applies assumption polarity to verdicts and is another cluster's verb.

## Technical approach

**Kind.** `read`: it changes nothing. In preview mode it evaluates the edit on a scratch copy; it never mints a
design version.

**Input (`frob.phylum.reuse.in/1`).** Either `{ design, edit }` (a design reference and one typed edit with its
arguments, or a patch) or `{ from, to }` (two versions of one lineage); optional `kinds` (a filter over node kinds:
analysis, synthesis, step-plan, kernel, scene, episode, comparison), optional `task`, and pagination fields.

**Output (`frob.phylum.reuse.out/1`).**

```json
{ "edit": {"kind": "swap-module", "path": "/limbs/of/of", "symmetry_effect": "reported"},
  "scope": "leaf-local",
  "survives": [ {"result": "r:…", "kind": "analysis", "name": "workspace:leg-fl",
                 "licence": "dependency", "dep_digest": "b3:…"} ],
  "invalidated": [ {"result": "r:…", "kind": "episode", "forced_by": "/limbs/of/of/chain/1/body/fill",
                    "also": ["/limbs/of/of/chain/1/body/region"], "recompute_cost": {"gpu_s": 1.8}} ],
  "refused": [ {"result": "r:…", "kind": "analysis", "code": "FROB-REF-162", "reason": "dep_digest: absent"} ],
  "orbit": {"group": "C2", "element": "mirror-xz", "address_mapping": "available"},
  "totals": {"by_kind": {"analysis": {"survives": 9, "invalidated": 3, "refused": 0},
                         "episode": {"survives": 0, "invalidated": 64, "refused": 0}}},
  "reuse_ledger": {"column": "exact reuse", "gpu_s_reused": 0.0, "cpu_s_reused": 0.41,
                   "share_of_prior_work": 0.02} }
```

Field rules. `scope` is `none` (nothing changed in any read set), `leaf-local` or `global`, by the substitution
conditions of the design language. `licence` is one of `identity`, `dependency`, `orbit-distributional`,
`orbit-address-mapped`. `forced_by` is the first differing field of the result's read set in canonical path order.
`orbit` is present when the edited design is an image of the original under an element of the
observation-preserving group. `reuse_ledger.column` is always `exact reuse`: the figure is never mixed with
evidence carried forward or with training avoided by warm starts. `survives + invalidated + refused` equals the
number of cached results in scope, per kind. Long lists are paginated and say so; nothing is cut silently.

**Evidence.** `evidence = { class: "Tested", tier: "static", determinism: "exact" }`: the verdicts are exact digest
comparisons, and their soundness rests on the completeness of the read sets, which is tested and shadow-checked,
not proved.

**Refusals and exits.** A result without a dependency digest, or of a quarantined kind, appears under `refused`
with `FROB-REF-162`, and the envelope's exit is 2 (completed with flags). If every result in scope is refused the
verb itself refuses with `FROB-REF-162`, exit 3. An edit that fails its preconditions is refused with the design
language's own code. Exit 0: completed, nothing flagged.

**Example.**

```text
frob phylum reuse --design quad-a --edit swap-module --path /limbs/of/of --to std/leg-3r-qdd-l.fmodule --json
  # illustrative: scope leaf-local; 9 sibling analyses survive; 64 episodes invalidated,
  # forced by the swapped limb's inertia; exact reuse 2% of prior work
```

**Layout.** Executor in `crates/frob-phylum/src/reuse/verb.rs`, registered through `frob-verbs`.

## Acceptance criteria

- [ ] `frob phylum reuse … --json` writes one envelope with the schema above; both modes work; the verb mints no design version and writes nothing but its own ledger read receipt.
- [ ] For each of the five scripted edits below the lists equal the contract's verdicts, and applying the edit and recomputing with memoization off confirms them: every result listed as surviving is byte-equal to its recomputation.
- [ ] `survives + invalidated + refused` equals the cached results in scope for every kind.
- [ ] Each invalidated entry names `forced_by`; the named field is one the edit changed.
- [ ] `FROB-REF-162` appears for an undigested result and for a quarantined kind, with exit 2, or exit 3 when nothing else is in scope.
- [ ] The reuse figure is labelled with its ledger column and matches the ledger's own accounting within rounding.
- [ ] The same call through MCP returns the same envelope.
- [ ] Replaying sequences 0 to 99 of BD-286's equivalence campaign through the verb gives, for every edit, the verdicts the campaign recorded (0 mismatches).
- [ ] Step 5 of N19cx-02's `scripts/e2e/scene_map_address.sh` (the verb on a mirror-swapped pair: per-address results served only at mapped addresses) runs and passes, as step 9 of this bead's script; it is the first bead at which that step can run, since the verb is this bead's and N19cx-02 precedes BD-286.

## Test plan

### Unit tests (`cargo test -p frob-phylum reuse::verb`)

- `preview_changes_nothing`: the lineage head and the ledger's design table are unchanged after a preview.
- `counts_add_up`: on a fixture with 12 analyses and 64 episodes, a leaf swap gives analysis 9 + 3 + 0 and episode 0 + 64 + 0.
- `scope_classification`: rename → `none`; leaf module swap → `leaf-local`; battery swap → `global`; a limb in a closure swapped → `global`.
- `forced_by_names_changed_field`: for a shell-thickness edit every invalidated episode's `forced_by` lies under the edited body.
- `orbit_block_present_only_under_gamma_obs`: a mirror swap on a symmetric design fills `orbit`; the same swap with a front-only sensor mounted off-axis does not.
- `refused_162_paths`: one undigested analysis → listed under `refused`, exit 2; all results undigested → exit 3.
- `ledger_column_fixed`: the serialized output never carries another column name.
- `from_to_equals_preview`: reporting between two stored versions equals the preview of the edit that separates them.
- `pagination_pinned_to_frontier`: 1,000 cached episodes at page size 100 → ten pages under one committed frontier; an episode stored between pages 3 and 4 appears on no page; the union of the pages equals the unpaginated answer and the totals are those of the frontier.
- `kinds_filter`: `kinds = [analysis]` lists analyses only and the totals carry only the `analysis` row; an unknown kind name is the schema refusal `FROB-REF-802`, exit 3.

### End-to-end script and logging

`scripts/e2e/phylum_reuse.sh` sources the helper of `STD-E2E` and writes
`target/e2e-logs/phylum_reuse/<utc>.ndjson` with a transcript. Setup: `frob design check quad-mod --json`, three
analyses, and `frob phylum sweep --designs quad-mod --worlds-per-design 64 --task flat-stand --tier batch-cpu
--seed 5 --key reuse-<run>-setup --json` to populate the cache. Then five edits, each first previewed with `frob
phylum reuse --design <d> --edit <edit…>`, then applied with `frob design edit <d> <edit…> --key
reuse-<run>-<step>-edit --json` and recomputed with registered inputs only: the analyses with `frob design show
<d′> --products --no-memo --json` (`design.show`'s input), the episodes with `frob sim run --tier batch-cpu
--designs <d′> --worlds-per-design 64 --task flat-stand --steps <n> --seed 5 --key reuse-<run>-<step>-solo --json`
on the setup's addresses (the task is the setup sweep's, since the world addresses and the environment depend on it). `design.edit` is a `mutate` verb and the other two run verbs: every call carries its own key (`<run>`
names this invocation; a call without one is `FROB-REF-805`) and every envelope must show `idempotent_replay:
false`, since a replayed run would present a stored result as a recomputation:

1. `rename` of a body: expect everything to survive.
2. `swap-module` of one leg: expect sibling analyses to survive and all episodes invalidated.
3. `swap-battery`: expect every electrical and thermal analysis and every episode invalidated.
4. `mirror` swap under the sagittal mirror: expect distributional results reused and per-address results reused
   after mapping.
5. `set-param` followed by its inverse: expect zero evaluations after the pair.
6. `frob phylum reuse --design @fixture:quad-undigested --edit @fixture:edit-on-undigested-result --json`, N17-REF's
   fixture pair, in which the cached analysis was stored without a dependency digest: expect exit 3 with
   `FROB-REF-162`, as N17-REF's row states, logged as a `refusal` event with the whole block (the exit-2 case, an
   undigested result beside others in scope, is `refused_162_paths` and step 7).
7. Quarantined kind through the verb (the command-line half of N17b-13's calibration, which that bead asserts
   in-process because this verb depends on it): with the test feature that alters one cached analysis node, repeat
   `frob design check quad-mod --json` until a shadow fires (at most 64 repeats), then `frob phylum reuse --design quad-mod
   --edit @fixture:rename-body --json`: every cached result of the latched kind is under `refused` with `FROB-REF-162`,
   `pointer` naming the kind and the mismatch record; exit 2, logged as a `refusal` event.
8. Replay of the gate campaign through the verb: sequences 0 to 99 of BD-286's equivalence campaign, edit by edit,
   each edit previewed with `frob phylum reuse --design <current version> --edit <edit> --json` and then applied
   with `frob design edit <current version> <edit> --key reuse-<run>-camp-<seq>-<i> --json`; every verdict (survives with its licence, invalidated with `forced_by`, refused) must equal the verdict
   the campaign recorded for the same seed and edit index in `target/reuse_campaign/verdicts.ndjson`. On a
   mismatch the log carries the seed, edit index, result, both verdicts and the saved sequence's path.
9. N19cx-02's `scripts/e2e/scene_map_address.sh` step 5 (`frob phylum reuse` on a mirror-swapped design pair:
   per-address results served at mapped addresses only), which that script skips until this verb exists, is run
   as a stage of this script and must pass; its log lines are carried under this script's `step` 9.

Each command is a `cmd` event with the exact command line, exit code, wall time and the `evidence` block; each
comparison is an `assert` event with the digests of the surviving result and of its recomputation and, on failure,
the first differing result, its kind, the `forced_by` the verb reported and the artifact paths; `metric` events
give counts per kind and the reused share with its ledger column. The `summary` lists assertions passed and failed;
the gate itself is recorded by BD-286 from its script's receipt.

### Known answers and negative controls

- KA-377 (mirror swap: distributional results reused; per-address after mapping) and KA-379 (controls of the contract) are exercised through the verb.
- Negative controls: a planted verdict that lists a mass-edited episode as surviving must be caught by the recomputation comparison; a planted omission of one cached result from all three lists must fail `counts_add_up`; a reuse figure printed without its column name must be refused by the report builder.
- Metamorphic relation MR-10: an edit followed by its inverse restores every verdict with zero evaluations; an edit to a field the mission does not read keeps every result.
- Determinism lanes: the verb's output is byte-identical run to run and across platforms (class D0).

## Considerations

- The verb reports; it does not decide what to rerun. Scheduling the reruns and pricing them is the revalidation verb's job, which consumes the same verdicts.
- A long campaign can hold many cached results per design; the output is paginated against a committed frontier so that two pages describe one state.
- The reused share will usually be small after any edit that touches mass or geometry. The verb prints that number plainly; a large number appears only for edits the mission does not read.
- Results derived from private scenes are listed by identifier only.
