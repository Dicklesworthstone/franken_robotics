## Background

GATE-TRAC-01 (claim: Known answer; TARGET) says: every row of the Traction known-answer battery that tests a Solid
mechanism passes on the `strict` profile and on `batch-cpu`, and on the `referee` **for the rows FrankenSim's solve
can express, with the list recorded with the gate**; rows for the fast law pass on GPU tiers within the stated
creep. The gate is split over three beads by tier: this bead owns the referee rows at M1, BD-161 the `strict` rows
at M2, BD-168 the batched rows at M2.

The referee cannot run every row, because the sibling solve it wraps has stated limits: at most 21 contacts per
solve, no spin (torsional) component in its friction cone as this project specifies it, signed-distance and mesh
pairs refused by `fs-query` as `MissingCapability`, and fixed witnesses inside one call. A known-answer battery that
silently skipped the rows the referee cannot run would report a pass that means less than it says. The rule here is
therefore that the list of expressible rows is itself an output: each row is either run and compared, or recorded
as `not-expressible` with the limit that prevents it and the tier that carries it instead.

A known answer is a case whose truth is derived by hand or in closed form; the oracle is pinned and never
regenerated from the candidate implementation.

## Scope

In: fixtures, closed-form oracles and tolerances for the referee rows below; the expressibility list written to
`registries/gates.toml` beside GATE-TRAC-01; the per-row negative controls.

Out: the thin-barrier and sill fixtures (BD-086, GATE-TRAC-06); joint stiction and backlash rows on the referee
(BD-084); the same rows on `strict` (BD-161) and on batched tiers (BD-168); rows of wheels, tracks, soil and
tyres (the unit that owns those laws).

## Technical approach

Fixtures live in `crates/frob-conformance/src/batteries/traction_referee/`; each is a `.fbot`/scene pair built from
primitives and planes, run through `sim.run --tier referee` under the transactional step. g = 9.81 m/s².

**Rows run on the referee (the initial list, DESIGN; the measured list replaces it).**

| KA | Fixture (parameters are DESIGN defaults) | Truth | Tolerance |
|---|---|---|---|
| KA-387 Block on an incline | 1 kg box, μ = 0.5, incline angle α swept over tan α ∈ {0.45, 0.48, 0.495, 0.505, 0.52, 0.55}; 2 s each | Stays if tan α < μ, slides if tan α > μ; under exact Coulomb the creep below threshold is zero | Measured threshold (bisection on α) within 1% of μ |
| KA-388 Sphere rolling down an incline | Uniform sphere r = 0.1 m, α = 10°, μ = 0.5 (no slip since tan α < 3.5·μ) | Centre acceleration (5/7)·g·sin α = 1.2168 m/s² | 0.5% (TARGET set here; the register says "to set") |
| KA-389 Disk rolling on a plane | Disk r = 0.1 m rolling at ω = 5 rad/s, then a constant-curvature turn | v = ω·r; the path equals Δp = v·Δt·sinc(δ/2)·(cos(θ + δ/2), sin(θ + δ/2)), δ = ω_yaw·Δt, sinc(0) = 1 | v = ω·r within 0.1%; path within 0.1% of arc length |
| KA-392 Dropped body, inelastic law | Box from 0.5 m, restitution 0 | Total mechanical energy never increases | Exact in sign (slack 10⁻⁹ J for round-off) |
| KA-395 Ring on a cone | A rigid ring resting on a cone whose surface makes angle α with the horizontal; μ = 0.4; tan α ∈ {0.38, 0.42} | Slides if and only if tan α > μ | Verdict exact at both angles |
| KA-396 Painlevé rod | Uniform rod sliding on a rough plane, μ = 1.5, inclination tan θ = 2 (the paradox region μ > (tan²θ + 4)/(3·tan θ), whose minimum is 4/3 at tan θ = 2) | The referee reports the indeterminate configuration (`FROB-REF-224`, exit code 3) and returns no number | Verdict exact |

The independent rolling formula lives in `frob-conformance`; `fs-mbd::planar_drive` is not used as an oracle (a
near-straight integration defect is reported there; it becomes an oracle only after its admission test passes).

**Rows recorded as `not-expressible` on the referee (initial list, each with its reason and carrier).**

| Row | Why the referee cannot express it | Carried by |
|---|---|---|
| KA-391 Box stack, ten high | About four contacts per interface gives roughly 40 contacts in one island, above the cap of 21 | `strict`, lockstep |
| KA-393 Capsule against a spherical distance field | Signed-distance pairs are `MissingCapability` in `fs-query` | `strict`, lockstep |
| KA-394 Mecanum base sideways | Needs the anisotropic friction ellipse of this project's cone | `strict`, lockstep |
| KA-397, KA-399, KA-400, KA-401 Spin and coupled sliding rows | Need the four-dimensional cone (spin component) | `strict`, lockstep (BD-154) |
| Film, soil, tyre, capacity-bias rows | Laws that exist only on our tiers | Their own beads |

**Procedure per row.** (1) Build the fixture. (2) Attempt it on the referee. (3) If it commits, compare with the
oracle and record `pass` or `fail` with the measured value. (4) If the referee refuses, record `not-expressible`
with the refusal code and upstream reason; a row in the "run" table that refuses is a finding, not a silent move to
the other table. (5) Write the list to the gate record: `expressible = [...]`, `not_expressible = [{ka, reason,
carrier}]`.

Outputs carry claim Known answer, class `Tested`, tier `referee`, determinism D2 on one platform.

## Acceptance criteria

- [ ] Every row of the first table passes on the referee with its measured value recorded against the tolerance (the seed done-condition: the referee rows of GATE-TRAC-01).
- [ ] The expressibility list is stored beside GATE-TRAC-01 in `registries/gates.toml`, and every `not-expressible` entry names a refusal code or a missing capability and its carrier tier.
- [ ] KA-396 returns `FROB-REF-224` and no trajectory; a mutant solver that returns one of the distinct motions fails the row.
- [ ] The endpoint-only mutant and the "skip silently" mutant (a row dropped from the list without a reason) are both caught.
- [ ] The battery runs as `frob eval run --battery fixtures --tier referee --json` (or its registered equivalent) and under `cargo test -p frob-conformance traction_referee`.
- [ ] The gate record carries measured values, the commit, the hardware fingerprint and the seed, not the targets.

## Test plan

### Unit tests
- `ka387_incline_threshold`: bisection over α to the stay/slide boundary; asserts |tan α* − 0.5| ≤ 0.005 and zero net displacement at tan α = 0.45 over 2 s (below 10⁻⁹ m).
- `ka388_sphere_incline`: fits acceleration over 1 s; asserts within 0.5% of 1.2168 m/s² and no slip (|v − ω·r| ≤ 10⁻⁶ m/s).
- `ka389_disk_rolling`: asserts |v − ω·r|/v ≤ 10⁻³ and the half-turn chord (0, 2/π) m for unit speed through a half turn from θ = 0.
- `ka392_drop_energy`: asserts E never increases after release.
- `ka395_ring_on_cone`: two angles, two verdicts.
- `ka396_painleve_indeterminate`: asserts refusal code 224 and an empty trajectory.
- `expressibility_list_complete`: every Solid row of the Traction registry (N18-KA) appears in exactly one of the two lists.

### End-to-end script and logging
`scripts/e2e/traction_referee.sh` (bead N18a-35), step `battery`: runs the battery through the `frob` binary, one
`assert` event per row with the KA number, measured value, unit, truth, tolerance and verdict; one `refusal` event
per `not-expressible` row with code and upstream reason; a `metric` event with the two list lengths. NDJSON under
`target/e2e-logs/traction_referee/`, with the evidence block and run digest on every line and the fixture path on
failure.

### Known answers and negative controls
KA-387, KA-388, KA-389, KA-392, KA-395, KA-396 with the values above. Negative controls: a solver that returns a
number for the Painlevé rod; an incline run with friction disabled (must slide at every angle and fail KA-387);
`planar_drive` used as the oracle on the near-straight case (heading 32 rad, wheel speeds 1 and 1 + 6·10⁻¹³ m/s,
track 0.5 m, 400 steps of 1/400 s, truth about (0.8342, 0.5514) m) must be rejected as an oracle until admitted.
Metamorphic: rotating the whole fixture about the vertical leaves every verdict unchanged. Determinism: twice on
one machine with equal digests; debug and release.

## Considerations

- The expressible list grows when upstream items land (FD-FSIM-03 for distance-field pairs, FD-FSIM-13 for capacity); the switch-over rule is to re-run this battery and re-record the list.
- KA-388 and KA-389 move the material witness continuously; on the referee they rely on witness migration between calls (BD-093). If the sibling's fixed-witness gate still refuses, the row is recorded `not-expressible` and `strict` carries it.
- The 0.5% tolerance of KA-388 is set by this bead because the register leaves it open; it is recorded as a TARGET with the measured error.
- Risk: a battery that passes because fixtures are easy. Each row therefore has a mutation that must fail.
