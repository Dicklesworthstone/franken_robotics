## Background

A robot's collision primitives are fitted from its link Regions by the model compiler with a recorded fitting
error, or authored. The Solid set is spheres, capsules, boxes, cylinders and rounded boxes; **convex hulls are
Frontier**. A hull is funded only if its pilot (N18a-07) shows that a fixed-iteration support-map descent gives a
gap inside the error budget at an acceptable cost and that hulls reduce fitting error where primitives do not
suffice. This bead is the mechanism on that branch. If the pilot is falsified, this bead is closed as not funded
and primitive unions remain the only moving geometry.

Decision context (ADR-TRAC-01): moving geometry stays a union of convex pieces so that pair tests have fixed
shapes; a hull keeps that property only because its vertex count is capped and its iteration count is a literal.

## Scope

In: the hull primitive type (capped vertex list, support map); fitting in the model compiler with recorded error;
the pair routines hull–hull and hull–primitive in `K-np-prim` with the certified residual; sample spheres on hulls
for static contact; parity with `fs-query`. Out: non-convex meshes for moving bodies (not offered); the pilot.

## Technical approach

1. **Type.** `Hull { vertices: [Point3; V_MAX], count }` with V_MAX from the pilot (at most 32); the unused slots
   repeat the last vertex so a support scan over V_MAX is exact without a mask.
2. **Fitting.** The model compiler computes the convex hull of a link Region's surface samples, simplifies it to
   at most V_MAX vertices by removing the vertex whose removal changes the hull least, inflates it so the Region
   stays inside (outer fit), and records the fitting error (largest distance from the hull surface to the Region
   surface). The error enters ε_g as the fitting term.
3. **Pair routine.** Frank–Wolfe on the Minkowski difference for exactly N iterations (N from the pilot), with
   selects and no early exit; output: gap, normal, witness points, and the duality-gap residual, which enters ε_g
   as the routine term. Hull against sphere, capsule or box reuses the same loop with the other shape's analytic
   support map.
4. **Samples.** For contact with the static field a hull carries sample spheres at its vertices (radius zero plus
   the inflation) or at curvature-chosen points, like any primitive.
5. **Kernels.** The routines are added to `K-np-prim` as new type-pair entries; the kernel's manifest declares N
   and V_MAX as resource bounds, and they are part of the step-plan identity. Class `float`, determinism D2.
6. **Parity.** Hull pair distances are compared with the hull oracle on 10⁶ random pairs: within the reported
   residual in every case, and within 10⁻⁹ m in `f64` when N is raised until the residual is below that (the parity
   lane). The oracle is `fs-query` where it has hull support maps; at the pinned commit it does not (upstream work
   item FD-FSIM-03, interim posture "parity only where both apply"), so until FD-FSIM-03 lands the oracle is the
   independent `frob-conformance` reference admitted by the pilot N18a-07 (Frank–Wolfe with away steps on the
   Minkowski-difference vertices to a certified duality gap below 10⁻¹² m in `f64`), and the record of GATE-TRAC-02
   names which oracle was used.

## Acceptance criteria

- [ ] On 10⁶ random hull pairs the true error against the hull oracle (`fs-query` once FD-FSIM-03 has landed, the independent `frob-conformance` reference before) never exceeds the reported residual, and the parity lane meets 10⁻⁹ m in `f64` (the extension of GATE-TRAC-02 to hulls); the gate record names the oracle.
- [ ] Fitted hulls contain their Regions; the recorded fitting error is at least the true surface deviation on 10³ random Regions.
- [ ] A model using hulls compiles, runs on `batch-cpu` and on devices, and its digests are independent of slot and co-tenants.
- [ ] `contact.probe` reports the routine residual and fitting term separately for a hull contact.
- [ ] The pilot's verdict and numbers are cited in the bead's close reason.

## Test plan

### Unit tests
- `hull_support_scan_padding_exact`: a hull with 5 real vertices padded to V_MAX gives the same support as the unpadded scan.
- `hull_fit_contains_region`, `hull_fit_error_recorded`.
- `hull_pair_vs_oracle`: 10⁶ pairs; residual bounds error.
- `hull_cube_cube_gap`: unit cubes 3 m apart give 2 m.
- `hull_vertex_cap_enforced`: a Region needing more than V_MAX vertices is simplified, and the added error is recorded.
- `hull_static_shape`: operation count is a function of N and V_MAX.

### End-to-end script and logging
`scripts/e2e/traction_cone_rows.sh` gains a step `hull_pairs` (script of N18a-36, a dependency): `frob spark check
--kernel K-np-prim --backend <batch-cpu|gpu-cuda:0|gpu-metal> --reference batch-cpu --seed 0 --key hull-<backend>
--json` with the hull type pairs on `batch-cpu` and each device (a device step whose device is absent is logged
with `e2e_skip`, never as a pass;
`spark.check` is a run verb, so each call carries its own key); `FROB_TEST_SEED=0 cargo test -p frob-contact --test
hull_pairs` for the 10⁶-pair oracle comparison; and `frob contact probe` on a hull–box contact of the fixture model,
asserting that the routine residual and the fitting term are reported separately. Logged per STD-E2E (the shared
helper, `bead` field `N18a-08`): the exact command lines, exit codes, wall time, the evidence block, `max_error_m`,
`max_residual_m`, the assertion error ≤ residual, the oracle used, kernel identity, N and V_MAX, and the first
violating pair with its pose on failure.

### Known answers and negative controls
KA-425 extended to hulls. Negative controls: an inner fit (hull inside the Region) must fail containment; a
residual that omits the duality gap must fail the bound test.

## Considerations

- Cost: a hull pair costs several box–box tests; hulls should be used where they remove primitives, and `sim.estimate` must account for them.
- If FD-FSIM-03 lands, re-run the parity lane against the sibling's hull support maps.
- Kill gate KILL-HULL (the row N40-24 introduces by amendment, since the plan names none for hulls; the pilot N18a-07 names it in its record): trigger, the pilot's falsifier holds, or this bead's parity lane fails after one repair cycle; fallback, primitive unions with their recorded fitting error, which returns the item to "not offered". This bead is fundable only while `fundable --bead N18a-08` answers `Fundable` (N38a-09).
