## Background

A contact is more than a gap. It carries a **witness pair** (one point on each body, in body coordinates), a
**contact frame**, and **tangential memory**: the stick anchor of a regularized law, the accumulated tangential
displacement, and the warm-start impulse. FACT: FrankenSim's sustained contact step assumes the witnesses and the
frame are fixed ("Body pairs retain their ORIGINAL material witnesses and fixed contact frame") and refuses
tangentially separating witnesses. A wheel rolling over a lip, a sliding sole and a foot rocking heel to toe all
violate that assumption. The posture until the sibling gains a moving-surface owner (upstream work item
FD-FSIM-12) is that `frob-contact` migrates witnesses between calls, so each call sees an interval short enough
that its witnesses are fixed.

The danger is silent carry-over. If tangential memory stays attached to a contact whose feature changed (the
wheel's contact moved from the flat to the lip), the stored anchor and impulse point along a direction that no
longer lies in the tangent plane, and a couple appears that the contact forces do not explain. The invariant
(INV-TRAC-06): **tangential memory is transported or reset at every witness change, and each reset is an event.**

This bead is the migration algorithm as a pure function with its data types. Its wiring into the transaction
(after an event, redetect and migrate) and the energy-ledger closure are BD-093; its fixture is the sharp sill
(BD-086).

## Scope

In: the contact-memory types; contact matching across redetections; the four-step migration; the event record;
the tolerances (δ_w and the largest transported rotation) as parameters with their fail-closed defaults;
property tests.

Out: transaction wiring (BD-093); the sill fixture (BD-086); the experiment that decides the two tolerances on
that fixture and writes the constants (OPEN-TRAC-5: N18b-38, which depends on this bead); friction laws that
read the memory (N18a-16 and the law beads); migration inside FrankenSim (FD-FSIM-12).

## Technical approach

```rust
// DESIGN
pub struct ContactMemory {
    pub id: ContactId,                                   // stable across redetections of the same pairing
    pub witnesses: (Point3<BodyA>, Point3<BodyB>),
    pub features: (FeatureId, FeatureId),
    pub frame: ContactFrame,                             // normal and two tangents, world
    pub anchor: Option<Vector2<Tangent>>,                // stick anchor of a regularized law
    pub slip: Vector2<Tangent>,                          // accumulated tangential displacement
    pub warm_start: Impulse4,                            // normal, two tangential, spin
    pub film_h: Option<Metres>,                          // per-contact film thickness, when the film law is on
}
pub enum WitnessChange { SameFeature, AdjacentFeature, NewContact }
pub struct WitnessReset { pub id: ContactId, pub from: (FeatureId, FeatureId), pub to: (FeatureId, FeatureId),
                          pub reason: ResetReason }      // NewContact | PointJumped | RotationTooLarge | Antiparallel
```

**Matching.** A redetected hit is matched to an existing memory by the pairing (body pair, primitive or sample
identifiers). Unmatched hits are new contacts; unmatched memories are released.

**Migration, at every redetection.**
1. **Re-localize** the witnesses by closest features, with one consistent world contact point at touching (both
   witnesses map to the same world point when the gap is zero).
2. **Classify** the change as `same-feature`, `adjacent-feature` (face to edge to face around a lip; edge to
   vertex) or `new-contact`, by comparing the stable feature identifiers and the primitive's feature adjacency.
3. **Keep** the tangential memory on the same feature. For an adjacent feature whose world contact point moved
   continuously (the displacement of the world contact point between redetections is inside a tolerance δ_w),
   **transport** it: rotate it by the minimal rotation that takes the old normal n₀ to the new normal n₁ (the
   rotation about n₀ × n₁ by the angle between them) and project the result onto the new tangent plane.
4. For a new contact, or when the contact point jumped (displacement above δ_w), or when the normal turned by
   more than the largest transported rotation, **reset** the tangential memory to zero and emit a `witness-reset`
   event.

A law with no anchor (exact Coulomb) transports warm starts only. Film thickness, where present, is kept on
`same-feature` and `adjacent-feature` within one patch and reset when the sample leaves the patch.

**Tolerances (OPEN-TRAC-5).** δ_w: default the sample radius. Largest normal rotation transported: default 30°.
They are decided on the sill fixture at M1; the fail-closed default for anything outside them is reset with an
event. Antiparallel normals (n₀ = −n₁) have no minimal rotation and always reset, whatever the rotation limit,
with their own reason `Antiparallel`. The four reasons are the four causes of a reset, tested in this order so
that each reset has one reason: a new contact, a jump of the contact point, antiparallel normals, a rotation
above the limit. A law without an anchor
is not a cause: it has no anchor to reset, and its warm start is transported or reset by the same four tests.

**Properties of transport.** It preserves the norm of the transported vector up to round-off (a rotation followed
by a projection of an already tangent vector); it is the identity when n₁ = n₀; composing the transport from n₀ to
n₁ with the transport from n₁ to n₀ returns the original vector.

**Record.** Every migration writes the change class; every reset writes a `WitnessReset` event into the episode's
event stream. The whole `ContactMemory` set is part of the restore set of the transaction, so a retried interval
equals a first attempt.

## Acceptance criteria

- [ ] INV-TRAC-06 as a property test: over 10⁵ random redetection sequences no tangential memory survives a feature change without a transport or a reset, and the number of resets equals the number of `witness-reset` events.
- [ ] Transport preserves norm to 10⁻¹² relative and is the identity for an unchanged normal.
- [ ] A contact point that jumps by more than δ_w, a normal that turns by more than the limit, and antiparallel normals each reset with the right reason.
- [ ] At touching, the two re-localized witnesses map to one world point within ε_g.
- [ ] The `keep-memory` mutant (memory copied across a feature change) is caught by the property test.
- [ ] With an anchor-free law, anchors are never written and only warm starts are transported.
- [ ] Contact memory round-trips through a checkpoint: restore then migrate equals migrate without the checkpoint.

## Test plan

### Unit tests
- `transport_norm_and_identity`: random n₀, n₁ within 30°, random tangent vectors.
- `transport_round_trip`: n₀ → n₁ → n₀ returns the vector to 10⁻¹².
- `transport_face_edge_face_lip`: a 90° lip crossed in six 15° transports, as when the normal of an edge contact turns continuously while a wheel pivots on the lip; the anchor ends in the top face's tangent plane with unchanged norm and no reset.
- `classify_same_adjacent_new`: a box corner sequence face → edge → vertex → other face.
- `reset_on_jump`, `reset_on_large_rotation` (31° with the default limit), `reset_on_antiparallel`.
- `reset_emits_event_exactly_once`.
- `relocalize_single_world_point_at_touching`.
- `no_anchor_law_transports_warm_start_only`.
- `memory_checkpoint_round_trip`.
- `keep_memory_mutant_detected`.

### End-to-end script and logging
`scripts/e2e/traction_referee.sh` (bead N18a-35), step `sill`: the torque-driven wheel over a sharp sill. Logged
per STD-E2E: the feature sequence (expected flat, edge, top), change classes, the count of `witness-reset` events,
`max_couple_nm` against 10⁻⁹, and the event-sequence digest.

### Known answers and negative controls
KA-409 (the sill: sequence flat, edge, top; work and impulse within 1% at h/4; no couple above 10⁻⁹ N·m in `f64`).
Hand case: a tangent vector (1, 0, 0) on a floor with normal +z, transported to a wall with normal +x through
90°, would become (0, 0, −1); with the default 30° limit a single 90° change is reset instead, and the vector is
carried only by a sequence of transports of at most 30° each, which is what a continuously turning edge normal
produces. Negative control: counterexample CX-183 (memory kept on a changed feature).
Metamorphic: rotating the whole scene leaves change classes and reset counts unchanged.

## Considerations

- Resets are safe and lossy: a reset discards stick history and can release a contact that was sticking; counting them per run shows whether the tolerances are too tight.
- INT-FSIM-07 at the pin: the flat-to-edge-to-top transition returns the sibling's typed refusal without migration, and completes under migration with the energy ledger closed to its stated residual.
- When FD-FSIM-12 lands, re-baseline the fidelity ledger once; this function stays as the `strict` profile's own migration.
- RISK-24 and RISK-31: the fixed-witness limit is a foundation fact relied on only after its admission test records it.
