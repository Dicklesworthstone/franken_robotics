## Background

Terrain is modelled by tier of fidelity:

| Ground | Model | Tier |
|---|---|---|
| Rigid floor with a friction map (tile, concrete, wood, wet patch, grease) | The default compliant law with per-texel interface cards; the film law where the card carries a film | Solid |
| Compliant coverings (carpet, mats) | The default law with covering stiffness and a rolling-resistance row | Solid |
| Soft soil under wheels and tracks | Bekker–Wong pressure–sinkage and Janosi–Hanamoto shear | Frontier |
| Granular media under legs | Resistive force theory | Frontier |
| Terrain that deforms and stays deformed | Rut and footprint fields | Moonshot |

This bead builds the soft-soil row as **laws and cards**: pure functions that map a soil card and a contact
state to sinkage, shear stress and thrust, with the card's validity ranges enforced. They are the evaluators
behind the read verb `contact.soil` and the functions the step calls (N18b-13). Keeping the laws as pure,
host-testable functions separate from the solve is what lets the law-evaluation rows of the soil gate be exact
arithmetic (10⁻⁶ in `f64`) while the simulated rows carry a 2% tolerance.

The laws are semi-empirical; their parameters come from soil cards, and a soil card declares the ranges of
pressure, slip and sinkage over which it holds. A query outside them is refused (`FROB-REF-243`), because a
power law extrapolated beyond its fitted range returns a confident number with no support. The values a gate
pins are derived on file from a cited soil table read at its primary source; no value is taken from a script
that is not in the repository. Funded only after the pilot N18b-11.

## Technical approach

**Soil card (DESIGN).** A `.fcard` of kind `soil`, immutable, content-addressed, each field with provenance
(`measured`, `datasheet` with citation, `assumed`) and uncertainty:

```rust
// DESIGN sketch
pub struct SoilCard {
    pub k_c: Qty,        // cohesive modulus of deformation, units Pa/m^(n-1)
    pub k_phi: Qty,      // frictional modulus of deformation, units Pa/m^n
    pub n: Ratio,        // sinkage exponent, > 0
    pub c: Pressure,     // cohesion, Pa
    pub phi: Angle,      // angle of internal shearing resistance
    pub k_shear: Length, // shear deformation modulus K, m
    pub valid: SoilValidity, // ranges: pressure [p_min, p_max], slip [i_min, i_max], sinkage [0, z_max]
    pub z_eps: Length,   // numerical: linearization depth for n < 1, reported
}
```

Load-time checks: n > 0, K > 0, c ≥ 0, 0 ≤ φ < 90°, k_c/b + k_φ > 0 for every admitted width; a violation
refuses the card and names the field.

**Evaluators (pure functions, `f64` on the host and `f32` in kernels, typed quantities).**

1. *Pressure–sinkage.* p = (k_c/b + k_φ)·zⁿ for a contact of width b (the smaller dimension of the contact
   patch). Inverse: z = (p/(k_c/b + k_φ))^(1/n). `sinkage(card, b, p) -> z`; `pressure(card, b, z) -> p`.
2. *Shear.* τ = (c + σ·tan φ)·(1 − exp(−j/K)) for shear displacement j ≥ 0 under normal stress σ.
   `shear(card, sigma, j) -> tau`. Limits: j = 0 gives 0; j → ∞ gives c + σ·tan φ.
3. *Track thrust.* For a track of length L and ground area A under weight W at slip i, with j = i·x along the
   track and uniform pressure, F = (A·c + W·tan φ)·(1 − (K/(i·L))·(1 − exp(−i·L/K))).
   `thrust(card, A, L, W, i) -> F`. For i·L/K below 10⁻⁴ the factor is evaluated by its series
   x/2 − x²/6 + x³/24 with x = i·L/K to avoid cancellation.
4. *Quadrature form* (used by wheels and by non-uniform pressure): F = Σ_k A_k·(c + σ_k·tan φ)·(1 −
   exp(−j_k/K)) over patch stations with their own areas, stresses and shear displacements. For a wheel, the
   stations are its tested rim samples and j_k is the shear displacement accumulated by each sample while in
   contact; no separate wheel closed form is used, so the verb and the step share one code path.

The exponentials and the power use the deterministic elementary functions of the kernel dialect on devices (no
built-in transcendental); the host reference uses `f64` and is the oracle for the 10⁻⁶ rows.

**Validity and the refusal.** Every evaluator checks its arguments against the card's validity block: pressure
(or σ), slip and sinkage. Outside any range: `FROB-REF-243`, "Soil or tyre law out of range", exit code 3,
`pointer` to the quantity, `observed` and `required` with units, `retry` = `after-change`, ranked repairs:
(1) another card; (2) the rigid-floor model. The check is strict in both the verb and the step: inside a run
an out-of-range contact marks the world's result `out-of-domain` for the soil law and the envelope counts such
worlds; under the `refuse` policy the run refuses.

**Regime report.** Each evaluation returns, beside its value, the position of the state within the card's
ranges (fractions of p_max, i_max, z_max) and the card's provenance class, so a consumer can see how close to
the edge of validity a result sits. Outputs are classed `Estimated` (semi-empirical law), and `Estimated` with
weakest input "card" when a field is `assumed`.

**Module layout (DESIGN).** `crates/frob-contact/src/soil/{card.rs, laws.rs, validity.rs}`; derivations in
`docs/derivations/soil-laws.md` (the thrust integral ∫₀ᴸ (1 − e^(−i·x/K)) dx = L − (K/i)·(1 − e^(−i·L/K))).

## Considerations

- Uniform pressure under a track is an assumption of the closed-form thrust; the quadrature form removes it and
  is what the step uses.
- For n < 1 the tangent stiffness is unbounded at zero sinkage; `z_eps` is a numerical parameter, reported, and
  its effect was measured by the pilot.
- Slip-sinkage (additional sinkage caused by slip) and multi-pass effects are not in the specification and are
  not built; repeated passes belong to the rut Moonshot.
- A later planning model for one soft-soil regime reads the soil card and its declared ranges as its own
  admission data; the validity block is therefore part of a contract with another subsystem.
