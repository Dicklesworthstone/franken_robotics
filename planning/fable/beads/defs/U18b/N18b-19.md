## Background

The soft-ground capability has three faces an agent uses: a read verb that predicts sinkage and thrust on a
soil card before any simulation (`contact.soil`); a simulation in which wheels and tracks actually sink and
pull on a soil region; and the evidence that says the model is Frontier, semi-empirical and, on generic cards,
`Estimated`. If the soft-soil kill gate fired, the same commands must still work and must say plainly that a
rigid fallback is in force and that results are exploratory.

This bead is the end-to-end script for that capability. It drives the real `frob` binary on real fixtures and
writes a structured log. It passes in both worlds (soil kept, soil fallen back) and fails only if the system
misreports which world it is in or misses a known answer it claims.

## Scope

In: one shell script with stages (`laws`, `verb`, `refusal`, `plate`, `drawbar`, `ruts`, `fallback`, `gate`),
its fixtures and log. The stages `laws`, `verb`, `refusal`, `plate` and `drawbar` run the scripts that the
mechanism beads own (`soil_laws.sh` of N18b-12, `soil_verb.sh` of BD-366, `soil_step.sh` of N18b-13), so each
mechanism was verified from the command line when it landed and this script adds the mode (kept or fallback),
the terrain-reset check, the fallback and the gate record read in both modes. The `ruts` stage exposes a hook
for `ruts.sh` of N18b-17: the rut field is a Moonshot at priority 4, which this bead does not wait on; N18b-17
depends on this bead and turns that branch on when it lands. Out: the mechanisms and the gate record (BD-366 and
its dependencies); the tracks-on-rubble scenario script (NS-08) and the capability script that runs it
(N18b-09).

## Technical approach

**Script.** `scripts/e2e/contact_soil.sh`, plain shell, sourcing the shared helper of the end-to-end harness;
`--stage` selects stages; idempotent with explicit idempotency keys; `SEED` explicit (default 1337); non-zero
exit on failure after the summary line. The script first reads the KILL-SOIL decision entry in force from
`registries/gates.toml` and sets the mode from its outcome (N40-03's closed set): `not-fired` → `MODE=kept`;
`fired` or `not-reached` → `MODE=fallback`; `deferred`, or no entry in force, stops the script with a named
error before any stage (the mode is undecided). Assertions that depend on the mode say so in the log.

**Fixtures.** Public synthetic: soil cards `cards/e2e/soil-a.fcard` (k_c = 1 kPa/mⁿ⁻¹, k_φ = 1,500 kPa/mⁿ,
n = 1.1, c = 1 kPa, φ = 30°, K = 25 mm; all fields `assumed`) and `soil-b.fcard` (k_c = 0.41 kN/m^1.5,
k_φ = 21.6 kN/m^2.5, n = 0.5), each with a validity block, delivered by N18b-12; the plate and drawbar fixtures
of N18b-13's script; the fallback tow fixture `traction/kill_soil_tow` of N18b-18's script; owned here: the
conformance fixture `traction/soil_reset` (a tracked base and a soil region on `soil-a`; it declares no task) with
the tasks `one-episode.ftask` and `two-episodes.ftask` in its directory, for the terrain-reset check.

**Stages.**

0. `laws`: runs `scripts/e2e/soil_laws.sh` (owned by N18b-12) and reads its `assert` and `summary` lines.
1. `verb`: runs `scripts/e2e/soil_verb.sh --stage verb` (owned by BD-366) and reads its `assert` and `summary`
   lines; no second copy of its commands. What it asserts: `frob contact soil --soil soil-a --plate 0.1m@20kPa
   --json` → 19.6 mm within 10⁻⁶ relative of the closed form; `--track 0.5x0.1x2 --load 500N --slip 0.2` →
   293 N, limit 389 N; `--wheel 0.15x0.1 --load 200N --slip 0.2` → a sinkage, a thrust and a validity report
   computed by station quadrature (the output names the quadrature); `--soil soil-b` with 441.45 N and 735.75 N
   (45 kg and 75 kg) on 8 cm and 12 cm tracks of length 0.55 m → 3.52, 9.79 and 4.96 cm, and exit code 2 with
   the finding "sinkage exceeds clearance" for 9.79 cm against an 8 cm clearance; the registry's example form
   `--wheel w-75 --soil sand-dry --load 40N` parses (exit 0, or exit 3 with a named refusal if that card is
   absent from the fixture set, never exit 1); class `Estimated`, tier label Frontier, and the card named as
   weakest input. In MODE=fallback this script additionally asserts that the verb's evidence names the fallback
   in force.
2. `refusal`: runs `scripts/e2e/soil_verb.sh --stage refusal` the same way. What it asserts: a pressure above
   the card's range → exit 3, `FROB-REF-243`, repairs "another card" and "the rigid-floor model"; no clipped
   value is returned.
3. `plate` and 4. `drawbar` (MODE=kept): run `scripts/e2e/soil_step.sh` (owned by N18b-13, which verified them
   when it landed) and read its log; no second copy of its commands. What they assert: settled plate sinkage
   on `strict` within 2% of 19.6 mm and of 3.52 cm, the lockstep value logged; the tracked base held by a
   drawbar at 20% slip on `strict` → pull within 2% of 293 N; at 100% slip the pull is below the 389 N limit and
   above 360 N.
5. `ruts`: reads the rut row of the GATE-TRAC-08 record. Always: `frob sim run --fixture traction/soil_reset
   --task crates/frob-conformance/fixtures/traction/soil_reset/two-episodes.ftask --tier batch-cpu --worlds 4
   --seed $SEED --key cs-reset --json`; the second episode's starting state digest (from the run envelope's
   per-world digests) equals a fresh world's (the same command with `one-episode.ftask`, key `cs-reset-fresh`),
   and while the row reads "off; terrain resets each episode" the evidence claims no persistence. Hook: when the row is a measured row of N18b-17, run `scripts/e2e/ruts.sh` (owned by N18b-17)
   and read its log: 10³ resets on the leak scene → leak count 0; a second pass at the same load sinks no
   further. Until N18b-17 lands (it depends on this bead and turns the branch on), the branch logs
   `e2e_skip "needs N18b-17"`, which is never counted as a pass.
6. `fallback` (always run, because the fallback must work before it is needed): runs `scripts/e2e/kill_soil.sh
   --stage fallback` (owned by N18b-18, with its fixture `traction/kill_soil_tow`) and reads its log; no second
   copy of its commands. What it asserts: a region with rolling resistance c_rr = 0.05 and the drag card
   c_d = 0.1 → tow force for a 100 N load is 15 N within 1%; the result carries `exploratory`; citing it as a
   soft-ground verdict is refused (N18b-18's `exploratory_label_propagates`).
7. `gate`: read the GATE-TRAC-08 record → every row has a measured value with its threshold, or a named
   fallback with a reason; no row is marked passed without a receipt; the rut row is the fallback "off" or a
   measured row of N18b-17, never a fallback shown as measured. In MODE=fallback assert that the soil rows of
   the law-admission table show `fallback` (`frob contact laws --json`) and that `frob sim run --fixture
   traction/soil_plate_n11 --law <the soil row, spelled as the law table spells it> --tier batch-cpu --seed $SEED
   --key cs-law-refused --json` refuses with the law-not-admitted code (`FROB-REF-246`, exit 3) naming the
   fallback.
8. Determinism: stages 1, 3 and 6 repeated → identical digests. MCP parity for `contact_soil`.

**Logging.** Newline-delimited JSON to `target/e2e-logs/contact_soil/<utc-timestamp>.ndjson` with a
human-readable transcript beside it. Every line: `ts`, `script`, `bead` (`N18b-19`), `step`, `event` (`start`,
`cmd`, `assert`, `metric`, `refusal`, `end`), the exact command line, exit code, wall time, the envelope's
`evidence` block (claim, class, tier, determinism, identities, seed), measured values with units and thresholds
(sinkage in mm, pull in N, leak count, tow force), the mode, digests where state is compared, and on failure
the first differing value and artifact paths. A final `summary` line gives assertion counts, the mode and the
gates touched (GATE-TRAC-08, KILL-SOIL). No private-scene data is logged.

## Acceptance criteria

- [ ] The script exists, sources the shared helper and passes on a clean checkout with `batch-cpu` only, in
      both modes (CI runs it against a fixture gate registry for each mode).
- [ ] Every stage logs at least one `assert` with a measured value and a threshold.
- [ ] `FROB-REF-243` is observed with exit code 3; the clearance finding with exit code 2; exit code 1 never
      appears.
- [ ] In fallback mode the script asserts the `exploratory` label and the refusal to cite; it does not assert
      soil known answers on simulated rows it cannot run, and it logs that it skipped them and why.
- [ ] Repeat runs reproduce digests.
- [ ] A self-test shows the script fails when an expected value is altered (19.6 mm changed to 21.0 mm).

## Test plan

### Unit tests

None of its own; the harness self-test above.

### End-to-end script and logging

As specified: `scripts/e2e/contact_soil.sh` driving the scripts of N18b-12, BD-366 and N18b-13, `frob sim
run`, `frob contact laws` and `frob-mcp`, with the `ruts` hook for N18b-17's script.

### Known answers and negative controls

KA-415 (19.6 mm), KA-416 (389 N and 293 N), KA-419 (rut isolation, through the `ruts` hook once N18b-17 has
landed), KA-837, the late plate-sinkage row (3.52, 9.79, 4.96 cm). Planted failures (mutant builds in CI): the
exponent n = 0.7 in place of 0.5 must fail stage `verb` (9.16 cm, 0.091646 m, in place of 3.52 cm); shear
displacement ignored must fail stage `drawbar` (389 N at every slip); terrain state carried across a reset must
fail stage `ruts` (and, once the hook is on, a shared rut buffer); an evidence block without the Frontier label
must fail stage `verb`.

## Considerations

- The script proves reachability, labelling and the known answers at smoke scale; the gate itself is recorded
  by the conformance run cited in BD-366.
- Run time target: under ten minutes on `batch-cpu` (TARGET).
- All fixture cards are `assumed`; the script therefore also guards the rule that such results are `Estimated`.
