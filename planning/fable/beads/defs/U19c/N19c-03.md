## Background

A scan sees part of a place. The space it did not see is neither empty nor solid: it is unknown. **ADR-HAB-10:
unobserved space is unknown, not free and not solid.** Occupancy is three-valued in every ingested scene, and each
consumer states how it treats `unknown`. Reason: closing a scan can create a wall where a door exists, and leaving it
open can create a route through a wall. Counterexample to "import the mesh and trust it": a corridor whose far half was
never observed appears as empty space in a naive import, and a traversal certificate over it would be false; with a
coverage mask the same query returns unknown. Rejected alternatives: treating unobserved space as free (false routes);
as solid (false impossibility cuts); deciding per importer (no consumer could rely on a meaning).

**INV-HAB-04.** `unknown` is never changed to free or occupied without a recorded observation or a recorded, named
assumption. This bead owns the mask, the single interface that can resolve unknown space, and the per-consumer
conformance tests. Tier Frontier (ingested scenes only); generated scenes have no unknown space.

## Scope

In: the occupancy model and the `unknown` map of a pack; where unknown comes from; the resolve interface that
enforces INV-HAB-04; the treatment table with a conformance test per consumer; `FROB-REF-305`; the degraded mark for
contact with unknown; the record of what a watertight proxy may be used for.

Out: the kernels and analyses of each consumer (contact BD-166, rays BD-187, clearance N19b-30, spawn checks N19a-19,
task binding BD-122); probe requests (N19c-05); the decision whether contact with unknown degrades or refuses
(OPEN-HAB-6, N19c-10); the import pipeline (N19c-04).

## Technical approach

**1. Model (DESIGN sketch).**

```rust
pub enum Occupancy { Free, Occupied, Unknown }
pub struct UnknownMask { origin_cell: [i32; 3], dims: [u32; 3], bits: BitLattice /* one bit per coarse cell */,
                         sources: Vec<UnknownSource> }
pub enum UnknownSource { Coverage { region: RegionId, confidence: f32, threshold: f32 }, Unseen { box_m: Aabb },
                         HoleFill { receipt: Blake3, box_m: Aabb }, UpstreamMask { digest: Blake3 } }
pub fn occupancy(pack: &ScenePack, x: Point3) -> Occupancy;     // Unknown if the coarse cell is flagged; else by the sign of φ
```

The mask is the pack's `unknown` map: a bit lattice at the coarse spacing S (default 16 cm; about 9 kB for a 300 m³
home), part of `SceneId`. Surfaces bounding unknown space carry the reserved region class `unknown-surface` in the
region table, so every consumer that reads a region identifier can tell.

**2. Where unknown comes from.** (a) Coverage or confidence per region supplied by the capture: a region below the
import profile's threshold is unknown. (b) An upstream coverage mask (the drone route): it becomes the unknown-space
label directly. (c) An unseen underside stays unknown: space below an observed top surface with no observed underside
is flagged down to the nearest observed surface. (d) A hole closed by the explicit repair pipeline is marked
`derived: hole-fill` and its neighbourhood stays unknown: DESIGN, every coarse cell that intersects the filled patch
dilated by the truncation distance T. Flagging is conservative: a coarse cell touched by any source is unknown.

**3. Resolving unknown (INV-HAB-04).** The only function that clears a flag is
`resolve_unknown(pack, box, Evidence) → new pack`, with `Evidence::Observation { capture, coverage }` (a later scan
or probe result, by digest) or `Evidence::Assumption { name, reason, author }`. It produces a new pack (new
`SceneId`) whose provenance lists each resolution; an assumption is counted in the manifest
(`unknown_resolved_by_assumption`) and printed by every report. No compiler stage, repair or optimization may clear a
flag by any other path; a lint in the crate forbids writing `UnknownMask::bits` outside this module.

**4. Treatment by each consumer (binding; each row has a conformance test).**

| Consumer | Treatment of `unknown` | How it is realized |
|---|---|---|
| Spawn and goal placement | Not allowed in or adjacent to unknown space | A spawn or goal whose footprint, inflated by one coarse cell, touches a flagged cell is `FROB-REF-305` |
| Clearance complex | Blocked for witnesses, free for cuts | Inner complex: unknown is an obstacle. Outer complex: a cell whose clearance is limited by an `unknown-surface` gets c_hi = +∞. A witness never crosses unobserved space; an impossibility cut never relies on it |
| Contact | Solid keep-out; a contact with an unknown surface marks the world `Degraded: contact-with-unknown`, and the episode is excluded from metrics with a count | Unknown volume is compiled as solid with class `unknown-surface`; a contact record whose region has that class sets the mark at commit |
| Ray kernels | A ray that enters unknown space returns `invalid: unknown-region` | The march tests the cell flag before the field; the first flagged cell ends the ray with that reason |
| Tasks | May require known traversability; a required route through unknown space is `FROB-REF-305` | Route-graph edges are intersected with the mask at task binding |

**5. `FROB-REF-305`** "A required route, spawn or contact lies in an unknown region". Block: `pointer` (the route
edge, spawn, goal or surface), `observed` (the unknown box in scene coordinates and its source), `required` (known
space). Ranked repairs: emit a probe request for the named box; choose another route. Exit 3.

**6. Proxies.** A watertight proxy may serve a navigation experiment while gripper contact with the same object stays
unresolved. The pack records which, per region: `proxy_scope = { navigation: admitted, manipulation: unresolved }`
(DESIGN field); a manipulation task that needs contact with such a region is `FROB-REF-305`.

**7. The degraded mark.** `Degraded: contact-with-unknown` is a per-world, per-episode mark carried in telemetry and
in the scorecard: the episode is excluded from metrics, and the count of excluded episodes is printed beside every
metric (a success rate always has its numerator, denominator and exclusions). This is the default of OPEN-HAB-6.

**8. Layout.** `crates/frob-scene/src/ingest/{unknown.rs, resolve.rs}`; conformance rows in `frob-conformance`.

## Acceptance criteria

- [ ] Every ingested pack has an `unknown` map; a generated pack has none and every query returns `Free` or `Occupied`.
- [ ] INV-HAB-04: over 10⁴ random sequences of compile, repair and resolve operations, the set of cells that changed from unknown equals the union of recorded resolutions (property test); no other code path writes the mask.
- [ ] Each of the five consumer rows passes its conformance test on the half-observed corridor fixture: spawn refused; `scene.fit` returns no witness through the unseen half and no cut that depends on it; a contact with the unknown wall sets the degraded mark and the scorecard excludes and counts the episode; a ray into the unseen half returns `invalid: unknown-region`; a task requiring the route is refused.
- [ ] `FROB-REF-305` carries the unknown box and its source; repair 1 yields a probe request naming the same box.
- [ ] A hole closed by explicit repair leaves its dilated neighbourhood unknown, and the receipt is linked from the mask.
- [ ] `proxy_scope` is recorded, and a manipulation contact on a navigation-only proxy is refused.
- [ ] `CONTRACT.md` carries the treatment table.

## Test plan

### Unit tests
`crates/frob-scene/tests/unknown.rs`; fixtures `synthetic` (a 10 m corridor observed for its first 5 m; a table seen from above; a mesh with one 0.3 m hole).
- `occupancy_three_values`: points at 2 m (free), inside a wall (occupied), at 7 m (unknown).
- `unseen_underside_unknown`: space under the table top is unknown down to the floor.
- `hole_fill_neighbourhood_unknown`: cells within T = 0.08 m of the filled patch are flagged; cells 0.5 m away are not.
- `resolve_requires_evidence`: `resolve_unknown` without evidence does not compile (type-level); with an assumption it increments `unknown_resolved_by_assumption` and changes `SceneId`.
- `inv_hab_04_property` (the property test of the acceptance criterion).
- `spawn_adjacent_refused`: a spawn whose footprint edge is 0.10 m from a flagged cell (less than S = 0.16 m) returns `FROB-REF-305`; with the edge 0.40 m away it is accepted.
- `ray_into_unknown_invalid`: a ray from 2 m toward +x returns `invalid: unknown-region` at 5.0 m ± S.
- `contact_with_unknown_marks_degraded`: a body pushed into the unknown wall sets the mark; a world that never touches it does not.
- `clearance_inner_blocks_outer_frees`: a route through the unseen half: answer `unresolved`, never a witness and never a cut.

### End-to-end script and logging
`scripts/e2e/scene_unknown_regions.sh` (sources the STD-E2E helper; header `plants=unknown-as-free,unknown-as-solid`;
every `run` call carries its own `--key`). The steps that need an ingested pack call the `place` form of
`scene.import`, registered by BD-398 after this bead; while `frob capabilities --json` lists it absent they log
`e2e_skip "needs BD-398: scene.import --kind place"` (never a pass), and BD-398's acceptance makes them run. Steps
that run at this bead's close: `frob schema frob.scene/1 --json` (the pack's `unknown` map, its sources and the
counter `unknown_resolved_by_assumption` are in the schema); `frob --json scene gen --family home --seed 7 --key
sur-gen-1` and `frob --json scene show <id>` (a generated pack has no `unknown` map and the counter is 0). Place-lane
steps, on the half-observed corridor: `frob --json scene import --kind place` (synthetic capture with a coverage
mask, `--key sur-imp-1`), `frob --json scene show <id>` (mask summary), `frob --json sim run … --key sur-run-1` of a
short push task (expect exit 2 with the degraded count), `frob --json scene fit … --key sur-fit-1` across the
corridor (expect `unresolved`), a `frob --json telemetry stills` depth image (expect masked pixels with reason
`unknown-region`), and a task binding that requires the far goal (`frob --json sim run … --key sur-run-2`, expect
exit 3, `FROB-REF-305`). Every NDJSON line carries `ts`, `script`, `bead`, `step`, `event`, the command, exit code,
wall time, evidence block, counts of flagged cells, `degraded_episodes`, the verdicts, and digests of the mask
before and after; on failure the first differing value and the pack identity; a final `summary` line; logs under
`target/e2e-logs/scene_unknown_regions/`. Only synthetic data is logged.

### Known answers and negative controls
- Known answer: the half-observed corridor returns unknown where a naive import returns free.
- Negative controls: an importer that fills unobserved space as free must produce a witness through the unseen half and fail; one that fills it as solid must produce a cut and fail; a compiler pass that clears a flag without evidence must fail the property test.
- Determinism: the mask is integer data; identical bytes twice and across platforms.

## Considerations

- OPEN-HAB-6 (owner Habitat lead; decided at M5 with the first real place): whether contact with unknown space degrades the world or refuses the run. Fail-closed default implemented here: degrade, exclude from metrics, count.
- Coarse-cell granularity over-flags by up to 16 cm; a finer mask is a compile setting if the first real place needs it.
- "Adjacent" for spawns and goals is one coarse cell beyond the footprint (DESIGN); the plan gives no number. This
  bead owns the treatment table, and both earlier checks apply its rule: the pack validation of N19a-04 (M2) at
  region level (a spawn or goal region whose dilation by ρ + S touches a region labelled `unknown` is
  `FROB-REF-305`), and compile stage 9 of N19a-19 (M2) pose by pose (a pose whose nominal footprint, inflated by
  one coarse cell S, touches a flagged cell is invalid with reason `unknown`, also where the reference point lies
  farther than the footprint radius from it). When every cell of a goal region is invalid and some fail for
  `unknown` alone, N19a-19 records `goal_admissible: unknown`, which BD-234 tags `unresolved`, never `impossible`,
  so that no impossibility relies on unknown space. (The route-margin test of OPEN-HAB-6, N19c-10, is a different rule and keeps its own
  footprint-radius margin.)
- Unknown space also carries no material: an unprobed surface gets an interface card of class `assumed` (N19c-04).
- Private data: the mask describes a private place and inherits the private mark.
