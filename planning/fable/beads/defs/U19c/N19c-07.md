## Background

GATE-HAB-03 is the gate of real-place ingestion (claim kind Reality, tier Frontier, milestone M5). Its statement:
**one real place ingested end to end, privately, with its scale label and unknown regions respected, and at least one
probe request emitted for it. A place for which no capture exists is recorded as `no-claim`, not as a pass.**

Terms used below. A **scene pack** is Habitat's compiled, immutable form of a place. Its **scale label** is one of
`relative-only`, `estimated`, `witnessed`, `surveyed` and bounds what a task may do (a metric task on a `relative-only`
pack is refused with `FROB-REF-304`). Its **unknown mask** marks unobserved space, which every consumer treats
conservatively (no spawn in or beside it, no clearance witness through it, a ray into it returns
`invalid: unknown-region`, a required route through it is `FROB-REF-305`). A **probe request** names the measurement
that would settle an unresolved answer. A **private** pack lives under a private root outside the repository, is
absent from every listing except the explicit private listing (`scene list --private`, under a session holding
`private:read`, BD-305), and marks everything derived from it.

This bead is the gate's script and record. It exists apart from the mechanism beads because the gate is measured on a
running system from the user's side, and because a real place brings a constraint the other gates do not have: the
log must prove the gate without containing the place.

## Scope

In: the end-to-end script in two lanes (a synthetic rehearsal lane that runs anywhere, and a private lane on the
owner's capture), its assertions, its structured log, the gate record, and the `no-claim` record when no capture
exists. Out: the mechanisms (N19c-02 to N19c-05, BD-398); the kill decision when the gate cannot pass (N19c-08).

## Technical approach

**1. Script.** `scripts/e2e/gate_hab_03_real_place.sh [--lane rehearsal|private] [--package <dir>] [--from
twin|fdgr]` (`--from` is passed to the import as the adapter, default `twin`; the switch-overs NFp2-02 and NFp2-03
run the script on the drone route's generation and on the extended twin package), plain shell
driving the real `frob` binary, idempotent, seed-explicit, non-zero exit on any failed assertion; every `run` call
carries its own `--key` (prefix `gh3-`), distinct for every pair of runs the script compares. The private root is
not a script or verb option: it is the owner-held `roots.private` of `$FROB_STATE/safety.toml` (N37-02, BD-305).
The rehearsal lane uses `fixtures/ingest/synthetic-twin/` (labelled `synthetic`) with a scratch `FROB_STATE` whose
`roots.private` is a temporary directory outside the repository, and can never record the gate as passed: a Reality
gate needs a real capture. The private lane uses the owner's state; it requires `--package`, reads the configured
root (`frob --json doctor` reports it), and refuses to run, before any `frob` command that writes, if the root is
unset or if the root or the package lies inside a version-controlled tree. `FROB_PRIVATE_ROOT` is exported as the
same path, so the helper's redaction masks it.

**2. Steps and assertions.**
1. `frob --json doctor` and `frob --json spark fingerprint --key gh3-fp-1` (record commit and hardware fingerprint).
2. `frob --json scene import --kind place <package> --from <twin|fdgr> --key gh3-imp-1` (import takes no seed: the pack is a pure
   function of the source bytes, the profile and the correspondences). Assert exit 0 or 2; the envelope's evidence
   block; `private: true`; the pack path resolves under the private root.
3. The loss report, read from the import result (`/result/loss_report`), and `frob --json scene show <id>`. Record
   (digests and counts only): the scale label, the landmark residual, the transform class, the unknown fraction, the
   count of `assumed` cards, holes repaired. Assert a scale label is present and that the four-point registration
   receipt is present.
4. **Scale label respected.** Bind a metric navigation task at a requirement one level above the pack's label
   (`frob --json sim run <reference design> --scene <id> --task <nav-above> --key gh3-bind-1`) and assert exit 3
   with `FROB-REF-304`; bind it at the pack's level (`--key gh3-bind-2`) and assert admission (or, for a
   `relative-only` pack, assert that every metric task is refused).
5. **Unknown regions respected.** (a) `frob --json sim run <reference design> --scene <id> --task <nav> --worlds
   1000 --seconds 1 --key gh3-spawn-1` samples 1,000 spawn poses by address; read each world's spawn pose from the
   run's receipts (`frob --json run show <run>`; they inherit the private mark and only the count of violations is
   logged) and assert none lies in or adjacent to a flagged cell. (b) `frob --json telemetry stills` from a pose
   facing an unknown region: assert masked samples with reason `unknown-region`. (c) `frob --json scene fit … --key
   gh3-fit-1` on a route chosen to cross an unknown region: assert the answer is `unresolved` (never a witness,
   never a cut). (d) Bind a task whose required goal lies in an unknown region (`--key gh3-bind-3`): assert exit 3
   with `FROB-REF-305` and a probe request in the first repair.
6. **A probe request.** `frob --json scene probe-request <scene_id> --status open` (the reference is positional, as
   the verb's registry row spells it): assert at least one open request with target, quantity, accuracy and
   threshold; and `frob --json scene probe-request <answer_ref>` on the unresolved answer of step 5c: assert a request
   whose box is the unknown region that answer crosses.
7. **Evaluated in the place.** `frob --json eval run … --key gh3-eval-1` of the reference robot on a short route in
   known space, 64 worlds, seed-explicit. Assert a scorecard with numerator, denominator and the count of episodes
   excluded as `Degraded: contact-with-unknown`; assert its `reality:` line reads `no-claim` unless Reality-lane data
   for this place exists.
8. **Privately.** `frob --json scene list`: the pack is absent, with no count of withheld rows; `frob --json scene
   list --private` under a session without `private:read`: exit 5 with `FROB-REF-720`; the same under a session
   holding it: the pack is listed and the envelope carries the privacy mark (BD-305). `frob --json artifact
   export <still digest> --out exports/ --key gh3-exp-1` of a still from step 5 without the scope and flag: exit 5
   with `FROB-REF-731`. Assert the still's mark is `private` (inherited).
9. **Identity.** Re-import with the same package and settings under a second key (`--key gh3-imp-2`, so the call
   is a new import and not the stored receipt of the first): the same `SceneId`.
10. Write the receipt and the gate record (section 4).

**3. Logging.** The script sources the STD-E2E helper and writes NDJSON to
`target/e2e-logs/gate_hab_03_real_place/<utc>.ndjson` (rehearsal lane) or to `logs/…` beneath the private root (private lane),
with a transcript beside it. Every line has `ts`, `script`, `bead`, `step`, `event` (`start`, `cmd`, `assert`,
`metric`, `refusal`, `end`), the exact command with private paths replaced by `<private>`, exit code, wall time, the
envelope's evidence block, measured values with units and thresholds, digests where state is compared, and on failure
the first differing value and the artifact identifiers needed to reproduce. **No geometry, image, feature name or
coordinate of the private place is logged**: features appear as salted digests, boxes as volumes. A final `summary`
line gives assertions passed and failed and names GATE-HAB-03.

**4. The gate record.** A row for GATE-HAB-03 in `registries/gates.toml` with: verdict; the package digest; the
`SceneId` digest; the ingest contract row the pack was admitted under (N19c-09, from the import result); scale
label; unknown fraction; number of probe requests; counts from step 5; commit; hardware
fingerprint; seed; the path of the private log (not its content). Verdicts: `PASS` (private lane, all assertions);
`no-claim` (no capture exists, or only the rehearsal lane ran, or the place is a surveyed proxy); `FAIL`. The script
writes the receipt (the summary line's hash, carrying these values) and prints the recording command; the value is
recorded with `cargo run -p frob-conformance --example record_gate -- --gate GATE-HAB-03 --receipt <hash> --part M5`
by a fresh-context session that did not implement the work (INV-GAUNT-05, N38b-19: the recorder refuses the
implementing session); the script never edits the register itself.

## Acceptance criteria

- [ ] The rehearsal lane passes every assertion on the synthetic package on Linux and macOS and records `no-claim` with the reason "synthetic rehearsal".
- [ ] The private lane, run on one real capture, passes every assertion and records `PASS` with the measured values (scale label, unknown fraction, probe requests, exclusions), the commit, the fingerprint and the seed.
- [ ] If no capture exists at M5, the gate row reads `no-claim` and names the missing capture; the milestone does not record a pass.
- [ ] The private log, searched for the package's feature names and for raw coordinates, contains none (an automated scrub check is part of the script).
- [ ] The scale label recorded for the passing run is `witnessed` or better; a lower label is recorded as measured and handed to the kill decision.
- [ ] Negative controls of the Test plan each make the script fail.

## Test plan

### Unit tests
The script's helpers are tested in `scripts/e2e/tests/gate_hab_03_helpers.sh` (plain bash sourcing the STD-E2E
helper, no test framework beyond it; real files in a temporary directory):
- `refuses_private_lane_inside_repo`: a state whose `roots.private` lies under the repository, or a `--package` under it, exits non-zero before any `frob` command that writes.
- `refuses_private_lane_root_unset`: a state without `roots.private` exits non-zero before any command that writes.
- `keys_distinct`: the keys of the two imports and of every compared pair of runs differ.
- `scrub_check_finds_planted_name`: a log with a planted feature name fails the scrub.
- `rehearsal_cannot_pass_gate`: the rehearsal lane's record is `no-claim` whatever the assertions.
- `record_has_measured_values`: the gate row carries values, not thresholds.

### End-to-end script and logging
This bead is the script (section above; header `bead=N19c-07 milestone=M5 gates=GATE-HAB-03
plants=unknown-as-free,no-scale-label,public-private-pack,three-landmarks,mirrored`). It is run in CI in the
rehearsal lane, and once by hand in the private lane.

### Known answers and negative controls
- Known answers on the rehearsal package (its truth is authored): scale witness 0.800 m ± 4 mm → label `witnessed`, ε_c = 0.5%; unknown fraction equal to the authored unseen volume within one coarse cell layer; door D3 request "clear width to ±0.005 m".
- Negative controls (each a planted build or fixture the script must catch): an importer that treats unobserved space as free (step 5c returns a witness); one that omits the scale label (step 3); one that lists the private pack publicly (step 8); a package with three landmarks (step 2 must exit 3 with `FROB-REF-302`); a mirrored package (same).
- Determinism lanes: the rehearsal lane twice on one machine and across platforms gives identical `SceneId` and identical assertion results.

## Considerations

- KILL-INGEST: if this gate cannot be passed with a scale label of `witnessed` or better after one repair cycle, the place is authored as a surveyed proxy and the gate reads `no-claim` (decision bead N19c-08).
- OPEN-HAB-5 blocks the private lane: the package and version that form the import contract must be chosen first (N19c-09).
- OPEN-HAB-6: the count of `Degraded: contact-with-unknown` episodes from step 7 is the data for deciding whether such contact should refuse the run instead (N19c-10).
- A "Reality" gate here means a real place entered the system under its rules; it is not a statement that simulated outcomes match the place. That needs the Reality lane's data and stays `no-claim`.
- The private lane cannot run in shared CI; its evidence is the gate row plus the private log kept by the owner.
