## Background

Scene geometry is often authored as instances: one shape placed many times, each through a transform that may scale
it, sometimes differently along each axis. A signed distance evaluated in the shape's own (local) coordinates is then
not a distance in the world. The scene compiler avoids the problem for compiled packs: it bakes scales before it
computes a field, so a compiled pack is in world metres. This bead states and builds the **conversion rules for any
query that reaches geometry through an instance transform with a scale** [S], which bind wherever a scaled transform
survives to query time: an imported pack inspected before it is compiled, a distance brick shared by instances of
different size, the viewer's picking rays, and any adapter over a sibling's ray primitive. Owners: `frob-scene`
(compiler and bricks; this bead), `frob-sense` (ray kernels) and the viewer (N19c-39). Verbs touched: `scene.compile`,
`scene.accept`.

**Rules (DESIGN).** Let A be the linear part of the instance transform, local to world.

1. *Distance.* A local signed distance d outside the shape bounds the world distance to [σ_min(A)·d, σ_max(A)·d],
   where σ_min and σ_max are the smallest and largest singular values of A. It equals the world distance only for a
   uniform scale, where both ends coincide. An unresolved query is refined, or the field is baked in world metres; a
   local distance is never returned in metres.
2. *Normals.* A surface normal transforms as A⁻ᵀ·n and is then renormalized, before any contact frame or optical
   response is built from it.
3. *Rays.* For a unit world direction d the local direction is A⁻¹·d. If the primitive renormalizes it, the hit
   parameter is in local units and s_W = s_L/‖A⁻¹·d‖. The conversion happens before hits are sorted, clipped to a
   range gate, or used as optical depth. (Rule 3 is implemented in N19c-39.)

**Counterexample that fixes rule 1.** A unit sphere scaled by (2, 0.5, 1). At the world point (0, 0.6, 0) the local
distance is 0.20 and the clearance is 0.10 m: read as metres, the local value admits a 0.15 m probe that intersects.
At (2.2, 0, 0) the local distance is 0.10 and the clearance is 0.20 m. Both lie inside the bounds [0.5·d, 2·d].

Why rule 1 holds (derivation). With x_L = A⁻¹·(x_W − t) and y_L any point of the shape's surface, the world
separation is ‖A·(x_L − y_L)‖, which lies between σ_min·‖x_L − y_L‖ and σ_max·‖x_L − y_L‖. Taking y_L as the local
nearest point gives world distance ≤ σ_max·d; taking the world nearest point gives world distance ≥ σ_min·d. The
same argument bounds a penetration depth. Alternatives rejected: returning the local value (the counterexample);
scaling by the cube root of det A or by any single "effective" scale (exact only for uniform scale, and silently
wrong otherwise).

## Scope

In: the instance type with its singular values; the typed local distance that cannot be read as metres; the interval

## Technical approach

1. **Types (DESIGN sketch).**

```rust
pub struct ScaledInstance { a: Mat3, t: Vec3, a_inv: Mat3, a_inv_t: Mat3, sigma_min: f64, sigma_max: f64, uniform: bool }
pub struct LocalDistance(f64);                       // no conversion to Length; only the methods below
pub struct WorldDistanceBound { lo: Length, hi: Length }
impl ScaledInstance {
    pub fn new(a: Mat3, t: Vec3) -> Result<Self, InstanceError>;             // refuses a singular A
    pub fn distance_bound(&self, d: LocalDistance) -> WorldDistanceBound;    // rule 1, outward rounded
    pub fn normal_to_world(&self, n_local: UnitVec3) -> UnitVec3;            // rule 2
}
```

   `LocalDistance` is a distinct type with no `Into<Length>`; the only way to obtain metres from it is
   `distance_bound`, which returns an interval. "A local distance is never returned in metres" is thereby a compile
   property, not a convention.
2. **Singular values.** σ_min and σ_max are the square roots of the smallest and largest eigenvalues of AᵀA,
   computed by a symmetric 3 × 3 eigen-solve (Jacobi rotations, fixed sweep count, deterministic), then rounded
   outward (σ_min down, σ_max up by a few units in the last place) so that the bound is safe. `uniform` is set when
   AᵀA = c²·I within the classification tolerance of the compiler's stage 2; then both ends coincide at c·d.
3. **Rule 1 with sign.** For d ≥ 0 the bound is [σ_min·d, σ_max·d]; for d < 0 (a point inside the shape) it is
   [σ_max·d, σ_min·d], so the depth magnitude lies between σ_min·abs(d) and σ_max·abs(d).
4. **Refinement.** A query is **resolved** when its bound decides the question asked (the whole interval lies on one
   side of the threshold, or the caller asked only for a bound). Otherwise, in order: (a) if the instance is
   uniform, return c·d (exact); (b) if the shape has an exact world-space form under A (a sphere becomes an
   ellipsoid, a box stays a box with scaled half-extents), evaluate that; (c) otherwise bake a local patch of the
   field in world metres around the query (the compiler's stage 5 on a small box) and sample it with its recorded
   bound. A query that none of these resolves returns the interval with `resolved: false`; it never falls back to
   the local value.
5. **Rule 2.** `normal_to_world(n) = normalize(A⁻ᵀ·n)`; used for every normal that feeds a contact frame or an
   optical response computed before compilation, and by the compiler when it bakes normals of analytic overlays.
6. **Scaled sharing of a distance brick.** A compiled pool shares bricks only between identical world-metre content.
   Where a design shares one brick among instances through a scale (an optimization some importers offer), DESIGN:
   it is admitted only for a **uniform** scale c, recorded with the directory entry; the consumer multiplies the
   decoded distance and the brick's recorded bound by c and treats the brick's spacing as c·s; truncation becomes
   c·T and the saturation test uses it. A non-uniform scaled share is refused at compile: the instance is baked.
7. **Pre-compilation query path.** `scene.show --probe` on a source that has not been compiled, and from M3
   `scene.accept` on an import, evaluate source shapes through their instance transforms. Their results are
   `WorldDistanceBound`s with `resolved` and the method used; a report prints an interval, never a single number,
   unless resolved. On the command line the uncompiled source is named with `--source <path>` in place of a
   `scene_id`: `frob scene show --source <path> --probe x,y,z` (DESIGN: an additive option of `scene.show` that this
   bead adds; it reads the source through compile stages 1 and 2 only, writes nothing and returns no `SceneId`;
   VERBS-scene's `scene.show` row lists it with this bead, so the scripts may call it; an earlier text still called
   it requested).
8. **Evidence.** A resolved distance by (a) or (b) is exact to round-off (`Certified` where interval arithmetic
   bounds it); by (c) it carries the patch's brick bound (`Tested` or `Certified` as the compiler's bound is).
9. **Layout.** `crates/frob-scene/src/instance/{scaled.rs, svd3.rs, refine.rs}`.

## Acceptance criteria

- [ ] The anisotropic sphere: before compilation, the query at (0, 0.6, 0) returns the interval [0.10, 0.40] m from local 0.20, and at (2.2, 0, 0) the interval [0.05, 0.20] m from local 0.10; neither returns the local value; after refinement by the exact ellipsoid or a baked patch the clearances are 0.10 m and 0.20 m.
- [ ] No public function returns a `LocalDistance` as a `Length` (compile-fail tests), and no code path in the crate constructs a `Length` from a local distance outside `distance_bound` (a lint over the instance module's callers).
- [ ] For 10⁴ random instances with singular values in [0.25, 4] and random query points against a sphere, a box and a capsule, the true world distance (from a dense world-space sampling of the surface) lies inside the returned bound; for uniform scales the bound's ends coincide.
- [ ] Normals: a plane with local normal (1, 1, 0)/√2 under diag(2, 1, 1) has world normal (0.5, 1, 0)/‖(0.5, 1, 0)‖; a mutant that transforms normals by A fails.
- [ ] A uniform scaled brick share returns c times the stored distance and c times the bound; a non-uniform share is refused at compile.
- [ ] A singular instance transform is refused.
- [ ] `CONTRACT.md` states the three rules and the counterexample.

### Known answers and negative controls
- Known answers: the sphere's two points (0.10 m and 0.20 m; intervals [0.5·d, 2·d]); the plane normal.
- Negative controls: a query that returns the local distance as metres (0.20 and 0.10: fails both points); a bound scaled by det(A)^(1/3) = 1 (returns 0.20 and 0.10, the same wrong values); normals transformed by A.
- Counterexample CXH-A (N19-CX, provisional tag until its `cx` block is issued; `control_kind = mutation`, plant `N19c-38:cxh-a`): the first of those controls is the registered one, built as the Cargo feature `cxh-a` of `frob-scene` under `gauntlet-mutations`, in which `distance_bound` returns the degenerate interval [d, d] in metres. With it enabled, `sphere_counterexample_bounds` and `probe_015_would_intersect` must fail (the 0.15 m probe at (0, 0.6, 0) is admitted); run as `cargo test -p frob-scene --features gauntlet-mutations,cxh-a --test scaled_instance -- sphere_counterexample_bounds probe_015_would_intersect`, expected to fail. N19c-40's gate script runs the same plant at the gate.
- Metamorphic: composing the instance with a rigid motion changes no bound; scaling A by k scales both ends by k.
- Determinism: the eigen-solve uses a fixed number of sweeps and basic operations; identical bits in debug and release and across platforms.

## Considerations

- The interval can be wide (a factor σ_max/σ_min); that is information, not a defect: it tells the caller that the question needs baking.
- Shear is covered: the singular values of any invertible A bound the distance; only the exact-form shortcut (b) is lost.
- Reflections (det A < 0) do not change singular values; whether a reflection is admissible at all is the registration question, handled elsewhere.
- The sibling ray primitive that renormalizes directions is a recorded convention hazard; its adapter is in N19c-39.
