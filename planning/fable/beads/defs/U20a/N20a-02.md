## Background

**ADR-SENS-07: a missing measurement is a masked value with a reason, never a number.** A numeric zero is a measurement only where the schema says so. Reason: a depth pixel that returns 0 m, a lidar beam that returns its maximum range, or an encoder that repeats its last value are all numbers a consumer will use; the failure then looks like data. A sensor model is useful to a designer in proportion to the failures it shares with the instrument, and every such failure needs a name that survives to the estimator, the policy, the telemetry and the viewer.

**INV-SENS-05: a masked value never appears as a number, and every mask has a reason.** This bead supplies the types that make the invariant hold by construction and the registry of reasons that every sensor model of Sensorium uses.

Alternatives rejected: a sentinel value per sensor (0, NaN or max range), because sentinels are numbers and leak into means and filters; a single Boolean validity bit, because a designer needs to know whether the pane was glass, the floor was sunlit or the steam was too thick; per-sensor ad hoc enums, because the viewer, the telemetry histograms and the gates need one vocabulary.

## Scope

In: the reason registry; the mask and flag types and their buffer layout on the host and on devices; the read interface that cannot yield a number for a masked sample; canonical bytes for digests; reason counts for telemetry; the rule for how a policy schema sees a mask.

Out: the models that set each reason (the sensor beads); the viewer's colouring of rays by reason (N20a-33).

## Technical approach

**1. Two kinds of annotation.** A *mask reason* applies to one sample (a pixel, a beam, a taxel, one scalar) and replaces its value. A *quality flag* applies to a packet or a channel and accompanies values that are still numbers (a clipped reading is a number, and is flagged).

**2. Reason registry** (`registries/mask_reasons.toml`, closed and versioned; an unknown code is a load-time error; codes are never reused). Names in the first group are the plan's; names in the second are DESIGN names for causes the plan lists without naming.

| Code | Reason | Set when |
|---|---|---|
| 0 | `valid` | The sample is a measurement |
| 1 | `weak` | A diffuse return below the detection threshold |
| 2 | `absorbed` | The ray ended on an `absorber` region |
| 3 | `attenuated` | The return fell below threshold after an optical volume |
| 4 | `mixed` | Sub-samples of one pixel disagree beyond the threshold (flying pixel; Frontier exposure integration) |
| 5 | `invalid: unknown-region` | The ray ended in a region the scene marks unknown |
| 6 | `pattern-through-glass` | Projected pattern passed through glass |
| 7 | `pattern-reflected-away` | Pattern reflected away by a mirror or polished metal |
| 8 | `pattern-absorbed` | Pattern landed on an absorber |
| 9 | `ambient-washout` | Surface lit above the pattern's irradiance |
| 10 | `beyond-range` | Past the card's maximum range |
| 11 | `near-blind` | Inside the near-plane blind zone |
| 12 | `grazing` | Incidence beyond the card's grazing limit |
| 13 | `projector-shadow` | Visible to the camera and not to the projector |
| 14 | `no-return` | No surface within the trace limit |
| 15 | `fault: dead` | Injected dead sensor |

**3. Flag registry** (bit set per packet, same file): `saturated` (clipped at the card range), `late` (lateness above zero under `hold`), `held` (a value older than one period presented again; never presented as fresh), `duplicate`, `ambiguous` (an encoder velocity whose sample gap violates the unwrapping condition), `overload-unknown` (a force reading with no resolved or modeled force history), `fault: stuck`, `fault: bumped`. A flag never replaces a value.

**4. Layout.** Every payload buffer has a parallel mask buffer of one unsigned byte per sample (reason code; 0 is valid) and each packet has one 32-bit flag word. On devices both are ordinary slabs in the exact-integer class. The value slot of a masked sample holds one canonical bit pattern (all zero bits), written by the kernel that masks it, so that a digest over payload and mask is canonical and two backends cannot differ in the garbage they leave behind.

**5. Read interface** (DESIGN).

```rust
pub enum Sample<T> { Valid(T), Masked(MaskReason) }
impl ObservationBuf { pub fn get(&self, i: usize) -> Sample<f32>; pub fn valid_iter(&self) -> impl Iterator<Item = (usize, f32)>; }
```

There is no accessor that returns the raw value slot without the mask; reductions (mean, min, max) are defined over `valid_iter` and return `Masked` when nothing is valid. Estimators and analyses receive `Sample`. A policy's observation schema must declare, per channel, how a mask is presented: a mask channel beside the values, with a declared fill. The fill is then part of the frozen schema, and the zero it writes is a declared encoding, not a measurement.

**6. Telemetry.** Per sensor and per reason, a count per packet is accumulated as an integer histogram; a design report can then say "31% of depth pixels `pattern-through-glass` on route segment 4".

## Acceptance criteria

- [ ] The registry loads; an unknown reason or flag code is a load-time error; removing a code that a recorded run used is refused.
- [ ] No public function of `frob-sense` returns a numeric value for a masked sample (a test enumerates the public read functions over a buffer with every reason planted).
- [ ] Every masked sample in the output of every sensor kernel has a non-zero reason code, and every valid sample has code 0 (property test over the sensor fixtures as they land).
- [ ] The digest of a buffer depends only on values of valid samples and on the reason codes (the canonical-slot rule): planting different garbage in masked slots before the kernel runs does not change the digest.
- [ ] Reason counts in telemetry equal a recount of the mask buffer.
- [ ] A policy schema without a declared mask presentation for a maskable channel is refused at registration.

## Test plan

### Unit tests
`crates/frob-sense/tests/mask.rs`; `cargo test -p frob-sense mask`.
- `registry_closed`: codes 0 to 15 and the eight flags load; code 200 fails to load.
- `sample_never_numeric`: for each reason r in 1..=15, `get` returns `Masked(r)`; `valid_iter` skips it; `mean` over an all-masked buffer is `Masked`.
- `canonical_slot`: two buffers with identical valid samples and masks and different pre-existing bits in masked slots have equal digests after `finalize_masks`.
- `flag_keeps_value`: a `saturated` packet still yields `Valid(clip_value)`.
- `held_flag_set`: re-presenting a sample older than one period sets `held` and its age exceeds the period.
- `reason_histogram_recount`: 10⁴ synthetic samples with a known reason mix give exact counts.
- Property `inv_sens_05`: for random buffers, (value is exposed) ⇔ (code is 0).

### End-to-end script and logging
Exercised by `scripts/e2e/sense_optical_failures.sh` (N20a-46), which asserts that every masked sample in every fixture carries a reason and logs the reason histogram as `metric` lines (`sensor`, `reason`, `count`). No private-scene geometry is logged: only counts.

### Known answers and negative controls
KA-485 (each pattern-camera dropout cause has its own reason; a masked value never appears as a number). Negative controls: a kernel that writes range 0 for an absorbed ray with code 0 (the property test must catch it); a kernel that sets a mask without a reason (code 0 on a masked slot) must be caught by the canonical-slot digest comparison against the reference. Determinism: mask buffers are exact-integer data, bit-identical across backends.

## Considerations

- The reason list will grow with the Frontier sensor models; growth is by appending codes, never by renumbering.
- Estimators must treat `held` and `late` correctly; a consumer that ignores flags is a consumer defect that the causal-policy and estimator tests surface.
- Memory: one byte per sample; for a 640 × 480 depth image that is 307,200 bytes beside 1.2 MB of values.
- Open point (DESIGN names): the nine reason names not given in the plan are proposals; the Sensorium lead may rename them before the registry is first frozen.
