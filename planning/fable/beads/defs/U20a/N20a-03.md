## Background

**ADR-SENS-09: truth, measurements, belief and policy observations are four namespaces with declared access.** The actor's input schema is frozen and is run with every privileged channel absent. Reason: the commonest silent defect in learned control is a leak of simulator truth. A policy that reads true base velocity, true friction or a curriculum parameter trains well and transfers to nothing, and nothing in its reward curve says so.

The four namespaces:

- **Truth**: the simulator's physical state and parameters (poses, velocities, contact forces, friction, hidden randomization values).
- **Measurements**: what sensors produced, as delivered packets with their instants, masks and flags.
- **Belief**: what an estimator computed from measurements (state estimate, covariance).
- **Policy observations**: the tensor an actor receives at a decision instant, assembled from delivered measurements and belief under a frozen schema.

**INV-SENS-07: the actor's inference input contains no privileged channel.** An asymmetric critic may read privileged state during training, under a schema marked training-only. The actor's inference schema is frozen, and tests run with the privileged channels physically absent, not zeroed: a zeroed channel still has a shape and a slot that a wiring mistake can fill.

Alternatives rejected: a naming convention (`priv_` prefixes), which nothing enforces; zeroing privileged inputs at evaluation, which hides a leak instead of removing it; one flat observation dictionary, which is how leaks happen.

## Scope

In: namespace-typed channel identifiers and references; the access table; the frozen actor schema type with its freeze function and the training-only schema (this bead is their one home in the workspace: the four reference types, channel identifiers and declarations, `ActorSchema`, `CriticSchema`, `freeze_actor_schema`; no other crate defines a second set); the second clause of refusal `FROB-REF-442` (a privileged channel in an inference schema, refused at schema time); the "physically absent" execution mode of the observation service; tests that the types forbid the leak.

Out, among the users of these types: the two state sources of hand-specified control, `EstimatedState` and `PrivilegedState`, with the out-of-sequence rule, the decision record and the estimated-against-privileged report (N22a-03 in `frob-control`, which depends on this bead and builds its wall from these reference types); the learner's access classes (`actor`, `critic-only`, `evaluation-only`), the tensor layout and projection of a schema, the freezing of a schema into a checkpoint manifest, refusal `FROB-REF-524`, isolated inference of a trained policy and the causality harness over a `VecEnv` (N23a-03 in `frob-learn`, which depends on this bead, re-exports `ActorSchema` and `CriticSchema` and defines no second schema type).

Also out: the leak registry, the five planted leaks and the conformance runner that executes an actor under the frozen schema with privileged buffers absent (N20b-10, which depends on this bead and uses its schema type); the twin worlds (N20b-09); the causal-policy test that catches leaks behaviourally (BD-119, BD-215); the presentation-state clause of `FROB-REF-442` (raised at registration by the observation service, N20a-01; presentation noninterference on every tier is measured by BD-215); the gym surface, whose access classes are built on these types; the estimator.

## Technical approach

**1. Types** (DESIGN).

```rust
pub enum Namespace { Truth, Measurement, Belief, PolicyObs }
pub struct ChannelId { ns: Namespace, name: InternedName }
pub struct TruthRef<'a, T>(/* … */);   pub struct MeasRef<'a, T>(/* … */);
pub struct BeliefRef<'a, T>(/* … */);  pub struct ObsRef<'a, T>(/* … */);
```

The four reference types are distinct and have no conversions between them. A value moves from one namespace to another only through a declared producer: a sensor (Truth history → Measurement), an estimator (delivered Measurement → Belief), an observation assembler (delivered Measurement and Belief → PolicyObs).

One home (DESIGN). These are the only namespace types of the workspace, and they live in `frob-sense`. Reason: the decision is the sensing chapter's; `frob-sense` comes after `frob-dyn` in the crate map's layer 3, so it can wrap the simulator's state as a `TruthRef`, while `frob-dyn` needs no namespace type in its own traits; and the two consumers that build walls from them, `frob-control` and `frob-learn`, are layer 4 and may name them. `frob-control` uses `TruthRef`, `MeasRef` and `BeliefRef` for its two state sources (N22a-03) and `frob-learn` uses `ChannelId`, `ActorSchema` and `CriticSchema` (N23a-03); neither declares wrappers of its own.

**2. Access table** (who may read which namespace).

| Reader | Truth | Measurement | Belief | PolicyObs |
|---|---|---|---|---|
| Sensor model | history view only | writes | — | — |
| Estimator | — | delivered packets only | writes | — |
| Observation assembler | — | delivered packets only | read | writes |
| Actor (inference) | — | — | — | read |
| Hand-specified controller, state source `estimated` (N22a-03) | — | — | read | — |
| Hand-specified controller, state source `privileged` (N22a-03; the run and its result are labelled privileged) | read | — | — | — |
| Critic (training-only schema) | read | read | read | read |
| Requirement monitors, reward terms | read | read | read | read |
| Telemetry, Autopsy, Nemesis, the analyses | read | read | read | read |

A reward may read truth (it scores the task); an actor may not.

**3. Schemas.** `ActorSchema` is a content-hashed, frozen list of channels: name, namespace (must be `PolicyObs`), source (which sensors or belief outputs, by identifier), shape, unit, mask presentation, and whether observation age is included (OPEN-SENS-3: by default age is recorded in telemetry always and given to a policy only if the schema declares it). `CriticSchema` carries `training_only = true` and may list Truth channels. Freezing means the schema's identity is part of the policy's identity and of every evaluation record; changing a channel makes a different policy.

**4. Validation at registration.** For each channel of an actor schema, resolve its source chain. Refuse with `FROB-REF-442` (second clause: "an actor schema names a privileged channel"; exit code 3) if any source is in Truth, or is a Belief or Measurement channel whose own producer was declared with privileged inputs, or is a task or curriculum parameter, or is a reward or termination signal, or if the channel is not of actor access (the same list as the division paragraph below). `pointer`: the channel; `observed`: the privileged source; ranked repairs as N20-REF's row orders them: 1. "use the observation service" (naming the delivered-packet channel that measures the quantity), 2. "move the channel to the training-only schema". The freeze also checks mask presentation: a channel that N20a-02's rule makes maskable and that declares no `MaskPresentation` is not frozen; `freeze_actor_schema` returns a typed schema error naming the channel (a schema error, not one of the chapter's refusal codes). A verb that offered the schema answers it as its schema failure, `FROB-REF-802`, exit code 3, with `pointer` the channel (DESIGN: the surface's code for an input that fails its schema, which every verb's refusal list carries; the chapter defines no code for this case and none is invented).

**442 and 524 (DESIGN; the plan gives both codes to an actor schema that touches a privileged channel and does not divide them).** They are divided by raising site, so that one event has one code. `FROB-REF-524` is the learner's: `frob-learn` raises it when one of its components asks to read, as the actor, a channel that the task classifies `critic-only` or `evaluation-only` (a network specification; a checkpoint's schema checked against the current task; a host caller's request for an actor view). That check runs before any schema is frozen, so such a request never reaches the freeze. `FROB-REF-442`, second clause, is the freeze's: `freeze_actor_schema` in `frob-sense` raises it, for whatever caller, when a channel offered for an actor schema is privileged by source (the truth namespace; a belief or measurement channel whose producer had privileged inputs; a task or curriculum parameter; a reward or termination signal) or is not of actor access. A learner's request that passed the class check and is still privileged by source (a task that classifies a truth channel as `actor`) is therefore 442. The same text stands in N20a-03, N23a-03 and the learning registry N23-REF.

**5. Physically absent.** In inference and in every test of causality, the environment is built from the actor schema alone: buffers for channels outside it are not allocated and no kernel argument refers to them. A run built this way and a run built with the critic's channels present and unused must produce identical actor inputs and commands.

## Acceptance criteria

- [ ] Converting a `TruthRef` into an `ObsRef` does not compile (compile-fail test); the only producers of `PolicyObs` are registered assemblers.
- [ ] An actor schema that names a truth channel, a curriculum parameter or a belief channel with a privileged producer is refused with `FROB-REF-442`, exit code 3, naming the channel, with N20-REF's two repairs in its order.
- [ ] An actor schema with a maskable channel (N20a-02's rule) that declares no mask presentation is not frozen, and the error names the channel.
- [ ] A critic schema without `training_only` that lists a truth channel is refused; with the mark it is accepted and is rejected by the inference builder.
- [ ] With privileged channels physically absent, actor inputs and commands are byte-equal to a run in which they are present and unused (INV-SENS-07, unit level).
- [ ] The schema identity changes when a channel, its source, its mask presentation or the age option changes.
- [ ] The access table is in `CONTRACT.md`, and each row has a test (the two rows of the hand-specified controller are tested in N22a-03).
- [ ] No crate other than `frob-sense` defines a namespace wrapper or an actor schema type: `frob-control` and `frob-learn` import these (checked by a workspace test that searches public items named `TruthRef`, `MeasRef`, `BeliefRef`, `ObsRef`, `ActorSchema` or `CriticSchema` outside `frob-sense` and admits only re-exports).

## Test plan

### Unit tests
`crates/frob-sense/tests/namespace.rs`; `cargo test -p frob-sense --test namespace`.
- `no_truth_to_obs_conversion` (compile-fail), `no_meas_to_truth_conversion` (compile-fail).
- `actor_schema_refuses_truth`: channel `base_lin_vel_true` sourced from Truth → 442, pointer the channel, the two repairs in N20-REF's order.
- `actor_schema_refuses_curriculum_param`: channel sourced from the task's terrain-difficulty parameter → 442.
- `actor_schema_refuses_privileged_belief`: a belief channel whose estimator was configured with `--state privileged` → 442.
- `critic_training_only`: accepted with the mark; the inference builder rejects it.
- `actor_schema_requires_mask_presentation`: a channel sourced from a delivered encoder packet without a mask presentation is not frozen and the error names it; with a mask channel and a declared fill it freezes.
- `absent_equals_unused`: on a synthetic one-joint world with an encoder, the actor input bytes over 1,000 decisions are equal in the two builds.
- `schema_id_sensitivity`: four single-field edits change the identity.
- `access_table_rows`: each forbidden read in the table is a type error or a registration refusal.

### End-to-end script and logging
No script of its own. The behavioural check is the causal-policy test's script `scripts/e2e/sense_causal_test.sh` (N20b-11, for BD-119), whose five planted leaks include the privileged channel wired into the actor; its step 4 registers the planted schema `names_truth_channel.json` through `frob sense causal-test --actor-schema …` and asserts a `refusal` event with code 442, exit code 3 and both repairs. The refusal is also triggered from the user's side by `scripts/e2e/sense_refusals.sh` (N20-REF, fixture 442b: an actor schema naming `truth.base_velocity`) on the CLI and over MCP. Both log through the STD-E2E helper: the exact command line, exit code, wall time, the envelope's evidence block, and the `refusal` line with code, pointer, observed source and repairs.

### Known answers and negative controls
KA-497 (the five planted leaks) is measured by BD-119; the first leak (a privileged state channel wired into the actor's input) and the fourth (a curriculum parameter passed as an observation) must be stopped at registration by this bead, and must also fail the behavioural test if registration is bypassed in a test build. Negative control for this bead: a build with the validation disabled must make `actor_schema_refuses_truth` fail.

## Considerations

- The reward and termination predicates read truth by design; their outputs must never be wired back as observations. The validator treats reward and termination signals as privileged sources.
- OPEN-SENS-3 (owner: Sensorium lead; decided at M3 with the first tasks that randomize latency): whether observation age is a default policy input. Fail-closed default: recorded in telemetry always; given to a policy only when its schema declares it.
- Distillation from a privileged teacher is legitimate; it runs under the training-only schema and its student is validated like any actor.
- Performance: absent channels cost nothing; that is also the fastest configuration.
