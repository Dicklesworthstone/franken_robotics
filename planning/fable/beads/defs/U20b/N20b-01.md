## Background
The observation-preserving subgroup Γ_obs is the set of elements g of the mechanical symmetry group Γ_mech (construction C-09) that also preserve everything the closed loop can see or is asked to do. The group operations belong to `frob-algebra`; the **predicates** that decide whether one element preserves the sensing interface belong to `frob-sense`, because only Sensorium knows what a pattern, a beam instant, a clock or a link is. This bead writes those predicates in their full form. The M1 analysis (BD-102) used only mount transforms and card identities; that is not enough, and the chapter gives two hand cases that show why.

- **A forward camera (KA-493).** A quadruped symmetric fore-aft and left-right, Γ_mech = C₂ × C₂, with a depth camera facing forward on the sagittal plane. The left-right reflection maps the camera to itself and each image row to itself, so it survives **if rows are read out top to bottom**. The fore-aft reflection and the half-turn do not survive. Γ_obs has order two; data augmentation doubles the data, it does not quadruple it.
- **A spinning lidar on the plane of symmetry (KA-494, CX-210).** A reflection reverses the order in which beams fire. With per-beam instants the mirrored robot would need a lidar that spins the other way, so the reflection is broken at first order in the product of body rate and scan time. It is restored only if the scan is treated as instantaneous, and the report must say which was assumed.

An IMU mounted off the plane of symmetry breaks the reflection of raw observations too; the symmetry analysis reports it as a near-symmetry with its repair (move the IMU by the stated offset, or declare the lever-arm correction part of the observation map).

Definition carried by this bead. Γ_obs is the set of g in Γ_mech that also preserve:
1. every sensor: g maps each mount frame to the mount frame of a sensor with an identical card, and maps its pattern (beam set, pixel grid) to itself **including its timing**;
2. every clock, link and latency of the interface;
3. the payload's inertia and any declared asymmetry of the load;
4. the task: its goal set, requirement predicates and reward terms;
5. the law of the scenes: the scene family is invariant under the corresponding reflection or rotation of the world.

The elements that preserve a structure form a subgroup (PO-SENS-05), so Γ_obs ≤ Γ_mech. Tier: Solid. Reason for the timing clause (DESIGN): a symmetry consumer that augments data or ties weights under an element that the timing breaks trains on observation streams no physical robot produces.

## Scope
In: the five predicate families as functions over one group element; the per-sensor induced channel permutation (pixel, row, beam, axis signs); the `scan_timing` assumption switch and its record; breaker records with sizes; the off-plane IMU near-symmetry and the lever-arm declaration; the closure card and exhaustive check for PO-SENS-05.
Out: computing Γ_mech and the generic filter loop (Marrow); the verb and storage (BD-241); the equivariance test on running worlds (BD-241); refusing consumers (N20b-02); equivariant networks (Frontier, the learning chapter).

## Technical approach
**Interface (DESIGN, `crates/frob-sense/src/symmetry/predicates.rs`).**
```rust
// DESIGN. Fixes intent, not signatures.
pub enum Preserved { Yes { channel_map: ChannelMap }, No(Breaker), Undeclared { term: TermPath } }
pub struct Breaker { field: FieldPath, family: Family, size: BreakSize, first_order_in: Option<&'static str> }
pub enum Family { SensorMount, SensorCard, PatternGeometry, PatternTiming, Clock, Link, Payload, Task, SceneLaw, Gravity }
pub enum ScanTiming { PerBeam, Instantaneous }   // recorded in the result and in the stored tuple
pub fn preserves(g: &Isometry, ctx: &ObsContext, timing: ScanTiming) -> Vec<(Family, Preserved)>;
```
`ObsContext` holds the sensor profile (suite, cards, patterns, clocks, links), the payloads, the task's declared terms and the scene family's declared invariance.

**1. Sensors.** For each sensor s with mount transform T_BS (pose of sensor frame S in the body frame B), the image under g with orthogonal part P and translation t is the frame g·T_BS. Search the suite for a sensor s′ with the same card hash such that g·T_BS = T_BS′·Q, where Q is one of the card's declared frame symmetries (a signed axis permutation under which the instrument is unchanged, for example a depth camera mirrored across its vertical plane; an IMU has the full signed-permutation set compatible with polar and axial parity). No such s′: breaker `SensorMount` with the distance and angle to the nearest candidate (this is what makes the off-plane IMU a near-symmetry: size = twice the offset from the plane). Then the pattern:
- *Geometry.* The image of the pattern's direction set under Q must be the direction set of s′, as a permutation π of ray indices. A depth camera with a symmetric pixel grid maps column u to W − 1 − u under the left-right mirror and row v to itself.
- *Timing.* Under `PerBeam`, the instant of each ray must be preserved: t_offset(π(i)) = t_offset(i) for every ray i, where t_offset is the ray's instant relative to the sample instant (row index times row time for a rolling shutter; firing time for a lidar beam). A top-to-bottom rolling shutter under the left-right mirror keeps each row, hence each instant: preserved. The same camera with a left-to-right column readout is broken. A spinning lidar under a reflection maps azimuth φ to −φ, so the beam fired at fraction f of the scan maps to the one fired at 1 − f: breaker `PatternTiming` with `first_order_in: "body rate × scan time"` and size = the largest instant mismatch. Under `Instantaneous` the timing clause is skipped and the result records the assumption.
- *Channel map.* The preserved case returns the signed permutation on the sensor's channels: ray permutation π for ranging sensors; for an IMU, accelerometer axes by P (polar) and gyroscope axes by det(P)·P (axial), composed with Q.
- *Raw IMU lever arm.* If the IMU is on the plane, preserved. If off the plane and the observation term is the raw reading, broken with the near-symmetry repairs. If the task declares the term "specific force at reference point O on the plane, with lever-arm correction", the predicate evaluates the corrected term and it is preserved.
**2. Clocks, links, latency.** Sensors exchanged by g (s ↦ s′) must have equal `ClockSpec` (period, phase, rate error, intra-step policy), equal link model parameters (latency, jitter, loss, duplication, reordering) and equal queue capacity. A phase that the task randomizes is compared in law (same distribution). Controller and actuator channels exchanged by the joint permutation must have equal command clocks and actuation latencies. Breaker `Clock` or `Link` with the differing field.
**3. Payload.** Each payload's pseudo-inertia must map to a payload's pseudo-inertia under g, and any declared asymmetry of the load (an off-centre centre of mass, a one-sided tote) is a breaker `Payload`.
**4. Task.** Every observation, action, reward and requirement term carries a declared transformation kind (invariant scalar, polar vector, axial vector, joint-indexed, foot-indexed, sensor-indexed, scan with a ray permutation). The predicate applies the induced representation and requires the term set, the goal set and the reward to be invariant. A term with no declaration returns `Undeclared` and excludes the element (fail-closed).
**5. Scene law.** The scene family declares the group of world isometries under which its distribution is invariant. g's world action must be in it. This is invariance in law: no single world need be symmetric (a quadruped crossing a patch slippery on one side only still licenses augmentation and forbids reduction inside that world, which is the separate stabilizer of the context).
**Gravity.** g must fix the direction of gravity at the reference configuration.

**PO-SENS-05 (the elements of Γ_mech that preserve the sensor suite, the task and the scene law form a subgroup).** Closure card, kept in `docs/derivations/po_sens_05_closure.md`: each of the five clauses has the form "g maps a set X with structure to itself"; if g and h do, then g·h does (composition of structure-preserving bijections) and g⁻¹ does (the inverse of a structure-preserving bijection of a finite set), and the identity does. The timing clause is such a structure (a function t_offset on the ray set, preserved under the permutation). Verification: the card, plus an exhaustive check on the template designs that the set returned by the predicates is closed under the multiplication table of Γ_mech.

**Determinism and evidence.** All comparisons are exact (rational mounts, integer instants in quanta, card hashes): D0. The result is `Certified` when the mounts come from constructors or exact arithmetic and `Tested` on the tolerance route for imported designs, with the tolerance recorded.

## Acceptance criteria
- [ ] `preserves` implemented for all five families plus gravity, with a `CONTRACT.md` entry stating each clause and its fail-closed behaviour.
- [ ] Forward depth camera with top-to-bottom rows on the symmetric quadruped: left-right mirror preserved with the column-reversing channel map; fore-aft mirror and half-turn broken with breaker `SensorMount`; Γ_obs of order two (KA-493).
- [ ] The same camera declared with column readout: left-right mirror broken with breaker `PatternTiming`.
- [ ] Spinning lidar on the plane of symmetry: broken under `PerBeam` with `first_order_in` set; preserved under `Instantaneous`, and the result records `scan_timing: instantaneous` (KA-494).
- [ ] Off-plane IMU: broken on the raw term with both repairs; preserved once the lever-arm correction is declared.
- [ ] Two mirrored sensors with periods 1/30 s and 1/31 s: breaker `Clock`.
- [ ] A task term without a declared transformation excludes every non-identity element and is reported as `Undeclared`.
- [ ] PO-SENS-05: the closure card is on file and the exhaustive closure check passes on every template available at the milestone.
- [ ] Negative controls caught here, at unit level: a predicate set with the timing clause removed admits the reflection of the spinning lidar, which contradicts KA-494's expected exclusion and fails `timing_clause_removed_mutant_admits_lidar_reflection`; a channel map that treats gyroscope axes as polar (P instead of det(P)·P) gives the wrong signs under a reflection and fails `gyro_polar_parity_mutant_caught` against the expected axial map. (The same timing mutant also fails BD-241's behavioural equivariance test, which depends on this bead and asserts it there.)

## Test plan
### Unit tests
(`cargo test -p frob-sense symmetry::`)
- `camera_rows_preserved_under_lr_mirror`, `camera_columns_broken_under_lr_mirror`.
- `lidar_spin_broken_per_beam`: 10 Hz spin, 360 azimuth steps: beam at step k maps to step 360 − k; instants k/3,600 s and (360 − k)/3,600 s differ; the largest mismatch, |360 − 2k|/3,600 s at k = 1 or 359, is reported as exactly 358/3,600 s.
- `timing_clause_removed_mutant_admits_lidar_reflection` (KA-494's control).
- `gyro_polar_parity_mutant_caught`: under the left-right mirror P = diag(1, −1, 1), det(P) = −1, the gyroscope map is diag(−1, 1, −1); the polar mutant's diag(1, −1, 1) is rejected.
- `lidar_spin_preserved_instantaneous_records_assumption`.
- `imu_offplane_near_symmetry_size`: offset 12 mm gives size 24 mm to the image mount.
- `clock_mismatch_breaks`, `link_latency_mismatch_breaks`.
- `payload_one_sided_breaks`.
- `undeclared_task_term_excludes`.
- `scene_law_in_law_not_per_world`: a family declared mirror-invariant passes although a sampled world is not mirror-symmetric.
- `closure_exhaustive_templates` (PO-SENS-05): for each template, the preserved set is closed under products and inverses.
- Property test `preserved_set_is_subgroup` over random sensor placements on mirror-constructed designs.
### End-to-end script and logging
Exercised from the user's side by the `sense.symmetry` script of N20b-03 (`scripts/e2e/sense_symmetry.sh`), which logs per STD-E2E: the group orders, each breaker with its family and size, the `scan_timing` assumption, and the closure check as `assert` lines.
### Known answers and negative controls
KA-493 (order two inside order four; control: the fore-aft reflection fails the equivariance test), KA-494 (broken with per-beam instants), CX-209, CX-210. Planted failures: timing clause removed; card equality by kind instead of hash (admits two different lidars as images); polar parity applied to the gyroscope (must break the mirror for a correctly mounted IMU pair and is caught by the equivariance test). Determinism: D0, identical results across platforms.

## Considerations
- The set of declared frame symmetries Q of a card is new card data; a card without it is treated as having only the identity, which can only shrink Γ_obs (fail-closed).
- A `retime` edit applied to one sensor of a mirrored pair changes Γ_obs although the typed-edit table lists `retime` as symmetry-preserving; the predicate is authoritative and the mismatch is reported to the lead in the unit's coverage file.
- The `Instantaneous` switch exists because some consumers legitimately model a scan as instantaneous (a slow robot, a fast scan); it is an assumption recorded in the stored tuple, never a default.
- Every move of a sensor mount recomputes these predicates (the visibility optimizer of N20b-36 relies on that).
