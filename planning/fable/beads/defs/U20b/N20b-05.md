## Background
A pose-graph calibration (N20b-04) estimates corrections δ to sensor mounts from pairwise relative-pose measurements with stacked residual r, block incidence matrix B and weights W. Two different faults must be told apart, because their repairs differ: a **bumped sensor** (its mount really moved; the repair is to accept the new extrinsics) and a **faulty edge** (one pairwise estimate is wrong, or one pair has a time offset; the repair is to distrust that measurement). The tool that separates them is the part of the residual that no assignment of extrinsics can explain:

  r_⊥ = (I − B·(Bᵀ·W·B)⁻¹·Bᵀ·W)·r.

- A bumped sensor is a change of extrinsics. The solve absorbs it: the estimate δ̂ at that node moves by the bump and r_⊥ stays at noise level. It is detected as a change of δ̂ beyond its covariance.
- A faulty edge is inconsistent round every cycle through it: r_⊥ is not small.

Two facts constrain what can be claimed, and each is a counterexample to a tempting shortcut.

1. **The projector is orthogonal in the metric W, not in the Euclidean metric** (PO-SENS-08, CX-212). Rotations in radians and translations in metres have different scales; the Euclidean projector I − B·(Bᵀ·B)⁻¹·Bᵀ gives a different and wrong decomposition whenever W is not a multiple of the identity.
2. **An inconsistent loop does not identify the bad measurement** (CX-211). On a tree, B is square after anchoring and r_⊥ is identically zero: there is no redundancy, a bump and a bad edge are indistinguishable, and a request for fault localization is refused (FROB-REF-446). Detecting a bad edge needs that edge to lie on a cycle. Identifying which edge is bad needs more. With scalar offsets, unit weights and one edge biased by β: three sensors with three pairwise edges (one cycle) give a least-squares residual of β/3 on every edge, so the loop is known to be inconsistent and the bad edge is not identified; four sensors with all six pairwise edges give β/2 on the bad edge, β/4 on the four edges that share a node with it and zero on the opposite edge, so the bad edge has the unique largest residual, by a factor of two.

Tier: Solid. Owner: `frob-sense`.

## Technical approach
**Consistency residual.** With N = Bᵀ·W·B and the converged estimate δ̂ = N⁻¹·Bᵀ·W·r, r_⊥ = r − B·δ̂. Define P = B·N⁻¹·Bᵀ·W (the W-orthogonal projector onto the range of B). Properties that the code asserts in debug builds and the tests check: P·P = P; Bᵀ·W·r_⊥ = 0 (the residual is W-orthogonal to everything extrinsics can explain); r_⊥ᵀ·W·(P·r) = 0. Per-edge report: the six components of r_⊥ on edge e, its angular norm in radians, its linear norm in metres, and its whitened norm (r_⊥,eᵀ·W_e·r_⊥,e)^½.

**Graph support, computed before any fault claim.** Let m be the number of edges and n the number of nodes (anchor included).
1. Not anchored or not connected: refused upstream (FROB-REF-446).
2. Redundancy number ν = 6·(m − n + 1) (six times the cycle-space dimension). ν = 0 is a tree: r_⊥ ≡ 0, no fault test is possible.
3. For each edge e and each of its six components, the response pattern is the column c = (I − P)·u, with u the unit vector of that component. The edge is **detectable** iff its patterns are not all zero (equivalently, it lies on a cycle). It is **identifiable** iff no other edge has a pattern parallel to it in the W-inner product (the normalized inner product of the two patterns is below 1 − 10⁻⁹). In a single triangle the three scalar patterns are all proportional to (1, 1, 1): detectable, not identifiable. In the complete graph on four nodes the patterns are distinct.
4. For each node v, a bump at v is separable from a bad edge iff every edge at v is detectable.
The support report lists, per edge, `detectable` and `identifiable`, and per node, `bump_separable`.

**Fault tests (DESIGN; thresholds are TARGETs to set against the fixture's noise).**
- *Global consistency.* q = r_⊥ᵀ·W·r_⊥ is, under the noise model, chi-squared with ν degrees of freedom. `consistent` if q is below the 1 − α quantile, α = 10⁻³ (TARGET).
- *Bad edge.* If inconsistent: score each identifiable edge by its normalized residual w_e = (r_⊥,eᵀ·(W_e⁻¹ − B_e·N⁻¹·B_eᵀ)⁺·r_⊥,e)^½ (the residual divided by its own covariance, which is what makes scores comparable between edges of different redundancy). Attribute to the edge with the largest score if it exceeds the runner-up by a declared factor (1.5, TARGET; the scalar four-node case gives exactly 2). Otherwise report `inconsistent, not localized` with the tied candidates.
- *Bumped sensor.* Compare δ̂ with a reference solution δ̂_ref (the last accepted calibration): for each node, d_v² = (δ̂_v − δ̂_ref,v)ᵀ·(Σ_v + Σ_ref,v)⁻¹·(δ̂_v − δ̂_ref,v), chi-squared with 6 degrees of freedom under no change. A node with d_v² above the 1 − α quantile, while the graph is `consistent`, is a bump at v, reported with the change in degrees and millimetres and its covariance.
- A request that asks for a localization the support report does not allow (bad-edge localization with a non-identifiable edge set; bump-against-edge discrimination on a tree) is refused with **FROB-REF-446** "a calibration request exceeds what the graph supports: no anchor, or fault localization on a graph without the needed cycles"; ranked repairs: anchor the base; add pairwise measurements (the support report names which missing edges would make each undetectable or unidentifiable edge identifiable). Exit code 3.

**Scalar known answers, with derivation (KA-495).** For the complete graph on n nodes with unit weights, P = (1/n)·B·Bᵀ, whose diagonal is 2/n and whose entry between two edges sharing one node is ±1/n and between disjoint edges 0. A bias β on one edge therefore leaves a residual of β·(1 − 2/n) on that edge, β/n in magnitude on each edge sharing a node with it, and 0 on disjoint edges. n = 3: β/3 on all three. n = 4: β/2, β/4 on the four adjacent edges, 0 on the opposite edge.

**Control case with anisotropic weights (derived here for the negative control; to be re-derived on file before it is pinned).** Triangle with nodes 0 (anchor), 1, 2; edges a: 0→1, b: 1→2, c: 0→2; scalar offsets; weights (1, 1, 4); bias β on edge a, so r = (β, 0, 0). Then N = [[2, −1], [−1, 5]], δ̂ = (5β/9, β/9), and r_⊥ = (4β/9, 4β/9, −β/9), which satisfies Bᵀ·W·r_⊥ = 0. The Euclidean projector returns (β/3, β/3, −β/3), for which Bᵀ·W·r = (0, −β) ≠ 0: it leaves part of the residual that the extrinsics could have explained, and reports the wrong sizes.

**Determinism and evidence.** Host `f64`, D2 on the host; outputs `Tested`.

## Considerations
- The normalized-residual score needs a pseudo-inverse of each edge's residual covariance; for an edge with zero redundancy that covariance is zero and the edge is, correctly, not scored.
- The thresholds α and 1.5 are TARGETs: they are set once against the simulated rig's noise before GATE-SENS-11 is run and are recorded in the gate receipt, not tuned per seed.
- A time offset on one pair is a faulty edge whose size depends on velocity. With a single axial velocity it cannot be separated from a mount translation; the diagnosis then reports the identified combination and updates neither, which N20b-08 carries for real logs.
- Two simultaneous bad edges can mimic a bump at their common node; the report states that attribution assumes one fault.
