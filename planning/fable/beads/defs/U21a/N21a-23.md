## Background

To know that two runs of a world agree, the system compares **digests** of the world's state. Reading whole state
slabs back from a GPU for every comparison would dominate the run, so a kernel on the device computes a small
digest per world, and only those cross to the host. Spark's fourth class rule fixes what that kernel is:

**Digests are integer mixes.** `K-x-digest` folds the raw bit patterns of the canonical state slabs of one world
into four `u32` words in slab order. A run digest is the wrapping sum of per-world digests keyed by address, which
is independent of slot order. The device digest is a **tripwire** classed `Tested`; identities in the record (for
example `EpisodeId`) are BLAKE3 hashes computed by the host over committed snapshots.

Reasons (DESIGN). (1) Integer arithmetic is exact (determinism class D0) on CPU, CUDA and Metal, so a digest
difference means a state difference, never a rounding difference in the digest itself; a digest computed with any
floating operation could differ between backends on identical states. (2) Folding **bit patterns** makes −0.0 and
+0.0 different, which is what a bitwise-replay claim needs. (3) Keying by the world's address and summing with
wrapping addition makes the run digest independent of which slot a world occupied, which matters because slots
are reassigned (persistent environments pull the next episode into whichever slot frees up) and worlds are
permuted and regrouped freely. (4) A 128-bit integer mix is not an identity: it is not collision-resistant against
an adversary and must never name an artifact; that is BLAKE3's job on the host.

The counterexample the rule protects against: a digest that chains in slot order (h ← mix(h, state of slot 0),
then slot 1, …) changes when the same worlds are placed in a different order, so it reports a difference where
there is none. Tier: Solid. Rejected alternatives: BLAKE3 on the device (needs far more state and rounds per
world than a tripwire warrants, and 64-bit rotations in some variants); CRC of floats after conversion (a float
operation in the digest path); a per-run chained digest (order-dependent).

This bead fixes the contract and the reference implementation. The replay bead (BD-203) wires the kernel into the
chunk record, per-stage digests and snapshots.

## Scope

In: the mix function, frozen with test vectors; the canonical order of words; the active-lane rule (padding is not
folded); the address key; the run digest; Rust and dialect implementations in the exact class; law tests.
Out: where digests are stored and compared (BD-203, BD-204, BD-206); BLAKE3 identities on the host; the

## Technical approach

All operations are the exact-integer operators of the kernel IR (N21a-17): `addw`, `mulw`, `xor`, `shl`, `shr`
with masked counts; rotl(x, r) = or(shl(x, r), shr(x, 32 − r)). Floats enter only through `bits(x)`, a
reinterpretation with no arithmetic. Kernel class `exact`, math mode `ExactInteger`, determinism D0.

**Canonical word order.** The step plan lists the *canonical state slabs* in a fixed order (configuration,
velocity, anchors, warm starts, actuator and battery state, packet queues and whatever else a snapshot must
restore; the list is part of the plan and of the digest's version). For one world, the word sequence is: for each
slab in that order, for each **active** element of the world's row in index order, each 32-bit word of the element
in field order. Padding lanes (beyond the world's active count for that slab, which comes from its model variant)
are not folded. Reason: a world's digest must be the same at two bucket capacities, and padding length is a
property of the bucket, not of the world.

**Per-world digest D(addr, words) (DESIGN; the constants and rounds below are the proposal this bead freezes after
the avalanche tests; any change after freezing is a new digest version).**
1. Initialize four accumulators: accᵢ = Sᵢ xor addrᵢ, with S = (0x243F6A88, 0x85A308D3, 0x13198A2E, 0x03707344)
   and addr the four `u32` words of the world address.
2. For the j-th word w of the sequence (j counts folded words only, from 0): let i = j mod 4;
   accᵢ ← mulw(rotl(addw(accᵢ, mulw(w, 0x85EBCA77)), 13), 0x9E3779B1).
   In the kernel the loop runs to the slab's capacity with a literal or capacity bound; a padding lane leaves the
   accumulators unchanged through a select on (lane < active count), and j advances only on folded words.
3. Cross-mix: t = addw(addw(rotl(acc₀, 1), rotl(acc₁, 7)), addw(rotl(acc₂, 12), rotl(acc₃, 18))).
4. Finalize each word: x = addw(addw(accᵢ, t), addw(n, i)) with n the number of folded words; then
   x ← x xor shr(x, 15); x ← mulw(x, 0x85EBCA77); x ← x xor shr(x, 13); x ← mulw(x, 0xC2B2AE3D);
   x ← x xor shr(x, 16); Dᵢ = x.
The digest is the four words (D₀, D₁, D₂, D₃), presented as a `u128` with D₀ least significant.

**Run digest.** R = Σ over worlds of D(addr, words), as four independent wrapping sums (word-wise addw). It is
computed on the device by the fixed-tree integer reduction (wrapping addition is associative and commutative, so
any order gives the same bytes) or on the host from the per-world digests. Because each term is keyed by its
world's address, exchanging the states of two worlds changes R, while exchanging their slots does not.

**Per-stage digests.** The same function over the output slabs of one stage, with a stage tag folded as the first
word; used to localize a first divergence to a stage. The tag values are part of the digest version.

**Evidence class.** A digest comparison is a test: equal digests are evidence class `Tested` that states agree;
they are never cited as an identity. `EpisodeId` and chunk content hashes are BLAKE3 over committed bytes on the
host.

**Manifest.** Read footprint: the world's own rows of the canonical slabs and its address and active counts;
write footprint: the world's digest slot (four words). No cross-world access in `K-x-digest`. The run-digest
reduction reads every world's digest, so it is a separate kernel of class `stat` (inner class `exact`) built on the
library's fixed-tree integer reduction (`K-reduce` with `addw`, word-wise); its output is telemetry and feeds no
state, which the statistics data-flow check of N21a-22 verifies like any other `stat` output.

**Probe suite.** This bead adds the suite `digest` to `spark.probe` (BD-017's verb, through the harness used by the
suite `exact-ops` of N21a-17): it runs `K-x-digest` and the run-digest reduction on a seeded synthetic state slab,
once in slot order and once with the slots permuted, and reports the per-world digests by address and the run
digest. The verb's registry row in VERBS-spark lists the suite `digest` (M2) with this bead as its carrier, and
`all` includes it once this bead is in the build.

## Acceptance criteria

- [ ] `K-x-digest` exists in Rust and in the dialect, class `exact`; dialect text passes the lint (unsigned 32-bit arithmetic, masked shifts, literal or capacity loop bounds).
- [ ] Test vectors are checked in (at least: the empty sequence at address (0, 0, 0, 0); one word 0; one word 1; the 16 words 0 … 15; a 1,000-word seeded sequence at a seeded address) and are reproduced byte for byte on `batch-cpu`, each RTX 4090 and Metal.
- [ ] Slot independence (KA-535): for 256 worlds under 100 seeded slot permutations the run digest is unchanged, and every per-world digest is unchanged when looked up by address.
- [ ] Negative control: a variant that chains per-world digests in slot order changes under the same permutations and is caught.
- [ ] Capacity independence: a world's digest is identical at two bucket capacities (padding not folded); a variant that folds padding lanes is caught by this test.
- [ ] Sensitivity: flipping any single bit of any folded word changes the digest (tested for every bit position of a 64-word sequence); −0.0 against +0.0 in one field changes it; exchanging the states of two worlds changes the run digest.
- [ ] Avalanche (the freeze criterion): over 10⁵ random single-bit flips, each of the 128 output bits flips with frequency between 0.45 and 0.55.
- [ ] The manifest declares footprints and passes the footprint audit; the kernel is in the library index with its digest version.

## Test plan

### Unit tests (`cargo test -p frob-kernels digest`)
- `digest_test_vectors`: the five vectors.
- `digest_bit_patterns_not_values`: +0.0 and −0.0 differ; two NaNs with different payloads differ.
- `digest_keyed_by_address`: the same words at two addresses give different digests.
- `run_digest_slot_permutation_invariant` (KA-535).
- `run_digest_chained_variant_is_caught` (negative control).
- `run_digest_state_swap_detected`.
- `digest_capacity_independent`; `digest_folding_padding_is_caught` (negative control).
- `digest_single_bit_sensitivity`; `digest_avalanche`.
- `digest_length_matters`: sequences [w] and [w, 0] differ (the count n is mixed in).
- `digest_rust_equals_interpreter`: the IR program evaluated by the reference interpreter equals the Rust skeleton.
- Property test: for random word sequences and random permutations of worlds, R is invariant under the permutation and D is a function of (addr, active words) alone.

### End-to-end script and logging
`scripts/e2e/spark_probe.sh` (bead N21b-40), step `digest`: `frob spark probe --suite digest --device <d>
--seed <s> --key dg-<d> --json`, once for `batch-cpu`, for each CUDA card and for Metal (the verb is run-kind: a
call without `--key` is refused with `FROB-REF-805`; an absent device is logged `not-run`), computes per-world and
run digests of a seeded synthetic state slab on that backend, in slot order and again with slots permuted. Asserts the test vectors, equality across
backends, and invariance under permutation. Logged per line: command, exit code, wall time, evidence block
(determinism `exact`), the run digest as hex, the permutation seed, and on failure the first world address whose
digest differs with both values.

### Known answers and negative controls
- KA-535: the run digest is unchanged under slot permutation; negative control: a digest that chains in slot order.
- Negative controls: folding padding; chaining; a mix variant with one constant changed must fail the checked-in vectors.
- Metamorphic: appending a world adds its D to R (R′ − R = D word-wise mod 2³²); removing it subtracts it.
- Determinism lanes: byte equality twice on one machine, across worker counts, debug and release, across platforms and the three backends (class D0).

## Considerations

- A wrapping sum of per-world digests is linear, so two compensating state changes in different worlds can cancel in R with probability about 2⁻¹²⁸ per attempt at random and by construction for an adversary. R is a tripwire; divergence localization always follows up with per-world digests, which do not have that weakness between themselves.
- The digest version (constants, slab list, stage tags) is part of every record that stores a digest; a version change is not a state change and comparisons across versions are refused, not attempted.
- Cost: about 4 integer operations per folded word plus the finalization; a quadruped's integration state of a few hundred words is a few thousand integer operations per world per digest. The plan's memory arithmetic puts a humanoid's integration state at about 540 bytes.
- The digest covers what a snapshot restores; anything a replay depends on that is left out (a warm-start buffer, a packet queue) would let two different worlds share a digest. The canonical slab list is therefore reviewed against the snapshot's restore set whenever either changes.
