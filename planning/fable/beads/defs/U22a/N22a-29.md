## Background
The symmetry atlas (analysis A-04) lists the gaits a body can have. The gait crate `frob-gait` (layer 4, tier Frontier) computes whether a listed gait exists as a periodic orbit of the closed loop, whether it is stable, how it moves when the design changes, and what a design change does to a metric measured on it. Everything in the crate rests on one object, built here: the map that advances the closed loop by one stride.

Two decisions shape it.
- ADR-REFLEX-04: gait orbits are computed for the design under its synthesized baseline controller, first on the compliant tier by differentiating the discrete step; event-located orbits with saltation matrices are a second route. Reason: an orbit belongs to a closed loop, not to a body; and on the throughput tiers contact force is a continuous function of state, so the step map is continuous and piecewise smooth and the first implementation needs no event bookkeeping. Alternative rejected: starting from the sibling simulator's orbit tools (FACT: `frankensim/crates/fs-orbit` has shooting, pseudo-arclength continuation and monodromy for a nonlinear island on a linear port; it has no hybrid multiple-shooting solver on articulated models and no derivatives of articulated dynamics with respect to state or design, and serves here as an oracle for toy known answers only).
- The layering rule: `frob-gait` and `frob-control` are both in layer 4, and no layer-4 crate imports a sibling it does not strictly follow. The controller therefore reaches this crate only as an implementation of the `Controller` trait declared beside the step plan in `frob-dyn`. The verb layer builds the baseline and hands it over.

The state of the closed loop is x = (q, v, a, c): configuration, velocity, actuator and thermal states, and controller state (the gait clock, and the filter state when the loop runs on estimated state). One control period on a batched tier is a map F_θ: x ↦ x⁺, with θ the design parameters. The baseline's gait clock forces the loop periodically, so a stride of N control periods is the stroboscopic map P_θ = F_θ^N, and the stride period is a rational number in the clock contract.

On flat ground under a body-frame velocity command the closed loop is equivariant under horizontal translation, and under yaw when heading is not tracked. Those coordinates are removed and listed in the result; x̄ is the state without them. A gait is a fixed point P̄_θ(x̄*) = x̄*, which is a relative periodic orbit of the full state whose drift is the stride displacement.

Every result that leaves this crate is labelled `screening: gait-orbit`: published full-order orbit solves cost about 4 to 260 s of CPU at 20 to 68 states (about 1% to 63% of a 410 s quadruped training run), an orbit is not an accepted controller, and local stability on flat ground supplies no estimate of recovery on a staircase.

## Scope
In: the crate `crates/frob-gait/` with its contract file and layer checks; the closed-loop harness over a batched tier; the control-period map and the stride map; the reduced chart with its removed coordinates, lift and reduce; the equivariance precondition; the stride displacement; the contact-sequence signature; stride metrics; batched evaluation with per-world design parameters; the refusal of a clock-less loop.
Out: derivatives of the map (N22a-30); shooting (N22a-31); monodromy, blocks and spectrum (N22a-32); event-located maps and saltation (N22a-33); simultaneous impacts (N22a-34, N22a-35); the result record (N22a-36); continuation (N22a-37); gradients and the verbs (BD-333, BD-334, BD-335); enumeration of gaits and phase lags (the atlas, BD-332); autonomous loops, which are solved on an event section (N22c-36) or through a bordered system with a phase condition (N22c-37), the beads of the autonomous-orbit subsection; the `gait-instability` failure-class monitor of the record subsystem, which reads stride events of a declared periodic gait in this bead's scaled chart and is switched to `available` by N22ap2-03 (it depends on this bead and on the failure-class rows of N24a-38).

## Technical approach
**Crate.** `crates/frob-gait/` with modules `map`, `chart`, `deriv`, `shoot`, `monodromy`, `event`, `impact`, `cont`, `grad`, `record`, and `CONTRACT.md` with its ten sections (purpose; inputs; outputs; invariants; refusals; determinism class; evidence class of outputs; validity domain; oracles; known gaps), filled for what exists and marked `pending` per capability otherwise. Allowed dependencies: `frob-core`, `frob-fsim`, `frob-lie`, `frob-algebra`, `frob-model`, `frob-kernels`, `frob-dyn`. Forbidden: every other layer-4 crate, including `frob-control`, and every layer-5 crate; the layer check enforces it.

**Types (DESIGN sketch).**
```rust
pub struct ClosedLoop<'a> {
    pub model: &'a CompiledModel,          // the design at parameters θ
    pub controller: &'a dyn Controller,    // any implementation; identity via controller.id()
    pub state_mode: StateMode,             // Privileged | Estimated
    pub tier: TierId, pub step_plan: StepPlanId,   // batch-cpu, f64, lockstep by default
    pub world: OrbitWorld,                 // flat ground, nominal friction, command twist, no randomization, noise-free sensors
}
pub struct StrideSpec { pub periods: u32 /* N */, pub control_period: Rational, pub substeps: u32, pub phase0: u32 }
pub struct ReducedChart { pub removed: Vec<RemovedCoord>, pub scales: Vec<f64>, pub dim: usize }
pub struct StrideEval {
    pub xbar_next: Vec<f64>, pub drift: PlanarDrift,        // (Δx, Δy, Δψ) in the frame at stride start
    pub contact_seq: ContactSeqSig, pub active_set_sig: Vec<u64>,   // per physics step
    pub metrics: StrideMetrics, pub status: StrideStatus,   // Ok | Fell | ChartLeft | StepFault
}
pub trait StrideMap {
    fn chart(&self) -> &ReducedChart;
    fn eval_batch(&self, xbars: &[Vec<f64>], thetas: &[DesignPoint], periods: u32, cx: &Cx)
        -> Result<Vec<StrideEval>, GaitError>;
}
```

**The control-period map.** One evaluation of F: read the state view through the declared `StateSource`, evaluate the controller, apply the command through the actuator limiter, advance `substeps` physics steps of size h, with control period Δt_c = substeps·h checked as an exact rational identity. For F to be a function of x alone: the orbit world draws no randomness and its sensors use their noise-free models; solver warm starts are disabled in the step plan used for orbit work (DESIGN default `cold-start`, recorded in every result) or, when the tier exports them, carried as part of `a`. The gait clock is an integer tick counter modulo N; it is carried as a discrete index beside x̄, never as a differentiable coordinate.

**Classification gate.** The controller's record declares its phase source: `clock`, `event-reset` or `none`. The stride map is built only for `clock`. For the other two the constructor returns the refusal registered under the slug `fixed-period-shooting-on-free-period` (the row is N22-REF's, a dependency; slug-keyed until the refusal-allocation round gives it a number; exit code 3), carrying the phase source and the transverse events available, with the repair "use the section form on a named event, or the bordered form with a phase condition". A loop with a free period has a multiplier of exactly one along its flow, so the fixed-point equations of this crate would be singular on every such orbit and would report a fold that is not one.

**The reduced chart.**
1. Base pose (p, R) with R = R_z(ψ)·R_tilt. Kept: height p_z; the tilt as the first two components of the body-frame gravity direction Rᵀ·e_z (unchanged by world yaw; valid while its third component is positive, otherwise status `ChartLeft`). Removed: p_x, p_y, and ψ when the controller does not track heading.
2. Velocities as the body-frame twist (invariant under world translation and yaw).
3. Joint positions and rates, actuator and thermal states, and the continuous part of the controller state.
4. Scales: lengths by the leg length ℓ₀, speeds by √(g·ℓ₀), angles by 1 rad, rates by √(g/ℓ₀), currents and temperatures by their card ratings. Reduced coordinates are stored dimensionless, because the spectral analysis downstream takes a dimensionless matrix in a disclosed chart.
5. `lift(x̄)` places the base at the origin with zero yaw; `reduce(x)` returns x̄ and the removed values. `reduce(lift(x̄)) = x̄` to round-off.
6. For a 12-joint quadruped with two states per actuator on privileged state, the reduced dimension is 3 + 6 + 24 + 24 = 57 (DESIGN estimate for the robots in scope: 40 to about 130).

**Equivariance precondition.** Before any coordinate is removed, the harness checks the symmetry it relies on: for sixteen sampled planar transforms g (translations up to 10 m, yaw over the circle), `reduce(F^N(g·x))` equals `reduce(F^N(x))` and the drift composes as g predicts, within 10⁻¹⁰ in the scaled norm. If translation fails (terrain that is not flat, a controller that tracks an absolute position) nothing is removed and the result says `symmetry-not-available` with the coordinate that broke it. If only yaw fails (heading is tracked), yaw stays in x̄.

**Stride map and drift.** P̄(x̄) = reduce(F^N(lift(x̄))). The drift (Δx, Δy, Δψ) is the stride displacement; mean speed is the planar distance over the stride period N·Δt_c. A fixed point of P̄ is a relative periodic orbit of the full state.

**Signatures.** Per physics step, the hash of the active contact set with a stick or slip state per contact (`active_set_sig`); per stride, the ordered list of touchdown and liftoff events by foot identity and tick (`contact_seq`). Derivative labels and continuation's `mode-change` outcome are computed from these.

**Stride metrics** (each a sum or extremum over the stride, read from telemetry of the same run): cost of transport E_elec/(m·g·d), with E_elec the electrical energy drawn over the stride, m the total mass and d the planar stride distance; peak torque margin, the minimum over ticks and joints of 1 − abs(τ)/τ_env(ω) against the card's torque-speed envelope; friction utilization, the maximum over ticks and contacts of abs(fₜ)/(μ·fₙ); duty factor per leg.

**Estimated state.** DESIGN default: orbits are computed on privileged state, and the record says so. On estimated state the belief enters x̄ relative to truth (the invariant error and its covariance in the body frame). The filter's covariance along its four unobservable directions (position and yaw) grows without bound and cannot be part of a fixed point; it is excluded and listed among the removed coordinates. HYPOTHESIS: the reduced loop is then closed. The test is the equivariance precondition applied to truth and belief together; if it fails the result is `unsupported: belief-not-reducible` and the privileged-state orbit stands, labelled.

**Batched evaluation.** `eval_batch` runs one world per (x̄, θ) pair in a single batch, with θ supplied as parameter variants. A world's result does not depend on the other worlds in its batch. This is what makes tangent worlds cheap: a Jacobian is a batch.

**Determinism and evidence.** Class D2 on `batch-cpu` in `f64` (bit-identical on one device family, for any batch composition and worker count). Outputs are class `Estimated` (an orbit computation is neither a checker nor the Gauntlet harness nor the study runner, so its claim products are Estimated; the record bead N22a-36 and the verb registry's *screening* label say the same), in the model, on the named tier and step plan, with standing `screening`.

## Acceptance criteria
- [ ] The crate builds, `CONTRACT.md` has its ten sections, and the layer check rejects a planted import of `frob-control`.
- [ ] For the reference quadruped under its baseline trot on `batch-cpu`: the stride map evaluates; Δt_c = substeps·h and T = N·Δt_c hold as exact rationals; the stride displacement divided by T is within 20% of the commanded speed after ten settling strides.
- [ ] `reduce(lift(x̄)) = x̄` within 10⁻¹⁴ on 10³ random reduced states.
- [ ] The equivariance precondition passes on flat ground; with a planted 5% ground slope in the world, translation along the slope is reported `symmetry-not-available`; with a controller that tracks absolute heading, yaw is kept and translations are removed.
- [ ] The same (x̄, θ) evaluated alone, in a batch of 64 with unrelated co-tenants, in a permuted batch and across worker counts gives bit-identical results (class D2).
- [ ] With warm starts enabled and not carried as state, a planted test detects that the map is not a function of x̄ (two evaluations from the same x̄ after different histories differ), and the default `cold-start` plan passes the same test.
- [ ] A controller whose record declares phase source `event-reset` or `none` is refused with the registered slug, exit 3 at the surface, and the repair text.
- [ ] A stride in which the body falls returns status `Fell` with the tick, never a number for x̄⁺.
- [ ] Cancellation during a batch returns `Cancelled` and leaves no partial result.

`crates/frob-gait/tests/stride_map.rs`; the real batched step and the real baseline, built in the test from the registered archetype; fixtures that are not robots are labelled `synthetic`.
- `stride_period_is_rational`: Δt_c = 1/50 s, h = 1/500 s, N = 25 gives T = 1/2 s exactly; h = 3 ms is rejected because 20/3 is not an integer.
- `lift_reduce_round_trip`; `tilt_chart_leaves_at_horizontal`.
- `equivariance_flat_ground`; `slope_breaks_translation`; `tracked_heading_keeps_yaw`.
- `drift_matches_commanded_speed`.
- `batch_independence_bits`; `worker_count_independence_bits`; `replay_bits`.
- `warm_start_history_dependence_detected`.
- `phase_source_gate`: three controllers (clock, event-reset, none) give Ok, refusal, refusal.
- `fall_is_status_not_number`.
- `contact_sequence_signature_trot`: the trot's signature lists diagonal pairs touching down in the same tick, twice per stride.
- `metrics_cost_of_transport`: on a synthetic one-dimensional cart with constant drag force D moving a distance d, E/(m·g·d) = D/(m·g); with D = 9.81 N and m = 10 kg the value is 0.1.
- `synthetic_affine_stride_map`: a `StrideMap` implemented by x ↦ A·x + d with A = [[0.5, 0.2], [0, 0.3]], d = (1, 1) iterates to (18/7, 10/7); used by the later beads as their smallest fixture.
### End-to-end script and logging
The user-visible path is `frob gait orbit`, whose script is `scripts/e2e/gait_orbit.sh` (N22a-38). This bead's runner `scripts/e2e/gait_stride_map.sh` executes the test binary on `batch-cpu` and writes the shared newline-delimited JSON log to `target/e2e-logs/gait_stride_map/<utc>.ndjson` with a transcript: per test `ts`, `script`, `bead`, `step`, `event`, command line, exit code, wall time, tier and step plan, the reduced dimension and removed coordinates, the equivariance residual against 10⁻¹⁰, digests for the independence comparisons with the first differing value on mismatch, and a `summary` line.
### Known answers and negative controls
- The affine fixture's fixed point (18/7, 10/7) and the cart's cost of transport 0.1 are exact.
- Negative controls: the planted slope (the equivariance check must fail); warm starts left enabled (the function-of-state test must fail); a chart that removes yaw while heading is tracked (the fixed-point residual cannot fall below tolerance and the equivariance check names yaw); a stride map built on a clock-less controller (must be refused).
- Metamorphic: mirroring the design, the state and the command left to right mirrors the stride result; scaling a design by dynamic similarity leaves the dimensionless stride result unchanged within tolerance.
- Determinism lanes: twice on one machine; across worker counts; debug and release; across batch compositions.

## Considerations
- The choice of chart fixes the numbers that the spectral analysis sees (multipliers do not depend on it; transient growth does). The chart identity and scales are part of every result.
- Disabling warm starts changes the tier's iteration from the one training uses. An orbit is a property of the loop on the stated step plan; the record names the plan so that nobody reads it as a property of another.
- Whether an estimated-state loop reduces cleanly is open (the hypothesis above); the fail-closed default is privileged state with its label.
- Open question OPEN-GAIT-1 (when the referee route for orbits is built; owner the Kinesis lead with upstream; blocks nothing on the critical path): default, compliant tiers only. This bead builds the compliant route.
- Scope cap of the crate (DESIGN): 8,000 lines of Rust including tests; reaching 115% triggers a scope conversation.
