## Background
At an isolated event with transverse crossing (a foot touching down, a spoke striking the slope, a ball hitting the floor) a perturbation crosses the event through the saltation matrix

    Ξ_e = D_x R + (f⁺ − D_x R·f⁻ − D_t R)·D_x g/(D_t g + D_x g·f⁻),

for the guard g, the reset R and the vector fields f⁻ before and f⁺ after the event; the denominator is the transversality number τ_e. Every return map, Floquet multiplier and orbit gradient on an event-located route is a product of flow tangents and these matrices, so an error in one silently corrupts every stability figure and every design gradient built on it.

The plan asks for this matrix in two forms. The event-located tangent map of N22a-33 evaluates the formula numerically from an event record, with the reset's Jacobians D_x R and D_t R taken "from the derived kernel where one exists and from central differences of the reset otherwise; the source is recorded". Theorem card T-17 (CARD-T-17, M5) certifies, per event class, that "a derived saltation kernel equals the saltation formula for its flow, guard and reset". Neither bead builds the derived kernel: N22a-33 placed it out of scope, CARD-T-17 attributed it to the orbit verb BD-333, and BD-333 never stated it. Without it the event-located route runs on central differences of the reset for ever (truncation error of order 10⁻⁷, two reset evaluations per state coordinate), and T-17 has nothing to certify. This bead builds the kernels.

A derived kernel is straight-line code generated from the model compiler's symbolic flow, guard and reset through the per-body derivation pipeline (N21a-12) and the kernel IR (construction C-14): exact derivatives, dimension-typed, with a content hash that a certificate can bind to. Tier: Frontier (with the rest of C-16). Crates: `frob-gait` (binding and tests), generated sources in `frob-kernels`, derivation rows in `derive/kernels.toml`.

## Scope
In: the event-class key and the kernel set for each class whose symbolic inputs fit the per-body bound of the derivation manifest; derivation rows with budgets; generated kernels returning Ξ_e, τ_e and the cleared numerator that T-17's identity names; dimension typing of every output entry; binding into N22a-33's saltation step with the source recorded per event; the fallback for classes over budget or over the per-body bound, recorded and never silent; the event classes of the registered hybrid fixtures (bouncing ball, ball on a moving platform, rimless wheel, compass-gait heel strike) and, behind the same crate feature as N22a-33, the touchdown classes of the strict planar biped; differential tests against closed forms, against the formula with central-difference Jacobians and against perturbations with events re-located; mutants.
Out: the event record, the formula evaluation, the validation every `saltation` result passes, the refusals and the label (N22a-33); the derivation pipeline, its worker, caps and digest scheme (N21a-12); the kernel IR, its rewrite classes and dimension checker (SPEC-C-14 and its implementing beads); the certificates of T-17 on these kernels at their content hashes (CARD-T-17 at M5, through the instance-certificate pipeline N12-20; this bead leaves the kernels in the form that card certifies and does not wait for it); simultaneous events tied by a symmetry, which have no single-event kernel (N22a-34); the compliant tiers, which have no saltation matrix (N22a-30); the referee route (FD-FSIM-20); the verb `gait.orbit` and its end-to-end check that results name this source (BD-333 and N22a-38, which follow this bead).

## Technical approach
**Event class.** The key is (`ModelId`, guard identity, mode before, mode after): the guard identity is the stable geometry pair of a contact guard or the clock identity of a clock-triggered event, as in N22a-33's `EventId` without the time. One kernel set per class and model content hash; a model change produces new hashes and new kernels, never a reused kernel.

**Symbolic inputs.** From the model compiler, in the rational form the kernels use (unit-complex joint coordinates and Cayley updates, as T-17 states): f_m(x, θ) and f_m′(x, θ) of the two modes, g_e(x, t, θ) and R_e(x, t, θ), with θ the design parameters that enter them.

**Derivation rows.** One row per class in `derive/kernels.toml` (N21a-12's schema): `name = "salt-<model>-<class>"`, inputs (x⁻, t, θ) with dimensions, outputs, `budget` (the manifest defaults: 8,192 symbolic operations per expression, 60 s, 4 GiB, rewrite fuel 10⁵), `derivative = "forward"`, `certificates = ["T-17"]`. The worker differentiates symbolically to obtain D_x R, D_t R, D_x g and D_t g. A row whose inputs exceed the manifest's per-body bound (a whole-robot impact map through the mass matrix of an articulated quadruped) is not attempted: it is entered with `derivative = "excused(per-body bound)"`, and a row refused for its node budget is kept with the refusal report naming the sub-expression that grew. Both keep central-difference Jacobians in N22a-33, and both are listed by class in the kernel coverage report, so a reader sees which events run on derived code.

**Generated kernel.** Straight-line code through the kernel IR, emitted with rewrites of class E only (no reassociation, SPEC-C-14), so that the code a certificate later describes is the code that runs. At a pre-event state x⁻, time t and parameters θ it computes x⁺ = R(x⁻, t), f⁻ = f_m(x⁻), f⁺ = f_m′(x⁺), the four Jacobians, τ = D_t g + D_x g·f⁻, the cleared numerator N = τ·D_x R + (f⁺ − D_x R·f⁻ − D_t R)·D_x g, and Ξ = N/τ. It returns Ξ, τ and N. The kernel decides no refusal: N22a-33's grazing check (the normalized transversality against τ_graze) runs on τ before Ξ is used, and at τ = 0 the kernel returns N with no Ξ, never a division. Each entry of Ξ is dimension-typed with the unit of ∂x⁺ᵢ/∂x⁻ⱼ; the dimension checker rejects a kernel whose entries disagree. The generated files carry N21a-12's header and digest, and `cargo xtask check-generated` regenerates them byte for byte.

**Binding.** N22a-33's saltation step looks the class up by its key. With a kernel present, Ξ is the kernel's and the event's entry in the `saltation` label payload carries `source: derived-kernel` with the `KernelId`; without one, central differences as before with `source: central-difference` and, where the row exists, its excuse or refusal. The validation by re-located perturbations is unchanged and applies to both sources.

**Differential tests (on each kernel, 10³ pre-event states sampled in its validity domain, normalized transversality at least 10·τ_graze).** (a) Against the closed form where one exists: within 10⁻¹² relative. (b) Against N22a-33's formula evaluated with two-step central-difference Jacobians of the reset and the guard: within 10⁻⁶ relative, the truncation bound of that route under its Richardson check. (c) The cleared identity evaluated in `f64`: ‖τ·Ξ − N‖ at most 10⁻¹³ relative to ‖N‖. (d) Through N22a-33's validation against perturbed trajectories with events re-located: the kernel-sourced tangent map passes the same 10⁻⁶ rule as the central-difference one.

**Determinism and evidence.** Class D0 on the host for these straight-line kernels in `f64` (fixed expression order, no fused multiply-add); D2 on `batch-cpu`. A kernel's output is a labeled derivative of class `Estimated` (N00-26's creation rule); the kernel's coverage row reads `pending: T-17` until CARD-T-17's certificate for its content hash is accepted, which the coverage run of N12-36 then observes.

## Acceptance criteria
- [ ] Derivation rows exist for the classes of the ball, the moving-platform ball, the eight-spoke rimless wheel and the compass-gait heel strike; their generated kernels are checked in with digests, and `cargo xtask check-generated` passes.
- [ ] Ball (r = 0.8, v⁻ = −2 m/s, g = 9.81 m/s², guard y = 0, reset (y, −r·v)): the kernel returns Ξ = [[−0.8, 0], [8.829 s⁻¹, −0.8]] with det Ξ = 0.64 = r², τ = −2 m/s and N = [[1.6, 0], [−17.658, 1.6]], within 10⁻¹²; with r = 1, det Ξ = +1, where the reset Jacobian alone has −1.
- [ ] Ball on a moving platform (guard y − s(t), reset v ↦ −r·v + (1 + r)·ṡ(t); at the impact ṡ = 0.5 m/s, s̈ = −2 m/s², v⁻ = −2 m/s, r = 0.8, g = 9.81 m/s²): τ = v⁻ − ṡ = −2.5 m/s and Ξ = [[−r, 0], [−(1 + r)·(g + s̈)/(v⁻ − ṡ), −r]] = [[−0.8, 0], [5.6232 s⁻¹, −0.8]] within 10⁻¹², the fixture on which D_t R and D_t g are nonzero.
- [ ] Rimless wheel, eight spokes, l = 0.5 m, γ = 4°: the kernel's lower-left entry is −6.065528 s⁻¹ at the pre-impact rate 2.046947 rad/s (N22a-33's values), and the stride tangent built from it has det 0.5 and trace 1.5 within 10⁻⁸.
- [ ] A clock-triggered event (g = t − t_k) gives τ = 1 and Ξ = D_x R exactly.
- [ ] Compass-gait heel strike: the kernel agrees with the central-difference formula within 10⁻⁶ on 10³ states, and the multipliers of the compass-gait orbit computed through the kernel equal those through central differences within 10⁻⁶ and the pinned oracle of KA-561 within 10⁻⁶ (or the row stays `pending` with the oracle bead named, as N22a-33's).
- [ ] The label payload of a derivative over an interval with a kernel-sourced and a central-difference-sourced event names both sources per event; a class over the per-body bound is listed `excused(per-body bound)` and a class over its node budget is listed with the refusal report, and each keeps central differences.
- [ ] At τ = 0 (the ceiling-apex ball) the kernel returns N and no Ξ, and N22a-33's grazing refusal fires upstream of it.
- [ ] Every mutant below fails a differential test; a planted entry with the wrong unit is rejected by the dimension checker.
- [ ] The strict planar biped's touchdown classes: kernels derived and tested as above when the strict profile exposes its event records; until then the test is `not run` with that reason, as N22a-33's feature-gated test is.

## Test plan
### Unit tests
`crates/frob-gait/tests/saltation_kernels.rs` on the generated kernels and the real binding in N22a-33's tangent-map code; fixtures that are not robots are labelled `synthetic`. Mutants follow BD-025's form as N10a-01 section 6 states it: each of the controls (a) to (e) below is a mutation control compiled under its own Cargo feature `nc-<nnnn>` (a control this bead registers directly), declared by `frob-gait` and named in the control record's `feature` field, never in the `gauntlet-mutations` umbrella. The feature's branch sits in `frob-gait`'s binding and substitutes a mutated copy of the kernel's computation kept beside it, so the generated sources of `frob-kernels` and `cargo xtask check-generated` are untouched. One control per build: `cargo test -p frob-gait --features nc-<nnnn> --test saltation_kernels`, which must fail the test its record names. Control (f) changes no build: it is a planted rewrite trace, a control of kind `fixture`, fed to the IR's trace checker in the default build.
- `ball_kernel_closed_form`; `ball_cleared_numerator`; `elastic_ball_area_preserving` (r = 1: det Ξ = +1).
- `moving_platform_kernel_closed_form` (5.6232 s⁻¹; τ = −2.5 m/s).
- `rimless_wheel_kernel_entry` (−6.065528 s⁻¹); `rimless_wheel_stride_det_trace` (0.5, 1.5).
- `clock_event_kernel_is_reset_jacobian`.
- `compass_gait_kernel_vs_central_difference` (10⁻⁶ on 10³ states); `compass_gait_multipliers_both_sources`.
- `cleared_identity_holds_in_f64` (10⁻¹³ on every kernel's samples).
- `kernel_passes_relocated_perturbation_validation` (N22a-33's eight directions, 10⁻⁶).
- `source_recorded_per_event` (mixed interval: one event of each source).
- `over_bound_class_excused_named`; `over_budget_class_refusal_named` (a planted row with a 64-node cap).
- `zero_transversality_returns_numerator_only`.
- `dimension_typing_rejects_unit_mismatch`.
- `kernel_identity_tracks_model` (rebuilding gives the same content hash; changing the restitution in the model gives a new one).
- `strict_planar_biped_touchdown_kernels` (feature-gated; `not run` until the strict profile exposes event records).
- The controls, each caught in its own build as above (the named values are what the failing assertion prints): (a) the reset Jacobian alone as the kernel (ball: det −0.8 instead of 0.64); (b) f⁺ and f⁻ exchanged (ball: Ξ₁₁ = −1.25, coupling −11.03625 s⁻¹); (c) one changed coefficient (−(1 + r)·g/(2·v⁻), coupling 4.4145 s⁻¹); (d) D_t R omitted (moving platform: coupling 7.0632 s⁻¹ instead of 5.6232); (e) D_t g omitted from τ (moving platform: Ξ₁₁ = −1.25 and coupling 7.0290 s⁻¹); (f) a reassociating rewrite filed as class E (rejected by the IR's trace checker).
### End-to-end script and logging
`scripts/e2e/gait_saltation_kernels.sh` (plain shell, idempotent, seed 2202 printed, non-zero on the first failed assertion after writing its summary): (1) `cargo xtask check-generated`, asserting that the new kernel sources regenerate byte for byte and that their digests match; (2) `cargo test -p frob-gait --test saltation_kernels` (which includes control (f), the planted rewrite trace the checker must reject), then once per mutation control (a) to (e) `cargo test -p frob-gait --features nc-<nnnn> --test saltation_kernels`, one control per build, asserting that each build fails the test its control record names; (3) `FROB_TEST_SEED=2202 cargo test -p frob-conformance --test g1_known_answers -- KA-092 KA-560` with the kernel source bound, asserting that the ball and rimless-wheel rows still pass; (4) the coverage listing of the classes of each fixture model (derived, excused or over budget) read from the test binary's report. Logging through the shared helper of STD-E2E to `target/e2e-logs/gait_saltation_kernels/<utc>.ndjson` with a transcript: every line with `ts`, `script`, `bead` (`N22ap2-02`), `step`, `event` (`start`, `cmd`, `assert`, `metric`, `end`); `cmd` lines with the exact command line, exit code and wall time; per kernel its `KernelId`, class key, node count and derivation time, the source digest; `metric` lines with each differential test's largest relative error against its tolerance; per mutant an `assert` line of kind `negative-control` with `caught`; on failure the first differing entry of Ξ with its state and the paths needed to reproduce; a final `summary` with assertion counts. The verb-level check that `gait.orbit` results name `derived-kernel` belongs to the scripts of BD-333 and N22a-38, which are built after this bead.
### Known answers and negative controls
- Known answers: the ball's Ξ, det r² and N (KA-092); the moving-platform ball's Ξ (derived here: with v⁺ − v⁻ = −(1 + r)·τ the first entry stays −r); the rimless wheel's entry −6.065528 s⁻¹ and stride det 0.5 (KA-560, KA-093); the clock event's Ξ = D_x R; the compass gait against KA-561.
- Negative controls: the six mutants above; CX-043 (a matrix returned at the grazing state) through the τ = 0 case.
- Metamorphic: rescaling the guard function by a positive constant leaves Ξ unchanged and scales τ and N by that constant; permuting state coordinates permutes Ξ by the same similarity.
- Determinism lanes: twice on one machine; debug and release; across batch compositions on `batch-cpu`.

## Considerations
- The per-body bound is a rule of the derivation pipeline, not of this bead. Whole-robot impact maps of articulated quadrupeds fall outside it and stay on central differences until the pipeline offers a composed form (an impact map assembled from per-body kernels and a run-time solve). That is a known gap, listed in the coverage report, and not a reason to raise the bound here.
- T-17 certifies that the implementation equals the formula, not that an event in a run was isolated and transverse; the grazing and ordering refusals of N22a-33 remain the guard for that.
- Upstream FD-FSYM-01 (multi-output straight-line code with common-subexpression elimination, and a higher operation cap in FrankenSymPy) would let more classes fit their budgets; interim posture: N21a-12's caps as they stand.
- Risk: expression swell on the compass gait's heel strike (RISK-07). The node-budget refusal names the sub-expression; the class then stays on central differences with that report.
