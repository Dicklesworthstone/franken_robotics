## Background

For a small subsystem whose guard is ambiguous under sensing error (a wheel at a threshold, a tray about to
tip, braking across two floor materials), a runtime shield can look up a precomputed **reachable-set table**
instead of solving a filter: a table over at most 8 modes × 16,384 cells of at most four reduced states, built
by backward viability pruning. A cell K_m keeps a common safe action only if

    R_mn((K_m ⊕ E) ∩ G_mn, D) ⊆ K_n ⊖ (−E)    for every guard G_mn that may be enabled,

where cells hold **measured** states, the true state is the measured state plus an error in the bounded set E,
R_mn is the reset from mode m to mode n, D is the disturbance set, ⊕ is the Minkowski sum and A ⊖ B = {x : x + B
⊆ A} is erosion. The erosion is by −E, which equals E only for a centrally symmetric error set. (Where cells
hold true states and the whole belief set must stay in one cell, the condition is R_mn(K_m ∩ G_mn, D) ⊆ K_n ⊖
(E ⊕ (−E)).) Inter-sample sweep, actuation latency and chatter are accounted for. At run time the whole belief
set is looked up; outside the table the answer is `uncovered` and the backup controller's domain applies. The
reduction of a robot to four states is an assumption watched by monitors; it is not proved. The item is a
Moonshot, off the critical path. Its pilot row:

| Pilot | Falsifier | Ceiling of the benefit | Cost (DESIGN estimate) |
|---|---|---|---|
| Braking across two floor materials: two states and a mode | Coverage under 90% of the operating set at 16,384 cells per mode, or one false admission in 5,000 in-envelope episodes | A lookup replaces an online reachable-set computation; no design decision is known to depend on it | 3 engineer-days |

## Scope

In: a table for the braking subsystem; coverage of the operating set; 5,000 in-envelope episodes; the verdict.
Out: tables for other subsystems and the production table format as a shield payload (the epic BD-440).

## Technical approach

1. **Register first.** Mechanism "reachable-set tables", tier [M]; protocol; falsifier; ceiling; fallback (kill
   gate KILL-TUBE: no tables are built; reduced-order barriers cover those subsystems); cost; seeds.
2. **Subsystem (DESIGN elaboration of the one-line pilot).** A cart approaching a keep-out line. Reduced states: range s to the line and speed v. Modes:
   `grip` (floor material 1, μ₁ = 0.8) and `slick` (material 2, μ₂ = 0.3); the boundary between materials lies at
   an uncertain position within a declared interval, so that near it either mode may be enabled (the guard is
   ambiguous). Commands: `coast` or `brake` (commanded deceleration 5.0 m/s², delivered min(5.0, μ·g) with
   g = 9.81 m/s²). Control period Δt = 0.02 s. Sensing error E: range error in [−0.01, +0.01] m and a one-sided
   speed error in [0, 0.05] m/s (the encoder under-reads under slip), which makes E asymmetric on purpose.
   Disturbance D: deceleration reduced by up to 5%.
3. **Grid.** s ∈ [0, 3] m and v ∈ [0, 3] m/s, 128 × 128 = 16,384 cells per mode, two modes.
4. **Backward pruning.** Start with every cell that is outside the keep-out set. Repeat until no cell changes:
   for each remaining cell K_m and each command a, compute the image of (K_m ⊕ E) over one control period under
   every enabled mode and every disturbance (interval arithmetic with outward rounding; the inter-sample sweep
   is the hull of the trajectory over the period), and keep (K_m, a) only if the image lies in the union of
   surviving cells eroded by −E. A cell with no surviving command is removed. Cells whose only surviving command
   is `brake` record that command as the common safe action.
5. **Operating set.** The set of (s, v) from which the closed-form brake-in-time condition holds for the worse
   friction with the inter-sample term, s ≥ v²/(2·μ₂·g) + v·Δt, widened by the sensing error. Coverage is the
   share of the operating set's cells that survive.
6. **Episodes.** 5,000 in-envelope episodes on the referee or the `strict` profile: random start (s, v) in the
   operating set, random material boundary, sensing errors and disturbances drawn from E and D; the controller
   coasts where the table allows and brakes where it prescribes. A **false admission** is an episode in which the
   table admitted every belief set along the way and the true state crossed the line.
7. **Falsifier.** Coverage under 90%; or one false admission in the 5,000 episodes.
8. **Record.** Coverage, false admissions, table size and build time, the count of `uncovered` lookups.

## Acceptance criteria

- [ ] The record exists before the table is built.
- [ ] The table has 2 × 16,384 cells, a recorded build time and a recorded fixed point (the pruning terminated).
- [ ] Coverage of the operating set is reported against 90%.
- [ ] 5,000 episodes with seeds are stored; false admissions are counted from the simulator's true state.
- [ ] A lookup outside the table returns `uncovered` and the backup domain applies; the count is reported.
- [ ] The verdict is handed to the epic BD-440 and recorded for KILL-TUBE.

## Test plan

### Unit tests
- `erosion_one_sided_error`: one dimension, a cell [0, 1] of measured states, true = measured + e with e ∈ [0, 0.1]: the admissible true successors are [0.1, 1.0] (erosion by −E).
- `erosion_wrong_sign_is_caught`: erosion by E gives [0, 0.9], which admits 0.05 (whose measurement can be −0.05) and rejects 0.95 (whose measurements lie in [0.85, 0.95]); the test asserts the two sets differ and that only the first is sound.
- `pruning_terminates_and_is_monotone`: each sweep removes cells and never adds one.
- `intersample_sweep_in_image`: a cell whose end-of-period image is safe but whose trajectory crosses the line during the period is removed.
- `lookup_uncovered_outside_grid`: s = 3.5 m returns `uncovered`.

### End-to-end script and logging
`scripts/e2e/pilot_reachable_table.sh`: builds the table, computes coverage, runs the episodes with `frob sim
run`, replays lookups. Logged per the shared standard: commands, exit codes, evidence block, `cells_per_mode`
(16,384), `coverage` (threshold 0.90), `false_admissions` (threshold 0 of 5,000), `uncovered_lookups`,
`build_cpu_s`, the verdict and a summary.

### Known answers and negative controls
The one-sided erosion row above (a late known answer of the Gauntlet's fixture gate). Closed forms for the
braking subsystem: stopping distances 0.400 m at 5.0 m/s² and 0.6796 m at 2.943 m/s² from 2.0 m/s; threshold
0.7196 m with the inter-sample term. Negative controls: a table built with erosion by E in place of −E, and a
table built without the inter-sample sweep, must each produce at least one false admission in the episodes.
Determinism: the table build is interval arithmetic on the host and repeats bit for bit.

## Considerations

- The ceiling is modest by the plan's own statement: a lookup replaces an online computation, and no design
  decision is known to depend on it. The pilot exists to stop the epic cheaply if coverage is poor.
- The same braking physics is the Solid fixture of the pre-slip aliasing subsection, where a closed-form backup
  domain already gives a safe rule; the table must not do worse than that rule on the operating set.
- Moonshot: priority 4, feature-flagged, nothing in M0 to M7 depends on it.
