## Background

Gait analysis in `frob-gait` handles two kinds of closed loop. A clock-forced loop has a known stride period and
is solved by fixed-period (stroboscopic) shooting. An autonomous loop (a passive walker, a controller whose
phase is reset by touchdown, any loop that reads no clock) has a free period and always carries a trivial
Floquet multiplier of exactly 1 along the flow, which makes the clock-forced fold test fire on every orbit and
the gradient solve ill-posed. Two forms repair this: a return map on a transverse event section, and a bordered
system in the state and the period with a phase condition. The gate that says they work:

> GATE-GAIT-04. Known answer. On the planar loop the section and bordered forms agree with the closed forms to
> 10⁻⁹ on the multiplier, on dr*/dμ and on dT*/dμ; a stroboscopic solve of the same loop is refused, and is not
> reported as a fold. The rimless wheel and the compass gait of GATE-GAIT-01 pass through the autonomous path
> with the trivial multiplier removed and listed. M4.

This bead is the script that measures it through the user's surface.

## Scope

In: one script, three fixtures, both forms, the refusal check, the conformance case whose tier run produces the
gate's receipt, the M4 part recorded from it. Out: the mechanisms (N22c-36,
N22c-37); the kill decision (N22c-39).

## Technical approach

Script `scripts/e2e/gate_gait_04.sh`; seed from `FROB_E2E_SEED` (default 1); idempotent; non-zero exit on any
failed assertion. Fixtures are registered designs with their controllers' phase source declared `none`:
`fixture:planar-loop` (ṙ = r·(μ − r), φ̇ = 1), `fixture:rimless-wheel` (spoke half-angle α, slope γ, leg length
l) and `fixture:compass-gait`.

Every call uses the one input grammar of BD-333 (fixture parameters through `--set k=v[,…]`; `--param` and
unknown keys fail the schema with FROB-REF-802, exit 3) and carries `--key g4-<step>-<case>` (a `run` verb:
without a key FROB-REF-805); the determinism lane re-runs steps 1 and 4 under fresh run-scoped keys
`g4-det-a-<run-id>-<case>` and `g4-det-b-<run-id>-<case>`, the second with a different `--workers` count, and
asserts identical results and that neither envelope is a replayed receipt.
1. **Planar loop, section form.** For μ ∈ {0.1, 0.5, 1, 2}: `frob gait orbit fixture:planar-loop --set mu=<μ>
   --section phi=0 --key g4-1-mu<μ> --json`. Assert: fixed point r* = μ; return time 2π; section multiplier within
   10⁻⁹ of e^(−2πμ); `frob gait gradient <orbit> --wrt mu --state-sensitivity --key g4-1g-mu<μ> --json` returns
   dr*/dμ within 10⁻⁹ of 1 and dT*/dμ within 10⁻⁹ of 0.
2. **Planar loop, bordered form.** The same with `--form bordered` (keys `g4-2-mu<μ>`, `g4-2g-mu<μ>`): the same
   three assertions; additionally the result lists the trivial multiplier as removed and reports the bordered
   matrix as nonsingular.
3. **Refusal.** `frob gait orbit fixture:planar-loop --set mu=1 --form stroboscopic --period 2pi --key g4-3 --json`:
   assert `ok: false`, the refusal slug `fixed-period-shooting-on-free-period`, exit 3, a payload naming the
   phase source and the available sections; assert the envelope contains no outcome `fold`. The same with
   `--param mu=1` in place of `--set` fails the schema with FROB-REF-802 (the one-spelling check).
4. **Rimless wheel.** `frob gait orbit fixture:rimless-wheel --set spokes=8,l=1,slope=0.08 --section post-impact
   --key g4-4-section --json` and with `--form bordered` (key `g4-4-bordered`): assert fixed point
   ω*² = c²·b/(1 − c²) within 10⁻⁶ (with c = cos 2α and b = (4g/l)·sin α·sin γ; eight spokes is α = π/8, and for
   l = 1 m, γ = 0.08 rad and g = 9.81 m/s² this is 1.2000388 (rad/s)²); nontrivial multiplier cos²(2α) = 0.5
   within 10⁻⁶; the removed-coordinates list contains the phase; the trivial multiplier 1 is listed as removed.
   An uphill slope (`--set spokes=8,l=1,slope=-0.02`, key `g4-4-uphill`) returns no fixed point (a typed outcome,
   exit 2, no `GaitOrbit` record; not a crash).
5. **Compass gait.** Both forms (`frob gait orbit fixture:compass-gait --section auto --key g4-5-section --json`
   and `--form bordered --key g4-5-bordered`): assert the nontrivial multipliers agree with the pinned
   high-precision oracle values within 10⁻⁶, and with each other within 10⁻⁶; the trivial multiplier is listed as
   removed.
6. **Receipt.** `e2e_tier g1_known_answers GATE-GAIT-04 --mutations` (that is, `FROB_TEST_SEED=<seed> cargo test
   -p frob-conformance --test g1_known_answers --features gauntlet-mutations -- GATE-GAIT-04`): the tier run of the
   gate's entry, which holds this bead's case `gate_gait_04` (the planar loop through both forms, the refusal, the
   wheel and the compass gait against the pinned oracle, through the real `frob-gait` solvers, with controls (a)
   to (c) below compiled under `gauntlet-mutations` and caught in the same run). It writes one hash-named receipt;
   the script asserts on its `gates` and `controls` and that its errors equal the script's own, and records
   nothing.

**Recording (not part of the script).** A session that did not implement N22c-36 or N22c-37 enters the M4 part
from that receipt: `cargo run -p frob-conformance --example record_gate -- --gate GATE-GAIT-04 --receipt <hash>
--part M4`, with the largest closed-form error on the planar loop (multiplier, dr*/dμ, dT*/dμ), the refusal check
and the largest form disagreement on the wheel and the compass gait.

**Logging.** Newline-delimited JSON to `target/e2e-logs/gate_gait_04/<utc>.ndjson` and a transcript. Every line:
`ts`, `script`, `bead` (`N22c-38`), `step`, `event`, the exact command, exit code, wall time, the envelope's
`evidence` block (claim Known answer, class, tier, determinism, `ControllerId`, seed, standing `screening`).
Metrics with thresholds: `multiplier_err.section`, `multiplier_err.bordered`, `dr_dmu_err`, `dT_dmu_err` (each
≤ 10⁻⁹), `stroboscopic_refused` (true), `reported_as_fold` (false), `wheel_multiplier_err` (≤ 10⁻⁶),
`compass_oracle_err` (≤ 10⁻⁶), `form_disagreement_max` (≤ 10⁻⁶), `trivial_multiplier_listed` (true). On failure:
the first differing value, the parameter, and the orbit record's path. A `summary` line: assertions passed and
failed; gate GATE-GAIT-04 with its status.

## Acceptance criteria

- [ ] The script exits 0 only when every clause holds.
- [ ] The tier run writes one receipt that catches controls (a) to (c); the M4 part of GATE-GAIT-04 is recorded from it with `record_gate --part M4` by a non-implementing session, with measured errors (not the tolerances); the script's log contains no `record_gate` call.
- [ ] The compass-gait oracle values are pinned files that were never regenerated from the candidate; the script refuses to run if the oracle's digest changed without a recorded reason.
- [ ] The negative controls below have recorded failing runs.

## Test plan

### Unit tests
Helpers in `scripts/e2e/tests/`: `closed_form_planar` (e^(−2π·0.5) = 0.0432139); `closed_form_wheel` (b at
α = π/8, γ = 0.08, l = 1: 4·9.81·0.382683·0.0799147 = 1.20004); `no_fold_in_envelope` (a recorded envelope with
outcome `fold` fails the check).

### End-to-end script and logging
As specified above; this bead is the script.

### Known answers and negative controls
Known answers: e^(−2πμ) (0.533488, 0.0432139, 0.00186744, 3.4873 × 10⁻⁶ for μ = 0.1, 0.5, 1, 2); dr*/dμ = 1;
dT*/dμ = 0; cos²(2α) = 0.5 for eight spokes; ω*² = c²·b/(1 − c²) (KA-560). Negative controls through the same
script: (a) a build that runs the stroboscopic solve reports a fold on every orbit and must fail step 3; (b) a
build whose section Jacobian omits the projection along the flow keeps a multiplier at 1 and must fail steps 1
and 4; (c) a build that uses the reset Jacobian in place of the saltation matrix must fail step 4 or 5.
Determinism lanes: twice on one machine; across worker counts; debug and release; the fixtures run on the host
and on the referee's event-located flow, and both sites must agree within the tolerances.

## Considerations

- GATE-GAIT-01 already tests the wheel and the compass gait through the original path; this gate re-runs them
  through the autonomous path, so a change to either path must keep both gates green.
- The tolerance on the planar loop is 10⁻⁹ because its flow has a closed form; the hybrid fixtures get 10⁻⁶.
- All results carry the standing `screening`; the gate is a known answer about the analysis, not about any
  robot.
- If KILL-FREEPERIOD fired at the pilot (N22c-37 closed `not-funded`, N22c-39 rule 1), step 2 and the bordered
  halves of steps 4 and 5 are not run: they are logged and recorded `killed: fallback adopted` with the ADR cited,
  never as failures and never as passes, and the section-form clauses decide the row (logged as
  `bordered_clauses` = `killed`).
