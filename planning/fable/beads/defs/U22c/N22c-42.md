## Background

A gait that alternates between stride modes has one return-map Jacobian per mode, and testing each mode's
multipliers alone does not decide the alternation. `frob gait orbit` with a mode set therefore reports a bracket
on the worst growth rate over the admitted sequences of strides: a lower bound from products along admitted
cycles (with a witness word), an upper bound from one common quadratic norm found by a semidefinite program,
and a verdict `stable-under-switching`, `unstable-sequence` or `undecided`. The gate that says the analysis is
right:

> GATE-GAIT-05. Known answer. The counterexample returns the eigenvalue 3/4 + 1/√2 to 10⁻¹², the per-stride bound
> 1.2071 and the word (A, B); a pair of commuting contractions returns `stable-under-switching` with a common
> matrix that the checker verifies in exact rationals; a mutant that tests each mode alone labels the
> counterexample stable and fails. M4.

The counterexample: A = [[1/2, 1], [0, 1/2]], B = Aᵀ. Each alone has both multipliers at 1/2; B·A = [[1/4, 1/2],
[1/2, 5/4]] has the eigenvalue 3/4 + 1/√2 ≈ 1.457107, a growth of (1 + √2)/2 ≈ 1.207107 per stride.

## Scope

In: one script; the three clauses; the gate row. Out: the mechanism (N22c-41); the kill decision (N22c-43).

## Technical approach

Script `scripts/e2e/gate_gait_05.sh`; idempotent; non-zero exit on any failed assertion. The fixtures are
registered mode sets with prescribed Jacobians (`fixture:stride-seq-counterexample`,
`fixture:stride-seq-commuting`), so the analysis is exercised through the real verb without an orbit solve in
front of it; a third step runs it behind a real two-mode orbit.

1. **Counterexample.** `frob gait orbit fixture:stride-seq-counterexample --modes A,B --cycle-length 4 --json`.
   Assert: `switching.verdict == "unstable-sequence"`; `switching.word == ["A", "B"]`; the reported dominant
   eigenvalue of the word's product within 10⁻¹² of 3/4 + 1/√2 = 1.4571067811865475; `switching.lower` within
   10⁻⁴ of 1.2071; the per-mode multipliers are both 1/2 and are present in the record.
2. **Commuting contractions.** `frob gait orbit fixture:stride-seq-commuting --modes A,B --json` with
   A = diag(1/2, 1/3), B = diag(1/3, 1/2). Assert: verdict `stable-under-switching`; `switching.upper` < 1; a
   certificate (P, γ) in rationals is present. Then `frob-verify` on the certificate bundle: assert it accepts,
   on a machine path with no GPU. Then alter one entry of P in the bundle so that γ²·P − AᵀPA loses positive
   semidefiniteness: assert `frob-verify` rejects.
3. **Per-mode mutant.** Run step 1 against the build variant in which the switching block is replaced by the
   per-mode test (the registered mutant `per_mode_multiplier_test`, enabled through the test configuration).
   Assert the mutant returns a stable label for the counterexample and that the gate's assertion in step 1
   therefore fails for it (the script records the failing run as the control's evidence and continues).
4. **Behind a real orbit.** `frob gait orbit <quadruped archetype> --gait trot --modes up,down --task
   alternating-risers --json` on the compliant tier: assert the switching block is present with a graph
   identity, both bounds, a verdict, and the standing `screening`; no numeric threshold is asserted here.
5. **Record.** The gate row: the eigenvalue's error, the lower bound, the word, the certificate's acceptance and
   the rejection of the altered one, and the mutant's failing run; commit, command lines, output digest,
   receipt.

**Logging.** Newline-delimited JSON to `target/e2e-logs/gate_gait_05/<utc>.ndjson` and a transcript. Every line:
`ts`, `script`, `bead` (`N22c-42`), `step`, `event`, the exact command, exit code, wall time, the envelope's
`evidence` block (claim Known answer, class, tier, determinism, `ControllerId` where one exists, standing).
Metrics with thresholds: `eig_err` (≤ 10⁻¹²), `lower_bound` (1.2071 ± 10⁻⁴), `word` (`A,B`), `verdict.counterexample`
(`unstable-sequence`), `verdict.commuting` (`stable-under-switching`), `certificate_accepted` (true),
`altered_certificate_rejected` (true), `mutant_labels_stable` (true), `mutant_fails_gate` (true),
`cycles_enumerated`. On failure: the first differing value and the record's path. A `summary` line: assertions
passed and failed; gate GATE-GAIT-05 with its status.

## Acceptance criteria

- [ ] The script exits 0 only when the three clauses hold and the real-orbit step returns a complete switching block.
- [ ] The gate register holds a row for GATE-GAIT-05 with measured values, commit and receipt.
- [ ] The mutant's failing run is stored as the registered negative control's evidence.
- [ ] The certificate check runs through the offline auditor, not through the code that produced the certificate.

## Test plan

### Unit tests
Helpers in `scripts/e2e/tests/`: `expected_eigenvalue` (3/4 + 1/√2 = 1.4571067811865475; its square root
1.2071067811865475); `word_compare_up_to_rotation` ((A, B) equals (B, A) as a cycle); `mutant_run_must_fail`
(the harness treats a passing mutant as a script failure).

### End-to-end script and logging
As specified above; this bead is the script.

### Known answers and negative controls
Known answers: 1.457107, 1.207107, word (A, B); commuting pair with γ = 1/2 and P = I admissible
(γ²·I − AᵀA = diag(0, 5/36)). Negative controls: the per-mode mutant; the altered certificate. Determinism lanes:
twice on one machine with identical envelopes; debug and release; the rational check is exact on every platform.

## Considerations

- The eigenvalue tolerance of 10⁻¹² applies to the 2 × 2 fixture in `f64`; real mode sets get no such tolerance.
- The upper bound for the counterexample equals its lower bound (with P = I, ‖A‖₂ = ‖B‖₂ = 1.2071), so the
  bracket is tight there; the script logs both.
- If the kill gate fires, steps 1 to 3 remain as tests of the retired analysis only in the conformance history;
  the live behaviour is then the `single-mode-only` flag.
