## Background

Above the synthesized baseline controller, the control ladder has a rung that adds a small learned network: the
command is u = limit(u_base(x̂, t) + Δ(o)), where `limit` is the actuator limiter. The residual has **bounded
authority**: abs(Δⱼ) ≤ ρⱼ, a declared fraction of each channel's range. Its output layer starts at zero, so
training starts from the baseline's behaviour, and with Δ ≡ 0 the wrapped controller must reproduce the
baseline's digests bit for bit. A residual channel pinned at its bound for more than a declared fraction of
ticks sets the flag `residual-saturated`: the baseline is then not the controller, and the result says so.

Open question OPEN-REFLEX-3: the value of ρ per channel. Owner: the Reflex lead. It blocks GATE-REFLEX-05 (the
gate that checks the zero-residual identity, layer records, certificates and the `actuator-infeasible` mark),
because the wrapper's configuration, ρ included, is part of the `ControllerId` and must be fixed before the
gate's digests are recorded. Fail-closed default: ρ = 0.3 of range on every channel.

The trade-off: a small ρ keeps the baseline in charge (failures stay attributable to the body or the baseline)
and limits what the residual can fix; a large ρ lets the residual replace the baseline in effect, which defeats
the reason for having an inspectable baseline.

## Scope

In: the decision of ρ (one value, or per channel class), the saturation fraction that sets the flag, recorded
as an ADR before GATE-REFLEX-05 is measured. Out: the residual wrapper and the ladder (seed bead BD-330); the
pilot that supplies evidence (N22a-27).

## Technical approach

**Evidence to read.** From the residual pilot (N22a-27): the step fraction at ρ = 0.3 and the fraction of ticks
with any channel at its bound. Optionally, as separately registered pilot runs, the same at ρ = 0.15 and
ρ = 0.5 on the same quadruped: a result that needs ρ = 0.5 to match the specialist is evidence that the
baseline is not doing the work.

**Decision rule (DESIGN default, to be confirmed by the owner before the evidence is read).**
1. If at ρ = 0.3 the pilot is not falsified and saturation is below the flag threshold: ρ = 0.3 stands.
2. If saturation at 0.3 is above the threshold and the pilot at ρ = 0.5 is not falsified: ρ stays 0.3, the class
   is recorded as `residual-saturated` at the default, and escalation follows the ladder (the next rung), since
   raising ρ would hide the saturation.
3. If the pilot at 0.15 matches 0.3: ρ = 0.15 is adopted (the smaller authority that does the job).
4. Per-channel values are allowed only as a table by channel class (hip, knee, wheel, steering), not per robot,
   so that ρ is not a tuning knob per design.

**Saturation flag threshold.** The "declared fraction of ticks" is fixed with ρ: DESIGN default 10% of ticks on
any one channel over an episode.

**What is recorded.** An ADR with ρ (or the class table), the flag threshold, the evidence and the rule. The
values enter the residual wrapper's configuration and therefore the `ControllerId`; the open-questions register
marks OPEN-REFLEX-3 closed with a pointer to the ADR. Until the ADR exists the default (0.3; 10%) is in force
and GATE-REFLEX-05 has the status `blocked: OPEN-REFLEX-3` only if someone proposes a different value before
the measurement; otherwise it is measured at the default and the ADR records that.

## Acceptance criteria

- [ ] The ADR exists before GATE-REFLEX-05's digests are recorded, stating ρ, the flag threshold and the evidence.
- [ ] The residual wrapper reads ρ and the threshold from one configuration record whose hash is in the `ControllerId`; changing ρ changes the identity (test).
- [ ] A command with abs(Δⱼ) above ρⱼ never reaches the limiter (property test over random residual outputs).
- [ ] With ρ = 0 or Δ ≡ 0 the wrapped controller's digests equal the baseline's.
- [ ] The saturation flag is set exactly when a channel sits at its bound for more than the threshold fraction of ticks.

## Test plan

### Unit tests
- `residual_clamped_to_authority`: random Δ in [−2, 2] of range: outputs lie in [−ρ, ρ] of range for ρ = 0.3.
- `authority_in_controller_id`: ρ = 0.3 and ρ = 0.31 give different identities.
- `zero_residual_identity`: digests equal the baseline's on the smoke battery.
- `saturation_flag_threshold`: a channel at its bound on 9% of ticks does not set the flag; on 11% it does.
- `rule_table`: the four cases of the decision rule map to the stated outcomes.

### End-to-end script and logging
`scripts/e2e/open_reflex_3_authority.sh`: reads the pilot's log and the ADR, runs `frob control show` on a
wrapped controller, and checks the configuration. Logged per the shared standard: `rho`, `flag_threshold`,
`pilot_step_fraction`, `pilot_saturation_fraction`, the decision, the ADR path, the `ControllerId` before and
after a change of ρ.

### Known answers and negative controls
Zero residual reproduces the baseline's digests; a residual with a non-zero bias changes the digest (known
answer KA-557). Negative control: a wrapper that clamps after the limiter instead of before must fail the
authority property on a saturated channel.

## Considerations

- If the residual rung is removed at its kill gate, this question is moot and is closed with that decision.
- ρ interacts with the actuator limiter: authority is a fraction of the channel's range, and the limiter still
  enforces the card's envelope afterwards; a residual cannot buy torque the actuator does not have.
- A budget on the residual's work, where one is used, must reserve the held-command work bound; that rule is
  independent of ρ.
