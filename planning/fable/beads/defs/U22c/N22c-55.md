## Background

The energy-budget safety tier claims that the energy delivered to a declared boundary during a stop does not
exceed what the absorber there can take:

    T_ub + E_drive + E_ext + E_stored + E_reserve  ≤  W_abs.

W_abs is the lower envelope of the work the absorber takes before its limit (bottoming, or a stated force
limit). It comes from an interface card with provenance. The claim's class follows the claim product: the
arithmetic is `Certified` and the result is no better than its weakest input, so an absorber envelope marked
`assumed` yields an `Estimated` claim, and a request for a class above `Estimated` on an `assumed` envelope is
refused (FROB-REF-451). Reality is `no-claim` until bench data for the absorber and the drive are imported
through the Ground subsystem; one absorber measurement and one drive measurement would then serve every later
policy for that hardware, since no term of the budget depends on the policy.

Open question OPEN-SHIELD-1: **where absorber envelopes come from before any bench data exist**. Owner: the
actuator-and-card lead (Sinew), with Ground. It blocks any energy claim above `Estimated`. Fail-closed default:
`assumed` cards and `Estimated` claims.

## Scope

In: the decision on admissible sources for W_abs and the class each source earns, as an ADR; the rule that the
default holds until then; the test that the default is enforced. Out: the energy tier (seed bead BD-337); the
import lane; any bench work.

## Technical approach

**The default, in force now.** Every absorber card ships with `provenance: assumed` unless a source of a
better class is attached; every budget built on it carries `claim.class = "Estimated"` and `reality:
"no-claim"`; `shield.budget` refuses a higher class with FROB-REF-451 (repairs: bound the source or cut it;
import the absorber measurement).

**Sources the owner is to rule on, with the class each could earn (DESIGN proposal, for the owner's decision).**

| Source of W_abs | Proposed provenance class | Proposed effect on the claim in the model |
|---|---|---|
| A number typed by the designer | `assumed` | `Estimated` |
| A manufacturer's datasheet value with a document reference and the test condition stated | `declared` | `Estimated`, labelled with the reference |
| A first-principles lower bound computed in the workspace (for a crush element: plateau force lower bound × stroke; for a spring: ½·k_min·x²) from material and geometry cards that are themselves better than `assumed` | `derived` | `Tested` in the model, if every input card is `declared` or better |
| A bench measurement imported through Ground with its uncertainty, unit identity and conditions | `measured` | As the claim product allows; Reality as Ground admits |

The owner decides which rows are admitted, whether `declared` may lift a claim above `Estimated`, and what
derating applies (temperature, ageing, rate dependence).

**Decision record.** An ADR naming the admitted sources, the class mapping, the derating rule and the date. The
card schema's provenance enumeration and the claim-product table are updated to match; FROB-REF-451's second
trigger keeps firing for any class not earned.

**Until decided.** Status of any gate row that needs a class above `Estimated` for an energy claim: `blocked:
OPEN-SHIELD-1`. GATE-SHIELD-01 does not need it (it is a known answer in the model under the default) and is
not blocked.

## Acceptance criteria

- [ ] Under the default, every budget on an `assumed` absorber envelope reports class `Estimated` and reality `no-claim`, and a request for `Tested` or `Certified` is refused with FROB-REF-451 (test).
- [ ] The ADR, when written, lists admitted sources, the class each earns and the derating rule; the card schema and the claim-product table match it.
- [ ] No code path raises a claim's class by relabelling a card: a card's provenance can change only with an attached source record (test: editing the field without a source fails validation).
- [ ] The worked card's absorber (50 N over 40 mm, W_abs = 2.00 J, `assumed`) yields an `Estimated` claim.

## Test plan

### Unit tests
- `assumed_envelope_gives_estimated`: the worked card's budget has class `Estimated`.
- `higher_class_on_assumed_refused`: FROB-REF-451, second trigger, with the card's provenance in the payload.
- `provenance_needs_source_record`: `declared`, `derived` and `measured` require a source record of the matching kind.
- `claim_is_weakest_input`: a budget with every term `measured` except an `assumed` spring bound is `Estimated`.
- `derived_bound_arithmetic`: plateau force lower bound 50 N × stroke 0.040 m = 2.00 J; spring ½·k_min·x² with k_min = 2,500 N/m and x = 0.040 m = 2.00 J.

### End-to-end script and logging
`scripts/e2e/open_shield_1_absorber_provenance.sh`: `frob shield budget` on the worked card with the absorber
card at each provenance class available, requesting each claim class. Logged per the shared standard: the
card's provenance, the requested and granted class, refusals with their code, and the ADR's status (`open` or
its path).

### Known answers and negative controls
The worked card: 1.49 J ≤ 2.00 J, class `Estimated` (known answer KA-568). Negative control: a build in which a
card field edit raises the class without a source record must fail `provenance_needs_source_record`.

## Considerations

- A gate may need only what a simulator has; anything that needs a bench measurement is an import lane with a
  recorded `no-claim` until the data exist. This question is about what, short of a bench measurement, may count
  for the claim in the model.
- The budget supports no statement about peak force, pressure or injury thresholds except at the absorber, and
  only if W_abs was defined up to a force limit; the source of W_abs must therefore state which limit defines it.
- If the energy claim is withdrawn at its kill gate, this question is moot for claims and remains relevant only
  to the alarm's configuration.
