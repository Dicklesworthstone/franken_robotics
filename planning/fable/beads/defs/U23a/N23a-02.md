## Background
A common gym convention hands the learner an untyped array of floats. Nothing then says whether element 7 is a joint angle in radians or a velocity in the body frame, how old the sample was when the policy read it, whether it was valid, or what was done to it before the policy saw it. Policies trained that way cannot be moved between designs, cannot be checked for information leaks, and silently change meaning when a normalizer is refit. Rule **E-6** of the environment contract removes those failures: every channel of an observation or action space has a shape, a dtype, a channel id, a unit, a frame, a representation, a validity mask and a sample age taken from the simulator's clock contract; normalization is versioned and invertible; clipping is disclosed.

This bead builds the space descriptor and the normalizer. It is Solid tier, lives in `frob-learn::space`, and is consumed by the environment (BD-192), the actor schema and access classes (N23a-03), the checkpoint manifest (N23a-13, which stores the normalizer's digest), the mapping table that matches a policy to a design by role, and the equivariance machinery, which needs each channel's representation to build symmetric networks and mirrored data.

Terms. *Clock contract*: every sensor, controller and actuator channel has a rational period and phase; simulation time is an integer count of quanta; an observation's **age** is the decision instant minus the sample instant, an integer count of quanta. A held value is never presented as fresh. *Representation*: how a channel transforms under a symmetry of the robot (a signed permutation of its components; polar vectors map by an orthogonal matrix P, axial vectors by det(P)·P), declared per term in the task file so that the framework, not a hand table, builds mirrored data. *Delivered observation*: the value in the consumer's packet queue at the decision instant, after transport latency, loss and reordering.

Rejected alternatives: normalization fitted online and stored only inside the network weights (not invertible from outside, not versioned, changes during collection and so breaks the frozen-behaviour rule); silent clipping of normalized observations (hides saturation from the learner and from the evaluator); units carried only in documentation.

## Scope
In: `ChannelSpec`, `SpaceSpec`, the observation and action space descriptors and their digest; validity masks and sample ages as first-class tensors; `Normalizer` with version, forward, inverse, statistics, freeze and update-between-collections; the action out-of-range rule declaration and the logging of proposed against applied values (the declaration half of rule E-5; the check itself is in BD-192). Out: access classes and the actor schema (N23a-03); the compilation of observation terms from `.ftask` (BD-194, `frob-spec`); the merge of normalizer statistics across shards (N23a-19); the manifest (N23a-13).

## Technical approach
**Types (DESIGN).**
```rust
pub struct ChannelSpec {
    pub id: ChannelId,              // stable identifier from the task program, e.g. "base_ang_vel"
    pub role: Role,                 // design-relative role, e.g. leg[0].hip; matching is by role, never by position
    pub shape: SmallVec<[u32; 4]>,  // per-world extents
    pub dtype: Dtype,               // f32 for policy inputs; u32/i32 for counters and masks
    pub unit: Unit,                 // from frob-core's quantity module; dimensionless is explicit
    pub frame: FrameId,             // the frame the components are expressed in; heading-normalized where declared
    pub representation: RepId,      // how it transforms under the symmetry groups (signed permutation)
    pub period: Ratio,              // the channel's rate as a rational period, from the clock contract
    pub validity: ValidityKind,     // always-valid | per-sample mask | per-component mask
    pub exposes_age: bool,          // whether the age tensor is delivered with the value
    pub noise: Option<NoiseRef>, pub delay: Option<DelayRef>,   // by reference to the task program's declarations
}
pub struct SpaceSpec { pub channels: Vec<ChannelSpec>, pub layout: Layout /* offsets in the flat tensor */ }
pub struct ActionChannel { pub spec: ChannelSpec, pub bounds: (Qty, Qty), pub out_of_range: OutOfRange /* refuse | clip | squash */ }
pub struct Normalizer { pub version: u32, pub kind: NormKind /* affine per component */, pub mean: Tensor, pub scale: Tensor,
                        pub clip: Option<f32>, pub count: u64, pub frozen: bool, pub digest: Blake3 }
```
**Rules implemented.**
1. *Typed spaces.* A `SpaceSpec` is built only from a `TaskProgram`; there is no constructor from a bare length. Its digest is BLAKE3 over the canonical encoding of all channel fields in channel-id order, so two spaces with the same numbers in a different meaning have different digests.
2. *Validity and age.* For every channel with `validity ≠ always-valid` the environment produces a mask tensor; for every channel with `exposes_age` it produces an integer age tensor in quanta. Both are part of the space layout the policy sees (if declared) and are always written to telemetry. A missing sample is represented by its mask and its age, never by a stale value presented as fresh and never by a NaN.
3. *Normalization is versioned and invertible.* `y = (x − mean)·scale` per component, with `scale > 0` enforced; `x = y/scale + mean` is the inverse; `inverse(forward(x)) = x` to round-off when no clipping is active. The normalizer has a version that increments on every statistics update, and updates happen only between collections (it is frozen during collection; the frozen-behaviour rule P-2 of the PPO battery tests this). Statistics are kept as the triple (count n, mean μ, sum of squared deviations S) so that shards can be merged exactly later.
4. *Clipping is disclosed.* If `clip = Some(c)`, components with |y| > c are clipped and a per-channel counter of clipped components per collection is written to the step information and to the training receipt; the manifest records c. A policy evaluated with a clip that differs from its checkpoint's is refused with the mapping-table refusal (FROB-REF-531, "normalizer digest differs").
5. *Actions.* Each bounded action channel declares its out-of-range rule. The environment logs both the proposed and the applied value for every channel that differed, and the step view carries `applied_action` (after the limiter and any shield). The declared rule is what the registered action law (latent-then-limit, or clipped-with-endpoint-mass) assumes; a mismatch between the rule and the law is caught by the action-law bead.
6. *Units at the boundary.* Converting a channel to another unit is done by the quantity module, exactly for power-of-ten and rational factors; the normalizer is then re-expressed (mean and scale transform with the unit) so that the normalized values are unit-independent. This is the metamorphic relation tested below.

**Determinism and evidence.** Descriptors and digests are class D0 (exact). Normalizer application is elementwise and class D2 per backend, D1 where the backend's algebraic kernels are bit-equal. Ledger: the space digest, normalizer digest and version are recorded with every run and checkpoint.

## Acceptance criteria
- [ ] A `SpaceSpec` cannot be constructed without a unit, frame, representation and period for every channel (compile-time or constructor refusal), and its digest changes when any of those changes.
- [ ] For a channel sampled with period 1/10 s and phase 0, read by a policy with period 1/50 s and phase 0 and no transport delay, the age over five consecutive decisions after a sample is 0, 1, 2, 3, 4 control periods (0, 20, 40, 60, 80 ms), stored as the integers 0, 20·k, 40·k, 60·k, 80·k quanta where k is the number of quanta per millisecond of the clock contract, and the value is held; a dropped packet sets the mask and the age keeps growing (100 ms at the next decision) with the value not refreshed.
- [ ] `Normalizer::inverse(forward(x))` equals x within 2 ulp on 10⁴ random vectors; with clipping active the count of clipped components equals a reference count and appears in the step information.
- [ ] A normalizer update attempted while a collection is open is refused; the version increments exactly once per update between collections.
- [ ] Re-expressing a channel in another unit (metres to millimetres) changes the raw values and leaves the normalized values bit-identical after the normalizer is re-expressed.
- [ ] Proposed and applied actions are both logged for a bounded channel driven out of range, under each of the three out-of-range rules.
- [ ] Negative controls caught: a normalizer whose scale has a zero component is refused; a space built from two channels with exchanged units has a different digest; a held sample presented with age 0 fails the age fixture.

## Test plan
### Unit tests
`space_requires_all_fields`; `space_digest_sensitive_to_unit_frame_rep_period`; `age_and_hold_across_rates` (rational periods 1/10 and 1/50; expected ages as above); `mask_on_dropped_packet`; `normalizer_roundtrip_10k`; `normalizer_clip_count_disclosed`; `normalizer_frozen_during_collection`; `normalizer_version_monotone`; `unit_rescale_metamorphic`; `action_proposed_and_applied_logged_{refuse,clip,squash}`; property test `layout_offsets_disjoint_and_cover` (random channel lists: offsets partition the flat tensor).
### End-to-end script and logging
Exercised by `scripts/e2e/cortex_env.sh` (bead N23a-34), step `typed-spaces`: runs a short rollout, `frob sim run <reference quadruped> --task <reference task> --tier batch-cpu --worlds 8 --seconds 1 --seed $E2E_SEED --key e6 --json` (50 control intervals at 50 Hz under the design's baseline controller for the task), reads the space descriptor from the run manifest, asserts every channel has unit, frame, representation, period and access class, and logs `metric` lines for the count of clipped components and the maximum age per channel with their units.
### Known answers and negative controls
The age fixture above is an exact known answer from the clock contract (integer quanta). Negative controls as listed in the acceptance criteria; each is registered against GATE-CORTEX-06 (rule E-6 fixture). Determinism lanes: descriptor digests identical across machines and backends; normalizer outputs twice on one machine and across worker counts bit-identical.

## Considerations
- Whether a policy receives sample ages is a declaration of the task (an open question of the sensing chapter, OPEN-SENS-3, whose default is that telemetry always records ages and the policy receives them only if its schema declares them); this bead supports both.
- Normalizer statistics are part of the checkpoint and of every snapshot; losing them makes a checkpoint unusable, which is why the manifest stores the digest and the loader refuses a mismatch.
- Privacy: descriptors contain channel names and units only; no observation values enter logs.
