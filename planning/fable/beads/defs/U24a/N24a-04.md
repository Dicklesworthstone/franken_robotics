## Background

A requirement is a formula of signal temporal logic over unit-normalized predicates (construction C-30). It replaces
success flags hand-coded per task and rewards standing in for requirements. One artifact then serves as the
acceptance predicate of a mission, the falsification score of an adversarial search and a runtime monitor.

Every formula has two values at every tick of its clock: a Boolean value and a margin ρ, a dimensionless number whose
sign agrees with the Boolean value away from the boundary. The margin is what an agent acts on ("how far from
passing, and which condition binds"); the Boolean value is what is counted. They are computed by two parallel
recursions over the same tree, because at ρ = 0 the margin decides nothing and the declared comparators must
(ADR-ARENA-05).

This bead defines the tree, the semantics and the slowest possible evaluator: a direct transcription of the
definitions, quadratic in the window, with no cleverness. It is the oracle against which the two fast evaluators
(the online block kernels, N24a-07, and the referee's monotonic deque, N24a-08) and the offline verdict evaluator
(N24a-09) are tested bit for bit (proof obligation PO-ARENA-01). An oracle that shared an optimization with the code
under test would share its bugs; this one shares only the syntax tree.

## Scope

In: the Rust types of the requirement tree; the Boolean and margin semantics of every node; the definitional
evaluator on a tick-indexed trace with explicit coverage; binding-atom extraction; the two soundness laws as property
tests; canonicalization of negative zero; the treatment of NaN.

Out: units and scales (N24a-05 supplies the normalized atom values; here an atom is already a dimensionless margin
plus a Boolean); clocks, reductions and conversion of time windows to ticks (N24a-06); reach, `undetermined` and
decided-early (N24a-09); the boundary guard (N24a-10); the verdict record (N24a-11).

## Technical approach

**Types (DESIGN; they fix intent, not signatures).**

```rust
/// A comparison of two expressions of one dimension, with a scale of that dimension.
pub struct Atom { id: Ident, cmp: Cmp, lhs: Expr, rhs: Expr, scale: Scale }
pub enum Cmp { Gt, Ge, Lt, Le, Eq }
pub enum Scale { Qty(Qty), Exact }                 // Exact: integer-valued signal, margin +1 or −1
pub enum Expr { Signal(SignalId), Qty(Qty), Op(ArithOp, Vec<Expr>), Delay(Qty, SignalId) }
pub enum ArithOp { Add, Sub, Mul, Min, Max, Abs }

pub struct Window { lo: Qty, hi: Qty, round: Option<Rounding> }   // closed; exact rational comparison of ticks
pub enum Rounding { Inward, Outward }
pub enum Past { Atom(Ident), And(Vec<Past>), Or(Vec<Past>), Not(Box<Past>),
                Historically(Window, Box<Past>), Once(Window, Box<Past>), Since(Window, Box<Past>, Box<Past>) }
pub enum Future { Past(Past), And(Vec<Future>), Or(Vec<Future>), Not(Box<Future>),
                  Always(Window, Box<Future>), Eventually(Window, Box<Future>),
                  Until(Window, Box<Future>, Box<Future>) }

pub struct Requirement {
    clock: ClockId,                    // each requirement names the clock it is evaluated on
    atoms: Vec<Atom>,
    online: Vec<(Ident, Past)>,        // past-time signals, computed inside the step
    verdict: (Ident, Future),          // evaluated offline on the completed trace
    examples: Vec<(TraceRef, Label)>,  // at least two satisfied and two violated
}

pub trait Monitor {
    fn margin(&self, tick: Tick) -> Margin;        // dimensionless; its sign agrees with the Boolean value
    fn decided_at(&self) -> Option<Tick>;          // the tick at which a prefix fixed the verdict
}
```

**Atom semantics.** Let e₁, e₂ be the two expressions at tick t and s the scale.

| Atom | Boolean value | Margin ρ |
|---|---|---|
| `(> e₁ e₂)` scale s | e₁ − e₂ > 0 | (e₁ − e₂)/s |
| `(>= e₁ e₂)` scale s | e₁ − e₂ ≥ 0 | (e₁ − e₂)/s |
| `(< e₁ e₂)`, `(<= e₁ e₂)` scale s | e₂ − e₁ > 0, e₂ − e₁ ≥ 0 | (e₂ − e₁)/s |
| Any comparator, `:exact` (integer-valued signals such as a count of chassis strikes) | The comparison on integers | +1 if it holds, −1 if not |
| `(= e₁ e₂)` scale s (DESIGN, this bead's elaboration; the grammar admits it and the laws below hold) | e₁ = e₂ exactly | −\|e₁ − e₂\|/s, which is zero exactly at equality |

**Formula semantics.** Time is the tick index of the requirement's clock; a window [a, b] is already in ticks.

| Formula at tick t | Boolean | Margin ρ |
|---|---|---|
| ¬φ | not | −ρ(φ, t) |
| φ ∧ ψ ; φ ∨ ψ | and ; or | min ; max of the two margins |
| G_[a,b] φ ; F_[a,b] φ | for all ; for some t′ ∈ [t + a, t + b] | min ; max of ρ(φ, t′) over t′ ∈ [t + a, t + b] |
| φ U_[a,b] ψ | some t′ ∈ [t + a, t + b] has ψ at t′ and φ at every t″ ∈ [t, t′) | max over t′ ∈ [t + a, t + b] of min( ρ(ψ, t′), min of ρ(φ, t″) over t″ ∈ [t, t′) ) |
| H_[a,b] φ ; O_[a,b] φ | for all ; for some t′ ∈ [t − b, t − a] | min ; max of ρ(φ, t′) over t′ ∈ [t − b, t − a] |
| φ S_[a,b] ψ | some t′ ∈ [t − b, t − a] has ψ at t′ and φ at every t″ ∈ (t′, t] | max over t′ ∈ [t − b, t − a] of min( ρ(ψ, t′), min of ρ(φ, t″) over t″ ∈ (t′, t] ) |

A minimum over an empty index set is +∞ and a maximum is −∞ (so `U` with t′ = t has an empty inner minimum).

**The two laws (PO-ARENA-04).** ρ > 0 implies the formula holds; ρ < 0 implies it fails. At ρ = 0 the margin decides
nothing and the Boolean recursion, built from the declared comparators, is the answer.

**The two edges of a finite episode.** An episode has ticks 0 … T_end. The table above reads ticks that may not
exist, and the two ways of not existing are different facts with different rules.

- *After the end, or missing inside the episode* (the episode was truncated, or telemetry was dropped). The value is
  unknown: `None`. Nothing is computed from the part of a window that exists (INV-ARENA-02). `None` propagates
  through every operator; how a verdict can still be decided when some operand is unknown is the business of the
  offline evaluator (N24a-09).
- *Before the origin* (a past-time window, a delay, or a held slower-clock signal that reaches before tick 0 or
  before the signal's first sample). DESIGN, this bead's elaboration, forced by the chapter's own fixtures: **a tick
  before the origin satisfies nothing.** Consequently H_[a,b] φ at t with t − b < 0 is false with margin −∞ ("it has
  held for the whole window" is false when the window is longer than the time elapsed); O_[a,b] φ ranges over the
  existing ticks of its window and is false, −∞, when there are none; φ S_[a,b] ψ ranges over existing t′; an atom
  that reads `(delay d x)` at t < d, or a held signal before its first sample, is false with margin −∞. Each such
  value carries the flag `pre-origin`, so that consumers of margins (reward terms, splitting scores, reports) can
  exclude it while Boolean consumers read false. Negation applies as usual (¬H is true while H cannot yet hold).
  Reason: fixture 1's verdict `(U (0 s 8 s) hard-limits dwell)` with `dwell` = `(H (0 s 0.5 s) …)` must evaluate to
  `violated` with a finite margin on a run that never docks, which is what its worked verdict shows. The two
  alternatives fail: treating the pre-origin part as vacuously true is the padded window the chapter forbids (a cart
  would be "docked for 0.5 s" at tick 0); treating it as unknown makes the candidate t′ = 0 of every such until
  unknown and so every failed run `undetermined`.

**The definitional evaluator.**

1. Input: for each atom, an array of (Boolean, margin) per requirement tick, plus a coverage map with three states
   per tick: present, missing, pre-origin.
2. Evaluate the tree by structural recursion with explicit loops over the index sets of the table. No sliding-window
   data structure, no memoization across ticks beyond per-node result arrays.
3. Apply the two edge rules above at the node that reads the non-existent tick. No padding, and no clamping of a
   universal window to the part that exists.
4. Floating-point rules: atom margins are IEEE doubles (or singles on device tiers). Negative zero is canonicalized
   to +0 at the atom, so `min(+0, −0)` cannot differ between implementations. A NaN in any atom input marks the
   world `Faulted`; the evaluator returns the fault, and the verdict becomes `invalid` (N24a-11). Minimum, maximum
   and negation are exact in floating point, so every evaluator that implements this table returns identical bits
   for identical atom values.
5. Binding atom: together with each margin the evaluator returns a witness (atom identifier, tick) whose atom margin
   equals the formula's margin up to sign. Ties are broken deterministically: earliest tick, then atom declaration
   order (DESIGN). The witness is what the verdict record prints as `binding_atom` and `binding_time_s`.
6. Complexity is O(T · W) per temporal node and O(T · W²) for `U` and `S`; that is the point. It runs in tests and in
   `task.check` on labelled examples, never in a stepping loop.

**Determinism and evidence.** Boolean values built from `:exact` atoms are class D0. Margins computed from floating
telemetry are class D2 (the same bits per backend). Evidence class of an evaluated formula: Tested.

## Acceptance criteria

- [ ] All nodes of the grammar evaluate; the fixture 1 verdict `(U (0 s 8 s) (and tilt-ok current-ok no-strike)
      dwell)` evaluates on a synthetic trace to the hand-computed margin and binding atom.
- [ ] Law tests pass on 10⁶ random (formula, trace) pairs: no case with ρ > 0 and Boolean false, none with ρ < 0 and
      Boolean true.
- [ ] A window that reaches past the end of the trace, or onto a missing sample, yields `None`, never a value from
      the part that exists; a universal past window that reaches before the origin yields false with margin −∞ and
      the flag `pre-origin`, never the minimum over the part that exists.
- [ ] A NaN atom input yields a fault, never a margin; `−0.0` and `+0.0` inputs yield identical bits at every node.
- [ ] The evaluator has no dependency on any reward type and no access to anything but the atom arrays (purity,
      INV-ARENA-01).

## Test plan

### Unit tests

- `atom_margins`: clearance signal 0.12 m, atom `(> (- x 0.10 m) 0 m) :scale 0.10 m` → ρ = 0.2, true; x = 0.10 m →
  ρ = 0, false (strict); the same with `>=` → ρ = 0, true.
- `exact_atom_is_plus_minus_one`: `(= strikes 0) :exact` with strikes 0 → +1, with 2 → −1.
- `equality_with_scale`: `(= x 1 m) :scale 0.5 m` at x = 1.25 m → −0.5, false; at x = 1 m → 0, true.
- `always_eventually_small`: margins [3, 1, 2, −1, 4]; G_[0,2] at t = 0 → 1; F_[1,3] at t = 0 → 2; G_[0,3] at
  t = 0 → −1 with witness tick 3; G_[0,4] at t = 1 → `None` (tick 5 does not exist).
- `historically_once_small`: same array; H_[0,2] at t = 2 → 1; O_[1,2] at t = 3 → 2 (ticks 1 and 2).
- `pre_origin_rule`: same array; H_[0,2] at t = 1 → false, −∞, flagged `pre-origin` (not min(3, 1) = 1);
  O_[0,2] at t = 1 → 3 (existing ticks 0 and 1); O_[2,3] at t = 1 → false, −∞ (no existing tick); ¬H_[0,2] at
  t = 1 → true.
- `fixture1_shape_never_docks`: `hard` = [1, 1, 1, 1, 1, 1], `inside` = [−0.5, −0.4, −0.3, −0.3, −0.31, −0.31],
  `dwell` = H_[0,2] `inside`, verdict `hard` U_[0,5] `dwell` at t = 0 → violated with margin −0.31: the candidates
  t′ = 0 and 1 contribute −∞ (pre-origin), and t′ = 2, 3, 4, 5 contribute −0.5, −0.4, −0.31, −0.31; the binding
  atom is `inside` at tick 4. The result is never `None`.
- `until_small`: φ = [2, 2, −1, 2], ψ = [−3, −3, 5, 1]; φ U_[0,3] ψ at t = 0 → max(min(−3, +∞), min(−3, 2),
  min(5, 2), min(1, −1)) = 2.
- `since_small`: the mirror case, evaluated at the last tick.
- `law_positive_implies_true`, `law_negative_implies_false`: 10⁶ random pairs (depth ≤ 5, windows ≤ 16 ticks,
  traces of 64 ticks, margins drawn so that exact zeros occur in about 1% of atoms).
- `duality`: ρ(¬G φ) = ρ(F ¬φ) and ρ(¬(φ ∧ ψ)) = ρ(¬φ ∨ ¬ψ), bit for bit, on 10⁴ pairs.
- `past_future_mirror`: G over [0, T] at tick 0 equals H over [0, T] at tick T (metamorphic relation MR-20).
- `nan_faults`, `negative_zero_canonical`: as in the acceptance criteria.
- `binding_witness_is_attained`: the witness atom's margin at the witness tick equals ±ρ on 10⁴ pairs.

### Known answers and negative controls

- KA (construction C-30, streaming control): the fast evaluators must equal this one on random signals; this bead
  supplies the oracle half.
- Negative control: an evaluator that pads a short window (treats missing ticks as +∞ under `G`) must fail
  `always_eventually_small`'s fourth assertion. This is the negative control of KA-596.
- Negative control: an evaluator that decides the Boolean value from the sign of ρ must fail `atom_margins` at
  ρ = 0 under `>=`.
- Determinism lanes: the 10⁴-pair suites run twice on one machine, in debug and release, and on both operating
  systems; results are compared as bits.

## Considerations

- The `=`-with-scale margin and the `:exact` inequality are elaborations made here because the grammar admits them
  and the chapter states the margin only for inequalities with a scale and for exact equality. Both satisfy the
  laws. If the owner prefers to refuse them, the change is one parser rule and two tests.
- Honest limit of the construction: margins are comparable across atoms only through their declared scales, which
  are judgments recorded in the task file.
- A 600 s future window at 50 Hz is 30,000 samples; the definitional evaluator is unusable there by design, and the
  offline evaluator of N24a-09 is the production path.
- What would make us revisit: a need for unbounded operators (refused by ADR-ARENA-02) or for a smooth margin as a
  first-class value (today a training-only option, behind KILL-SPEC-REWARD).
