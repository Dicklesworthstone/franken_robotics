## Background

`telemetry.query` is how anything outside the simulator reads what happened: columns by stream and range, paged
against a committed frontier. Requirements are evaluated on its columns, metrics are computed from them, the
replay packet's probe values are checked against it, and an agent drills into a failing world through it. Two
properties make it trustworthy, and both are easy to get wrong.

*It must not change physics on the page.* Every channel declares its kind, unit, frame, sampling, quantization and
permitted consumers. The kind fixes how the channel may be downsampled; a downsampling that ignores it is a defect
that changes physics on the page. Averaging an impulse train changes momentum transfer; sampling mean power drops
energy; decimating events deletes the event that explains the failure.

*It must return each row exactly once while the run is still being written.* Episodes are published in chunks as
they are simulated. A query that pages through a growing table with an offset will skip or repeat rows. Pagination
is therefore pinned to the committed frontier (invariant INV-CHRON-04: a paginated query returns every row visible
at its pin exactly once).

## Scope

In: the query model (run, worlds, episodes, streams, channels, tick range, downsampling); kind-correct downsampling;
pinned pagination with cursors; gaps; refusals FROB-REF-888 and FROB-REF-896; the verb.

Out: the chunk protocol and frontier themselves (the chunk-protocol bead); the general pagination and
large-integer rules of the surface (the M2 surface bead generalizes what this verb does first); histograms and
divergence search (their own verbs).

## Technical approach

**1. Streams and channels.** Telemetry is organized in nine streams (Kinematics, Contact, Energetics, Control,
Sensing, Solver, Runtime, Task, Provenance); a chunk belongs to one stream. Levels: T0 per-episode metrics and
envelopes for every world; T1 events for every world; T2 traces at control rate for an address-keyed sample of
worlds and every failing world; T3 snapshots. A query names a run, a set of world addresses and episodes, a stream,
channels, a tick range and optionally a target sample period.

**2. Downsampling by kind.** If the requested period is coarser than the stored one, each channel is reduced by the
only rule its kind admits:

| Kind | Example | Correct downsampling | Wrong, and why |
|---|---|---|---|
| State | Joint angle, base pose | A sample, or a minimum-maximum envelope; orientation by a group-aware mean or a sample | A componentwise mean of quaternions leaves the group |
| Interval mean | Mean power over a tick | Duration-weighted mean | A sample drops energy |
| Impulse | Contact impulse | Sum over the window | A mean or a sample changes momentum transfer |
| Event | Contact made, limit hit | All events, or a count | Decimation deletes the event that explains the failure |
| Cumulative counter | Energy drawn, distance | Last value | A sum counts everything twice |

The response states, per column, the reduction applied. A request for a reduction the kind does not admit is
refused with the admitted ones. At a jump (an impact, a reset map, a mode switch) the state before and the state
after are both returned.

**3. Gaps and missing samples.** Telemetry that was dropped is marked with its interval and its reason, and the
query returns the gap as a gap. A derived value over missing samples (an envelope, a mean, a sum whose window
contains a gap) is refused (FROB-REF-888: a metric computed over missing samples; repairs: re-run with the channel
retained, or accept `unavailable`), not estimated from its neighbours. Worlds not in the T2 sample return their T0
and T1 data and a statement that no trace was retained, with the sampling rule.

**4. Pinned pagination.** On its first page a query fixes four things: the run; the value of `commit_seq` at that
moment (the pin); its filters; and a total order (tick, world, episode, stream, sample identifier), so that samples
with equal timestamps are ordered. Rows committed later are invisible to that query. The cursor is the pin plus the
last order key. Appends between pages can therefore neither skip nor repeat a row. A cursor used with a different
pin, filter or order is refused (FROB-REF-896; repair: restart the query). The response carries `cursor` and
`frontier`; a long answer is paginated and says so, never cut silently. Page size is bounded by the caller's token
budget.

**5. Encoding.** Columns are returned as arrays with the channel header (name, kind, unit, frame, quantization);
quantized integer columns are returned as stored, with their scale, so that a consumer can reproduce exact stored
values. Integers that can exceed 2⁵³ (ticks, sequence numbers, digests) are strings in every JSON view. Channels are
labelled as visible to the acting policy or privileged; the label is returned so that an audit can read it.

**6. Evidence.** The envelope's evidence block carries the run's tier and determinism class and the frontier the
rows were read at; a verdict or metric computed from a query cites that frontier.

## Acceptance criteria

- [ ] 10⁴ rows read in pages during concurrent appends: each row visible at the pin appears exactly once, and no row
      committed after the pin appears (INV-CHRON-04).
- [ ] A cursor replayed with a changed filter, order or pin is refused with FROB-REF-896.
- [ ] An impulse train downsampled over a window is summed and conserves momentum transfer; a request to average it
      is refused.
- [ ] A window containing a dropped interval returns the gap with its reason, and an aggregate over it is refused
      with FROB-REF-888.
- [ ] Equal-timestamp samples from several streams are returned in the stated total order on every call.
- [ ] Every column carries kind, unit, frame and quantization; integers above 2⁵³ are strings.
- [ ] Reachable through `frob telemetry query --json` and MCP; page size respects the token budget.

## Test plan

### Unit tests

- `pinned_pages_under_appends`: a writer thread publishes chunks while a reader pages; set equality with the rows
  visible at the pin; no duplicates.
- `timestamp_only_order_fails` (negative control as a test of the test): ordering by tick alone repeats or skips
  equal-time samples at a page boundary.
- `cursor_misuse_refused`: three variants (pin, filter, order).
- `downsample_impulse_is_sum`: impulses (0.2, 0, 0.1, 0.3) N·s over one window → 0.6 N·s.
- `downsample_mean_power_is_duration_weighted`: 10 W for 2 ms and 40 W for 8 ms → 34 W.
- `downsample_counter_is_last`: (1.0, 2.5, 4.0) J → 4.0 J, not 7.5 J.
- `downsample_state_envelope`: angles (0.1, 0.4, −0.2) rad → min −0.2, max 0.4.
- `events_never_decimated`: three events in one window → three events, or the count 3.
- `quaternion_mean_refused`: a componentwise mean of orientations is not an admitted reduction.
- `jump_returns_both_states`.
- `gap_returned_and_aggregate_refused`.
- `big_integers_are_strings`: tick 2⁵⁴ round-trips as a string.

### End-to-end script and logging

Steps `query-*` of `scripts/e2e/telemetry_verbs.sh` (N24a-39): while a referee batch is still running under the
daemon or a second process, `frob telemetry query <run> --stream contact --ticks 0:… --page-size 500 --json` is
paged to exhaustion; the union of pages is compared with a query issued after the run with the same pin. Then a
cursor is reused with a changed filter (expects exit 3, FROB-REF-896), and an impulse channel is requested with
`--reduce mean` (expects a refusal listing `sum`). NDJSON lines carry the command, exit code, wall time, evidence
block, rows returned per page, the pin and final frontier, duplicate and missing counts (threshold 0), and refusal
blocks.

### Known answers and negative controls

- Record subsystem known answer (pagination): 10⁴ rows read in pages during concurrent appends: each row visible at
  the pin appears once. Negative control: a query ordered by timestamp alone repeats or skips equal-time samples.
- Record subsystem known answer (downsampling): an impulse train summed over a window conserves momentum transfer.
  Negative control: the same train averaged.
- Metamorphic relation MR-36: a page sequence pinned to a frontier shows each row once under concurrent appends;
  mutation that must break it: offset pagination.
- Determinism: identical bytes for identical (pin, filters, order, page size), across platforms.

## Considerations

- OPEN-CHRON-2 (chunk length and device ring depth; default 256 control ticks per chunk and 2 s of ring) changes
  page boundaries, not results.
- Reading T2 traces of private scenes requires the caller's scope; channel labels (policy-visible or privileged) are
  information for audits, and isolation itself is enforced elsewhere.
- Cost: a query never triggers simulation; if the data was not recorded the answer is "not retained", with the
  manifest fields that would have retained it.
