## Background

A fixed-n study has a frozen rule and therefore a finite set of outcomes; a wanted verdict may not be among
them. The verb `eval.preanalyze` enumerates the reachable verdicts and the power of a fixed-n rule at a given
n and level, and the study admission layer refuses a study that mixes types, lacks a pre-analysis, names an
unreachable verdict or asks for paired statistics under an uncontrolled determinism class. This script drives
both from the user's side with the real `frob` binary. It is the script from which GATE-ARENA-05 is recorded
(claim: Known answer; M1; TARGET: `eval.preanalyze` reproduces the tables of fixture 1 exactly and refuses the
unreachable verdict).

## Scope

In: one script covering the pre-analysis tables, the level dependence, the equivalence and absolute rules, and
the study-type refusals; its structured log and negative controls. Out: the enumerator (N24b-06), the admission
layer (N24b-14) and the study engines (BD-124) themselves.

## Technical approach

**Path and invocation.** `scripts/e2e/arena_study_preanalysis.sh [--mutants]`. Plain shell; non-zero exit on a
failed assertion; idempotent (writes only under `target/e2e-logs/arena_study_preanalysis/` and a scratch
store); no randomness except the seeded null simulation of step 9, whose seed is printed.

**Steps.**

1. `enumerate`: `frob eval preanalyze --rule paired-clopper-pearson/1 --n N --level 0.05 --margin 0.05 --json`
   for N = 64, 86, 128, 256. Assert outcomes and counts: 2,145 → 521, 521, 0, 1,103; 3,828 → 1,031, 1,031, 1,
   1,765; 8,385 → 2,517, 2,517, 4, 3,347; 33,153 → 11,384, 11,384, 39, 10,346.
2. `consequences`: at N = 64 assert the concordance interval ±0.0662, `min_b_for_prefer` = 15, 17, 19, 21, 23
   for a = 0 … 4, and `first_reachable` for the tie = 86 with the single pair (0, 0).
3. `power`: alternatives (0.17, 0), (0.25, 0.02), (0.40, 0.02) for "prefer B" and (0.02, 0.02), (0, 0) for the
   tie. Assert at N = 64: 0.117, 0.406, 0.962, 0, 0; at 128: 0.775, 0.906, above 0.999, 0.072, 1; at 256:
   0.998, above 0.999, above 0.999, 0.427, 1.
4. `levels`: `--level 0.05/2`, `0.05/110`, `0.05/250500`; assert the tie is first reachable at 99, 178 and 328,
   and that N = 64 at level 0.05/2 has 478 preferring outcomes.
5. `other_rules`: `--rule paired-total-discordance/1 --n 64 --level 0.05` gives 0.0457 for zero discordant
   pairs; `--rule one-sided-binomial-bound/1 --n 200 --level 0.05/2` gives bounds 0.0432 and 0.0504 at 3 and 4
   failures.
6. `refuse_unreachable`: the same call at N = 64 with `--declared prefer-b,b-inferior,practical-tie`; assert
   refusal `FROB-REF-532`, exit code 3, the reachable set and the repair "n = 86" attached.
7. `committed_table`: regenerate `registries/preanalysis/paired-clopper-pearson-1.toml` to a scratch path and
   assert byte equality with the committed file.
8. `refuse_mixture`, `refuse_no_preanalysis`, `refuse_uncontrolled_class`: `frob study plan` with a request
   carrying both type declarations (expect `FROB-REF-552`); a fixed-n plan with no pre-analysis (expect
   `FROB-REF-532`); a paired plan with one arm under the labelled nondeterministic profile (expect
   `FROB-REF-533`). Exit code 3 each.
9. `race_level` and `status_interim`: a 5-way race plan shows level 0.0125 per pairwise study; `frob study
   status` on a fixed-n study at 30 of 64 units returns progress and no interval or verdict.
10. `peeking` (context for the refusal of step 8): the admission layer's test target prints the exact
    false-rejection chances of the sign test looked at after every pair; assert 13/256 after 8 looks and 17.4%
    (± 0.05 points) after 64.
11. `hash_stability`: run step 1 twice; assert identical pre-analysis hashes.
12. `negative_controls` (with `--mutants`): a build whose endpoints are rounded inward, and a build using tails
    of α/2 instead of α/4; step 1's assertions must fail under each, and the script records the control as
    caught.

**Logging.** Per the shared helper of STD-E2E: newline-delimited JSON at
`target/e2e-logs/arena_study_preanalysis/<utc-timestamp>.ndjson` with a transcript beside it; every line has
`ts`, `script`, `bead`, `step`, `event`, the exact command line, exit code, wall time, the envelope's
`evidence` block (claim Known answer, class Tested, tier static, determinism exact), expected and measured
values per table cell, the pre-analysis hash, and for refusals the code, pointer and ranked repairs. The final
`summary` line gives assertion counts, controls caught and the gate touched (GATE-ARENA-05).

## Acceptance criteria

- [ ] The script exists, is executable and passes on a clean checkout at M1.
- [ ] Every table cell of steps 1 to 5 is asserted individually and logged with expected and measured values.
- [ ] The tie request at N = 64 is refused with FROB-REF-532 and the three study-type refusals fire with their codes and exit code 3.
- [ ] The committed table equals a fresh generation.
- [ ] With `--mutants`, both planted defects are caught.
- [ ] The gate record for GATE-ARENA-05 cites this script's log by path and digest, with the control (the refused tie) recorded as caught.

## Test plan

### Unit tests
A `--list-steps` mode prints the step names; a small test asserts the list so that a dropped step is caught. A
`--selftest` mode alters one expected count (521 to 520) and must make the script fail, showing its assertions
can fail.

### End-to-end script and logging
This bead is the script. Commands from the user's side: `frob eval preanalyze`, `frob study plan`, `frob study
status`. Assertions and log content as above.

### Known answers and negative controls
KA-612 (enumeration; control: a tie verdict requested at n = 64 is refused), KA-613 (power), KA-614 (0.0457),
KA-618 (peeking: 13/256 after 8 looks; 8.76%, 12.9%, 17.4%), KA-621 (99, 178, 328; 478). CX-265, CX-266.
Negative controls: the refused tie; the two mutant builds; the self-test. Determinism: output hashes identical
twice, and on both platforms (class D0).

## Considerations

- The whole script is arithmetic and should finish in seconds; N = 256 dominates.
- Rules registered by other subsystems under the same verb (a cadence rule for threshold crossings; the ten-fold study plan) get their own steps in their owners' scripts; this script fails if the verb's rule list loses one of the three rules it tests.
