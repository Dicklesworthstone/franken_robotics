## Background

Ground is the subsystem that compares simulation with reality (crate `frob-ground`, layer 5). Reality is the
one claim the first release mostly cannot make: nothing in the project has been compared with a physical robot,
agreement between simulation tiers cannot reveal a wrong actuator card, and a measurement that has not been
taken cannot be replaced by a larger batch. So every report prints `reality: no-claim` until measured data
supports something else. The admission lane exists so that the first real dataset has somewhere to land with
its licence, its provenance and its measurement uncertainty, and so that a simulated number can never be read
as a measured one.

Three decisions govern admission. **ADR-GROUND-01:** Ground is file-in, file-out; it never commands or reads a
device (scope and safety: a simulator's gate cannot depend on hardware the project does not have).
**ADR-GROUND-02:** the unit of calibration is the cell, and a band belongs to exactly one cell (coverage holds
for exchangeable draws only, and pooling hides a failing regime). **ADR-GROUND-05:** a prediction is frozen
before its trial data is readable; a refit opens a new prediction version; a scored holdout is retired
(otherwise the comparison is a fit, and its error rate is unknown). Admission is where the second and third
are made enforceable: a dataset declares its cell, and its validation and holdout parts are sealed at the
moment it enters, before anyone could have looked.

Rejected alternatives: a new file extension for real data (a real dataset is an episode bundle whose manifest
says so); random splits of rows (rows inside one episode are dependent, so a random split leaks the
validation set into the fit); sealing by convention (a guard that is not in the storage path will be bypassed
by the first convenient script).

Tier: Solid for admission. Nothing here needs hardware; every test runs on data labelled `synthetic`.

## Scope

In: the manifest schema and its validation; the dataset identity; the cell key; split assignment; sealing and
the read guard; the `ground.ingest` verb for logs and bench measurements; refusals 873, 883 (the guard) and
814 (at admission); the plants of CX-G-05 and CX-G-06. Out: clock fitting (BD-389); the synthetic rehearsal generator (BD-388); freezing
predictions and scoring (BD-392); scans and as-built data (BD-395); bands, drift and kits.

## Technical approach

1. **Manifest.** A real dataset is a `.frun` episode bundle whose manifest declares `origin = "real"`; the
   manifest schema is `frob.ground.dataset/1` (DESIGN):
   ```toml
   [dataset]
   id       = "blake3:…"        # over the canonical manifest and every chunk hash
   origin   = "real"            # "real" | "synthetic"; a synthetic set can never be relabelled
   kind     = "robot-log"       # "robot-log" | "bench" | "scan"
   license  = "CC-BY-4.0"       # or "private"; private data never enters a replication kit
   acquired = { by = "operator-id", on = "2027-03-14", rights = "owner" }
   [rig]
   units = ["unit-07"]          # serial-level identity; one unit is one cluster
   controller = "blake3:…"; firmware = "2.4.1"; surface = "sealed-concrete/dry"
   envelope = { temperature_C = [18, 24], payload_kg = [0, 2], speed_m_s = [0, 1.2] }
   [[instrument]]
   name = "encoder-knee-L"; quantity = "angle"; unit = "rad"; sigma = 1.5e-4; bias_bound = 3.0e-4
   instant = "sample"; clock = "mcu"; calibration = "cal-2027-02"
   [[clock]]
   name = "mcu"; nominal_hz = 1000; marks = ["pulse-0", "pulse-1"]   # raw source timestamps are retained
   [split]
   by = "day"                   # "hardware" | "condition" | "day"; never a random split of rows
   calibration = ["2027-03-14"]; validation = ["2027-03-15"]; holdout = ["2027-03-21"]
   sealed = ["validation", "holdout"]      # readable only through ground.score
   attempts = "all"             # every attempted trial is a row, including aborted ones
   ```
2. **Admission rules**, each with its reason:
   - Licence, provenance (`acquired`), rights and measurement uncertainty (`sigma` and `bias_bound` on every
     instrument) are required. A dataset without them is refused with `FROB-REF-873`, listing the missing
     fields: a Reality result must be able to name what it rests on.
   - **The cell is declared.** The manifest must determine every component of the cell key (step 3). A
     dataset with no declared cell (no units, no controller identity, no firmware, no surface, no envelope,
     or no design and task family supplied with the ingest call) is refused, with the missing components
     named (reported under 873: the registry has no narrower code). A component that does not exist for the
     thing measured is written explicitly as `"none"`, never omitted (DESIGN): a scale reading, a pendulum
     period or a scan of one part (`kind = "bench"` or `"scan"`) has no controller, firmware, surface or
     task, so its manifest says `controller = "none"`, `firmware = "none"`, `surface = "none"`, an empty
     `envelope = {}`, and the call says `--task-family tf:none`. `none` is a value of the key like any other:
     the result is scoped to "this unit, no controller", a different cell from any driven log, so such data
     cannot be pooled with one; `units` is never `none` (a measurement of no physical unit is not admitted).
   - Splits follow hardware, condition or day. `by` outside those three, a split whose parts overlap, or an
     episode assigned to no part or to two, is refused (`FROB-REF-873`, pointer `split`, naming the parts or
     the episode: the registry files the split rule under 873).
   - The full denominator is recorded. `attempts = "all"` is checked against the operator's trial counter
     shipped with the bundle; a log that contains only the trials that completed calibrates a band on
     survivors and is refused (`FROB-REF-873`, pointer `split.attempts`, `observed` the row count, `required`
     the counter).
   - Synthetic stays synthetic. `origin` is inside the hashed manifest; nominal parts and simulated logs
     carry `origin = "synthetic"` for life, and a relabelled set fails its hash (invariant INV-GROUND-06):
     the recomputed id differs from the declared one, `FROB-REF-873`. A relabelled set whose id was also
     recomputed is caught by its chunks: admission writes every chunk hash it admits under origin `synthetic`
     to the record table `synthetic_chunk` of BD-139 (and the dataset and cell rows to `dataset` and `cell`),
     and one of those hashes inside a dataset declared `real` is refused with `FROB-REF-814`.
   - Privacy is inherited. A dataset recorded in a private place carries the private mark and every artifact
     derived from it does.
3. **The cell**, the scope key of every Reality result:
   `CellKey = (design: DesignId, units: set of unit ids, controller: ControllerId, firmware: text, surface:
   class, task_family: TaskFamilyId, envelope: box over the recorded conditions)`. A change to any component
   is a scope change. Two cells are never pooled, nor two model identities, nor synthetic with real data
   (`FROB-REF-814`; repair: separate the pools).
4. **Identity.** `dataset.id` is the BLAKE3 hash over the canonical manifest bytes and the ordered list of
   chunk hashes; the bundle's chunks are verified against their digests on ingest, and a chunk whose bytes
   do not match its digest, like any other difference between the recomputed and the declared id, is refused
   with `FROB-REF-873` (pointer `dataset.id`).
5. **Sealing.** For every part listed in `sealed`: the chunk hashes are committed in a ledger event at
   admission (`ground.sealed`, with the dataset id, the part and the hashes); the chunks are moved to a
   sealed area of the store whose only read path takes a score token. A score token is minted by
   `ground.score` alone, for one prediction record whose `frozen_at` ledger sequence precedes the read
   (invariant INV-GROUND-03: a prediction's ledger sequence precedes the first read of the sealed chunk it
   predicts). Every other read (through `artifact.read`, `run.export`, telemetry queries, the viewer, or a
   direct store call) is refused with `FROB-REF-883` (a read of sealed data with no frozen prediction, or a
   prediction changed after freezing; repair: register a new version), exit 3, and logged.
6. **`ground.ingest`** (kind mutate; idempotency key; capability `ground:import`, the scope the verb
   registry gives admission):
   `frob ground ingest <bundle> --design d:… --task-family tf:… --key <k> --json` (a call without `--key` is
   `FROB-REF-805`, as on every `mutate` verb). Result: `dataset`, `cell`, `origin`,
   `kind`, `split` (counts per part and which are sealed), `sealed_commitment` (ledger sequence), `private`,
   `already_admitted`, and `reality` (unchanged by ingestion: admission alone creates no Reality status).
   Re-admission (DESIGN: the identity is content-derived, so admission is idempotent by content as well as
   by key): a bundle whose dataset id is already admitted, offered under a new idempotency key, returns the
   existing receipt with `already_admitted: true` and writes no ledger event; nothing is re-sealed or
   unsealed. Refusals raised here: 873; 814; 883, when the bundle declares unsealed (as `calibration`, or in
   a part missing from `sealed`) a chunk hash that an earlier admission committed as sealed and that has not
   been scored, because admitting it would open a read path with no frozen prediction; the private-scope
   refusal `FROB-REF-731`; the schema refusal `FROB-REF-802`; and the importer's own 828 and 832 on the file
   argument. Three further codes on this verb's list are raised by later beads on this same path: 876 by
   clock fitting (BD-389), 812 by scan admission (BD-395), and 886 by the holdout-retirement bead (N30a-34,
   which owns the spent set: a spent chunk hash declared as `holdout` or `validation` again).
7. **No device input or output** (invariant INV-GROUND-07): `frob-ground` has no socket, serial or bus crate
   in its dependency graph; `xtask check-deps` asserts it.
8. **The plants of CX-G-05 and CX-G-06.** N30-CX's catalogue names this bead as the planting bead of two late
   entries stated in words, CX-G-05 ("a log of completed trials is a log of trials", GATE-GROUND-01) and
   CX-G-06 ("split rows at random", GATE-GROUND-05). Each plant is `BD-387:cx-<nnn>`, where `<nnn>` is the
   number N30-CX's block issued to the entry (the tags are not used past M1), and is a Cargo feature
   `cx-<nnn>` of `frob-ground`, built only as `--features gauntlet-mutations,frob-ground/cx-<nnn>` and never in a
   default or release build (BD-025). Each changes the real admission path, with no mock:
   - CX-G-05's feature removes the check of `attempts = "all"` against the trial counter; the 17-of-20 bundle
     (trial counter 20, 17 rows) is then admitted, so `attempt_count_mismatch_refused` fails.
   - CX-G-06's feature makes the manifest validator accept `by = "rows"`; the random-row bundle is then
     admitted, so `split_by_rows_refused` fails.
   When both plants are built, this bead records each case in its entry of
   `crates/frob-conformance/registry/counterexamples.toml`: `case_supplied_by = "BD-387:
   crates/frob-ground/tests/fixtures/cx-<nnn>/"` (the generator's bundle that the plant admits),
   `numeric = true` and `plant = "BD-387:cx-<nnn>"`, with `plan_case` left `"words"`. It then re-runs N38b-05's
   seeding tool (`cargo test -p frob-conformance --test seed_controls -- --ignored seed`), so that each
   control turns from `obligation` to `runnable` under its existing `NC-` number.

Determinism: admission is a pure function of the bundle and the call (D0). Evidence class of everything Ground
later produces is `Estimated`; admission itself produces identities and commitments, not claims.

## Acceptance criteria

- [ ] A dataset with no declared cell is refused (seed done-condition), with each missing component named.
- [ ] A read of a sealed split before its prediction is frozen is refused (seed done-condition) with 883 on
      every read path, and the attempt appears in the ledger.
- [ ] A dataset missing licence, provenance, rights or an instrument's uncertainty is refused with 873.
- [ ] A random-row split, an overlapping split, an unassigned episode and a row count below the trial counter
      are each refused with 873 and the pointer stated above.
- [ ] A synthetic dataset relabelled as real fails its hash (873); the same set with a recomputed id is refused
      by its chunk hashes (814); pooling two cells is refused with 814.
- [ ] A bundle that declares as `calibration` a chunk hash sealed and unscored in an earlier dataset is refused
      with 883 and nothing is unsealed; an identical bundle under a new key returns `already_admitted: true`
      with no new ledger event.
- [ ] Ingesting the same bundle twice with one idempotency key returns the original receipt and changes
      nothing; the sealed commitment's ledger sequence precedes every later read event for those chunks.
- [ ] `cargo tree -p frob-ground` shows no network, serial or bus crate.
- [ ] Reachable through `frob ground ingest --json`; cancellation mid-ingest leaves no partially sealed part.
- [ ] Under `frob-ground/cx-<nnn>` of CX-G-05 the 17-of-20 bundle is admitted and `attempt_count_mismatch_refused`
      fails; under CX-G-06's the `by = "rows"` bundle is admitted and `split_by_rows_refused` fails. Both
      catalogue entries carry `case_supplied_by` naming this bead's fixture, `numeric = true` and
      `plant = "BD-387:cx-<nnn>"`. After the re-seeding both controls are `runnable`, and
      `cargo test -p frob-conformance --test seed_join` passes.

## Test plan

### Unit tests

`crates/frob-ground/tests/admission.rs`, on `synthetic` bundles written by a small generator in the test
tree (two days of calibration, one validation day, one holdout day; three instruments; two clocks):
`complete_manifest_admitted`; `missing_license_refused_873`; `missing_sigma_refused_873`;
`missing_units_means_no_cell_refused`; `missing_design_or_task_family_refused`;
`bench_mass_with_explicit_none_components_admitted` (a scale reading with controller, firmware and surface
`none` and `tf:none` is admitted, and its cell differs from the driven log's of the same unit);
`omitted_controller_still_refused_for_bench`;
`split_by_rows_refused`; `overlapping_split_refused`; `episode_in_no_part_refused`;
`attempt_count_mismatch_refused` (trial counter 20, rows 17: 873 with `observed` 17 and `required` 20);
`relabelled_synthetic_fails_hash` (873); `relabelled_synthetic_with_recomputed_id_refused_814`;
`sealed_chunk_redeclared_as_calibration_refused_883`; `same_bundle_new_key_is_already_admitted`;
`dataset_id_changes_with_one_chunk_byte`; `sealed_read_without_prediction_refused_883` (one test per read
path: artifact read, run export, telemetry query, direct store call); `sealed_read_with_token_succeeds_once`
(using a prediction record written with an earlier ledger sequence); `prediction_frozen_after_read_attempt_is_rejected`;
`pooling_two_cells_refused_814`; `private_mark_inherited`; `ingest_is_idempotent`.

### End-to-end script and logging

`scripts/e2e/ground_ingest.sh` (bead N25a-29) drives `frob ground ingest` on the synthetic bundles and the
mutated ones, then attempts every read path on a sealed part. Logged: the dataset id and cell key, split
counts, the commitment's ledger sequence, each refusal's code and missing fields, and the ledger sequences
that prove the freeze-before-read order. No dataset content is written to the log.

### Known answers and negative controls

The protocol row of the synthetic rehearsal: read before freeze, refit without a new version, and holdout
reuse are each refused (the first is tested here; the other two belong to the scoring bead). Negative
controls: a store build with the sealed-area guard disabled must fail
`sealed_read_without_prediction_refused_883`; the plants of step 8, CX-G-05 (the trial-counter check removed,
caught by `attempt_count_mismatch_refused`) and CX-G-06 (a validator that accepts `by = "rows"`, caught by
`split_by_rows_refused`), whose controls N38b-05's seeding writes from the catalogue. Chaos (tier G4): a kill during sealing followed by recovery leaves either no
commitment or a complete one.

## Considerations

- OPEN-GROUND-1 (no public paired dataset with enough robots per class was identified) and OPEN-GROUND-2
  (whether any bench hardware is acquired; default: none, Reality stays `no-claim`) mean that this lane may
  never see real data before release; that is a legitimate state, and the lane is then exercised by the
  synthetic rehearsal only.
- The verb table of the plan gives `ground.ingest` a first milestone of M1 "for admission and the `reality:`
  line", while this bead is scheduled at M5; at M1 only the report line exists, with no dataset to admit.
- The verb table also lists refusal numbers for the cluster that differ from the chapter's refusal table and
  from the registry; this bead uses the registry's codes (873, 883, 814). The split, denominator and identity
  refusals have no narrower code than 873, and the registry row of 873 lists them.
- Licence joins and the private mark decide what may later enter a replication kit; there is no override.
