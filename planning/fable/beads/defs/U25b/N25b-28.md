## Background

When two hidden situations need different actions and the robot cannot tell them apart, there are three kinds of
engineering answer: extract the information (a better sensor), move to acquire it (a probing action or a
different mount), or change the mechanics so that the information is unnecessary. This bead is the exact fixture
for the third kind: a body that removes the need for a sensor.

Two sealed payload classes require disjoint final forces, [2, 4] N and [7, 9] N. For a controller that commands
terminal force, the two bands are disjoint and no single command serves both; that is the perceptual ambiguity.
Consider a different, explicitly modelled plant: a displacement-driven jaw with a series spring of stiffness K
closes by x mm on one of two linearly elastic objects, both in contact at x = 0, with stiffnesses k₁ = 1 and
k₂ = 4 N/mm. At quasi-static equilibrium F_j = x / (1/K + 1/k_j). Put c = 1/K in mm/N. With at most 6 mm of
stroke, a single command works on both hidden classes exactly when

  max{ 2(c + 1), 7(c + 1/4) }  ≤  x  ≤  min{ 4(c + 1), 9(c + 1/4), 6 }.

In (c, x) coordinates this is an exact polyhedral family, and it is an inner cell with a shared policy: one
command for both hidden classes, with nothing observed. At K = 4 N/mm any x ∈ [7/2, 9/2] mm works, and x = 4 mm
gives 3.2 N and 8 N. With stroke capped at 6 mm the stiffness must be at least 28/17 N/mm; at that boundary
x = 6 mm, the stiffer object receives 7 N and the softer 56/15 N, and the binding condition is the stroke
available for the 7 N requirement. Relaxing the stroke reveals the force-compatibility bound K ≥ 4/3 N/mm.

This change of body alters the map from command to force. It leaves the information bound for a force-commanded
plant intact. A conventional impedance engineer given the same equations designs the same jaw; the value claimed
is that the three answers are returned by one query in one comparable form. Tier: the fixture is exact and Solid;
the mechanism it exercises (a shared-policy cell over a hidden world parameter) is part of a Frontier subsystem.

Rejected alternative: stating the result in stiffness K. The constraints are affine in the compliance c = 1/K,
not in K; convexity and monotonicity are properties of a chart, so the free parameter is declared in the chart
`compliance` and the answer is translated to K only for display.

## Scope

## Technical approach

1. Mission (DESIGN, fixture `fixtures/missions/passive-jaw.fmission`). Design domain: one free parameter c, the
   series compliance in mm/N, chart `compliance`, box [0, 1]; bound parameter: stroke limit 6 mm. World: hidden
   class j ∈ {1, 2} with object stiffness k₁ = 1 and k₂ = 4 N/mm, persistence `fixed-per-execution`; both objects
   in contact at x = 0 (DESIGN: a hidden contact offset `world.contact_offset`, x₀ ∈ [0, 0] mm, declared so
   that the misaligned falsifier of step 6 is a one-field amendment). Observation: none before the command. Policy class: causal, indexed by nominal design,
   law class `constant` (one closing displacement x), no randomization. Horizon: static (quasi-static
   equilibrium). Predicates: F_j ∈ [2, 4] N for j = 1 and F_j ∈ [7, 9] N for j = 2, with
   F_j = x / (c + 1/k_j); 0 ≤ x ≤ 6. Prefix: exists policy per nominal design, for all worlds, for all
   executions. Evidence profile `exact`.
2. Lowering. Multiplying each band inequality by the positive denominator c + 1/k_j gives constraints affine in
   (c, x): x ≥ 2(c + 1), x ≤ 4(c + 1), x ≥ 7(c + 1/4), x ≤ 9(c + 1/4), x ≤ 6, x ≥ 0, c ≥ 0. The second lowering
   required of every template evaluates the forces directly in rationals on a grid and must agree exactly.
3. Exact answer in the chart c. Breakpoints: the two lower bounds cross at c = 1/20; the upper bounds 9(c + 1/4)
   and 4(c + 1) cross at c = 7/20; 4(c + 1) meets the stroke at c = 1/2; the lower bound 7(c + 1/4) meets the
   stroke at c = 17/28. The last one bounds the family; the first decides which lower bound is active; the two
   in between change only the form of the admissible range of x.
   - Inner cells, each with a witness affine in c (so checking its two ends checks the cell):
     [0, 1/20] with x = 2(c + 1), and [1/20, 17/28] with x = 7(c + 1/4) (the smallest admissible closing
     displacement). All ends are closed; the cells' union is c ∈ [0, 17/28], that is K ≥ 28/17 N/mm (c = 0 is
     the rigid jaw, which works with x ∈ [2, 9/4] mm).
   - Excluded cell: c ∈ (17/28, 1], by the dual that adds x ≥ 7(c + 1/4) and x ≤ 6: 7c + 7/4 > 6 for every
     c > 17/28. Binding constraint: the stroke for the 7 N requirement.
   - A `partition` object for [0, 1].
   - Without the stroke bound the inner set is c ∈ [0, 3/4] (K ≥ 4/3 N/mm), from 7(c + 1/4) ≤ 4(c + 1).
4. Policy scope. The cells are marked as sharing one policy across the hidden classes. A proposal that indexes
   the command by the hidden class (x₁ for class 1, x₂ for class 2) is refused (FROB-REF-887: a policy is
   indexed by a parameter the controller cannot observe; repair: move the parameter into the world, or add the
   calibration observation), and a certificate built from one command per class is evidence for the easier
   quantifier order and is rejected (FROB-REF-881).
5. Proof objects: `lp-primal` for each inner cell (the affine witness at both ends, the two world vertices
   j = 1, 2, law class `constant` with no observed argument); `lp-farkas` for the excluded cell; `partition`.
6. Falsifiers, each a registered amendment or referee check with its expected outcome:
   - Break the assumed correlation between required grip and object stiffness: allow the same stiffness in both
     hidden classes (k₁ = k₂; fixture `fixtures/missions/passive-jaw-equal-k.fmission`, the second object's
     stiffness set equal to the first's). The passive jaw then supplies the same force to both and cannot meet
     disjoint bands; the amended mission, queried afresh (a new `MissionId`), must return the whole domain
     excluded. Under revalidation every inner cell of the original answer is withdrawn (the world family grew);
     that verb (N25a-16) and the campaign's gate script (N25a-26) come after this bead and BD-290 in the graph,
     so this bead registers the amendment with that expected outcome as a fixture for them and does not run
     revalidation.
   - Misaligned initial contact: object j first touches at x = x₀ with x₀ ∈ [0, e], unknown to the controller.
     The forces become (x − x₀)/(c + 1/k_j); the lower bands bind at x₀ = e and the upper ones at x₀ = 0, so the
     family is max{2(c + 1), 7(c + 1/4)} + e ≤ x ≤ min{4(c + 1), 9(c + 1/4), 6}: it stays polyhedral and shrinks
     with e. Exact values: at e = 1/2 mm the inner set is c ∈ [1/28, 15/28]; the largest gap between the two
     sides is 6/5 mm, at c = 7/20, so at e = 6/5 mm the family is the single point c = 7/20, x = 27/5 mm, and
     for e > 6/5 mm it is empty. The amended answer is exact and is compared with direct evaluation.
   - Hysteresis, settling time and impact overshoot: referee runs of the jaw on a compliant contact law at
     three closing speeds; the terminal force must lie in the band after the settling time, and the peak force
     during closing is recorded against the upper band. These are `Tested` checks that can only remove a cell
     from the inner set or attach a condition (a maximum closing speed) to it.
7. `mission.refute` on a jaw outside the family (for example K = 1.5 N/mm, c = 2/3) reports the binding
   constraint from the dual (the stroke for the 7 N requirement) and the smallest admitted changes that relax
   it: stiffness to at least 28/17 N/mm, or stroke to at least 7(c + 1/4) = 77/12 mm.

Determinism class D0. Evidence: `Certified` for the static cells under the declared quasi-static model; the
dynamic checks are `Tested`.

## Acceptance criteria

- [ ] Through the public verb the answer is: inner c ∈ [0, 17/28] in two cells with the stated witnesses,
      excluded c ∈ (17/28, 1] with the stated dual, a partition of [0, 1]; every bundle accepted by the auditor.
- [ ] Known values exact: at K = 4 N/mm (c = 1/4) the admissible commands are x ∈ [7/2, 9/2] mm and x = 4 mm
      gives 3.2 N and 8 N; at K = 28/17 N/mm, x = 6 mm gives 7 N and 56/15 N; with the stroke bound removed the
      boundary is K = 4/3 N/mm.
- [ ] The cells are marked shared-policy; a per-class command pair is refused (FROB-REF-887 as a policy,
      FROB-REF-881 as a certificate).
- [ ] The equal-stiffness amendment, queried afresh, excludes the whole domain; its expected revalidation outcome
      (every inner cell of the original answer withdrawn) is registered with the fixture.
- [ ] The misaligned-contact amendment returns the exact shrunken family and matches direct evaluation on a
      rational grid.
- [ ] The referee checks report settling and peak force at three closing speeds, and a cell whose terminal
      force leaves its band at some speed carries that speed as a condition or is removed.
- [ ] The two lowerings agree exactly on a 101 × 121 rational grid of (c, x); the invalid lowering (the
      denominators c + k_j in place of c + 1/k_j) is caught.
- [ ] Negative control: dropping the stroke cap changes the boundary from 28/17 to 4/3 N/mm, and a certificate
      that claims the uncapped family for the capped mission is rejected (an omitted active bound, FROB-REF-851).

## Test plan

### Unit tests

`crates/frob-mission/tests/passive_jaw.rs`; exact rationals.
- `forces_at_k4_x4`: F₁ = 4/(1/4 + 1) = 16/5 N; F₂ = 4/(1/4 + 1/4) = 8 N.
- `boundary_k_28_17`: c = 17/28, x = 6: F₂ = 6/(17/28 + 7/28) = 7 N; F₁ = 6/(17/28 + 1) = 56/15 N.
- `breakpoints`: 1/20, 7/20, 1/2, 17/28 in the chart c.
- `cells_and_witnesses`: each of the two witnesses satisfies all seven inequalities at both ends of its cell
  (at c = 1/20 both give x = 21/10; at c = 17/28 the second gives x = 6).
- `excluded_cell_dual`: 7c + 7/4 − 6 is positive on (17/28, 1] and zero at 17/28 (so the end is open).
- `uncapped_boundary_4_3`.
- `rigid_jaw_works`: c = 0 admits x ∈ [2, 9/4].
- `equal_stiffness_excludes_all`: with k₁ = k₂ = 1, the fixture's amendment, the bands require x/(c + 1) in
  [2, 4] and in [7, 9] at once, which is impossible for every c ∈ [0, 1]; the same holds for any common
  stiffness (checked also at k₁ = k₂ = 2: x/(c + 1/2)).
- `misaligned_contact_family`: e = 1/2 gives c ∈ [1/28, 15/28]; e = 6/5 gives the single point c = 7/20,
  x = 27/5; e = 5/4 gives the empty set; each compared with direct evaluation on a rational grid.
- `per_class_policy_refused`.
- `refute_reports_stroke_binding`: at c = 2/3 the required stroke is 77/12 mm against 6 mm.
- `referee_closing_speeds` (the real referee on the compliant contact law, three closing speeds, at the witness
  x = 4 mm for K = 4 N/mm): the terminal force after the settling time lies in its band for each class, the peak
  force during closing is reported against the upper band, and a speed whose terminal force leaves the band is
  attached to the cell as a maximum closing speed or removes it; the result is `Tested` and never widens a
  cell.

## Considerations

- The certificate is about the declared quasi-static, linear-elastic model with both objects in contact at
  x = 0. Each of those words is an assumption in the bundle; the falsifiers above are the tests of each.
- The passive jaw depends on a correlation in the world (stiffer objects need more force). Where that
  correlation is absent the mechanics cannot substitute for information, and the equal-stiffness amendment is
  the registered demonstration.
- The agent chooses between a better sensor, a passive constitutive law and a low-cost probe by their robustness
  over independently measured variations; this is a co-design question with a clear experimental answer even if
  simulation speed is unchanged, and no speed is claimed.
- Kill gate of the surrounding mechanism: KILL-AUGUR-ALIAS; the jaw fixture survives it, being an exact static
  family.
