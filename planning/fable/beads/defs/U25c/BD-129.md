## Background

A first control input can be a probe: it changes what later observations reveal. Whether that helps depends on
when the observation arrives. The docking family is the first mission slice of the program (M1, CPU only) because
it is exact, dynamic, causal, and small enough to check by hand. It demonstrates the North-Star scenario "the
docking fixture": before, a simulator scores a given controller on sampled worlds and cannot say whether any
controller exists; after, the mission query returns checked facts about every causal controller at once.

It serves the bet that answers over families beat scores of points, and it tests the semantic kernel of
`frob-mission` on the three things static fixtures cannot: information with a clock, strict comparators, and an
infimum that is not attained. The same hardware and the same two plants admit opposite answers to the robust
mission solely because of the delivery time of one packet.

Honest scope (FACT, plan-time pilot re-run by BD-041): an ordinary observation-tree robust planner given the
same model, actions and latencies gets the same answer. There is no claim of a new algorithm, and no product or
device timing follows from a scalar model. What is built is the typed question and the checked answer.

## Technical approach

**Model.** Position in metres, time in seconds. A robot docks in three one-second ticks from x₀ = v₀ = 0, with
acceleration g·u_k held constant over tick k, hidden fixed gain g ∈ {1, 2}, commands bounded by abs(u_k) ≤ U,
and target (x₃, v₃) = (1, 0). Exact zero-order-hold integration gives

  v₃ = g·(u₀ + u₁ + u₂),   x₃ = g·(5·u₀/2 + 3·u₁/2 + u₂/2).

The only informative packet is the first velocity reading v₁ = g·u₀, with additive error e in the closed interval
[−ε, +ε]. It arrives either before the second command is decided (on time), or after the third command is
committed (late). A packet whose arrival coincides with a decision instant is delivered before the controller is
evaluated, so it is on time.

**Mission document.** Design parameters: U ∈ [1/2, 1] and ε ∈ [0, (U + 1/2)/2] (the hardware an engineer
chooses: actuator authority and sensor error), declared as the box U ∈ [1/2, 1], λ ∈ [0, 2] in the named chart
λ = 4·ε/(U + 1/2) of step 4; the box contains every point of the grid below, since ε ≤ 1/2 ≤ (U + 1/2)/2 there. World: `bounded-set`, hidden g ∈ {1, 2} with persistence `fixed-per-execution`, and
the read error e. Observation: the velocity packet with noise bound ε and its arrival instant. Policy class:
`causal`, indexed by the nominal design, no randomization, one decision maker. Horizon: three ticks. Predicates:
x₃ = 1 and v₃ = 0 (equality atoms), abs(u_k) ≤ U. Prefix: exists policy, for all worlds, for all executions.
Evidence profile `exact`.

**On-time packet: a witness.** Write p = u₀. The terminal equations force u₁ = 1/g − 2·p and u₂ = p − 1/g.
With p = 1/4 the packet identifies g = 4·v₁; the sequences are (1/4, 1/2, −3/4) for g = 1 and (1/4, 0, −1/4)
for g = 2, both within U = 3/4, and both reach (1, 0) exactly.

**The exact sensor–actuator family.** Intersecting the actuator bounds for both worlds gives
1 − U ≤ p ≤ (U + 1/2)/2 (nonempty exactly for U ≥ 1/2). At a reading possible in both worlds the required second
commands differ by 1/2, so the two reading sets, [p − ε, p + ε] and [2·p − ε, 2·p + ε], must be disjoint:
p > 2·ε. Maximizing the separation gives the exact family

  ε < (U + 1/2)/4,   with equality excluded.

For U = 3/4 the probe p = 1/4 tolerates ε below 1/8; the probe p = 5/8 tolerates ε below 5/16, a tolerable sensor
error 2.5 times larger on the same actuator. At equality both worlds can report 15/16 while requiring second
commands −1/4 and −3/4.

**Late packet: an exclusion.** A causal controller must issue the same command vector in both worlds. The
terminal position for a common vector scales with g, so it cannot equal 1 for both gains. Private randomization
cannot give guaranteed success in both either. This is an `alias-pair` certificate whose scope is "all admitted
policies".

**Lowering (the finite observation game).**

1. Enumerate the hidden worlds (finite) and the packet schedule (finite). Build the tree of decision instants;
   at each instant the information set is the set of worlds consistent with the packets that have arrived.
2. Inclusion at a design point (U, ε): choose p* = (U + 1/2)/2; the policy table maps the reading y to
   (u₁, u₂) = (1 − 2·p*, p* − 1) if y ≤ p* + ε, and to (1/2 − 2·p*, p* − 1/2) otherwise. Emit a `finite-game`
   proof object: the table keyed by observation history. The checker evaluates every world at every error vertex
   (e = ±ε), checks the terminal equalities and the command bounds exactly, and checks that equal histories
   receive equal commands.
3. Exclusion at a design point with ε ≥ (U + 1/2)/4: a `partition` of the probe axis into three pieces. For
   p < 1 − U the world g = 1 needs u₂ = p − 1 < −U (`lp-farkas`). For p > (U + 1/2)/2 the world g = 2 needs
   u₁ = 1/2 − 2·p < −U (`lp-farkas`). For p between them p ≤ 2·ε, so the worlds (g = 1, e₁) and (g = 2, e₂) with
   e₁ − e₂ = p share a reading and need second commands that differ by 1/2 (`alias-pair`, scope "all admitted
   probes").
4. Family answer on the continuous domain. Cells are boxes in a named chart (the `partition` kind checks box
   arithmetic). In the chart (U, λ) with λ = 4·ε/(U + 1/2) both the domain and the boundary are axis-aligned.
   Inner cell: U ∈ [1/2, 1], λ ∈ [0, 1) (open end at λ = 1). Excluded cell: U ∈ [1/2, 1], λ ∈ [1, 2] (closed
   end). DESIGN, reason: the affine chart s = 4·ε − U also straightens the boundary, but there the edge ε = 0
   becomes the slanted line s = −U and the cells are not boxes. Every quantity the certificates of steps 2 and 3
   constrain is affine in each chart variable separately (ε = λ·(U + 1/2)/4, p* = (U + 1/2)/2, p* + ε =
   (U + 1/2)·(2 + λ)/4, and the separation p* − 2·ε = (U + 1/2)·(1 − λ)/2), so the checker verifies the
   non-strict constraints at the four vertices of each cell (a function affine in each variable takes its extremes
   at vertices) and verifies the open or closed status of λ = 1: the separation is zero exactly on that face,
   which the `partition` entry assigns to the excluded cell.
5. Late packet: one `alias-pair` proof with empty observation sets up to commitment and disjoint success sets
   ({u : 5·u₀/2 + 3·u₁/2 + u₂/2 = 1} against the same expression equal to 1/2).

**Grid that checks the implementation.** 17 actuator bounds U = 1/2 + i/32 (i = 0…16) and 33 error levels
ε = j/64 (j = 0…32) give 561 cells; a cell is admitted exactly when 2·j < 32 + i. Result: 344 admissible, 217
excluded, nine of them exact boundary cases (2·j = 32 + i, the even i). All 561 late-packet cells are excluded.

**Minimum and repair claims.** Strict feasible sets can have an unattained infimum. `mission.refute` at
U = 3/4, ε = 5/16 reports the binding constraint (separation of the two reading sets, which meet at 15/16) and
the open repair threshold U > 3/4 with `attained: false`; on a continuous catalogue there is no smallest
increase, so the answer also returns any feasible priced candidate and its gap to the infimum. Comparators are
evaluated as declared: strict, non-strict and equality atoms are distinct.

**Evidence.** Class `Certified`, tier `static`, determinism `exact` (D0): every number is a reduced rational.
The answer carries the three no-authorization flags, all `false`.

## Test plan

### Unit tests

- `zoh_integration`: for random rational g, u: v₃ = g·(u₀ + u₁ + u₂) and x₃ = g·(5·u₀/2 + 3·u₁/2 + u₂/2).
- `witness_sequences`: (1/4, 1/2, −3/4) with g = 1 and (1/4, 0, −1/4) with g = 2 end at (1, 0).
- `probe_range`: for U = 3/4 the admissible p is [1/4, 5/8]; for U = 1/2 it is {1/2}.
- `tolerance_by_probe`: U = 3/4: p = 1/4 tolerates ε < 1/8; p = 5/8 tolerates ε < 5/16.
- `equality_reading`: U = 3/4, ε = 5/16, p = 5/8: both reading sets contain 15/16; required u₁ are −1/4, −3/4.
- `grid_counts`: 344, 217, 9; the nine boundary cells are (i, j) = (0, 16), (2, 17), …, (16, 24).
- `late_packet_all_excluded`: 561 of 561.
- `grid_labels_equal_committed_vector`: the 561 labels of the family answer, in N20b-13's row-major order (i
  outer, j inner), equal that bead's committed label vector byte for byte (equal BLAKE3 digests); on a mismatch
  the first differing cell (i, j) and both labels are reported.
- `point_inclusion_table`: at (U, ε) = (3/4, 1/8) the table of step 2 (p* = 5/8, threshold y ≤ 3/4) replayed at
  e = ±1/8 in both worlds reaches (1, 0) with every command within 3/4; at (3/4, 5/16) the same table misroutes
  the g = 2 reading 15/16 and the `finite-game` object is not emitted.
- `point_exclusion_three_pieces`: at (U, ε) = (3/4, 5/16) the probe axis splits at p = 1/4 and p = 5/8 into the
  two `lp-farkas` pieces and the `alias-pair` piece (e₁ = p/2, e₂ = −p/2); the three pieces cover the axis
  exactly.
- `family_cells_partition`: in the chart (U, λ) the inner cell [1/2, 1] × [0, 1) and the excluded cell
  [1/2, 1] × [1, 2] partition the declared box; the separation (U + 1/2)·(1 − λ)/2 is positive at the inner
  cell's vertices with λ = 0 and zero at those with λ = 1; declaring λ = 1 closed in the inner cell is rejected.
- `game_policy_consistency` (property test for INV-AUGUR-07): no table entry reads a packet before its arrival.
- `mission_id_sensitivity` (INV-AUGUR-03): changing the comparator, the gain support, the persistence or the
  arrival instant changes `MissionId`.

  iff ε < (U + 1/2)/4 on U ∈ [1/2, 1]; 344, 217, 9; at U = 3/4, ε = 5/16 both worlds can read 15/16.
- Negative control (strictness): a non-strict comparator admits the equality case; exactly nine cells change.
- Negative control (CX-275): sample points in a cell fail, so the cell is excluded: rejected; a cell that
  straddles the boundary needs a certificate valid over the cell or stays unresolved.
- Negative control (clairvoyance): a per-world command table offered for the late packet is rejected as evidence
  for a different prefix (`FROB-REF-881`).
- Metamorphic: rescaling position by a factor k (target k, gains unchanged, U and ε scaled by k) preserves
  every verdict; swapping the labels of the two worlds preserves every verdict.
- Determinism: identical answer bytes twice on one machine, across worker counts, debug and release, two hosts.

## Considerations

- First reading of KILL-AUGUR-TIE is taken on this slice at M1: if a conventional scenario-tree program gives
  the better answer per engineering hour, that program ships behind the same verbs (N25c-20).
- Stop decision at M1: if a fresh agent cannot complete the docking amendments after one repair cycle, the
  mapping from sensors and actuators to the query is the defect and the chapter is re-planned before physics.
- The fixture is also owned, as a sensing known answer, by the sensing chapter; the constants here and there
  must be the same fixture identity. N20b-13 commits the 561 labels and their digest as the single source, and
  this bead's grid is compared with that vector, which is why N20b-13 is a prerequisite.
- With bounded probes and ε > 0, a nondegenerate interval of hidden positive gains contains an indistinguishable
  pair that requires different second commands, so an exact docking guarantee fails on any gain interval.
