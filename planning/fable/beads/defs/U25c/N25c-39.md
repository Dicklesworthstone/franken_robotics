## Background

The label query asks how much a factory must tell a shared controller: the least number of calibration labels
that lets one controller serve every manufactured variant. On supplied command sets the query is solved, and
ordinary solvers tie the product. The open problem is extraction: the expensive step is obtaining the command
set K_s of each variant from a physical gripper across friction, pose, deadline and compliant contact. That part
is Moonshot.

Before any extraction machinery is built, the plan requires a paper-scale pilot with a falsifier.

- **Pilot.** One manufacturing fixture: derive inner and outer command sets for three gripper variants from the
  referee, compare the label interval with direct per-part testing at equal cost. The SMT or mixed-integer
  baseline receives the same command envelopes, their full derivation costs, and equal access to existing
  labels.
- **Falsifier.** Derivation costs more than direct labelling, or an inner set contains a command the referee
  shows failing.
- **Ceiling.** The label count saved, times the per-label cost, minus derivation cost; unknown until the pilot.

The first purchase decision this informs is whether deriving command sets from a qualified gripper is cheaper
than testing or labelling every part directly.

## Scope

In: one frozen manufacturing fixture; derivation of inner and outer sets by referee campaigns; the label
interval; the direct per-part arm at equal cost; the baseline arm; the cost ledger; the falsifier verdict. Out:
the general extraction mechanism (N25c-41); the kill decision (N25c-40); the supplied-set query (BD-363).

## Technical approach

**Fixture (frozen before execution; values recorded in the protocol).** One gripper design in three
manufactured variants that differ in a pad parameter (for example pad offset or pad stiffness within tolerance
classes). One grasp-and-place task with a commitment deadline. Command: a low-dimensional vector (closure
displacement and approach offset). Admitted payloads and tolerances: friction interval, object pose interval,
object stiffness interval. Success: the object is placed within tolerance without slip beyond the monitor's
bound.

**Derivation of sets.**

1. *Outer set of variant s.* A command is removed from the outer set only by a failing execution on the referee
   for some admitted payload and tolerance (a `trace-witness` counterexample), or by a static necessary
   condition with a certificate (force closure impossible, stroke exceeded). What is not removed stays: the
   outer set over-approximates K_s. An impossibility needs inconsistent outer sets.
2. *Inner set of variant s.* A command cell enters the inner set only when success holds over the whole admitted
   payload and tolerance box. With no sound reachable tubes for compliant contact, that is available only where
   a quasi-static argument applies (a force-closure margin valid over the box, checked by interval or dual
   certificates). Elsewhere a densely tested cell is labelled `Tested`, kept apart from the certified inner set,
   and reported as such. A constructive common action needs inner sets.
3. Run the label query (BD-363) on inner sets (upper count), on outer sets (lower count), and return the
   interval with the narrowing measurement.

**Arms, at equal cost.**

- *Derivation arm.* The procedure above; cost = referee seconds, checker seconds, engineering time to set up the
  fixture and the sets.
- *Direct arm.* Per-part testing or labelling of every part: each part is tested at a small set of commands and
  given its own label. Cost per part is registered in the protocol.
- *Baseline arm.* An SMT or mixed-integer encoding given the same command envelopes, their full derivation
  costs, and equal access to existing labels.

**Checks.**

- *Inner-set soundness.* Every command of every certified inner set is replayed on the referee at the corners
  and at random interior points of the payload and tolerance box (registered count). One failing execution
  falsifies the pilot.
- *Cost comparison.* Derivation cost against the cost of labelling every part over the fixture's production
  volume (registered); the break-even volume is reported.
- *Value.* The label count saved by the derivation arm relative to "one label per variant", times the per-label
  cost, minus the derivation cost.

## Acceptance criteria

- [ ] The protocol (fixture, payload and tolerance box, sampling counts and seeds, cost definitions, production volume, falsifier) is hashed before execution.
- [ ] Inner and outer sets exist for the three variants, with certified and `Tested` parts kept separate.
- [ ] The label interval is reported with its narrowing measurement; the baseline arm returns the same interval from the same envelopes.
- [ ] Every certified inner command was replayed; the number of failing replays is reported (the pilot passes only at zero).
- [ ] Derivation cost, direct-labelling cost and the break-even volume are reported; the falsifier verdict is written to the review log and handed to N25c-40.

## Test plan

### Unit tests

- `outer_removal_needs_witness`: a command is removed from an outer set only with a failing replay address or a
  static certificate attached.
- `inner_needs_box_certificate`: a cell with 10⁴ passing samples and no certificate is `Tested`, not inner.
- `interval_polarity`: the upper count uses inner sets and the lower count uses outer sets; exchanging them is
  detected on a constructed case.
- `equal_cost_accounting`: the comparison refuses to run when an arm's cost ledger is incomplete.
- `supplied_set_self_check`: the three-variant fixture (x ≥ 2/3, y ≥ 2/3, x + y ≤ 1) returns two labels through
  the same pipeline before the contact fixture is used.

### End-to-end script and logging

`scripts/e2e/pilot_labels_gripper.sh`: runs the referee campaigns with `frob sim run` (seeds explicit), builds
the sets, calls `frob mission synthesize labels-gripper.fmission --json` on inner and outer sets, replays the
inner commands, and evaluates the falsifier. It logs through the shared end-to-end helper: commands, exit codes,
wall time, evidence blocks (class per set), set sizes, the label interval, failing replays against the threshold
0 with their replay addresses, the cost ledger rows as metrics, the break-even volume, and the falsifier
verdict; summary naming KILL-AUGUR-LABELS.

### Known answers and negative controls

- Known answer (self-check): the three-variant supplied-set fixture.
- Negative control 1: a planted failing command inside an inner set (a command at which the object slips for
  the lowest friction) must be found by the replay check.
- Negative control 2: an inner set built from samples at nominal friction only is contradicted at the friction
  bound and must be caught.
- Determinism: referee campaigns repeat exactly with the same seeds; the label interval is a deterministic
  function of the sets.

## Considerations

- Without sound enclosures through compliant contact the certified inner sets may be small or empty; then the
  upper label count is "one per variant" and the derivation arm saves nothing. That outcome is a legitimate
  pilot result and fires the kill gate's first clause if derivation still costs more than labelling.
- Compute: referee campaigns over a three-dimensional payload box for three variants; within the default CPU
  envelope at the registered sample counts.
- The fixture is synthetic until bench data exists; no claim about a real gripper follows.
