## Background

How much must a factory tell a shared controller? On command sets that someone supplies, the label query answers
exactly. On a real line nobody supplies them. The expensive step is obtaining K_s, the set of commands that work
for variant s for every admitted payload and tolerance, from a physical gripper across friction, pose, deadline
and compliant contact. For a real commissioning question only inner and outer command sets may be known: a
constructive common action needs inner sets, an impossibility needs inconsistent outer sets. The verb returns a
lower and an upper label count when they differ, and names the one measurement that would narrow the gap.

This bead is the Moonshot mechanism that produces those sets from the studio's own models. It exists only if
the pilot on three gripper variants passed and KILL-AUGUR-LABELS did not fire (N25c-39, N25c-40). Its ceiling is
unknown until then: the label count saved, times the per-label cost, minus derivation cost.

Why it is Moonshot and not Frontier: an inner set is a universal statement over a payload and tolerance box
under compliant contact. The suite has no sound reachable tubes for contact-rich full-order dynamics, so the
only certified route today is quasi-static, and it may certify little.

## Scope

In: the extraction procedure for outer and inner sets with their evidence classes; cell refinement of the
command space; the hand-off to the label query; the narrowing measurement; soundness checks. Out: the label
query itself (BD-363); encoder premise and histories (N25c-36, N25c-37); the pilot and the decision.

## Technical approach

**Objects.** For each variant s: a command space C (low-dimensional, bounded), a payload and tolerance box Θ
(friction, object pose, object stiffness, hidden manufacturing offsets within the variant's tolerance class), a
deadline, a success monitor. K_s = { c ∈ C : success for every θ ∈ Θ on every admitted execution }.

**Outer set (what cannot be excluded).**

1. Start with C. Partition it into cells.
2. Remove a cell only with a reason valid over the whole cell: a static necessary condition with a certificate
   (the required grip force exceeds the actuator envelope for every command of the cell; the stroke is exceeded;
   force closure is impossible), as an `lp-farkas`, `conic-farkas` or `interval-box` proof.
3. A single failing execution at one command removes only that command; it is recorded as a `trace-witness` and
   used to steer refinement. Infeasible sample points do not eliminate their enclosing cell.
4. The outer set is the union of cells not removed. Class of the removals: `Certified`.

**Inner set (what is guaranteed).**

1. A cell enters the certified inner set only with a constructive argument over the cell and over all of Θ: a
   quasi-static force-closure margin whose enclosure is positive over the cell and the box, with the contact
   mode fixed (interval or dual certificates), and a timing bound for the deadline.
2. A cell with dense passing referee campaigns and no such argument is recorded as a `Tested` inner candidate,
   kept apart, and never used for a `Certified` label count.
3. Refinement splits cells that straddle; the split set is bounded and the remaining parameters are enclosed at
   full range; a cell that resists is unresolved.

**Label interval.** The label query runs on the certified inner sets (upper count U, with one command per
label) and on the outer sets (lower count L, from conflicts among outer sets). With `Tested` inner candidates
included, a second, lower-class interval may be reported beside the certified one; the classes are never mixed
in one cell.

**Narrowing measurement.** When L < U: find the conflict set that is empty for the inner sets and nonempty for
the outer sets, and within it the cell and the payload parameter whose uncertainty separates inner from outer.
Name the bench measurement or the higher-tier run that would move that cell, with its expected effect on L or U.

**Soundness checks.** Every certified inner cell is attacked by adversarial world search over Θ on the referee
before the answer is returned; a counterexample withdraws the cell, files it as a false certificate if a
certificate had been accepted, and fails the gate condition "an inner set contains a failing command".

**Surface.** `frob mission synthesize labels.fmission --derive-sets --key <k> --json` under the feature flag
`labels-from-contact` (`mission.synthesize` is a run verb, so every call carries an idempotency key). The answer
carries the label interval per evidence class, the sets, the narrowing measurement and the cost of derivation.
The option `--derive-sets` is registered on the `mission.synthesize` row of VERBS-mission (M8, this bead, behind
`labels-from-contact`), so it is in the generated schema of every build. When the feature is not compiled or not
admitted it answers `FROB-REF-724`, exit 5, status `not-in-build`, pointer `/derive_sets`, with the feature
`labels-from-contact` named in the first repair; after KILL-AUGUR-LABELS has fired, the same with status
`killed`. It is never 802, which is kept for an option that is not registered (VERBS-mission's rule for
feature-gated options, which `--atlas`, `--family`, `--relation compute` and the strategies follow).

## Acceptance criteria

- [ ] Feature flag off by default; KILL-AUGUR-LABELS recorded as not fired before work starts.
- [ ] On the pilot's three-variant gripper fixture the mechanism reproduces the pilot's inner and outer sets and label interval.
- [ ] No cell is removed from an outer set without a certificate valid over the cell; no cell is in a certified inner set without a constructive certificate over the whole payload box.
- [ ] `Tested` and `Certified` inner sets are reported separately and never combined in one label count.
- [ ] Adversarial search finds no failing command in any certified inner cell on the fixtures; a planted one is found.
- [ ] The narrowing measurement is named whenever the interval's ends differ.
- [ ] The generated verb registry lists `--derive-sets` on `mission.synthesize` with this bead as implementer and
      the feature flag named; a build without the flag answers it with `FROB-REF-724`, exit 5, status
      `not-in-build`, pointer `/derive_sets`, the feature named in the first repair, and its help schema is
      byte-identical to that of a build with the flag.

## Test plan

### Unit tests

- `outer_cell_needs_cell_certificate`: a cell with ten failing samples and no certificate stays in the outer set.
- `inner_cell_quasi_static` (synthetic): a two-finger grasp of a block of weight 10 N with friction in
  [0.4, 0.6]: a squeeze force F holds the block when 2·μ·F ≥ 10 N for every μ, that is F ≥ 12.5 N; with an
  actuator limit of 20 N the certified inner set of F is [12.5, 20] N, and the outer set is the same interval.
- `inner_cell_two_variants` (synthetic): a second variant with a pad that halves friction needs F ≥ 25 N,
  above the 20 N limit: its command set is empty and no label count makes the mission feasible.
- `tested_not_certified`: a densely sampled cell without a margin certificate lands in `inner_tested`.
- `planted_failing_command`: a cell certified with friction mis-declared as [0.5, 0.6] is contradicted at
  μ = 0.4 by adversarial search.
- `interval_from_sets`: on supplied inner and outer sets the pipeline equals BD-363's answer.

### End-to-end script and logging

`scripts/e2e/mission_labels_from_contact.sh` (seed printed; idempotent; built with `--features
labels-from-contact`). Steps: `derive-gripper` and `derive-block`, `frob mission synthesize <fixture>.fmission
--derive-sets --key lfc-<fixture>-<seed> --json` on the pilot's three-variant gripper fixture and on the synthetic
block fixture (distinct keys); `label-query`, the label query of BD-363 on the derived sets; `attack`, the
adversarial search on every certified inner cell, then on the planted cell with friction mis-declared as
[0.5, 0.6], which must yield a counterexample at μ = 0.4; `verify`, `frob prove verify <bundle> --json` on every
bundle; `flag-off`, the same synthesize call on a build without the flag, which must answer `FROB-REF-724`
(exit 5, status `not-in-build`, pointer `/derive_sets`, `labels-from-contact` in the first repair; logged as a
`refusal` line), never 802.
It sources the STD-E2E helper and writes `target/e2e-logs/mission_labels_from_contact/<utc>.ndjson` with a
transcript beside it. Every line carries `ts`, `script`, `bead` (`N25c-41`), `step`, `event` (`start`, `cmd`,
`assert`, `metric`, `refusal`, `end`), the exact command line, exit code and wall time; the evidence block per set
and per class (claim, class `Certified` or `Tested`, tier, determinism, seed); set sizes; the label interval with
the narrowing measurement; the known answer F ∈ [12.5, 20] N against the observed interval; counterexamples found
against the threshold 0 (the planted one against 1); derivation cost; bundle digests; on failure the first
differing cell with its bounds and the bundle and fixture paths to reproduce; a final `summary` with assertions
passed and failed, naming KILL-AUGUR-LABELS.

### Known answers and negative controls

- Known answer (synthetic block): F ∈ [12.5, 20] N for friction [0.4, 0.6], weight 10 N, limit 20 N; empty for
  the halved-friction variant.
- Negative control: sample-based exclusion of a cell (the shortcut "sample points in a cell fail, so the cell
  is excluded") must be rejected.
- Negative control: a failed training or search run recorded as an exclusion is rejected (a solver failure is
  never an exclusion).
- Determinism: certified parts exact or outward-rounded; campaigns seeded.

## Considerations

- The certified inner sets may be empty for realistic compliant contact; the mechanism is then an expensive way
  to say "one label per variant", and the kill gate's economic clause would have fired at the pilot.
- Hidden contact modes make command sets nonconvex, which removes the Helly bound and enlarges the conflict
  search in the label query.
- Counts toward the cap of four active Moonshot items; funding is the owner's decision.
