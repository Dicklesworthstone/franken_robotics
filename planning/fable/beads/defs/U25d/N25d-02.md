## Background

A body symmetry is a relabelling h of states, contacts and parameters (a signed permutation computed from the
design by the symmetry analysis: polar vectors map by the isometry's orthogonal part P, axial vectors by
det(P)·P). On smooth stretches of motion a symmetric model's kernels are equivariant, and the studio already uses
that. At a contact event it is not automatic: sole laws may differ left and right, packets may arrive at different
times, one foot may graze, the order of touchdowns may change. Before a derivative is transported from one event to
its mirror image, the studio must check that the relabelling commutes with that event:

  D h(x⁺) · S_e(x⁻)  =  S_{h·e}(h·x⁻) · D h(x⁻),

where e is a transversal event, x⁻ and x⁺ the states just before and after it, and S_e the saltation matrix (the
first-order map across the event, including the shift of the event's time):
S = D_xR + (f⁺ − D_xR·f⁻ − D_tR)·D_xg / (D_tg + D_xg·f⁻) for flows f⁻, f⁺, guard g and reset R; the denominator
is the transversality number. Tier Frontier [F]; crate `frob-mission` (the mission compiler uses the result to
decide whether a symmetry may reduce work), reading saltation data from `frob-gait`.

Design decision: a failed identity is a finding with its event, not an error, because a change of symmetry can
itself mark the physical decision boundary an engineer should inspect. Rejected: silently falling back to the
unreduced computation (the engineer never learns where the symmetry broke); refusing every simultaneous
touchdown (symmetric gaits depend on them).

## Scope

check's known answers (the two balls of KA-094, the sliding and sticking impacts, the grazing ball, the order

## Technical approach

Module `crates/frob-mission/src/symmetry_event.rs` (DESIGN).

```rust
pub struct EventRef { run: ReplayAddress, event: EventId }        // EventId is keyed by stable geometry and clock identity
pub enum SymEventStatus { Holds, Broken { dominant: ObservableId }, Inconclusive,
                          Unsupported(UnsupportedReason), Ambiguous(EventOrderChange) }
pub enum UnsupportedReason { Grazing { transversality: f64, threshold: f64 }, FrictionalDegeneracy, ActiveSetChange }
pub struct SymEventFinding { model: ModelId, element: GroupElementId, event: EventRef, image_event: Option<EventId>,
    status: SymEventStatus, residual: f64, error_estimate: f64, method: Method,   // Derived | RelocatedDifference
    observables: Vec<(ObservableId, f64)>, label: DerivativeLabel, class: EvidenceClass }
pub struct TransportLicence { from: EventId, to: EventId, element: GroupElementId, model: ModelId,
    scope: LicenceScope /* LocalDerivative only */, finding: FindingId }
```

**Algorithm, per (h, e).**
1. Admission. Read the transversality number of e, normalized by the guard's declared scale and the model's time
   scale. Below the threshold in force for labelled derivatives: status `Unsupported(Grazing)`; no matrix is
   produced (rule 1). Frictional degeneracy or a change of active set under the requested perturbation: the
   matching `Unsupported` reason.
2. Image event. Map e through h: the contact pair, the guard and the reset are relabelled with the contact
   permutation of h. The image event is evaluated on the same model, with the image contact's own parameters
   (its sole law, its interface card, the packet latency of the sensors that see it). Parameters are never carried
   along with the relabelling: left and right laws that differ must show up as a broken identity, exactly as two
   balls with different restitutions do. If h·x⁻ does not reach the image event next, or reaches it in a
   different order relative to other events, status `Ambiguous` (rule 2) with the two orders.
3. Both sides. Obtain S_e(x⁻) and S_{h·e}(h·x⁻): from the derived saltation kernels where they exist, otherwise by
   relocated finite differences (each perturbed run re-locates its event), one-sided where a two-sided step would
   change the event order. Form R = D h(x⁺)·S_e(x⁻) − S_{h·e}(h·x⁻)·D h(x⁻).
4. Decision in declared observables (for the reference fixture: tray roll and ankle load). With η the error
   estimate of the method (step-halving difference for finite differences; the certified round-off bound for
   derived kernels): `Holds` if ‖R‖ ≤ η; `Broken` if ‖R‖ ≥ 10·η, naming the observable with the largest share;
   `Inconclusive` between. Only `Holds` yields a licence.
5. Class and label. A finding from finite differences is `Tested`, label `finite-difference`. Where the exact
   identity has been certified for this generator and event class (theorem card T-18: a polynomial identity per
   pair), the finding is `Certified`, label `saltation`. A transported derivative carries the weaker of its
   source's class and the finding's.

**Routing rules.**
1. Grazing or uncertain guard-crossing speed: unsupported, as above.
2. New event order: the caller chooses one of three routes, each recorded: keep both continuations (both
   selection Jacobians, label `generalized`); split the symmetry class so that no transport crosses it; or run
   full referee trajectories.
3. A licence transports one local derivative to the corresponding event and nothing else. Reducing a nominal
   trajectory into symmetry blocks is refused unless h fixes the nominal state, history, parameters and event
   (h lies in their stabilizer), or a separately checked intertwining relation between the admitted subspaces at
   the trajectory's endpoints is supplied.
4. Sliding impacts: the identity can hold while a normal-speed perturbation changes tangential speed. The cross
   term is part of S and is never dropped by a block reduction. Mirrored sliding events and an invariant sticking
   event are separate cases with separate findings.
5. A licence supports derivative transport only. A finite performance claim needs finite changes over the
   complete operating envelope and goes through the study types.
6. A licence is bound to `ModelId`. Replacing a wheel or a limb is a different model; a result proved for
   fixed-shape gain changes does not carry through it.
7. Touchdowns simultaneous by symmetry (trot, bound, pronk: h maps the simultaneous group onto itself) are
   admitted: S is the saltation of the one coupled impact; the derivative is ordinary on the symmetric subspace
   and `generalized` off it.

**Refusals.** A derivative request at grazing, at an ambiguous event order, across a change of active set or at
frictional degeneracy: `FROB-REF-263`, carrying the offending state and directions; repair: the one-sided
estimates, or a full referee trajectory. A consumer that transports across an event with no licence:
`FROB-REF-852` (a symmetry transport lacks a side condition); first repair: the missing finding. Exit code 3.
Through `gait.gradient` the grazing case surfaces as `FROB-REF-431` wrapping 263 (BD-334's division of the
conditions); the other conditions are 263 there too.

**Surface (as the registry rows now carry it, with this bead as extender from M6: VERBS-analyze and
VERBS-gait).** `frob analyze symmetry <design> --symmetry-events <run> --json` (a `read` verb) lists, per (group
element, event), a finding {element, event, image event, status `holds`, `broken`, `inconclusive`,
`unsupported` or `ambiguous`, residual, error estimate, method, observables, derivative label, class} and the
licences issued, with FROB-REF-263 and FROB-REF-852 in the row's refusals; `frob gait gradient` returns a
`symmetry_events` block naming every licence it used and refuses an unlicensed transport with FROB-REF-852.
Findings are stored in the ledger with their replay address. Determinism class of a finding: that of the trajectory it was taken on.

## Acceptance criteria

- [ ] `symmetry_event.rs` exists in `frob-mission`; `CONTRACT.md` lists the finding, the licence scope and both
      refusals.
- [ ] On the two-ball model the status is `Holds` for equal restitutions and `Broken` for unequal ones, with the
      residual equal to the closed form.
- [ ] Each of the seven rules has a test that exercises its route; rule 3's block reduction without a stabilizer
      proof is refused with `FROB-REF-852`.
- [ ] No licence is issued for `Inconclusive`, `Unsupported` or `Ambiguous`.
- [ ] Findings are reachable through `frob --json` with a schema; cancellation of a long check drains cleanly.
- [ ] The evidence block of a transported derivative shows the weaker class of source and finding.
- [ ] `scripts/e2e/symmetry_events.sh` passes on this bead's fixtures through the public verb (the gate itself
      is measured later, on the landing fixture, by N25d-03).

## Test plan

### Unit tests

`crates/frob-mission/tests/symmetry_event.rs`:
- `two_balls_equal_restitution_holds`: r_L = r_R = 0.8, v⁻ = −2 m/s; residual 0 within η.
- `two_balls_unequal_restitution_broken`: r_L = 0.8, r_R = 0.6; residual equals
  −(r_L − r_R)·[[1, 0], [g/v⁻, 1]] = −0.2·[[1, 0], [−4.905, 1]]; status `Broken`.
- `sliding_impact_cross_term_kept`: planar point mass striking a plane, restitution r = 0.5, friction 0.5,
  sliding throughout; velocity reset J = [[−r, 0], [μ·(1 + r)·s, 1]] in (normal, tangential) order with
  s = sign(v_t⁻), so the cross term is 0.75·s. Under the tangential mirror D h = diag(1, −1) the identity holds
  (both sides equal [[−0.5, 0], [−0.75·s, −1]]); a block reduction that zeroes the cross term fails against
  relocated differences.
- `sticking_event_invariant`: J = [[−r, 0], [0, 0]] commutes with the mirror; separate finding from the sliding case.
- `grazing_is_unsupported`: a ball whose apex touches a ceiling returns `Unsupported(Grazing)` and no matrix.
- `event_order_change_is_ambiguous`: an image state that reaches the mirrored foot second returns `Ambiguous`.
- `ambiguous_routes_recorded` (rule 2): on that case each of the three routes is taken once (both continuations
  kept, with two selection Jacobians labelled `generalized`; the class split, after which no licence crosses it;
  full referee trajectories) and each choice is recorded in the finding.
- `block_reduction_needs_stabilizer` (rule 3): reducing a nominal trajectory into symmetry blocks with h outside
  the stabilizer of its nominal state, history, parameters and event is refused with `FROB-REF-852`, the first
  repair naming the missing stabilizer proof; with h in the stabilizer, or with a supplied and checked
  intertwining relation, it is admitted.
- `licence_scope_is_local` (rules 3 and 5): a licence used for a second event, or offered as support for a finite
  performance claim, is refused; the finite claim is routed to the study types.
- `symmetric_simultaneous_admitted`: a mirrored pair touching down together is evaluated as one coupled impact.
- `licence_bound_to_model`: a licence for model A is rejected on model B (a replaced limb).
- `gradient_transport_needs_licence`: through `frob-gait`'s gradient entry point, a transport across an event with
  no finding is refused with `FROB-REF-852` (first repair: the missing finding); with a `Holds` finding the
  transport is made and the `symmetry_events` block names the licence.
- Property test (INV: no operation raises a class): for random source classes the transported class is the meet.

### End-to-end script and logging
`scripts/e2e/symmetry_events.sh` (owned here, built on this bead's dependencies; header `# e2e: bead=N25d-02
milestone=M6 labels=augur,frontier seed=1 needs=cpu`; N25d-03's gate script runs it as its smoke stage). Fixtures
(`synthetic`, written by this bead under `crates/frob-conformance/fixtures/augur/symmetry-events/`, with the
derivation note `docs/derivations/augur-symmetry-events.md`): `two-balls-equal` (restitutions 0.8 and 0.8,
v⁻ = −2 m/s, g = 9.81 m/s²), `two-balls-unequal` (0.8 and 0.6), `slide-mirror` (r = 0.5, friction 0.5, sliding
throughout), `stick-invariant`, `ceiling-graze` (apex touching a ceiling) and `order-change` (an image state that
reaches the mirrored contact second). Steps, per fixture: `frob sim run <fixture design> --tier referee --seed 1
--key se-run-<fixture>-<run> --json` (one key per fixture and repeat), then `frob analyze symmetry <fixture design>
--symmetry-events <run id> --json`. Asserts: `holds` for equal restitutions; `broken` for unequal ones with the
residual −0.2·[[1, 0], [−4.905 s⁻¹, 1]] within η; on `slide-mirror` a `holds` finding whose matrix carries the
cross term 0.75·s; on `stick-invariant` a separate finding; on `ceiling-graze` `unsupported` with its
transversality number and no matrix; on `order-change` `ambiguous` with both orders; a licence only beside
`holds`; the evidence block's class `Tested` and label `finite-difference`. A repeat of the two-ball runs with new
keys gives identical finding digests. Through the STD-E2E helper it writes
`target/e2e-logs/symmetry_events/<utc>.ndjson` and a transcript: every line `ts`, `script`, `bead` (`N25d-02`),
`step`, `event`, the exact command, key, exit code, wall time and evidence block; `assert` lines with expected and
observed values; per finding `metric` lines for ρ, η and ρ/η (thresholds 1 and 10), the transversality number,
the status and the run's replay address; `refusal` lines with code, pointer and first repair for any refusal; on
failure the first differing value and the replay addresses; a `summary` with assertions passed and failed.

### Known answers and negative controls
KA-094; CX-042. Planted defects the tests must catch: the source contact's parameters carried onto the image
contact (unequal laws then pass wrongly); a fixed-time difference
used in place of a relocated one (it returns the reset Jacobian, wrong sign in the first entry); a licence issued
on `Inconclusive`. Metamorphic relation: applying h twice (an involution) returns the original finding.
Determinism: twice on one machine; debug and release.

## Considerations

- The referee route for saltation depends on upstream event sensitivities; until derived kernels exist the
  finite-difference method is the only one, and every finding is `Tested`.
- Thresholds (η multiples 1 and 10) come from the gate; they are TARGETs and are re-read after the pilot.
- If KILL-AUGUR-SYMEVENT fires this module is removed and consumers use per-event finite differences.
