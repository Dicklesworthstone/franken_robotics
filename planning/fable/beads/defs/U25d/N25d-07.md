## Background

Two small exact constructions ride on the machinery of the constructive lanes of Augur (the subsystem for
questions about families of designs) and need no lane of their own. Both are tagged Frontier [F], so by the
program's rule each needs a paper-scale pilot with a falsifier before its code is funded. The plan names the
constructions and a known answer but no pilot and no kill gate for them; this bead supplies the pilot, with a
falsifier and a fallback stated in advance (DESIGN), so the rule is not silently skipped.

- *Mass placement inside a chassis volume.* Given a target pseudo-inertia of a body and the CAD support of that
  body, find nonnegative masses on a finite basis of admissible sites that realize it. The pseudo-inertia of a
  rigid body is the 4×4 matrix P = [[Σ, h], [hᵀ, m]] with m the mass, h the first moment and Σ the second moment
  of mass; its ten entries are the body's ten inertial parameters. A point mass μ at x contributes
  μ·[[x·xᵀ, x], [xᵀ, 1]], so realizing P is a linear feasibility problem in the site masses.
- *Single-actuator-loss robustness.* For each catalogued actuator removal, a rank screen on the remaining wrench
  map, then a bounded feasible allocation as a linear program. It answers the static half of "is the route still
  available after one module drops out".

The pilot question is the one every plan-time pilot ended up answering: does a short conventional program already
give the same checked answer? If so, the construction is a lowering onto existing verbs and no dedicated solver is
written (the decision rule "conventional formulations first": a specialized solver is written only after measured
evidence that the ordinary route is the bottleneck).

## Scope

In: four hand fixtures; the run with a conventional linear-program solver; twenty random instances with planted
status; the falsifier; the pilot record. Out: the product code (N25d-08); placement and sizing along a prescribed
motion (a different lane, owned elsewhere); dynamic recovery after an actuator loss (stays `Tested`).

## Technical approach

**Tools.** Outside the product: exact rational arithmetic by hand or by script, and the linear-program solver
already admitted for mission work, called directly. No `frob-synth` code.

**Fixture A (infeasible placement; the plan's known answer).** Mass 1 kg in a ball of radius 1/10 m, principal
moments 1/125 kg·m² each about the centre. Positivity holds; the triangle inequalities hold; the per-axis bound
I ≤ m·r² = 1/100 holds. The mass-weighted mean squared distance from the centre is tr(I_C)/(2m) = (3/125)/2 =
3/250 m², and every site in the ball has squared distance at most 1/100 m². So no placement exists. Certificate:
the dual matrix Y = [[−1₃, 0], [0, 1/100]] gives ⟨Y, site⟩ = 1/100 − ‖x‖² ≥ 0 for every site in the ball and
⟨Y, P⟩ = m/100 − tr Σ = 1/100 − 3/250 = −1/500 < 0.

**Fixture B (feasible, at equality).** The same ball, principal moments 1/150 kg·m² (an isotropic thin shell).
Six sites at (±1/10, 0, 0), (0, ±1/10, 0), (0, 0, ±1/10) m with 1/6 kg each: Σ = diag(1/300, 1/300, 1/300),
h = 0, m = 1, and I = tr(Σ)·1 − Σ = 1/150 per axis. Exactly feasible.

**Fixture C (actuator loss, bounds).** A platform needs vertical force 180 N and zero moment about its centre.
Three identical actuators at x = −1, 0, +1 m each deliver a force in [0, 100] N. Wrench map rows (force, moment):
W = [[1, 1, 1], [−1, 0, 1]]. All present: (60, 60, 60) N. Middle removed: (90, 90) N, survives. Left removed:
the moment row forces the right actuator to 0, so the middle one needs 180 N against a 100 N rating: fails on
bounds, with dual y = (1, −1): yᵀW = (1, 0) on the remaining pair, so yᵀW·u ≤ 100 while yᵀw = 180.

**Fixture D (actuator loss, rank).** Actuators at x = 0, 0, +1 m and required wrenches {(180, 0), (180, 20)} N
and N·m. Removing the actuator at +1 leaves W = [[1, 1], [0, 0]] of rank 1; the second requirement has a moment
component outside its range: fails on rank, with the left null vector (0, 1).

**Random instances.** Twenty placement instances (S = 50 rational sites in a box; ten built from a planted mass
vector, ten with a target moved outside the reachable cone by a known margin) and twenty actuator-removal
instances (six actuators, a requirement polytope with four vertices, planted status).

**Measured.** Agreement of the linear program with the hand answers; for each instance whether an exact
certificate (a rational primal point or a rational dual) is recovered from the floating-point solve by solving
the active basis over ℚ; authoring effort in lines of problem setup.

**Falsifier (fixed before the run; DESIGN).** Any of: the linear program disagrees with a hand answer on A to D;
an exact certificate cannot be recovered on more than 5 of the 40 planted instances; or the whole construction is
expressed as an ordinary `mission.refute` or static-analysis call with no new lowering, in which case no code is
written in `frob-synth` and the fixtures become known answers of those verbs.

**Ceiling.** No speed is claimed: a pointwise mass-support check or a per-removal wrench check gives the same
verdict for one proposed design. The value is a witness or an exclusion in the common certificate form.

**Fallback.** The existing mass-support predicate at import (refusal `FROB-REF-106`) and the task-wrench
attainability analysis A-24 run once per removal, classed `Tested` where no certificate is produced.

## Acceptance criteria

- [ ] The protocol and its hash are committed before the run.
- [ ] Fixtures A to D are reproduced in exact rationals and by the linear-program solver; every value above is
      matched.
- [ ] The recovery rate of exact certificates on the 40 planted instances is reported.
- [ ] The falsifier's verdict is recorded in one sentence in the pilot register and the review log, with the
      decision "dedicated lowering" or "existing verbs only".
- [ ] The record states that the plan names no kill gate for these constructions and names the fallback above.

## Test plan

### Unit tests
The pilot's scripts carry their own assertions: `fixture_a_dual` (⟨Y, P⟩ = −1/500; ⟨Y, site⟩ ≥ 0 at 1,000 random
rational sites in the ball), `fixture_b_six_sites` (Σ = diag(1/300)), `fixture_c_left_removed` (180 > 100),
`fixture_d_rank` (rank 1 < 2).

### End-to-end script and logging
`scripts/e2e/pilot_exact_constructions.sh` runs the four fixtures and the 40 instances and logs per instance:
planted status, solver status, whether an exact certificate was recovered, the certificate's size in bits, wall
time; `metric` lines for agreement and recovery rate with the falsifier's thresholds; a `summary` with the verdict.

### Known answers and negative controls
KA-652 (fixture A). Controls: fixture B with one site moved to radius 0.11 m must be rejected as outside the
support; fixture C with ratings raised to 200 N must flip to `survives`.

## Considerations

- Fixtures B, C and D are synthetic and defined by this bead; each gets a derivation file before it supports a gate.
- An exclusion from a finite site basis excludes that basis only. The continuum claim of fixture A holds because
  the dual's quadratic 1/100 − ‖x‖² is nonnegative on the whole ball; the product code must make that distinction.
