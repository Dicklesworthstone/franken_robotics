## Background

A mission query asks for the set of designs for which some admitted causal controller succeeds in every admitted
world. For a static family over a set of loads (a payload that can sit anywhere in a rectangle, a disturbance
wrench in a polytope), the usual argument is: find one feasible command at each vertex of the load set; the
constraints are convex, so a feasible command exists for every load in the hull. That argument shows that a
feasible command exists for every load. It does not show that a controller of the declared class can produce those
commands. The class is the set of functions from the observed quantities to the command. This bead makes the class
a field of the query (`policy_class.law`, beside the authority model) and lowers each class correctly. Tier Solid
[S]; owner `frob-mission` for the lowering, `frob-cert` for the checking rule (N25e-29).

The stance family shows the size of the effect. Mission: 400 N on four point feet at (±a, ±b) with a = 1/3 m,
ratings of 160 N per foot, and load moments P = (P_x, P_y) with abs(P_x) ≤ 60 N·m and abs(P_y) ≤ 30 N·m. Feet are
ordered [++, +−, −+, −−], and foot i has signs (s_x, s_y). Smallest admissible half-width b by class:

| Class | Smallest half-width b | A law that attains it |
|---|---|---|
| `adjustable`: any function of the observed P | 3/14 m | f(P) = Σ_σ w_σ(P)·f_σ over the four vertex allocations f_σ, with w_σ(P) = ¼·(1 + σ_x·P_x/60)·(1 + σ_y·P_y/30) |
| `affine`: f(P) = f₀ + A·P | 1/2 m | fᵢ(P) = 100 + s_x·P_x/(4a) + s_y·P_y/(4b) newtons |
| `constant`: P is not observed before the command | none | No fixed f satisfies Σ xᵢ·fᵢ = P_x for two values of P_x |

The affine class needs 7/3 times the half-width of the adjustable class. And the passive suspension is an affine
controller: the symmetric affine law is the load sharing of four equal springs; at b = 1/4 m it gives
(175, 115, 85, 25) N at the vertex (60, 30), the passive allocation that exceeds the 160 N rating. The authority
counterexample and the class counterexample are one fact seen twice. Rejected alternatives: leaving the class
implicit (the vertex witnesses then certify a controller nobody declared); defaulting to `adjustable` (a silent
default is the error this rule exists to prevent).

## Scope

In: the field, its admission rule and refusal, the lowering for the four classes, the returned law, the `refute`
behaviour under `affine`. Out: the certificate's `law` object and its checks (N25e-29); the gate script (N25e-30).

## Technical approach

1. Schema. `policy_class` gains the field `law`, one of `adjustable`, `affine`, `piecewise-affine`, `constant`.
   The arguments of the law are the fields listed as observed before the decision (`observation.fields` whose
   arrival instant precedes the decision instant). `piecewise-affine` names a declared triangulation of the
   load set. The field is part of the canonical query and therefore of `MissionId`.
2. Admission. A query that asks for inclusion over a load or disturbance set (a `world` parameter given as a
   hull or box, under a `forall world` binder) and omits `law` is refused: "inclusion over a disturbance set
   without a declared law class". The refusal is row 2 of N25e-45 (a dependency; slug `law-class-missing`), a
   row the allocation ledger holds with family `8xx`: it is raised as the row's interim `FROB-REF-868` (the
   `.fmission` file is not valid: missing field) with `detail: law-class-missing`, through the constant of
   `frob_core::refusal::augur_late`, so that the ledger's assignment changes one line; pointer `policy_class.law`;
   ranked repairs: declare `adjustable` if the load is observed
   before the command and any function of it is realizable; `affine` for a linear or passive allocator;
   `constant` if the load is not observed. Exit 3. A law whose argument is not observed before the decision is
   refused with `FROB-REF-847`.
3. Lowering (module `crates/frob-mission/src/lower/law.rs`). Let the accept predicates be linear equalities
   E·f = M·P + e₀ and inequalities G·f ≤ h in the command f, for each load P in a polytope with vertices P_v.
   - `adjustable`: one command f_v per vertex, with E·f_v = M·P_v + e₀ and G·f_v ≤ h: the lifted program of the
     stance family. The returned law is the multilinear interpolant on a box, f(P) = Σ_v w_v(P)·f_v with
     w_v(P) = Π_axes ½·(1 ± P_axis/half-range), and the barycentric interpolant on a declared triangulation
     otherwise. The weights are nonnegative, sum to one and satisfy Σ w_v·P_v = P, so the interpolant meets
     every equality at every P and stays inside the inequalities by convexity.
   - `affine`: the unknowns are (f₀, A). Equalities are imposed as identities in P by matching coefficients
     (E·f₀ = e₀ and E·A = M). Inequalities are imposed at the vertices, where an affine function on a polytope
     takes its extremes: G·(f₀ + A·P_v) ≤ h for every v.
   - `piecewise-affine`: one command per vertex of the declared triangulation; on each simplex the law is the
     barycentric interpolant of its vertex commands, which is affine on the simplex and continuous across faces.
   - `constant`: one command f for every vertex: E·f = M·P_v + e₀ for all v and G·f ≤ h.
   Each lowering is a linear program in exact rationals after reconstruction; infeasibility returns its Farkas
   dual.
4. Answer. Every inner cell names the law class and carries the law as data (N25e-29's object). The objective
   "least half-width" returns the class's own minimum with a matching lower bound.
5. `mission.refute` under `affine`, for b in [3/14, 1/2) m, returns the dual of the affine program and names the
   class as a repair beside the geometric one: widen to 1/2 m, or admit a law that is not affine. In general,
   when a cell is excluded under the declared class and included under a richer one, both repairs are listed,
   each as a typed edit (a geometry edit; an edit of `policy_class.law`).

Why the four vertex witnesses are not values of one affine law: an affine function on a rectangle satisfies
f(60, 30) + f(−60, −30) = f(60, −30) + f(−60, 30). The vertex allocations at b = 3/14 m give (160, 240, 240, 160) N on
the left and (240, 160, 160, 240) N on the right. Why 1/2 m under `affine`: if an affine law is feasible, so is its
image under each reflection of the load rectangle with the matching exchange of feet, and so is the average of the
four images, because the constraints are convex and the mission is symmetric. The average is invariant under the
reflections, which forces the form fᵢ(P) = 100 + s_x·P_x/(4a) + s_y·P_y/(4b), with the coefficients fixed by the
balance equations. Its largest value is 100 + 60/(4a) + 30/(4b) = 145 + 15/(2b) N, which is at most 160 N exactly
when b ≥ 1/2 m; its smallest value, 55 − 15/(2b) N, is positive there. The matching dual: add the four rating
inequalities fᵢ(P_σ(i)) ≤ 160, each taken at foot i's own vertex P_σ(i) = (60·s_x, 30·s_y); the left side equals
Σ f₀ᵢ + 60·Σ s_x·A_ix + 30·Σ s_y·A_iy = 400 + 60/a + 30/b by the coefficient identities, so 580 + 30/b ≤ 640, that is
b ≥ 1/2. Under `constant`, subtracting the moment equation at P_x = −60 from the one at P_x = 60 gives 0 = 120.

Determinism D0; evidence class `Certified`, tier `static`.

## Acceptance criteria

- [ ] Stance family through `mission.synthesize`: 3/14 m under `adjustable` with the bilinear law; 1/2 m under `affine` with the symmetric law and a matching dual; an exclusion for every b under `constant`.
- [ ] A query over a load set with no `law` is refused (exit 3) with the three ranked repairs; a law reading a field that arrives after the decision is refused with `FROB-REF-847`.
- [ ] `MissionId` differs between the `adjustable` and `affine` versions of the same query.
- [ ] `mission.refute` under `affine` at b = 1/4 m returns the dual above (700 N required of 640 N available across the four own-vertex ratings, the symmetric law needing 175 N) and both repairs: widen to 1/2 m, or admit a law that is not affine.
- [ ] The adjustable law at b = 3/14 m returns 100 N per foot at P = 0 and has P_x·P_y coefficient (−20, 20, 20, −20)/1800 N per (N·m)².
- [ ] Each lowering has a second, independently written implementation in `frob-conformance` compared exactly, and one deliberately invalid fixture (PO-AUGUR-01).
- [ ] Reachable through `frob --json`; `CONTRACT.md` documents the field and the four lowerings.

### Known answers and negative controls

Rows of the stance family under three classes (exact rationals): `adjustable`, b = 3/14 m, inner with the bilinear
law, 100 N per foot at P = 0; `affine`, b = 1/2 m, inner, (160, 130, 70, 40) N at the vertex (60, 30); `affine`,
b = 1/4 m, excluded, the symmetric law needs 175 N; `constant`, any b, excluded. Related registry rows: KA-624
(stance family), KA-626 and CX-273 (passive equal springs). Negative controls: a lowering that accepts a constant
command because each vertex has some feasible command; an `affine` lowering that imposes equalities only at
vertices of a non-full-dimensional load set (planted: a segment of loads) and thereby accepts a law violating
balance off the segment's hull. Determinism lanes: twice on one machine; two solvers; debug and release.

## Considerations

- The class interacts with authority: `passive-equal-spring` authority admits only the symmetric affine law, so
  it is `affine` with A fixed; the lowering treats authority as extra equalities on (f₀, A).
- Convexity of the constraints in the command is assumed and checked; a nonconvex command set (contact
  switches) is outside this lowering and goes to cells or to the finite-game route.
- Piecewise-affine minima depend on the declared triangulation; the answer names it.
- The checker must see the law, not only the vertices (N25e-29); otherwise relabelled witnesses would pass.
