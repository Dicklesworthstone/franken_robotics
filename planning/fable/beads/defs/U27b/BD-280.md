## Background

`frob explain` reports the earliest anomaly before a failure and labels it `Estimated`, because ordering
anomalies in time is a heuristic. Autopsy replaces the heuristic with a measurement: forks that differ from the
failed world by one declared intervention. `autopsy.attribute` is the verb that reads those forks (run earlier by
`autopsy.intervene`) and reports, per intervention, three numbers and a label:

| Quantity | Definition |
|---|---|
| Rescue rate | The fraction of replicates of do(c) in which the requirement is not violated |
| Contrast | The rescue rate minus the placebo flip rate ρ₀ |
| Flip rate under perturbation | The fraction of replicates whose verdict differs from the unperturbed fork of the same intervention, at 10⁻¹² and at 10⁻⁷ |

Decisions that bind it:

- **ADR-AUTOPSY-01. A cause is what an intervention removes, net of a placebo.** A factor is named only when
  removing it prevents the failure more often than an irrelevant perturbation does.
- **ADR-AUTOPSY-04. Attribution reports a flip rate at round-off scale; double precision is the default for one
  failure.**
- **ADR-AUTOPSY-05. Contrasts first; Shapley values are a summary on a budget.** The table of what each
  intervention and each pair did is the result. Rejected: coalition-value attribution as the primary output,
  because such values can be negative and cannot establish necessity.
- **ADR-AUTOPSY-07. The cause is a cause in the model.** Every attribution is scoped to the model, the tier and
  the declared factor list.

Tier Solid: interventional contrasts with a placebo-referenced stability report are established technique
applied carefully. Crate `frob-autopsy`, layer 5. Construction C-29 (probability of necessity
PN(c) = P(no failure under do(¬c) | failure), named only when it exceeds ρ₀ under a test); decision core DC-06
(which cause, and which repair edit, ranks first); bet BET-23 with its falsifier (top-1 accuracy on planted causes
below 90%; or the placebo flip rate above 0.2 on more than half of the reference failures; or no saving of agent
repair turns); risk RISK-50 (attribution names a cause where none is stable; mitigations: abstention, double
precision, the kill gate).

## Technical approach

1. **Surface.** `frob autopsy attribute <fork> [--forks <f1,f2,…>] [--lane f64|tier-f32|auto] [--shapley
   auto|never] [--budget <tokens>] --json`; MCP tool `autopsy_attribute { "fork": … }`. Kind `read`: it reads the
   fork ledger and computes integer statistics; it runs no fork and changes nothing. Schemas:
   `frob.autopsy.attribute.in/1` (DESIGN name) and the result `frob.autopsy.attribution/1`.
2. **The record** (type sketch of the program, with the added fields marked +; all rates also kept as exact
   count pairs):
   ```json
   { "schema": "frob.autopsy.attribution/1", "fork": "f:a41c…", "tier": "batch-cpu", "precision": "f64",
     "horizon_s": "2", "forks_run": 137, "null_replay": "bitwise",
     "placebo": {"n": 64, "flips": 2, "rate": 0.031, "separation_growth": "2.1e4"},
     "contrasts": [
       {"do": "scene./floor/patch[galley-2]/film := dry", "class": "contact-affecting", "rescued": "8/8",
        "contrast": 0.97, "flip_rate": {"1e-12": 0.0, "1e-7": 0.0}, "label": "but-for"},
       {"do": "model.joint[*.knee].torque_limit := off", "class": "diagnostic", "rescued": "3/8",
        "contrast": 0.34, "flip_rate": {"1e-12": 0.375, "1e-7": 0.375}, "label": "contributing"},
       {"do": "sense.imu.latency := 0 s", "class": "information", "rescued": "0/8",
        "contrast": -0.03, "flip_rate": {"1e-12": 0.0, "1e-7": null}, "label": "none"} ],
     "pairs": [ {"do": ["film := dry", "torque_limit := off"], "rescued": "8/8", "interaction": -0.34} ],
     "refused": [ {"do": "model.joint[*.knee].gear_ratio := 16", "code": "FROB-REF-581",
                   "earliest_valid_fork_tick": 0} ],
     "outcome": "but-for", "ranking": ["…film := dry", "…torque_limit := off", "…latency := 0 s"],     (+)
     "top_factor": "…film := dry", "named_set": ["…film := dry", "…torque_limit := off"],              (+)
     "top_factor_stable_1e7": true,                                                                      (+)
     "test": {"type": "fixed", "alpha": "1/20", "factors": 3, "preanalysis": "b3:…"},                   (+)
     "route": "f64: decision-equivalent", "lane": {"requested": "f64", "ran": "f64"},                   (+)
     "scope": {"model": "m:…", "scene": "s:…", "tier": "batch-cpu", "precision": "f64",                 (+)
               "factors": ["…", "…", "…", "…"]},
     "evidence": {"class": "Estimated", "scope": "cause in the model at this tier, among the listed factors"},
     "next_actions": [ … ] }
   ```
   The numbers are illustrative; the shape is fixed. A second series that did not run prints `null`, never 0.
   `class` is the fork class of the intervention (`continuation`, `exogenous`, `contact-affecting`,
   `information`) or `diagnostic`.
3. **Assembly.** (a) Read the ledger header; refuse if the null fork was not bitwise (FROB-REF-583) or the route
   is precision-sensitive or the class uncontrolled (FROB-REF-584; below class D2 at admission is FROB-REF-562).
   (b) For each single and each coalition: counts → `ContrastStat` → test at level α divided by the number of
   single factors run. (c) Labels, ranking, named set and stability. (d) `pairs`: rescued count and interaction
   from the coalition bead; before that bead lands the block holds rescued counts only. (e) Scope block
   (INV-AUTOPSY-06: every attribution carries its scope: the model, the tier, the precision and the factor
   list). (f) Evidence: class `Estimated`, however strong the contrasts; contrasts themselves are replayable
   experiments of class `Tested` on their tier; `reality: no-claim`; the three no-authorization flags false.
4. **`next_actions` rules.** A refused design parameter: `frob autopsy rerun <run> --edit '<typed edit>' --worlds
   failing,sample:64` ("a design parameter is tested from the episode start on the same world addresses"). A
   `but-for` world factor: `frob nemesis shrink <run> --world <w>` ("find the smallest world that still fails").
   Rescuing factors none of which is the robot's to change: an `autopsy rerun` with a candidate design edit. No
   factor named: an earlier fork on the lead ladder (0.25, 0.5, 1, 2 s), then a re-run from the start.
   `chaotic: unattributable`: a shorter window, and `frob explain run` as the labelled fallback. Singles named
   `none` with coalitions not run: `frob autopsy intervene … --coalitions pairs`.
5. **Several forks.** With `--forks`, the result holds one attribution per fork and a pooled table over the
   failing worlds: per factor the worlds rescued by the unperturbed fork out of W, the worlds whose placebo
   flipped, the contrast, the exact test and the label; the pooled rescue rate is the estimate of the
   probability of necessity. Long results are paginated with a cursor; nothing is cut silently.
6. **Exit codes.** 3 on a refusal of the whole attribution; 2 when any factor is named, any intervention was
   refused, or the outcome is a flag (`chaotic: unattributable`, `marginal`, `precedes-snapshot`,
   `tier-specific`); 0 otherwise. A fork with no intervention set recorded returns an empty table with the flag
   `no-interventions-run` and `frob autopsy intervene` as the next action.
7. **Gate measurement in the crate.** Test `planted_single_causes_gate` runs the planted suite (N27b-08) in
   double precision and prints: accuracy (planted factor at `ranking[0]` with a label other than `none`) against
   90%; the share of cases whose top factor changes under 10⁻⁷ perturbation against 30%; and, when the coalition
   table exists, the agreement between ten one-at-a-time forks and the full table (recorded, no threshold).
8. **Layout.** `crates/frob-autopsy/src/attribute.rs`, `record.rs`; registry entry in N27b-16.

## Acceptance criteria

- [ ] Seed done-condition: GATE-AUTOPSY-03 is recorded with measured values (TARGET): the planted factor ranks
      first in at least 90% of 200 failures in double precision; the top factor changes in at most 30% of cases
      under 10⁻⁷ perturbation; the agreement between ten one-at-a-time forks and the full coalition table is
      recorded. (The clause for the single-precision lane at windows of at most 1 s is measured by N27b-28 and
      joined to the record by N27b-09.) KILL-AUTOPSY is decided and recorded as an ADR (N27b-11).
- [ ] The negative control of the gate is caught: a failure planted through a factor outside the declared list
      names no factor.
- [ ] The record validates against `frob.autopsy.attribution/1`; `contrast = rescued − placebo rate` and the
      interaction identity hold exactly on the stored counts.
- [ ] Every attribution carries `scope` with model, tier, precision and factor list, `evidence.class =
      "Estimated"`, both flip rates per intervention and the placebo separation growth.
- [ ] A null-fork mismatch yields FROB-REF-583 and no table; a precision-sensitive failure yields FROB-REF-584.
- [ ] The verb is reachable through `frob --json` and `frob-mcp` with the same envelope; it is a `read` verb
      (calling it twice changes no stored byte); `CONTRACT.md` documents the record.
- [ ] Outputs carry the claim product; the CPU reference path is the default path.

- `out_of_list_cause_names_nothing`.

### End-to-end script and logging
`scripts/e2e/autopsy_attribute_planted.sh` (N27b-09) drives `frob run fork`, `frob autopsy intervene` and
`frob autopsy attribute` over the 200 planted failures and writes the gate record; per attribution it logs the
record's counts, labels, route and scope with thresholds.

### Known answers and negative controls
KA-670 (planted single causes: 200 failures in five classes, ten candidate factors each; the planted factor
ranks first with label `but-for`; accuracy at least 90%; control: a failure planted through a factor outside the
list names no factor). KA-148 (planted cause recovered as first-ranked in at least 90% of cases). KA-147 and
KA-672 (a fixture where every nudge flips the outcome reports `chaotic: unattributable`). The worked card GB-34.
CX-301 ("a contrast between forks is a proof of cause": a contrast is a replayable experiment of class `Tested`
on its tier, and an attribution is `Estimated`). Negative controls: an attribution that subtracts no placebo; one
that reports a missing series as 0; one that raises the evidence class. Determinism lanes: the same ledger gives
the same record bytes twice, across worker counts, in debug and release and on both platforms (the verb is
integer arithmetic over a stored ledger).

## Considerations

- KILL-AUTOPSY (M3). Trigger: GATE-AUTOPSY-03 fails after one repair cycle: planted-cause accuracy below 90%, or
  the top factor changes in more than 30% of cases at 10⁻⁷. Fallback: single-factor paired re-runs from the
  episode start, with the first-anomaly ordering labelled `Estimated`; coalitions and Shapley summaries are
  removed. If it fires, this verb keeps its record shape and loses `pairs`, `shapley` and the label `joint`.
- The claim that agents repair designs in fewer turns with these tools than with logs is a HYPOTHESIS with its
  own gate at M4; nothing here depends on it, and if that gate fails the tools stay.
- OPEN-AUTOPSY-2 (owner: Autopsy lead; decided by GATE-AUTOPSY-03): whether one-at-a-time contrasts suffice,
  which would make pairs optional. Default: singles and pairs.
- Not a differentiator of the engine: an incumbent with restorable state and a thin layer can host the same
  method, and the program's comparison against a composed incumbent includes that arm.
