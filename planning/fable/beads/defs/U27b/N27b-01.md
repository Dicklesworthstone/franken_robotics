## Background

Autopsy is the subsystem that turns "what happened first" into a measurement: it restores a failed simulated world
to a moment before the failure, changes one thing, runs forward and records whether the failure still happens. The
one thing it changes is an **intervention**, written `do(factor := value)`. Everything downstream (the fork plan,
the contrast table, the repair search, the transcript) is expressed in this vocabulary, so it has to be exact
before any of them exists.

A **factor** is a path into the world or the model whose mechanism is declared. There are three sources of
factors and only three:

- a **world factor**: a typed edit of the scene, of one of the seven edit classes of the adversarial-world
  subsystem (Nemesis), each of which declares the causal path it changes;
- a **design factor**: a typed design edit of the design language (`regear`, `set-param`, `swap-actuator`, and
  the rest), which gives a new design identity;
- a **diagnostic factor**: one of a short registered list of changes no hardware could make, such as
  `torque_limit := off`, `estimator := privileged` and `latency := 0`.

Two architecture decisions govern this bead.

**ADR-AUTOPSY-06. Diagnostic interventions are not repairs.** Switching a torque limit off locates a cause; it is
not an edit anyone can build. The two kinds are typed apart. Rejected alternative: one flat list of
"interventions" with a boolean flag; rejected because a flag is dropped by the first consumer that forgets to read
it, and the repair search would then hand an agent "remove the torque limit" as a design change.

**ADR-AUTOPSY-07. The cause is a cause in the model.** Every factor resolves against one model identity and one
scene identity, and those identities travel with the intervention. A factor that cannot be resolved against the
identities of the fork is refused, never guessed.

Tier Solid. Crate `frob-autopsy`, layer 5 (it consumes Chronicle's forks, Arena's verdicts, Nemesis's world edits
and Skeleton's design edits; nothing below layer 5 depends on it). Serves construction C-29 (a deterministic
forkable simulator is a causal model: the *action* step of a counterfactual is a typed intervention recorded as a
model difference) and bet BET-23.

## Scope

In: the grammar and parser of `do(factor := value)`; the factor-path namespaces; resolution of a path to a typed
factor against the fork's identities; the mechanism registry; the diagnostic-factor registry; the canonical string
and hash of an intervention and of a change set; the type-level separation of diagnostic and buildable factors;
display short names.
Out: computing the model difference and enforcing one mechanism per intervention (N27b-02); classifying a change
set into the five fork classes and the earliest valid tick (the fork service, BD-205); running forks (BD-279);
turning rescuing factors into repair sets (N27b-14).

## Technical approach

1. **Grammar (DESIGN).** The CLI flag `--do` and the JSON field `do` take the bare assignment; `do( … )` around it
   is accepted and stripped.
   ```text
   assign    := path WS? ":=" WS? value
   path      := namespace "." selector
   namespace := "scene" | "model" | "sense" | "control" | "payload" | "disturbance"
   selector  := scene path ("/floor/patch[galley-2]/film") or dotted model path with bracket selectors
                ("joint[*.knee].torque_limit"); "*" matches one name segment
   value     := quantity with unit ("14 N·m", "0 s") | exact decimal ("0.50", "16") | identifier ("dry")
              | keyword: "off" | "nominal" | "privileged"
   ```
   Worked forms the parser must accept: `scene./floor/patch[galley-2]/film := dry`;
   `scene./fixtures/door[pass]/closer_torque := 14 N·m`; `model.joint[*.knee].torque_limit := off`;
   `model.joint[*.knee].gear_ratio := 16`; `sense.imu.latency := 0 s`; `payload.tray.fill := 0.50`;
   `control.estimator := privileged`. `nominal` resolves to the authored base value of the scene or the nominal
   value of the task's randomization card for that quantity, and the resolved value is stored, not the keyword.
   A quantity without a unit where the target has a dimension is refused (FROB-REF-802: arguments fail the
   schema; exit 3); an unknown or misspelt path is refused with the nearest registered paths as repairs
   (FROB-REF-802). A misspelt parameter is a refusal, never a default.
2. **Types (DESIGN; the first is the program's type sketch).**
   ```rust
   pub struct Intervention { factor: FactorPath, value: Value, mechanism: MechanismId, model_diff: Blake3 }
   pub enum FactorKind {
       World { edit_class: EditClass, causal_paths: Vec<CausalPath> },   // one of the seven edit classes
       Design { edit: TypedEdit },                                       // gives a new DesignId and ModelId
       Diagnostic { id: DiagnosticId, realizable: False },               // no hardware could realize it
   }
   pub struct ResolvedFactor { path: FactorPath, kind: FactorKind, instances: Vec<FieldPath>,
                               bound: Identities /* model, scene, task, policy */ }
   pub struct Buildable(ResolvedFactor);   // constructible only from World or Design
   ```
   `model_diff` is filled by N27b-02. `Buildable::try_from(Diagnostic)` does not exist: a compile-fail test pins
   it, which is how ADR-AUTOPSY-06 is enforced by type.
3. **The seven world-edit classes and what each declares** (carried from the world-edit vocabulary; an edit that
   cannot say which path it changes is not admitted, FROB-REF-362):
   | Edit class | Example | Declared causal path → mechanism family |
   |---|---|---|
   | Geometry | sill height, door width, obstacle place | collision geometry and clearance → `geometry.collision` |
   | Material | friction of a floor patch, a compliant mat, a film | contact → `contact.friction`, `contact.compliance`; optics as well if wet or glossy → `sensing.optics` |
   | Optics | a light position, a glass panel, a reflectance | sensing only → `sensing.optics` |
   | Fixture | a door-closer torque, a conveyor speed | dynamics of fixtures → `fixture.dynamics` |
   | Clock and link | a sensor latency, a dropout burst, jitter | timing only → `timing.link` |
   | Disturbance | a push of stated impulse, a payload shift | exogenous forces → `exogenous.force` |
   | Parameter | a value inside a card's uncertainty | model parameters → `model.parameter:<card field>` |
4. **Mechanism registry (DESIGN).** `registries/autopsy/mechanisms.toml`: one row per `MechanismId` with the
   component it belongs to, the fields of the compiled model and scene it owns, and the fork class it implies when
   it is touched (the classification itself stays with the fork service). A wildcard selector that touches several
   instances of one mechanism (`joint[*.knee].torque_limit`) is one intervention; `instances` lists each.
5. **Diagnostic-factor registry (DESIGN).** `registries/autopsy/diagnostic_factors.toml`, a closed list; adding a
   row is a reviewed change. First rows:
   | Id | Assignment | Mechanism | State handling at the fork tick | Shown class |
   |---|---|---|---|---|
   | `torque-limit-off` | `model.joint[<sel>].torque_limit := off` | `actuator.torque-limit` | Whole checkpoint restored; the limit row is disabled from the fork tick | `diagnostic` |
   | `estimator-privileged` | `control.estimator := privileged` | `estimator.source` | Filter state re-initialized from privileged state, as an information intervention | `diagnostic` |
   | `latency-zero` | `sense.<sensor>.latency := 0 s` | `timing.link` | Packet queue re-initialized as the intervention states | `information` (labelled diagnostic where no hardware could realize it) |
   Every diagnostic factor carries `realizable: false` and is excluded from repair sets by type.
6. **Canonical form and identity.** `canonical(intervention)`: namespace and selector with wildcards expanded and
   sorted, `:=`, the resolved value as an exact decimal string with its canonical unit. `change_set_hash =
   BLAKE3(sorted canonical strings joined by "\n")`. The canonical string is what the fork path, the fork ledger
   and the transcript store, so a replay reproduces the same hash on any machine. `short_name(intervention)` is
   the last path segment with the value (`film := dry`), unique within one change set or else lengthened.
7. **Module layout.** `crates/frob-autopsy/src/vocab.rs` (grammar, parser, canonical form), `mechanism.rs`
   (registry loader), `diagnostic.rs` (registry loader); the two registries under `registries/autopsy/`.
   Determinism class D0 (exact text and hashing). No output of this bead crosses the agent boundary by itself.

## Acceptance criteria

- [ ] The seven worked forms of step 1 parse, resolve on the wet-floor kitchen fixture and the reference
      quadruped, and print their canonical strings; parse → canonical → parse is the identity.
- [ ] Each of the seven edit classes resolves to its declared mechanism family; an edit with no declared causal
      path is refused with FROB-REF-362.
- [ ] An unknown path, a missing unit and a value of the wrong dimension are each refused with FROB-REF-802, exit
      3, a `pointer` to the token at fault and the nearest registered paths as ranked repairs.
- [ ] `Buildable` cannot be built from a diagnostic factor (compile-fail test).
- [ ] `change_set_hash` is independent of the order in which `--do` flags are given and of whitespace.
- [ ] Both registries load with an unknown key as a load-time error; `CONTRACT.md` of the crate documents the
      grammar, the three factor kinds and the diagnostic list.

## Test plan

### Unit tests
`crates/frob-autopsy/tests/vocab.rs`:
- `parse_worked_forms`: the seven strings of step 1 → expected `FactorKind` (World/Material; World/Fixture;
  Diagnostic/`torque-limit-off`; Design/`regear`; Diagnostic/`latency-zero`; Design/`set-param` on the payload;
  Diagnostic/`estimator-privileged`).
- `canonical_round_trip` (property, 1,000 generated assignments): parse(canonical(x)) = x.
- `hash_order_independent`: the three orders of three interventions give one `change_set_hash`.
- `nominal_resolves_to_value`: `scene./floor/patch[galley-2]/friction := nominal` stores the base value (0.8 on
  the split-grip landing fixture), not the keyword.
- `wildcard_is_one_intervention`: `model.joint[*.knee].torque_limit := off` on a quadruped gives 4 instances and
  one mechanism.
- `refuse_unknown_path`, `refuse_missing_unit`, `refuse_wrong_dimension` (`sense.imu.latency := 3 N`),
  `refuse_undeclared_edit_362`.
- `diagnostic_not_buildable` (trybuild compile-fail).
- `registry_unknown_key_is_load_error`.

### End-to-end script and logging
Exercised by `scripts/e2e/autopsy_intervene.sh` (N27b-04) and `scripts/e2e/autopsy_refusals.sh` (N27b-19): the
scripts pass each worked form to `frob run fork --classify-only` and `frob autopsy intervene`, assert the echoed
canonical string and log, per intervention, the canonical string, the kind, the mechanism and the change-set hash.

### Known answers and negative controls
Negative controls (planted defects the tests must catch): a parser that treats an unknown path as a no-op (the
refusal test fails); a canonical form that keeps input order (the hash test fails); a resolver that accepts a
diagnostic factor as buildable (the compile-fail test stops compiling as a failure). Metamorphic: renaming a
scene object changes the canonical string and the hash and nothing else. Determinism: identical bytes twice on one
machine, in debug and release, and on both platforms (class D0).

## Considerations

- The diagnostic list is deliberately short. A long list becomes a second, unreviewed model of the robot.
- An intervention is an experiment and need not lie inside a legality profile for adversarial worlds; when one
  does not, the resolved factor carries `outside_legality: true` so that the repair search can exclude it.
- A factor that touches two mechanisms (a wet floor changes friction and depth returns) parses here and is split
  or refused one step later (N27b-02); the parser does not decide that.
- Revisit if agents routinely need a factor that is neither an edit nor in the diagnostic list: that is a sign
  the edit vocabulary is missing a class, and the fix belongs there.
