## Background

The static-stability analysis A-08 (bead BD-100) decides whether a body can balance a load on its contacts
within per-contact force limits. A plausible cheaper test exists and is wrong: check that the support polygon
contains the load point and that the total force capacity is at least the weight. This bead is the exhaustive
battery that pins A-08 to the exact answer on a finite grid and shows the cheap screen failing, so that the
screen can never be substituted for the program unnoticed. It is the studio's first entry in the
negative-control registry: a hand-checkable family in which a plausible analysis gives the wrong answer.

The truth comes from a plan-time pilot (FACT, executed; re-run from its reproduction bundle by seed bead BD-042
at M0): two independent exact formulations agreed on 11,520 of 11,520 states. This bead does not trust that
record; it regenerates the counts with an independent enumerator in exact rational arithmetic and then requires
A-08 to match state by state.

## Scope

In: the grid generator, an independent exact classifier (a zonotope test, separate code from A-08's cone
program), the state-by-state comparison, the screen mutant, the registry rows. Out: A-08 itself (BD-100); the
family query that returns the whole set of admissible stance dimensions (mission subsystem, BD-130).

## Technical approach

**The grid (all values exact).** A planar four-foot template with feet at (±1/u, ±1/v) m, u, v ∈ {2, 3, 4} per
metre (half-sizes 1/2, 1/3, 1/4 m); four independent foot ratings c = (c₊₊, c₊₋, c₋₊, c₋₋) ∈ {0, 80, 160, 240}⁴ N.
That is 3 × 3 × 4⁴ = 2,304 bodies. The mission: a 400 N load whose centre of mass lies anywhere in a rectangle of
half-sizes 150 mm × 75 mm, represented by its four vertices and its centroid, i.e. the load states
(W, P) = (400 N, (±60, ±30) N·m) and (400 N, (0, 0)), with P = W·(x, y) the first moment. 2,304 × 5 = 11,520
body–load states.

**Feasibility of a state.** There exist foot forces f with 0 ≤ fᵢ ≤ cᵢ, Σ fᵢ = W, Σ xᵢ·fᵢ = P_x, Σ yᵢ·fᵢ = P_y
(authority: independently commanded normal forces).

**The independent classifier (projected form).** The attainable wrench set is the zonotope Σ [0, cᵢ]·gᵢ with
generators gᵢ = (1, xᵢ, yᵢ). Every facet of a full-dimensional three-dimensional zonotope is parallel to two
generators, so for each pair (j, k) with n = g_j × g_k ≠ 0 the state w = (W, P_x, P_y) is feasible only if
Σᵢ min(0, cᵢ·n·gᵢ) ≤ n·w ≤ Σᵢ max(0, cᵢ·n·gᵢ); with degenerate (lower-dimensional) zonotopes handled by an
explicit rank case. All arithmetic in exact rationals. The classifier shares no code with A-08's solver path.

**Expected counts (known answers).**

| Quantity | Value |
|---|---|
| Bodies | 2,304 |
| Body–load states | 11,520 |
| Feasible states | 2,254 |
| Bodies that cover the whole mission (all five states feasible) | 114 |
| Bodies the screen accepts and the exact model rejects | 1,596 |
| Agreement of A-08 with the independent classifier | 11,520 of 11,520 |

**The screen (the negative control), defined exactly.** Accept a body when (a) the rectangle of feet contains
the load point for every mission vertex, |x| ≤ 1/u and |y| ≤ 1/v, which holds for every body of the grid, and
(b) the total capacity Σ cᵢ is at least W = 400 N. First counterexample: u = v = 2, ratings (80, 80, 80, 160) N,
vertex (60, 30) N·m: total capacity 400 N passes the screen, while the moment equations need
f₊₊ + f₊₋ = 200 + 60·u/2 = 260 N from two feet rated 80 N each (at most 160 N), so the state is infeasible.

**Authority row.** At half-width b = 1/4 m and a = 1/3 m, ratings 160 N, vertex (60, 30): active allocation
(155, 135, 105, 5) N is feasible; equal passive springs force (175, 115, 85, 25) N, which exceeds the rating.
A-08 must return feasible under `independent-normal-force` and infeasible under `passive-equal-spring`.

**Procedure.** (1) Generate the grid and classify with the independent classifier; assert the counts above.
(2) Run A-08 on every state through the library API (not the CLI: 11,520 calls) and compare verdicts; on a
mismatch print the body, the state, both verdicts and the dual or primal witness. (3) Run the screen mutant and
assert it differs on exactly 1,596 bodies. (4) Bind the registry row KA-682.

## Acceptance criteria

- [ ] The independent classifier reproduces 2,254 feasible states and 114 covering bodies in exact arithmetic.
- [ ] A-08 agrees with it on 11,520 of 11,520 states; every infeasible verdict carries a dual vector that the
      test re-checks in exact rationals (Mᵀy ≥ 0, rᵀy < 0 for the standard-form system).
- [ ] The screen mutant accepts exactly 1,596 bodies that the exact model rejects, and the first counterexample
      is the stated one.
- [ ] The authority row returns the two verdicts with the two force vectors.
- [ ] The battery runs in under 60 s on one core (TARGET) and is part of the `fixtures` battery that runs on
      every change touching contact or analyses.

## Test plan

### Unit tests

`crates/frob-analyze/tests/stance_battery.rs`:
- `grid_sizes`: 2,304 and 11,520.
- `independent_counts`: 2,254; 114.
- `a08_agrees_all_states`.
- `dual_witness_rechecks`: every infeasible state.
- `screen_mutant_1596` and `first_counterexample_is_2_2_80_80_80_160`.
- `authority_row_active_vs_passive`.
- `degenerate_zonotope_cases`: a body with three zero ratings is infeasible for every non-degenerate load and
  the rank case reports it without dividing by zero.

### End-to-end script and logging

`scripts/e2e/atelier_stance_battery.sh` runs the battery through `cargo test -p frob-analyze stance_battery`
and one CLI spot check, `frob analyze stability <fixture> --authority passive-equal-spring --json`. It sources
the shared helper of STD-E2E and logs, as `metric` events, the six counts against their expected values, the
wall time, and on failure the first differing state with both witnesses and the path of the fixture file that
reproduces it.

### Known answers and negative controls

KA-682 (and its equivalents KA-625, KA-658 in the mission registry): the table above. Negative control CX-302:
the screen mutant must be caught; a second mutant that drops one foot's upper limit must change the feasible
count; a third that reorders the feet without reordering the ratings must be caught by the authority row.
Determinism: exact arithmetic, identical on every platform.

## Considerations

- The grid is `synthetic` and says nothing about how often real designs sit near the boundary; its purpose is
  to make the screen's failure concrete and permanent.
- The counts depend on the convention that rating 0 is a foot that carries nothing but still sits at its
  corner; the fixture file states it.
- If the re-run of the plan-time pilot (BD-042) disagrees with these counts, this battery and the plan's numbers
  are both suspended until the discrepancy is explained; neither is corrected to match the other silently.
