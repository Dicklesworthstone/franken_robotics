## Background

When a design or mission is edited, stored verdicts are put in question. The studio answers "which verdicts
survive?" with four grades of reuse. Grade 1 (identity: the obligation's full key is unchanged) and grade 2
(dependency: every changed field lies outside the obligation's recorded dependency support) are Solid and are
the default. Grade 3 is Frontier: a changed field lies inside the support, and a polarity rule of the
assumption lattice still preserves the obligation (for example, narrowing the disturbance set preserves an
inclusion result with the same witness). Grade 4 is no licence: rerun.

Every Frontier mechanism names a paper-scale pilot with a falsifier that must run before its work is funded.
Grade 3 needs one more than most, because of a negative result that was kept on purpose: on a four-state
camera-delivery fixture a semantic receipt and a correctly keyed dependency graph did identical work (2, 0, 0,
1 scene-pair evaluations and 1, 0, 0, 1 recomputations), so on small cases grade 3 has no demonstrated
advantage; and unsafe reuse is a false accept. Its open value is whether a useful implication can be checked
cheaply for a rich plant. The ceiling is stated first: rollouts and training are at least nine tenths of
per-design compute and depend on every mass and geometry parameter, so exact reuse after a dynamics-affecting
edit is at most about a tenth of compute; revalidation is an evidence rule and a hygiene measure, not a source
of the ten-fold.

## Scope

In: three paper-scale steps and their record. Out: the production grade-3 path and the gate (BD-347); the kill
decision (N28a-24); grades 1 and 2 (BD-292).

## Technical approach

**Step 1: written derivations (the paper part of proof obligation PO-ATEL-06).** For each row of the polarity
table, a short derivation that the stated verdict kind is preserved under the stated pure change, with its side
conditions, filed under `docs/derivations/polarity/<rule>.md`. The rows:

| Component | Change | Inclusion (a witness exists) | Exclusion (no witness can exist) |
|---|---|---|---|
| Disturbance or world set | Narrowed | Preserved, with the same witness | Recheck |
| | Enlarged | Recheck | Preserved, if the policy class and the information contract are unchanged |
| Hypothesis support (admitted hidden parameters) | Enlarged | Recheck | Preserved |
| Actuator limits | Relaxed | Preserved, if the old command stays realizable and the plant still realizes the old dynamics | Recheck |
| | Tightened | Recheck | Preserved |
| Requirement | Relaxed | Preserved | Recheck |
| | Tightened | Recheck | Preserved |
| Policy class | Enlarged | Preserved | Recheck |
| | Shrunk | Preserved only if the witness policy is still in the class | Preserved |
| Information contract | Refined: more, earlier or better observations, the old ones still recoverable | Preserved | Recheck |
| | Coarsened or delayed | Recheck | Preserved |
| Catalog and prices | Part added or price lowered | Preserved | Recheck (every cheaper rival must be excluded again) |
| | Part removed | Preserved unless the witness uses the part | Preserved; an optimum that used the part is void |
| Free space of the scene | Enlarged | Preserved, if the witness trace does not touch the changed region | Recheck every exclusion that used the removed obstacle |

Each derivation states the order relation it uses (inclusion for sets, pointwise order for limits, refinement
for information) and the check that the edit is a pure change in that direction.

**Step 2: the twelve scripted amendments, by fresh evaluation.** On the docking family (three one-second ticks,
hidden gain in {1, 2}, command bound U, read error ε; a robust causal policy exists exactly when
ε < (U + ½)/4) and on the stance family: an inclusion at (U, ε) = (¾, ¼) must survive ε falling to 1/8 and U
rising to 1; an exclusion at (¾, 3/8) must survive ε rising and U falling; each of the four opposite moves must
demand a recheck; enlarging the hypothesis support by one hidden gain 33/32 keeps every exclusion and forces a
recheck of every inclusion, and the inclusion at (¾, 1/64) reverses (the reading (65/64)·p is possible under
gains 1 and 33/32 for every first command p, and the least worst-case terminal error becomes 1/65 m). Twelve
moves per fixture, each compared with a fresh solve. **Falsifier: one survivor that fresh evaluation
contradicts.**

**Step 3: dry run on the frozen 30-amendment campaign.** The campaign (frozen before any implementation sees
it): visual-only edits, camera timing, sole geometry, floor law, torque, shared noise, load authority, facility
edits, and one apparently cosmetic change that advances a packet by one control tick. For each amendment and
each stored obligation, classify by hand from the recorded supports: grade 1, 2, candidate for grade 3 (naming
the rule and whether the change is pure), or 4. Using the recheck costs measured by the grade-1-and-2 engine,
compute: C₂ = the recheck cost grade 2 leaves; S₃ = the part of C₂ that a correct grade 3 would avoid.
**Second falsifier (TARGET): S₃ < C₂/5**, in which case grade 3 cannot pass its kill gate and its production
path is not funded.

**Record.** `registries/pilots/reuse-grade3.toml`: the derivation list with reviewers, the 24 scripted moves
with outcomes, the classification table (amendment × obligation), C₂, S₃, the ratio, and the recommendation
(fund, or do not fund and go straight to the fallback). The pilot is run by a session that will not implement
BD-347.

## Acceptance criteria

- [ ] Fourteen derivations exist (one per row with a "preserved" cell), each naming its side conditions and its
      purity check; two reviewers' sign-off recorded.
- [ ] All 24 scripted moves are evaluated fresh; survivors and rechecks match the table; the 33/32 amendment
      reverses the inclusion at (¾, 1/64).
- [ ] The dry-run table covers 30 amendments; C₂, S₃ and S₃/C₂ are recorded with the method.
- [ ] The record states the recommendation and both falsifier outcomes; if either falsifier holds, BD-347 is
      marked to implement grade 4 and the licence plumbing only.

## Test plan

### Unit tests

Scripted checks in `crates/frob-conformance/tests/polarity_pilot.rs`:
- `docking_boundary`: (U + ½)/4 at U = ¾ is 5/16; ε = ¼ is inside, ε = 3/8 outside.
- `inclusion_survives_narrowing`: ε → 1/8, U → 1, by fresh evaluation.
- `exclusion_survives_enlarging`: ε ↑, U ↓.
- `four_opposite_moves_need_recheck`: the fresh answer differs or is not implied in each.
- `hair_widening_reverses`: gain 33/32 added; inclusion at (¾, 1/64) fails; least worst-case error 1/65 m.
- `classification_table_complete`: 30 rows, every obligation classified.

### End-to-end script and logging

`scripts/e2e/reuse_pilot.sh`: runs the 24 moves through `frob mission synthesize` on the two fixtures (fresh
each time), compares with the table, and prints the dry-run summary from the registry file. Logged per the
shared standard: per move the amendment, the predicted survival, the fresh verdict, `match`; then C₂, S₃, the
ratio against 1/5, and the recommendation.

### Known answers and negative controls

KA-224 (the polarity table on the docking and stance fixtures, twelve moves per fixture), KA-701 (the 33/32
amendment: every one of the 34,590 positive decisions on each test grid is withdrawn). Negative controls:
CX-314 (enlarging the hypothesis support slightly leaves inclusions valid: must be contradicted); a planted
wrong rule ("requirement tightened preserves inclusion") must produce a contradicted survivor.

## Considerations

- A rule applies only to a pure change in its direction: a larger motor relaxes a torque limit and also changes
  mass and rotor inertia, so it is not a relaxation; the classification marks it grade 4.
- KILL-AUGUR-REUSE stands from the third milestone: one incorrectly inherited verdict from an implication rule
  removes that rule. The pilot's first falsifier is the same event seen before any production code exists.
- If the dry run shows grade 3 is not worth funding, nothing downstream is blocked: grades 1 and 2 are the
  default, and the cascade's reuse stage uses them.
