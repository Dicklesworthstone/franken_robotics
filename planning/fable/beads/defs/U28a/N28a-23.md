## Background

When a design or mission is edited, stored verdicts are put in question. The studio answers "which verdicts
survive?" with four grades of reuse. Grade 1 (identity: the obligation's full key is unchanged) and grade 2
(dependency: every changed field lies outside the obligation's recorded dependency support) are Solid and are
the default. Grade 3 is Frontier: a changed field lies inside the support, and a polarity rule of the
assumption lattice still preserves the obligation (for example, narrowing the disturbance set preserves an
inclusion result with the same witness). Grade 4 is no licence: rerun.

Every Frontier mechanism names a paper-scale pilot with a falsifier that must run before its work is funded.
Grade 3 needs one more than most, because of a negative result that was kept on purpose: on a four-state
camera-delivery fixture a semantic receipt and a correctly keyed dependency graph did identical work (2, 0, 0,
1 scene-pair evaluations and 1, 0, 0, 1 recomputations), so on small cases grade 3 has no demonstrated
advantage; and unsafe reuse is a false accept. Its open value is whether a useful implication can be checked
cheaply for a rich plant. The ceiling is stated first: rollouts and training are at least nine tenths of
per-design compute and depend on every mass and geometry parameter, so exact reuse after a dynamics-affecting
edit is at most about a tenth of compute; revalidation is an evidence rule and a hygiene measure, not a source
of the ten-fold.

## Scope

In: three paper-scale steps and their record: the written derivations; the polarity table checked by fresh
evaluation of twelve moves on each of two fixtures (24 moves), on stored verdict records; the dry run on the
frozen 30-amendment campaign with its own falsifier.

Out, with the bead that has it:
- The pilot of construction C-18, PILOT-C-18: the twelve scripted amendments (a fixed list of twelve, two per
  row of the six-row polarity table, on the certificates of the first mission slice), their protocol, the
  falsifier "one survivor that fresh evaluation contradicts" as the test that funds the revalidation engine,
  and the record: N10b-07, at M1, a dependency of this bead through the engine (BD-292 does not start before
  it). "The twelve scripted amendments" means that list and no other. This pilot does not redefine or
  re-register it: step 2 reuses its amendment definitions wherever the same fixture and direction occur, adds
  only the moves that list lacks, and treats a contradicted survivor as the same falsifier seen again.
- The production grade-3 path (BD-347); the registered polarity rules with their fixtures and the exhaustive
  finite-game check (N28b-34, which depends on this pilot and turns its written derivations into registry
  rows); the gate run on the sealed M4 campaign (N28b-35); the kill decision (N28b-36), which reads this
  pilot's record and can end the question on it; grades 1 and 2 (BD-292).

## Technical approach

**Step 1: written derivations (the paper part of proof obligation PO-ATEL-06).** For each row of the polarity
table, a short derivation that the stated verdict kind is preserved under the stated pure change, with its side
conditions, filed under `docs/derivations/polarity/<rule>.md`. The rows:

| Component | Change | Inclusion (a witness exists) | Exclusion (no witness can exist) |
|---|---|---|---|
| Disturbance or world set | Narrowed | Preserved, with the same witness | Recheck |
| | Enlarged | Recheck | Preserved, if the policy class and the information contract are unchanged |
| Hypothesis support (admitted hidden parameters) | Enlarged | Recheck | Preserved |
| Actuator limits | Relaxed | Preserved, if the old command stays realizable and the plant still realizes the old dynamics | Recheck |
| | Tightened | Recheck | Preserved |
| Requirement | Relaxed | Preserved | Recheck |
| | Tightened | Recheck | Preserved |
| Policy class | Enlarged | Preserved | Recheck |
| | Shrunk | Preserved only if the witness policy is still in the class | Preserved |
| Information contract | Refined: more, earlier or better observations, the old ones still recoverable | Preserved | Recheck |
| | Coarsened or delayed | Recheck | Preserved |
| Catalog and prices | Part added or price lowered | Preserved | Recheck (every cheaper rival must be excluded again) |
| | Part removed | Preserved unless the witness uses the part | Preserved; an optimum that used the part is void |
| Free space of the scene | Enlarged | Preserved, if the witness trace does not touch the changed region | Recheck every exclusion that used the removed obstacle |

Each derivation states the order relation it uses (inclusion for sets, pointwise order for limits, refinement
for information) and the check that the edit is a pure change in that direction.

**Step 2: twelve polarity moves per fixture, by fresh evaluation** (proof obligation PO-LEMMA-03 and known
answer KA-224: each row of the polarity table gives the stated survival on the docking and stance fixtures).
A move is one direction of change (world set narrowed or enlarged, policy class or authority grown or shrunk,
requirement relaxed or tightened: six directions) applied to one kind of stored verdict (an inclusion or an
exclusion): twelve per fixture, 24 in all, each compared with a fresh solve of the amended query. The verdicts
are the stored records of the two fixtures in the form `frob.verdict/1`, read through the grade-1-and-2 engine.

This is not the list called "the twelve scripted amendments": that is the fixed list of the C-18 pilot,
PILOT-C-18 (N10b-07, M1), whose amendments are numbered 1 to 12 there. One amendment has one definition, so
the moves here are taken from that list wherever it has the fixture and direction, and are scripted here,
before the run, only where it does not:

- *Docking family* (three one-second ticks, hidden gain in {1, 2}, command bound U, read error ε; a robust
  causal policy exists exactly when ε < (U + ½)/4). World set and authority, the moves of the plan's own test
  of C-18: an inclusion at (U, ε) = (¾, ¼) must survive ε falling to 1/8 (amendment 1 of PILOT-C-18, ε halved)
  and U rising to 1; an exclusion at (¾, 3/8) must survive ε rising and U falling; each of the four opposite
  moves (the inclusion under ε rising and under U falling, the exclusion under ε falling and under U rising)
  must demand a recheck. Requirement: relaxed as amendment 9 (only v₃ = 0 required) and tightened as
  amendment 11 (no overshoot), each on the inclusion and on the exclusion. Twelve moves.
- *Stance family.* Amendments 2 (rectangle reduced), 4 (rectangle enlarged), 6 (per-foot cap raised to 170 N),
  8 (equal passive springs) and 12 (every foot force at least 10 N) of PILOT-C-18, each on the family's
  inclusion and on its exclusion: ten moves. That list has no relaxed requirement on the stance family (its
  second such amendment is on the energy family), so this pilot scripts one (DESIGN): the inverse of
  amendment 12, starting from the query with the 10 N floor and removing the floor again, on an inclusion
  (must survive) and on an exclusion (must be rechecked). Twelve moves.
- *The hair-widening case*, in addition to the 24: enlarging the hypothesis support by one hidden gain 33/32
  (amendment 3 of PILOT-C-18) keeps every exclusion and forces a recheck of every inclusion, and the inclusion
  at (¾, 1/64) reverses (the reading (65/64)·p is possible under gains 1 and 33/32 for every first command p,
  and the least worst-case terminal error becomes 1/65 m).

**Falsifier: one survivor that fresh evaluation contradicts.** It is the falsifier of PILOT-C-18, met a second
time on verdict records; if PILOT-C-18's own record shows a contradicted survivor, the engine was not funded
and this pilot is not run.

**Step 3: dry run on the frozen 30-amendment campaign.** The campaign (frozen before any implementation sees
it): visual-only edits, camera timing, sole geometry, floor law, torque, shared noise, load authority, facility
edits, and one apparently cosmetic change that advances a packet by one control tick. For each amendment and
each stored obligation, classify from the recorded supports: grade 1, 2, candidate for grade 3 (naming the rule
and whether the change is pure), or 4. Whether a change is pure in a rule's direction is decided by the
pure-change check of the polarity-rule registry (N25ap1-01, M3) wherever a registered rule covers the row, so
that purity has one definition; a row no registered rule covers (or whose rule was removed under
KILL-AUGUR-REUSE) is classified by hand from its written derivation and marked `by-hand` in the table. Using the recheck costs measured by the grade-1-and-2 engine,
compute: C₂ = the recheck cost grade 2 leaves; S₃ = the part of C₂ that a correct grade 3 would avoid.
**Second falsifier (TARGET): S₃ < C₂/5**, in which case grade 3 cannot pass its kill gate and its production
path is not funded.

**Record.** One `[[pilot]]` row, `id = "PILOT-REUSE-01"`, in the one pilot register
`crates/frob-conformance/registry/pilots.toml` (schema `frob.gauntlet.pilot/1`, N38a-09; DESIGN: an earlier
draft of this bead kept a file of its own, `registries/pilots/reuse-grade3.toml`, but the register is one
file, the file in which PILOT-C-18 is recorded, and its completeness check reads no other). The identifier
follows N38a-09's grammar `PILOT-<SET>-<nn>` (set `REUSE`, first in its set); the earlier name
`PILOT-REUSE-GRADE3` has no two-digit number and the loader rejects it with `pilot-id-form`, and N10b-07 already
cites `PILOT-REUSE-01`. The row has `mechanism` (grade-3 reuse by polarity rules), `tier = "F"`, `bead =
"N28a-23"`, `work_package = "WP-63"`, `protocol` (the frozen protocol `docs/pilots/PILOT-REUSE-01.md` with its
BLAKE3 digest), both falsifiers, the ceiling, `fallback = { ships = "grades 1 and 2 with grade 4 and the
licence plumbing", kill_gate = "KILL-REUSE" }` and `cost`, registered before the run; the result is an
appended `[[pilot.result]]`. The detailed tables are a results file referenced from the result by digest,
`docs/pilots/PILOT-REUSE-01-results.toml` (DESIGN path): the derivation list with reviewers, the
24 moves and the hair-widening case with outcomes, the classification table (amendment × obligation), C₂, S₃,
the ratio, and the recommendation (fund, or do not fund and go straight to the fallback). The record cites
PILOT-C-18 by identifier for the amendment definitions it reuses. The pilot is run by a session that will not
implement BD-347.

## Test plan

### Unit tests

Scripted checks in `crates/frob-conformance/tests/polarity_pilot.rs`:
- `docking_boundary`: (U + ½)/4 at U = ¾ is 5/16; ε = ¼ is inside, ε = 3/8 outside.
- `inclusion_survives_narrowing`: ε → 1/8, U → 1, by fresh evaluation.
- `exclusion_survives_enlarging`: ε ↑, U ↓.
- `four_opposite_moves_need_recheck`: the fresh answer differs or is not implied in each.
- `requirement_moves_docking`: amendment 9 (only v₃ = 0) keeps the inclusion and sends the exclusion to recheck;
  amendment 11 (no overshoot) does the reverse.
- `stance_moves`: amendments 2, 4, 6, 8 and 12 of PILOT-C-18 and the inverse of 12, each on the inclusion and the
  exclusion; amendment 8 withdraws the inclusion at b = ¼ m (equal passive springs give 175 N on one foot
  against the 160 N cap), as PILOT-C-18 records.
- `twenty_four_moves_enumerated`: the move list has six directions × two kinds × two fixtures, with no
  (fixture, direction, kind) missing or repeated.
- `hair_widening_reverses`: gain 33/32 added; inclusion at (¾, 1/64) fails; least worst-case error 1/65 m.
- `classification_table_complete`: 30 rows, every obligation classified.

### End-to-end script and logging

`scripts/e2e/reuse_pilot.sh`: runs the 24 moves through `frob mission synthesize` on the two fixtures, fresh
each time: the amended query is the stored one with the move's one-field amendment, `frob mission synthesize
<q> --set <field>=<value> --budget cpu_core_s=60 --key "$(e2e_key reuse-<fixture>-<move>)" --sync-wait-ms 2000
--json` (a `run` verb: each move its own key, so no call returns another's stored answer, convention 5), and
the same for the hair-widening case; compares with the table; checks the register with `cargo test -p
frob-conformance --test pilots` (`PILOT-REUSE-01` loads, no `pilot-id-form` finding, its result after its
registration); and prints the dry-run summary from the results file. It sources the
STD-E2E helper and writes NDJSON to `target/e2e-logs/reuse_pilot/<utc>.ndjson`; every line carries `ts`,
`script`, `bead`, `step` (`move`, `hair_widening`, `dry_run`), `event`, the exact command line, exit code, wall
time, the envelope's `evidence` block; per move the fixture, direction, verdict kind, the PILOT-C-18 amendment
number (or `scripted-here`), the predicted survival, the fresh verdict, `match`; then C₂, S₃, the ratio against
1/5, the `by-hand` share of the classification, and the recommendation; on failure the first contradicted
survivor with its query files; a final `summary` line naming KILL-REUSE and both falsifier outcomes.

### Known answers and negative controls

KA-224 (the polarity table on the docking and stance fixtures, twelve moves per fixture), KA-701 (the 33/32
amendment: every one of the 34,590 positive decisions on each test grid is withdrawn). Negative controls:
CX-314 (enlarging the hypothesis support slightly leaves inclusions valid: must be contradicted); a planted
wrong rule ("requirement tightened preserves inclusion") must produce a contradicted survivor.

## Considerations

- A rule applies only to a pure change in its direction: a larger motor relaxes a torque limit and also changes
  mass and rotor inertia, so it is not a relaxation; the classification marks it grade 4.
- KILL-AUGUR-REUSE stands from the third milestone: one incorrectly inherited verdict from an implication rule
  removes that rule. The pilot's first falsifier is the same event seen before any production code exists.
- If the dry run shows grade 3 is not worth funding, nothing downstream is blocked: grades 1 and 2 are the
  default, and the cascade's reuse stage uses them.
