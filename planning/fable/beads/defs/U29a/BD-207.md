## Background

At milestone M1 telemetry exists on the referee, where every world can be traced and the host holds all state.
At M2 the same record must come out of a device that steps thousands of worlds per batch, where state stays
resident and the host synchronizes only once per chunk of control intervals. This bead makes the telemetry
levels real on the batched tiers (`batch-cpu`, CUDA, Metal):

| Level | Contents | Default scope |
|---|---|---|
| T0 | Per-episode metrics, the energy ledger totals, integer histograms and per-chunk minimum–maximum envelopes of declared channels, and state digests at intervals | Every world, always |
| T1 | Events: contacts made and broken, limit and saturation episodes, faults, refusals | Every world |
| T2 | Traces at control rate: joint states, torques, contact wrenches, estimator state | An address-keyed sample of worlds, and every failing world |
| T3 | Full state snapshots at intervals, sufficient for exact restart | Sampled and failing worlds |

Three constraints shape the design. First, determinism: nothing telemetry does may change a physics digest, and
every aggregate must have the same bits under any slot order or shard split (decisions ADR-CHRON-03 and
ADR-CHRON-04). Second, cost: the gate allows T0 and T1 on every world at most 3% of step time and T2 on a 1%
sample at most 2% more. Third, the commit fence: the host may read a device slab only after the command buffer
that last wrote it has completed, so telemetry leaves the device once per device chunk and is assembled into
the record's fixed logical chunks on the host.

Seed done-condition: GATE-CHRON-07 and GATE-CHRON-13. The reservoir, the histogram mathematics and the
histogram kernel are separate beads that this one wires together; the gate measurements are N29a-16 and
N29a-17. Tier Solid.

## Scope

In: which quantities each level emits on devices and from which stage; the statistics ring layout; the
traced-world mask on the device; per-chunk envelope and metric accumulation in-kernel; T1 event capture with
fixed capacity; T2 column capture for masked worlds; the host drain at each device commit; assembly into
logical chunks and publication; gap records for overflow; the `stat` isolation rule; channel declarations for
the reference robots.
Out: T3 snapshots and the per-world ring (N29a-11, BD-203); the energy-ledger terms (BD-208); the selection
rule (N29a-12); histogram definition and kernel (N29a-13, N29a-14); the wide-count drain (another unit); the
verbs.

## Technical approach

**1. Emission points in the ten-stage step.** After stage 9 (integrate) of each physics step: envelope updates
for step-rate channels and event detection (a contact made or broken is a change of the active-contact mask by
feature pair; a limit or saturation episode is a row's active flag changing). After stage 10 (sensors,
observations, rewards, resets) of each control tick: T0 metric accumulators, control-rate envelope updates,
histograms (`K-x-hist`), the state digest, and, for traced worlds, the T2 column write.

**2. The traced-world mask.** A `u32` per world row, set by the first kernel of each chunk from the address
hash: `traced = h(w) < T` with the two words of the threshold in the step-plan header (`K-x-philox` supplies
the hash; the tie-broken fixed-size bound uses the same comparison). The mask is recomputed when a slot takes a
new episode at a masked reset, because the address changed. A second bit, `failing`, is set by the failure
monitors and forces capture from the ring (N29a-11).

**3. T0 in-kernel accumulators (per world, exact integers or double-float pairs as declared).** Count of
ticks; per declared channel the quantized minimum and maximum of the current logical chunk (`Min`, `Max` of the
aggregate types, written by select, no atomics); per-world T0 histogram rows (m = 16, s = 3); per-episode
metric partials (integer counts, and energy totals from the ledger kernel). At a logical-chunk boundary of a
world (tick ≡ 0 mod L, or the terminal tick) the kernel copies the accumulators into the statistics ring's
`t0` section for that world and resets them.

**4. T1 events.** A fixed-capacity event buffer per world per device chunk (capacity from the shape class;
default 64 events), filled by count, exclusive scan and write so that order is deterministic: events are
ordered by (tick, substep, stage, feature key). Overflow sets a flag and a dropped count; the host records a
gap with reason `ring-overflow` for that interval, and any metric that needs those events is refused
(FROB-REF-888). No event is silently dropped.

**5. T2 columns.** For traced worlds the control-tick kernel writes the declared T2 channels (joint states as
group elements and velocities, torques, contact wrenches by site, estimator state, applied action) into the
ring's `t2` section at slot `compact_index(world)`, where the compact index is the exclusive scan of the mask;
capacity is ⌈p·worlds⌉ plus a margin of 4 standard deviations of the binomial count, and at least 8. A traced
world beyond capacity becomes a gap, never an overwrite.

**6. The statistics ring.** One slab, double-buffered by device-chunk epoch: sections `t0`, `t1`, `t2`,
run-level histogram bins, the per-world digest and digest chain. The host holds a read lease on epoch e − 1
while the device writes epoch e. Kernel class `stat`: these kernels read state and write only the ring;
nothing in the ring is ever read by a state-writing kernel (the rule that statistics never feed state).

**7. Host drain at each device commit.** After the receipt of device chunk e: read the ring's epoch e slot under
its lease; add run-level bins into 64-bit totals (the wide-count drain); append T1 events and T2 rows to the
open column buffers of each (world, episode, stream); copy completed T0 rows. When a world's logical chunk is
complete (its T0 row for index i arrived), close the column files of that chunk for each stream, hash them, and
publish them through the publishing transaction in index order, with `state_digest` from the ring. A retried
device chunk (after a failed command buffer) is drained once: the drain is keyed by (epoch, attempt) and a
replayed epoch replaces, never adds.

**8. Channel declarations.** `registries/channels/<robot-class>.toml`: per channel its stream, kind, unit,
frame, sampling, quantum, range, `envelope`, `histogram` (none, per-world, run-level), level and the
visible-or-privileged label. Defaults for the reference quadruped and humanoid are part of this bead (joint
torque: quantum 0.01 N·m, run-level histogram; friction utilization: quantum 2⁻¹⁰, run-level histogram; base
height: quantum 0.1 mm, envelope).

**9. Layout.** `crates/frob-chronicle/src/device/{ring.rs, drain.rs, assemble.rs, channels.rs}`;
`crates/frob-kernels/src/stat/{k_stat_t0.rs, k_stat_events.rs, k_stat_t2.rs}` with dialect twins.

## Acceptance criteria

- [ ] Seed done-condition, with N29a-16: GATE-CHRON-07 (TARGET): INV-CHRON-05 and INV-CHRON-06 hold over 100
      permutations, shard splits and co-tenancies on `batch-cpu`, CUDA and Metal; weighted estimates from the
      traced stratum recover a planted population mean inside the exact interval.
- [ ] Seed done-condition, with N29a-17: GATE-CHRON-13 (TARGET): T0 and T1 on every world cost at most 3% of
      step time, and T2 on a 1% sample at most 2% more, on the reference quadruped workload with the full
      disclosure block.
- [ ] Physics digests of a run are identical with telemetry at T0 only, at T0 + T1, and at T2 on any sample
      (telemetry never feeds state).
- [ ] The T0 rows, T1 events and T2 columns of a job on `batch-cpu` and on each device are identical where the
      device attains the bitwise class, and the T0 integer aggregates are identical in every case.
- [ ] Every world has a contiguous committed frontier on every stream it records; a forced event-buffer
      overflow produces a gap with reason `ring-overflow` and a refusal of the dependent metric.
- [ ] A device chunk retried after an injected command-buffer failure is drained exactly once (bin totals equal
      the unfaulted run's).
- [ ] The traced mask on the device equals the host's selection for every world, including after a slot takes
      a new episode.
- [ ] No kernel of class other than `stat` reads the ring (manifest check).

## Test plan

### Unit tests

- `mask_matches_host_selection`: 8,192 worlds, p = 1/100, 3 episodes per slot.
- `t0_chunk_rows_at_boundaries`: L = 256, a 700-tick episode yields T0 rows at ticks 256, 512 and 700.
- `envelope_in_kernel_equals_host`: the in-kernel min and max equal those computed from a full T2 trace.
- `events_deterministic_order`: two worlds with simultaneous contact events; order by feature key; equal under
  slot permutation.
- `event_overflow_is_gap`: 100 events in a buffer of 64: 64 stored, dropped count 36, gap recorded.
- `t2_compact_index_is_scan_of_mask`; `t2_capacity_overflow_is_gap`.
- `drain_once_per_epoch`: an epoch delivered twice (retry) changes totals once.
- `assemble_publishes_in_index_order`: T0 rows arriving for chunk 1 before chunk 0 of another world do not
  reorder a world's own sequence.
- `stat_kernels_write_only_ring` (manifest footprint).
- `digests_unchanged_by_telemetry_level`: three telemetry settings, equal run digests.

### End-to-end script and logging

`scripts/e2e/telemetry_sampling_histograms.sh` (N29a-16) and `scripts/e2e/telemetry_cost.sh` (N29a-17) drive
this bead from the user's side: `frob sim run --tier gpu-cuda|gpu-metal|batch-cpu --worlds 8192 --telemetry T2
--trace-rate 1/100 …`, then `frob telemetry query`, `frob telemetry histogram` and `frob run show`. Lines
carry the placement receipt, the telemetry level, per-stream chunk counts, frontier, gap counts, aggregate
digests and the physics run digest for each telemetry setting.

### Known answers and negative controls

- KA-713 (traced set identical under 100 slot assignments and shard counts) and KA-714 (histogram counts
  identical under 100 permutations and shard splits, on every backend), as wired through the device path.
- Negative controls: a `t2` writer indexed by arrival (the set of traced worlds changes with slot order); an
  event buffer that drops silently; a drain that adds on retry; a statistics value read back into a reward
  (the manifest check must refuse the plan); telemetry code that reorders a state reduction (the digest
  comparison across telemetry levels catches it).
- Metamorphic relations: permuting world indices permutes results and changes nothing else; adding inactive
  worlds or unused capacity changes no active world's digest; MR-32.
- Determinism lanes: twice on one device; across worker counts on `batch-cpu`; debug and release; across
  backends, each against its class (integers D0; floating T2 columns D1 where attained, otherwise D3).

## Considerations

- OPEN-CHRON-2 (owner: Chronicle lead): the logical chunk length (default 256 control ticks) is independent of
  the device chunk length (the shorter of one rollout segment and the number of control intervals that fit a
  250 ms cancellation latency at the 99th percentile). A logical chunk spans several device chunks; nothing
  here assumes they align.
- If the cost gate fails, the first lever is the digest and envelope cadence (every control tick against every
  physics step), then per-world histograms on fewer channels; each lever is measured one at a time with
  identical physics digests as its behaviour proof.
- Foundry load extraction, the noninterference test and stills all read T2 produced here.
- On Metal all storage is shared and readback is a host copy after completion; on CUDA it is an explicit
  stream-ordered copy. Neither is "zero copy" and neither needs to be: the ring is small.
