## Background

A run lives in two places: its metadata in the ledger and its bulk data in content-addressed column files. To
leave the machine that produced it (for the offline auditor, for another host, for the replay viewer, for
calibration against a real log) it must become one self-describing object. That object is the `.frun` bundle
(format `FMT-FRUN`, schema `frob.run/1`): a manifest in canonical JSON plus the column files it names. A `.frun`
is readable with no device and no daemon, and the offline auditor checks its hashes and chains with the standard
library alone. This bead is the verb that writes it: `frob run export <run>`, registry name `run.export`, kind
`run`, first milestone M1.

The byte format and its reader and writer functions belong to the schema bead (BD-090); this bead adds the
user-facing operation, which has three questions the format does not answer: *which* chunks are in the bundle
(a run may still be publishing), *where* the bundle may be written, and what a "view" is.

Design decisions:
- **The export is pinned to a committed frontier.** A bundle of a running job taken without a pin could hold
  chunk 7 of one stream and not chunk 6 of another committed a moment earlier. The export fixes the run's commit
  sequence number at the start and contains exactly the chunks committed at or below it. Rejected: exporting
  "whatever is on disk", which is not reproducible and can include files of an uncommitted publish.
- **A view is not an identity.** Array files and summaries are conveniences derived from the canonical bundle.
  They carry the hash of the bundle they came from and can never be hashed, signed, cited as evidence or used as
  a cache key.

## Scope

In: the verb, its schemas and registry entry; frontier pinning; bundle assembly; the view option; destination
rules; privacy and licence checks; idempotency; cancellation; the envelope.
Out: the format, its reader, writer and `verify` (BD-090); the offline auditor's independent check (N29a-03);
`artifact.export` of single objects (BD-097); the self-contained HTML replay `telemetry.export-html` (N24a-41,
M2); the evidence-graph recording function it calls in step 7 (BD-095).

## Technical approach

1. **Registry entry.** The row is VERBS-run's and this bead implements it without redefining it: `kind = "run"`,
   `idempotent = false`, capabilities `run:run` and `export:report` (plus `private:export` for a private run),
   schemas `frob.run.export.in/1` and `frob.run.export.out/1`, the `--estimate` cost model, the `run` wait, owner
   `frob-chronicle`, `exports = true`, evidence *pass-through*, and the row's chapter refusals FROB-REF-731,
   FROB-REF-733, FROB-REF-734 (destination), FROB-REF-816, FROB-REF-840, FROB-REF-888 and FROB-REF-892, all
   raised by this handler, beside the surface's FROB-REF-802 and FROB-REF-805. The row's eighth code,
   FROB-REF-883 (N30-REF, entered at M1), is raised by the sealed store's read guard (BD-387, M5) when an
   export would read a sealed validation or holdout chunk of a grounding dataset; this handler reaches it
   through the store read and raises nothing of its own for it. Exit codes are the registries': 731, 733, 734
   and 840 exit 5 (840 is outside the session's scopes, N24-REF); 802, 805, 816, 883, 888 and 892 exit 3; an
   integrity fault exit 9.
2. **Input.** `run` (identifier, resolved to an immutable `RunId` and echoed in `bound`); `out` (a path under
   the session's export root); `worlds`, `episodes`, `streams` (optional filters; the default is everything);
   `view` (absent for the canonical bundle; `arrays` or `summary` for a view); `at_frontier` (optional commit
   sequence number as a string; default: the current one); `idempotency_key`; `sync_wait_ms`. When `out` names a
   directory (it exists as one or ends in `/`, as in the registry's example `--out exports/`), the bundle is
   written inside it as `<first 16 hex digits of the RunId>.frun`, or `….<view>` for a view (DESIGN).
3. **Algorithm.**
   1. Refuse a sealed confirmation run (FROB-REF-840).
   2. Compute the privacy mark and licence set of the run as the join over its inputs (scene, design, policy),
      then check in the order of the export door of N37-18 (flags, privacy, licence, then the path in step
      3), so that the door, which replaces these handler checks at M3, changes no answer: an input artifact of
      the run whose three authorization flags are missing or not the literal `false` is FROB-REF-816 (the
      bundle would carry flags it cannot vouch for; the check is `frob_core::auth::check_carried` of N37-23,
      and the manifest's `/authorization` object is the carrier that N37-23's locator row for `run.export`
      names); a private run without the `private:export` scope and the explicit flag is FROB-REF-731; a
      licence set that forbids export is FROB-REF-733.
   3. Open the destination through the retained directory handle of the export root; a path that escapes it by
      `..`, an absolute path or a swapped link is FROB-REF-734. Write to a temporary name in the same directory.
   4. Pin: read the run's commit sequence number P (or take `at_frontier`). Select the chunk rows with
      `commit_seq ≤ P` that pass the filters; for each (world, episode, stream) record the frontier index at P.
   5. Write the manifest: run identity; model, scene, task and policy identities; kernel versions, tier,
      determinism class and effort profile; the chunk length; channel schemas; the chunk index with content
      hashes and chain digests; the frontier per (world, episode, stream) at P; every gap with its reason;
      `origin` (`sim`); the pin P; and the three no-authorization flags, all the literal `false`. Integers that
      can exceed 2⁵³ (ticks, sequence numbers, digests) are strings.
   6. Copy each selected column file, recomputing its BLAKE3 while copying; a file whose hash differs from its
      name is an integrity fault (exit 9) and the export is abandoned.
   7. Run `frun::verify` on the temporary bundle; rename it into place; record an `evidence` node of kind
      `chunk range` for the bundle so that it can be cited.
   8. A filtered export is still canonical for what it contains: the manifest lists the filter, and chains are
      complete from index 0 for every included (world, episode, stream). A filter that would cut a chain (a tick
      sub-range) is offered only as a view.
4. **Views.** `--view arrays` writes one array file per stream with a sidecar naming the source bundle hash,
   channel kinds and units; `--view summary` writes the token-budgeted summary as JSON. Each view's header
   carries `view_of: <bundle hash>`. Offering a view where an identity is required is FROB-REF-892.
5. **Idempotency.** As a `run` verb it needs a key (FROB-REF-805 without one). The same key with the same
   resolved request returns the stored receipt with `idempotent_replay: true` and does not rewrite the file. Two
   exports of the same run at the same pin with the same filters produce byte-identical bundles.
6. **Cancellation.** Checked between column files: the temporary directory is removed and nothing appears at
   the destination.
7. **Envelope.** `result`: `bundle` (path relative to the export root), `bundle_hash` (BLAKE3 over the manifest
   bytes followed by the content hashes in index order), `pin`, `chunks`, `bytes`, `gaps`, `filters`, `view`.
   `authorization`: the three flags, all `false`. `evidence` (*pass-through*): the run's own class, tier and
   determinism class; `claims: []`. Exit 0; exit 2 when the bundle contains gaps (a finding, listed).

## Acceptance criteria

- [ ] A referee run exported, read back with BD-090's `.frun` reader on a machine with no device and no daemon
      and written again gives byte-identical bundles; `frun::verify` (BD-090) accepts both. (The independent
      auditor `frob-verify` is N29a-03's, not a dependency; N29a-08's script runs it on these bundles.)
- [ ] An export started while the run is still publishing contains exactly the chunks at or below its pin; a
      chunk committed during the copy is absent and the manifest's frontier says so.
- [ ] Two exports at the same pin and filters are byte-identical; the second call with the same key writes
      nothing and returns `idempotent_replay: true`.
- [ ] A destination of `../x.frun`, an absolute path, and a link swapped to another directory after the check
      are each refused with FROB-REF-734 and nothing is written outside the export root.
- [ ] A private run is refused without scope and flag (FROB-REF-731, exit 5); a sealed confirmation run is
      refused (FROB-REF-840, exit 5); a run with an input whose authorization flags are missing is refused
      (FROB-REF-816, exit 3); a licence that forbids export is refused (FROB-REF-733, exit 5); a run that fails
      several of these checks answers the first in the door's order (816, 731, 733, 734).
- [ ] A view file names its source bundle hash and is refused as evidence (FROB-REF-892).
- [ ] A cancelled export leaves no file at the destination and no temporary directory.
- [ ] The envelope carries the authorization block with three `false` flags; the verb is reachable over MCP as
      `run_export`.

## Test plan

### Unit tests

- `pin_excludes_later_chunks`: a `synthetic` run with 6 committed chunks; pin taken; 2 more committed; the
  bundle has 6 and its frontier fields are those at the pin.
- `export_is_deterministic`: same pin and filters, two processes, byte comparison.
- `filter_keeps_chains_whole`: `--streams kinematics --worlds 0,2` yields complete chains from index 0 for the
  two selected (world, stream) pairs, (0, `kinematics`) and (2, `kinematics`), and none for the others.
- `tick_subrange_is_view_only`: a tick filter without `--view` is FROB-REF-802 naming the pointer.
- `column_hash_checked_on_copy`: one flipped byte in a stored column file gives exit 9 and no bundle.
- `path_jail_cases`: the three escape attempts; `private_requires_scope_and_flag`; `sealed_run_refused`.
- `input_flags_816`: a run whose scene artifact lacks `execution_authorized` is refused with FROB-REF-816;
  `licence_733`: a `research-only` design input is refused with FROB-REF-733.
- `export_checks_in_door_order`: a private run with a `research-only` design input whose scene artifact lacks
  `execution_authorized`, exported without the private scope, is refused with FROB-REF-816; with the flags
  restored, FROB-REF-731; with the scope and flag given, FROB-REF-733 (a handler that checks privacy first fails
  the first case).
- `out_directory_names_bundle`: `--out exports/` writes `exports/<16 hex>.frun`; `--out exports/a.frun` writes
  that file.
- `view_carries_source_hash`; `view_refused_as_identity_892`.
- `cancel_removes_temporary`; `gaps_listed_exit_2`.

### End-to-end script and logging

Steps `export-*` of `scripts/e2e/chronicle_record_surface.sh` (N29a-08; the group calls only this bead's verb
and its dependencies, the offline check by `frob-verify` being that script's `verify-*` group of N29a-03):
on the run of the script's `run-*` group (`frob sim run g1 --tier referee --worlds 3 --seconds 6 --telemetry T2
--seed 7 --key r1 --json`), `frob run export <run> --out exports/a.frun --key e1 --json`, the same again with `--key e2` to `b.frun`, a byte
comparison, then the three path-escape attempts expecting exit 5 with
FROB-REF-734, and `frob run export <run> --out exports/ --key e3 --json` asserting the directory form's file name. Lines carry the command, exit code, wall time, evidence and authorization blocks, the bundle hash,
the pin, and on failure the first differing chunk key with both hashes.

### Known answers and negative controls

- Negative controls: the flipped byte; the swapped link; the view offered as identity; a build that exports
  without a pin (the concurrent-publish test must catch it by finding a chunk above the recorded frontier).
- Metamorphic: export → import → export is the identity on bytes; export with all filters named explicitly
  equals the default export.
- Determinism lanes: twice on one machine; debug and release; the Mac and the Linux host (bytes are class D0).

## Considerations

- Telemetry derived from a private scene inherits the scene's privacy class through export; the join is
  computed, never typed in by the caller.
- A bundle is evidence only together with its hash; the export records that hash in the artifact graph so that
  a later citation can be checked against retention (a collected chunk makes the citation fail with its reason).
- Column compression is an open question (default: uncompressed quantized columns, no third-party codec);
  a later codec is a new minor format version and does not change this verb.
- Bundles of long device runs are large; the estimate (`--estimate`) reports bytes before anything is written.
