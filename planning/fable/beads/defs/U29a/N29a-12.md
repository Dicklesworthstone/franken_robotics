## Background

Control-rate traces (telemetry level T2) and full-state snapshots (T3) cannot be kept for every world of a batch
of thousands. A sample of worlds is traced. How the sample is chosen matters more than it looks. The usual
method, a reservoir filled in the order worlds finish, makes the sample depend on scheduling: which slot ended
first, how the batch was sharded, who else was running. Such a sample cannot be recomputed at replay and is not
the same for the two arms of a comparison.

**ADR-CHRON-04: worlds are chosen for tracing by address, never by arrival.** Reason: a sample that depends on
which slot finished first is not replayable and is not the same for two arms of a comparison.

The sample is chosen by a hash of the world's address:

```
h(w) = Philox( key = run_seed,  counter = (world, episode),  stream_id = "telemetry-sample" )   as u64
fixed rate p     trace w  iff  h(w) < ⌊p · 2⁶⁴⌋
fixed size k     trace the k worlds with the smallest h(w)
```

The stream identifier is its own, so the choice is independent of every random draw the physics makes. The
fixed-size form is a reservoir sample without the usual dependence on arrival order: the k smallest hashes of a
set are a uniform sample of size k without replacement, and the k smallest of a union are the k smallest of the
per-shard k smallest, so shards merge exactly. Four properties follow from the sample being a pure function of
addresses: replay needs no record of the choice, it recomputes it; two designs compared on the same addresses
are traced in the same worlds, so every traced pair is a pair; co-tenancy, slot assignment, preemption and
shard count cannot change it; and inclusion probabilities are known, so population estimates from traced worlds
are weighted. Tier Solid.

## Scope

In: the hash with test vectors; the two selection rules in exact integer arithmetic; the manifest fields
`trace.rate` and `trace.size`; the shard merge; the per-world trace mask handed to the device; inclusion
weights and the stratified estimator; proofs on file; property tests.
Out: emitting T2 and T3 for the chosen worlds (BD-207, N29a-11); the Philox kernel itself (BD-180); the
background referee's own sample, which uses the same construction under another stream identifier (another
unit); the gate's cross-backend run (N29a-16).

## Technical approach

**1. The hash.** Philox 4×32 with 10 rounds as the addressed-draw bead provides it. Key words: the low and high
halves of `run_seed`. Counter words: (`world`, `episode`, the registered 32-bit identifier of the stream
`telemetry-sample`, 0). h(w) = out₀ + 2³²·out₁. It is 32-bit integer arithmetic, class D0 on every backend.
Three test vectors (seed, world, episode → h) are frozen in `tests/fixtures/sample/vectors.toml` at first
implementation and never regenerated from a later build.

**2. Manifest fields.** Exactly one of `trace.rate` (a rational p = a/b with 0 ≤ a ≤ b) and `trace.size` (an
integer k ≥ 0) is set; the default is `trace.rate = 1/100` (DESIGN, the sample of the telemetry cost gate).
Both fields enter the run's identity. On the surface they are two inputs of `sim.run`, `--trace-rate <a/b>`
and `--trace-size <k>` (their row in VERBS-sim names this bead the owner, M2, with the default rate 1/100 and
the manifest fields `trace.rate` and `trace.size`; this bead adds them to the verb's input schema). Giving both, a rate that is not a
rational in [0, 1], or a negative size is FROB-REF-802 (the schema refusal), exit 3; neither option changes
the telemetry level, which `--telemetry` sets.

**3. Fixed rate.** Threshold T = ⌊a·2⁶⁴ / b⌋ computed in 128-bit integers. Trace iff h(w) < T; for p = 1 every
world is traced without a comparison (T would be 2⁶⁴). On a device the test is two `u32` comparisons in an
exact kernel, with the two words of T in the step-plan header.

**4. Fixed size.** The traced set is the k admitted addresses with the smallest (h(w), world, episode) in
lexicographic order (the address breaks a tie of hashes, which has probability about 2⁻⁶⁴ per pair and must
still be deterministic). The set of admitted addresses is known at admission from the manifest (worlds ×
planned episodes), so the host computes the k-th smallest key once and hands the device the same kind of
threshold as the fixed rate, with the tie rule folded in as a 128-bit bound.

**5. Shard merge.** `merge(a, b, k)` = the k smallest keys of the union of two per-shard k-smallest lists. It is
commutative and associative, and merging the lists of any partition of the addresses gives the k smallest of
the whole. Used when shards admit episodes independently (a follow-on job, a resumed run).

**6. Failing worlds.** Every failing world is traced in full from its ring buffer whatever its hash. The record
marks each traced episode with its stratum: `sampled` or `failing-only` (failing and not in the sample).

**7. Weights and the stratified estimator.** Let N be the number of admitted worlds, F the failing worlds, S
the sample. For a per-world quantity y available only from traces:
- fixed rate: Ŷ_total = Σ_{w ∈ F} y_w + (1/p)·Σ_{w ∈ S∖F} y_w;
- fixed size: Ŷ_total = Σ_{w ∈ F} y_w + (N/k)·Σ_{w ∈ S∖F} y_w;
- the mean is Ŷ_total / N.
Failing worlds form a stratum of weight one, and the estimate over all worlds is the stratified sum of the two.
Each non-failing world is included with probability p (or k/N), independent of y, so the second term is
unbiased for the total over non-failing worlds. Weights are exact rationals; every estimate carries its
strata sizes |F|, |S∖F| and N, and an estimate from an empty sampled stratum is refused, not reported as zero.

**8. Derivation on file** (`docs/derivations/chronicle-k-smallest-uniform.md`, the file of KA-713 written by the
registry bead N29-KA; this bead's tests cite it and may extend it, never contradict it): for independent identically
distributed continuous hashes every ordering of the N worlds is equally likely, hence the set of the k smallest
is uniform over k-subsets; the k smallest of A ∪ B are contained in (k smallest of A) ∪ (k smallest of B).

**9. The traced set as a value.** `sample::traced_set(manifest) -> Vec<(WorldAddr, Stratum, Weight)>`, sorted by
address, computed from the manifest alone (plus the failing worlds from the run's T1 events for the
`failing-only` stratum). It is what replay, the gate bead and any reader use; no reader reconstructs the set from
which chunks happen to exist. The function and its surface already exist when this bead starts: the query
bead N24a-36 (M1, a prerequisite of this bead through BD-094) added `sample::traced_set` with its M1 body
(every world of the manifest, stratum `all`, weight 1, when the run's level includes T2; empty otherwise) and
exposed it as the option `--traced-worlds` of `telemetry.query`. This bead **replaces that body** with the
address-keyed selection of steps 1 to 7 (strata `sampled` and `failing-only`, weights 1/p or N/k for the
sampled stratum and 1 for failing worlds) and changes neither the signature nor the option. A manifest
recorded before the trace fields existed carries neither of them: for it the function keeps the M1 answer
(every world, stratum `all`, weight 1), so the M1 records and their golden outputs do not change. The step
group below reads the set through the option.

**10. Layout.** `crates/frob-chronicle/src/sample/{hash.rs, select.rs, merge.rs, weight.rs}`.

## Acceptance criteria

- [ ] INV-CHRON-05 (the set of traced worlds is a pure function of the run manifest and the addresses): for
      1,000 manifests the traced set recomputed from the manifest alone equals the set a run recorded.
- [ ] The traced set is identical under 100 slot assignments and 100 shard counts of the same addresses.
- [ ] PO-CHRON-03, uniformity: over 10⁶ draws (run seeds), the inclusion frequency of each of 64 worlds under
      k = 8 lies inside the exact binomial bounds for probability 1/8 at a family error of 10⁻³.
- [ ] PO-CHRON-03, merge: for 10⁴ random shard splits the merged per-shard lists equal the global k smallest.
- [ ] Two designs run on the same addresses with the same manifest trace exactly the same worlds.
- [ ] The threshold arithmetic is exact: p = 1/3 gives T = ⌊2⁶⁴/3⌋ = 6,148,914,691,236,517,205; p = 0 traces
      nothing; p = 1 traces everything.
- [ ] The stratified estimator recovers a planted population total within the exact interval (see tests); an
      empty sampled stratum is refused.
- [ ] Setting both manifest fields (`--trace-rate` with `--trace-size`), or a rate outside [0, 1], is the
      schema refusal FROB-REF-802, exit 3.
- [ ] `sample::traced_set` keeps the signature N24a-36 gave it and `telemetry.query --traced-worlds` keeps its
      output shape; on an M2 run the strata are `sampled` and `failing-only` with their weights.

## Test plan

### Unit tests

- `hash_vectors`: the three frozen vectors.
- `hash_independent_of_other_streams`: registering an extra stream changes no h(w).
- `fixed_rate_threshold_exact`: p ∈ {0, 1/3, 1/100, 1}; the three values above; for p = 1/100,
  T = 184,467,440,737,095,516.
- `fixed_rate_fraction`: for 10⁶ addresses at p = 1/100 the traced count lies within 10,000 ± 520 (mean
  10,000, standard deviation √9,900 = 99.5, so 5.2 standard deviations; the binomial tail outside is below
  10⁻⁶).
- `fixed_size_exactly_k`: N = 8,192, k = 82 gives 82 worlds; k > N gives all N.
- `tie_break_by_address`: with a mutated hash that returns a constant, the k smallest addresses are chosen.
- `slot_and_shard_invariance` (KA-713): 100 permutations of slot order and shard counts 1 to 16.
- `merge_associative_commutative` and `merge_equals_global` (property, 10⁴ splits).
- `arrival_order_reservoir_differs` (control of KA-713, CX-325): a classical reservoir fed in two arrival
  orders returns two different sets on the same addresses.
- `uniformity_binomial_bounds`.
- `stratified_total_unbiased`: N = 10,000 non-failing worlds of which M = 2,000 have y = 1, 137 failing worlds
  with y = 1, p = 1/10: over 1,000 run seeds the mean of Ŷ_total is within 3 standard errors of 2,137, and each
  seed's sampled count of ones lies in the exact binomial interval for (M, p) at error 10⁻⁶.
- `fixed_size_weights`: N = 1,000, k = 50: weight 20.
- `empty_stratum_refused`.
- `traced_set_from_manifest_only`: the function's output for a recorded run equals the set of worlds with
  `sampled` T2 chunks, and is computed without opening any chunk.
- `traced_set_body_replaced_not_reshaped`: the M1 golden output of `--traced-worlds` (N24a-36's referee
  fixture, whose manifest has no trace field) is reproduced byte for byte; the same scene recorded with
  `trace.rate = 1/4` returns the address-keyed quarter with stratum `sampled` and weight 4 under the same
  output schema.
- `trace_options_schema`: `--trace-rate 1/100` and `--trace-size 82` each set their manifest field; both
  together, `--trace-rate 3/2`, `--trace-rate 0.01` (not a rational a/b) and `--trace-size -1` are
  FROB-REF-802.

### End-to-end script and logging

Step group `sample-*` of `scripts/e2e/telemetry_sampling_histograms.sh` (N29a-16): the same job is run on
`batch-cpu` alone, in two shards, and co-batched with another job; `frob telemetry query <run> --traced-worlds
--json` must return the same address list each time, equal to the list the script computes independently from
the manifest with a small reference implementation. Lines carry the manifest's trace fields, N, the traced
count, the digest of the sorted address list and, on failure, the first address present in one list only.

### Known answers and negative controls

- KA-713: the traced set is identical under 100 slot assignments and shard counts (exact; G5 · all tiers).
  Negative control: arrival-order reservoir sampling gives different sets. CX-325 is the same case in the
  counterexample catalogue.
- Metamorphic relation MR-32: address-keyed trace sampling is invariant under permutation, shard split and slot
  assignment.
- Further mutants: a hash that includes the slot index; a threshold computed in `f64` (p·2⁶⁴ rounds; the
  p = 1/3 vector catches it); weights applied to failing worlds as well (biases the total upward).
- Determinism lanes: the hash on `batch-cpu`, CUDA and Metal gives identical words (class D0), exercised by the
  gate bead.

## Considerations

- Paired comparisons rely on this bead: because both arms trace the same worlds, a trace-derived difference is
  a paired difference.
- The background referee uses the same construction with its own stream identifier and probability, so its
  sample is independent of this one by design and both are replayable.
- A fixed-size sample needs N at admission. Under slot dispatch with open-ended episode streams only the
  fixed-rate form is admissible; requesting `trace.size` there is refused at admission.
- A traced world costs T2 bytes at control rate; the default rate of 1/100 is the rate at which the telemetry
  cost gate is measured.
