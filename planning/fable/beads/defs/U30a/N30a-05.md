## Background

Ground (crate `frob-ground`) calibrates simulation against measurement. Its estimators are not written here: the
sibling project FrankenSim already ships checked estimators, and decision ADR-GROUND-08 says they are reached
through the airlock (the one crate, `frob-fsim`, through which sibling code enters the build) **as whole jobs**,
and that every Ground output has evidence class Estimated, because the siblings expose estimated candidates only
and require an external authenticated authority for more. What the siblings do not have is any robotics: joints,
actuators, trajectories, regressors, delay estimation, identifiability, the cell, the sealing protocol.

FACT, read at FrankenSim commit `483d09c682` (paths under `frankensim/crates/`; line counts approximate):

| Crate | Provides | Missing for Ground |
|---|---|---|
| `fs-assimilate` (about 13,000 lines, layer L4, depends on `fs-qty`) | A Gaussian `Belief` and linear `Observation` with sequential Kalman fusion (`assimilate`, `assimilate_all`; dense state at most 256, at most 4,096 observations per call). `assimilate_colored`: an estimated candidate tied to a validity regime, with misfit before and after. A UD-factor update with an interval-checked contraction receipt (`factor`). Linear and finite-difference extended-Kalman prediction (`factor::forecast`). Three consequences. (1) The siblings give Ground its estimators, receipts and refusals, and none of its robotics.
(2) Both crates depend on the units crate `fs-qty`, whose nightly-toolchain coupling is a named program risk
tested by the toolchain integration test; Ground's jobs are whole jobs of seconds to minutes, so the airlock's
worker-process fallback costs them nothing. (3) Three upstream work items exist in FrankenSim's repository.

## Scope

In: job request and response types for both crates; pre-checks of every cap; receipt retention; the two
execution modes; the fact re-check tests; interim postures for the three upstream items. Out: the adapters to
`fs-uq`, `fs-eproc` and `fs-voi` (N30a-06); the measurement models that fill these jobs (the identification
and as-built beads); the upstream work itself (`FD-FSIM-23`, `-24`, `-25`, done in FrankenSim under its rules).

## Technical approach

1. **Jobs** (DESIGN, `crates/frob-ground/src/sibling/`). Each call is a serializable request and response, so it
   runs in process through `frob-fsim` or out of process through the worker binary `frob-fsim-worker` with
   identical bytes: `KalmanJob` (belief, observations, groups), `IteratedJob` (prior, rows, the model callback
   replaced by a table of model evaluations and Jacobians supplied by Ground, loss `Gaussian | Huber{k}`,
   correlated-noise blocks), `EnsembleJob` (prior ensemble, predicted observations per member, blocks, lag),
   `Register3Job` (fiducial pairs, weights, `Rigid | Similarity`), `DatumJob`, `FieldJob`, `PropagateJob`,
   `WellPosedJob`, `StreamDesignJob` (candidate probes with their rows, costs and shared groups, budget).
   The mode is chosen per process by the environment variable `FROB_AIRLOCK`, defined here and read by the
   adapter at its first sibling call: `inproc` (the default) or `worker` (the job's canonical bytes go to
   `frob-fsim-worker`, built by N33c-12's `scripts/build/worker.sh`, BD-038's fallback); any other value is a
   typed configuration error, and the mode is written into every stored receipt. The Ground scripts and tests
   that run their sibling calls in both lanes use this variable.
   Because a job crosses a process boundary, model evaluation is done on Ground's side: the
   iterated update is driven as an outer loop in which Ground evaluates the simulator and hands residuals and
   Jacobians to the sibling's step (DESIGN; if the sibling's API takes only a closure, the worker hosts a
   closure that reads Ground's evaluation table).
2. **Pre-checks as typed errors**, before any sibling call: state dimension ≤ 256; observations per call ≤ 4,096;
   iterated rows ≤ 256, iterations ≤ 256, evaluations ≤ 65,536; shared parameters ≤ 64; stream rows ≤ 4,096;
   quantities of interest ≤ 64; scan points ≤ 10⁶; fiducials ≥ 3 and non-collinear. A violated cap returns
   `GroundError::SiblingCap { crate, cap, observed }` with the windowing or splitting repair, never a truncated
   call.
3. **Receipts.** Every sibling receipt (contraction receipt, finite-difference receipt, audit receipt of a
   censored batch, misfit before and after, validity regime, unit-suspicion diagnostic, sigma-point downgrade)
   is stored verbatim as an artifact and referenced from the calibration record or the as-built record.
4. **Class.** Responses are wrapped by `GroundResult::estimated`; the sibling's own "estimated candidate" label
   is preserved in the wrapper. Nothing here can raise a class (OPEN-GROUND-5 default: nobody can promote).
5. **Upstream items, interim posture and switch-over.**
   - `FD-FSIM-23` (a windowed or streaming entry to the iterated update beyond 256 rows; priority P3). Interim:
     traces enter as windows of summary features, and the window definition is part of the calibration record.
     Switch-over test: re-fit one recorded dataset both ways and compare posteriors.
   - `FD-FSIM-24` (a cross-ISA statement for the ensemble lane; P3). Interim: ensemble results are recorded with
     the machine fingerprint and are not compared across machines. Switch-over: re-run the replay known answers
     of the synthetic rehearsal on a second machine and record the comparison in the calibration record.
   - `FD-FSIM-25` (a correspondence-search lane in `fs-asbuilt`; P3). Interim: datums and fiducials are placed
     at design time so correspondences are known. Switch-over: re-run the as-built known answers without
     fiducials.
6. **Fact re-check.** The table above was read at one commit. At the commit pinned in `franken-stack.lock`,
   `crates/frob-ground/tests/sibling_facts.rs` asserts each stated behaviour and cap (list below). A fact that
   no longer holds is recorded in `CONTRACT.md` ("known gaps") with the pin, and the dependent bead is told.
7. **First-use admission at the M5 pin.** An admission is never inherited: the airlock's group gates were recorded for other consumers at earlier pins, and each crate is probed again at the milestone that first calls it, by the bead that calls it.
   This bead runs, at the commit pinned for M5, the first-use probe that the airlock's stats-group bead
   supplies for `fs-assimilate` (prior N(0, 1) and one observation y = 1 with unit noise variance give
   posterior mean ½ and variance ½; a negative variance is refused), the group gate of the structure group for
   `fs-asbuilt` (INT-FSIM-15), and the fact re-check of step 6 for the functions Ground calls: `fs-assimilate`
   (`assimilate`, `assimilate_all` and the dimensioned front door; `nonlinear::iterated` with its Huber fit;
   `groups`; `groups::stream::design`, the cost-budgeted measurement plan that excitation selection uses when
   instruments share a calibration error (N30a-17); `nonlinear::ensemble` behind its feature) and `fs-asbuilt`
   (`rigid3`, `datum`, `field`,
   `propagate`, `uncertainty`, `well_posed`). It writes one admission record per crate in
   `DEPENDENCY_ADMISSION.md` in the admission-record schema (commit, command, output hash, receipt hash, the
   functions covered, recorded limits). A Ground mechanism that calls a sibling function with no such record
   is refused by the adapter with the airlock's not-admitted refusal.

## Acceptance criteria

- [ ] Every job type round-trips through serialization and gives byte-identical responses in process and through
      the worker on one machine.
- [ ] Each cap is pre-checked: a 257-dimensional state, 4,097 observations, 257 iterated rows, 257 iterations,
      65,537 evaluations, 65 shared parameters, 4,097 stream rows, 65 quantities of interest and 10⁶ + 1 points
      each return `SiblingCap` without calling the sibling; two fiducials, or three collinear ones, are refused
      before the call.
- [ ] `FROB_AIRLOCK` selects the lane: unset or `inproc` runs in process, `worker` runs through
      `frob-fsim-worker`, another value is refused, and each stored receipt names the lane.
- [ ] Every fact in the two table rows has a passing re-check test at the pinned commit, or a recorded delta.
- [ ] Ensemble responses carry the machine fingerprint; a comparison across fingerprints is refused by the
      adapter with a message naming `FD-FSIM-24`.
- [ ] No response type exposes a class above Estimated.
- [ ] `DEPENDENCY_ADMISSION.md` holds an admission record at the M5 pin for `fs-assimilate` and for
      `fs-asbuilt`, each listing the functions Ground calls; a call to a function with no record is refused.

## Test plan

### Unit tests

`crates/frob-ground/tests/sibling_facts.rs` (real sibling code, no mocks): `kalman_scalar_fusion` (prior N(0, 4),
one observation 2 with variance 4 gives mean 1, variance 2); `state_cap_256`; `obs_cap_4096`;
`iterated_caps_256_256_65536`; `huber_downweights_planted_outlier`; `common_mode_floor` (1,000 samples with
σ = 1 sharing a bias of standard deviation 0.5 give a posterior standard deviation of at least 0.5, not
1/√1000); `groups_caps_64_and_4096`; `stream_design_conditions_on_shared_nuisance` (probe A reads θ directly
with σ = 1; probe B reads θ with σ = 0.1 through a shared bias of standard deviation 2; budget one probe: the plan
picks A, posterior variance of θ under a flat prior 1 against 4.01 for B; a plan that ignores the group would
pick B);
`ensemble_feature_gated`; `ensemble_same_machine_bitwise`;
`register_needs_three_noncollinear` (two fiducials refused; three collinear refused);
`rigid3_recovers_planted_pose` (rotation 10° about z, translation (1, 2, 3) mm, noise 0, exact to 10⁻¹²);
`similarity_scale_25_4_raises_unit_suspicion`; `pose_covariance_is_6x6_psd`; `propagate_cap_64`;
`sigma_point_downgrade_on_strong_nonlinearity`; `well_posed_screen_rejects_signal_below_residual`;
`diff_cap_1e6`. `tests/sibling_jobs.rs`: `job_roundtrip`; `inproc_equals_worker`; `caps_prechecked`.

### End-to-end script and logging

Exercised by `scripts/e2e/ground_identify.sh` (N30a-26) and `ground_asbuilt.sh` (N30a-48), which run once with
`FROB_AIRLOCK=inproc` and once with `FROB_AIRLOCK=worker` and assert equal result digests; they log the mode,
the sibling commit from the stack lock, and each receipt's artifact identity.

### Known answers and negative controls

The scalar Kalman fusion and the common-mode floor above are closed-form. Negative controls: an adapter build
that truncates 300 rows to 256 silently (must fail `caps_prechecked`); an adapter that drops the common-mode
group (the floor test must fail). Determinism: Kalman, UD and iterated jobs twice on one machine bit for bit;
ensemble jobs bit for bit on one machine only.

## Considerations

- Program risk: upstream breakage through `fs-qty`. The fallback is the pinned worker process exchanging whole
  jobs, which this adapter is shaped for.
- The iterated update's 256-row cap is the reason identification works on windows of summary features; the
  cap is a design constraint here, not a defect to work around by chunking correlated rows.
- Work in FrankenSim's repository follows that repository's rules; nothing in this bead edits it.
