## Background

Ground (crate `frob-ground`) reaches the estimators of the sibling project FrankenSim through the airlock as
whole jobs (decision ADR-GROUND-08), and every Ground output has evidence class Estimated. This bead covers the
three statistics crates Ground uses for experiment design, correlated sampling, conformal bands, drift
monitoring and the value of an experiment. The companion bead N30a-05 covers the two estimation crates.

FACT, read at FrankenSim commit `483d09c682` (paths under `frankensim/crates/`; line counts approximate):

| Crate | Provides | Missing for Ground |
|---|---|---|
| `fs-uq` (about 15,900 lines, layer L4) | Greedy block D-optimal selection of whole experiments, maximizing log det(I + Σ_g J_gᵀ·J_g/ridge) (`experimental_design`). Sobol indices by pick-freeze (`product_sensitivity`), Shapley effects (`product_shapley`), replicated Latin hypercubes, Gaussian-copula sampling of correlated inputs (`product_copula`), multilevel Monte Carlo with audited telescoping, polynomial chaos, defensive Gaussian importance sampling, chance constraints with anytime-valid estimates, worst-case propagation over epistemic boxes (`product_epistemic`). | No Fisher-information rank test and no profile likelihood. Importance sampling works on independent normal germs only. The multilevel driver is a per-call closure. No conformal prediction. |
| `fs-eproc` (about 1,400 lines; feature `conformal-hardening`, tagged Frontier upstream) | `MondrianConformal`: split-conformal calibration per bucket, refusing a bucket below its minimum count and returning an infinite band when ⌈(n+1)·(1−α)⌉ exceeds n. `DriftMonitor`: a two-sided betting e-process on the rank of each new value in a frozen sample, with slack δ = max(1/√n, 0.02). False-coverage budgets over many claims (`fcr_flag`, `admission_alpha`). Betting e-processes and a mixture confidence sequence in the crate root. | Buckets are opaque strings: the cell key, the scope-change rules and the cluster structure are Ground's. The slack makes the monitor insensitive at small n. |
| `fs-voi` (about 1,000 lines, L4) | Ranking-flip probability, multi-alternative expected opportunity loss, value of an action per unit cost, and `recommend` with a stop gate. | A finite Gaussian menu. Real-trial costs and the exchange rate between operator time and compute are Ground's. |

A naming trap (FACT): the sibling crate `fs-conform` is a conformance kit for chart-to-chart converters, not
conformal prediction, and is not admitted. Conformal calibration comes from `fs-eproc`.

## Scope

In: job types and pre-checks for the three crates; the bucket-string encoding of a cell; a local reference
implementation of the conformal index used as a differential check and as the fallback; fact re-check tests.
Out: what the jobs are used for (BD-390 and N30a-17 for design; N30a-27 for correlated draws; N30a-36 to
N30a-38 for bands; N30a-41 for the rank monitor; the decision model for reality calibration and the experiment
table, which belong to the unit that owns the chapter's second half).

## Technical approach

1. **Jobs** (DESIGN, `crates/frob-ground/src/sibling/`), serializable so that they run in process or through
   the airlock's worker binary with identical bytes:
   - `DesignJob { blocks: Vec<ExperimentBlock { id, jacobian (rows × params, scaled), cost_s }>, ridge,
     budget_s }` → ordered selection, the objective value after each pick, and the marginal gain of each pick.
   - `CopulaJob { marginals, correlation, n, seed_address }` → correlated draws by address.
   - `ConformalJob { bucket, residuals, alpha, min_count }` → `Finite(q̂) | Infinite | RefusedBelowMin { n,
     min }`, with the index used.
   - `DriftJob { frozen: Vec<f64>, alpha_d }` → a monitor state; `DriftStep { state, value }` → new state,
     e-value, the slack δ in force, alarm flag.
   - `FcrJob { claims: Vec<{id, alpha_share}>, evalues }` → reserved shares (`admission_alpha`) and flags
     (`fcr_flag`, the e-BH rule).
   - `VoiJob { menu: Vec<{id, mean, sd, cost}>, stop_price }` → ranking-flip probability, expected opportunity
     loss, value per unit cost, the recommendation or "stop".
2. **Bucket encoding.** A cell's bucket string is the lower-case hex of its `CellId` (the hash of the canonical
   cell key, N30a-07) followed by `/` and the band scope (`within-units` or `across-units`) and the metric
   name. Two cells can never share a string, so the sibling cannot pool them.
3. **Local conformal reference.** `frob_ground::band::reference_quantile(residuals, alpha)`: sort ascending;
   k = ⌈(n+1)·(1−α)⌉ computed in exact rational arithmetic on α given as a rational; return the k-th smallest
   if k ≤ n, else infinite. Every `ConformalJob` response is compared with the reference; a mismatch is a hard
   error with both values. If the upstream feature is withdrawn or changes meaning, the reference becomes the
   implementation and the contract records it (fallback named in advance).
4. **Pre-checks.** A `DesignJob` with zero blocks, non-positive ridge or budget, or Jacobians of unequal column
   count; a `ConformalJob` with a negative or non-finite residual for a two-sided band; a `VoiJob` with a
   non-positive cost: each is a typed error before the sibling call. Costs in a `VoiJob` are in GPU-second
   equivalents only when an exchange rate has been declared; by default (open question OPEN-GROUND-4, owner:
   project lead) real episodes are recommended, never scheduled, and no rate is assumed, so real-trial entries
   carry cost `undeclared` and are ranked in a separate column.
5. **Fact re-check** at the commit pinned in `franken-stack.lock` (tests below); deltas go to `CONTRACT.md`.
6. **First-use admission at the M5 pin.** An admission is never inherited: the airlock's group gates were recorded for other consumers at earlier pins, and each crate is probed again at the milestone that first calls it, by the bead that calls it.
   This bead runs, at the commit pinned for M5, the fact re-check of step 5 for the functions Ground calls and
   writes one admission record per crate in `DEPENDENCY_ADMISSION.md` in the admission-record schema (commit,
   command, output hash, receipt hash, the functions covered, recorded limits): `fs-eproc` with its feature
   `conformal-hardening` (`MondrianConformal`, `DriftMonitor`, `admission_alpha`, `fcr_flag`); `fs-uq`
   (`experimental_design`, `product_copula`); `fs-voi` (the ranking-flip probability, expected opportunity
   loss, value per unit cost and `recommend`). If the decision on admitting `fs-voi` leaves it out, the local
   closed form is recorded in its place and the `VoiJob` is served locally. A Ground mechanism that calls a
   sibling function with no such record is refused by the adapter with the airlock's not-admitted refusal.

## Acceptance criteria

- [ ] Each job round-trips and gives identical bytes in process and through the worker.
- [ ] `ConformalJob` agrees with the local reference on 10⁴ random residual sets across n ∈ [1, 400] and
      α ∈ {0.01, 0.05, 0.10, 0.20}; a planted off-by-one in the reference is caught by the comparison.
- [ ] Every fact in the table has a passing re-check test at the pinned commit, or a recorded delta.
- [ ] Two different cells never produce the same bucket string (property test over generated cell keys).
- [ ] A `VoiJob` containing a real-trial entry with no declared exchange rate returns that entry unranked
      against compute entries.
- [ ] `DEPENDENCY_ADMISSION.md` holds an admission record at the M5 pin for `fs-eproc` (with
      `conformal-hardening`), `fs-uq` and `fs-voi` (or the recorded local closed form), each listing the
      functions Ground calls; a call to a function with no record is refused.

## Test plan

### Unit tests

`crates/frob-ground/tests/sibling_stats_facts.rs` (real sibling code): `mondrian_refuses_below_min_count`
(min 19, n = 8); `mondrian_infinite_when_index_exceeds_n` (n = 8, α = 0.10: ⌈9·0.9⌉ = 9 > 8);
`mondrian_index_n20` (α = 0.10 gives the 19th smallest; α = 0.05 gives the 20th);
`mondrian_buckets_do_not_pool`; `conformal_shift_receipt_counts` (the sibling's own fixture: pooled calibration
covers 20 of 20 in one regime and 16 of 20 in the shifted one); `drift_slack_values` (δ = 0.2236 at n = 20,
0.0707 at n = 200, 0.02 at n = 10⁴); `drift_monitor_is_two_sided`; `fcr_shares_sum_to_budget`;
`design_objective_toy` (three one-row experiments with Jacobians (1, 0), (0, 1), (1, 0) and ridge 1: the greedy
order picks the two orthogonal ones first; objective ln 2, then 2·ln 2, then ln 6);
`copula_reproduces_correlation` (target 0.8, 10⁵ draws, sample correlation within 0.01);
`voi_ranking_flip_closed_form` (gap Δ = 1, s₁ = s₂ = 1: Φ(−1/√2) = 0.2398 to 10⁻¹²).
`tests/band_reference.rs`: `reference_index_exact` (n = 20: α = 1/10 → 19; α = 1/20 → 20; α = 1/25 → 21 >
20, infinite); `reference_matches_sibling` (property); `finite_minimum_n` (9, 19, 99 at 90%, 95%, 99%).
`tests/sibling_jobs_lanes.rs`: `jobs_identical_in_process_and_worker` (one job of each of the six kinds on the
toy inputs above, run in process and through the airlock's worker: equal response bytes);
`unadmitted_function_refused` (a job naming a function absent from the admission record is refused by the
adapter with the airlock's not-admitted refusal before any sibling call); `pre_checks_typed` (zero blocks,
ridge 0, a negative two-sided residual, a cost of 0: four typed errors, no sibling call).

### End-to-end script and logging

`scripts/e2e/ground_sibling_jobs.sh` (this bead; there is no verb for the adapters, so the script drives the
test targets above, once with `FROB_AIRLOCK=inproc` and once with `FROB_AIRLOCK=worker`, and reads
`DEPENDENCY_ADMISSION.md`). It asserts equal job-response digests across the two lanes, one admission record
per crate at the M5 pin, and the not-admitted refusal. Log `target/e2e-logs/ground_sibling_jobs/<utc>.ndjson`
through the STD-E2E helper: per command the exact command, exit code and wall time; the sibling commit and
feature set; for every conformal call the index, n and both quantiles (sibling and local reference); the two
lanes' digests; a final `summary`. The verb-level use is exercised later by `scripts/e2e/ground_band.sh`
(N30a-39), `ground_drift.sh` (N30a-44) and `ground_excite.sh` (N30a-19), each in both lanes.

### Known answers and negative controls

KA-728 (index 19 at n = 20, target 0.90) and KA-736 (36 of 40 pooled) are re-derived here on the sibling's own
code. Negative controls: a reference with ⌈n·(1−α)⌉ in place of ⌈(n+1)·(1−α)⌉ (caught: 18 against 19 at n = 20);
a bucket encoder that drops the band scope (caught by the pooling test). Determinism: all jobs here are
deterministic on one machine; copula draws are by address and identical in any batch.

## Considerations

- `conformal-hardening` is tagged Frontier upstream: its API may move. The local reference bounds the exposure
  to one adapter file.
- The rank monitor's slack is the sibling's; Ground does not change it, and prints it so that a quiet monitor
  at small n is not misread (N30a-43).
- `fs-voi`'s menu is finite and Gaussian; the value model only ranks experiments and never issues a verdict,
  so a wrong variance model costs efficiency and never validity.
