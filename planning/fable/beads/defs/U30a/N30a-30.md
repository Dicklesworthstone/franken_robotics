## Background

Ground (crate `frob-ground`) identifies card parameters from the logs of a particular physical robot. The
plan's third rule for card updates: **one robot calibrates one robot. A per-unit posterior describes that
unit's left knee. A part-class card is hierarchical: a class mean and a unit-to-unit spread. With one unit
measured the spread stays at its prior; with k units it is estimated on k − 1 degrees of freedom.**

The mistake this prevents is common and expensive: an actuator measured carefully on one unit is written into
the catalogue entry for the whole part class with the unit's tight posterior, and every other unit of that
class is then simulated with an uncertainty that describes measurement error on unit 7 and not the difference
between units. Manufacturing spread (magnet strength, gear preload, lubricant fill) is usually larger than the
measurement error of a good bench fit. The same idea appears for bands: twenty episodes on one machine are one
cluster, and for a new unit of the same design the units are the draws.

Rejected alternatives: pooling the raw logs of several units into one fit (that is pooling across cells, which
is refused, and it hides the spread inside the residual); copying a unit posterior to the class with an
arbitrary inflation factor.

## Scope

In: the scope of a per-unit card version; the hierarchical class card, its fields and its update from k unit
posteriors; which card a model binds; status and retirement of a class card. Out: writing a unit version
(N30a-27); admission of a unit version (N30a-28); bands across units (N30a-37).

## Technical approach

1. **Unit versions.** A card version written by identification carries, in each measured field's provenance,
   the cell (whose `units` component names the physical unit) and the instance (for example joint `knee-L`).
   `card::scope(version) -> UnitScope { unit, instance }`. Binding a unit version into a model whose declared
   unit is different, or into another instance of the same part on the same unit, is refused by the model
   compiler with the scope named (DESIGN; the left knee's friction is not the right knee's).
2. **Class cards.** For a part class (a catalogue class or a part number) a class card version has, per
   hierarchical field: `class_mean`, `class_mean_sd`, `unit_spread` (the unit-to-unit standard deviation),
   `spread_dof`, `units_measured`, and `value` and `uncertainty` as every card has, here set to the
   predictive distribution of a new unit (below). Provenance
   `measured-class { units: [...], versions: [...], cells: [...] }`.
3. **Model.** For one field: unit j has true value θ_j ~ N(μ, σ_u²); its admitted unit version reports
   θ̂_j with variance v_j (the floored variance, read through `ground::effective` with the unit's own cell,
   N30a-28 and N30a-29; a unit whose floor is `not-estimated` contributes no class update until it has one).
   Prior on the spread: scaled inverse χ² with ν₀ = 1 degree of
   freedom (DESIGN: weak) and scale σ₀², where σ₀ is the class card's prior spread (for a generic class, the
   field's stated uncertainty).
4. **Update with k admitted units.**
   - k = 1: the spread stays at its prior, σ_u = σ₀ (zero degrees of freedom added). The class mean is the
     precision-weighted combination of the prior mean μ₀ and θ̂₁ with weights 1/σ_prior,mean² and
     1/(v₁ + σ₀²), and `class_mean_sd`² = 1/(1/σ_prior,mean² + 1/(v₁ + σ₀²)). Here μ₀ and σ_prior,mean are
     the prior class card's `class_mean` and `class_mean_sd` when it is a measured class card, and the field's
     value and stated uncertainty σ₀ when it is generic (DESIGN: a generic class value is taken to be as
     uncertain as one unit). From k = 2 on, the prior mean is not used (DESIGN: the units then estimate the
     mean on their own, and a value that is not a measurement must not pull a measured class mean; the worked
     case below is computed this way).
   - k ≥ 2: θ̄ = (1/k)·Σ θ̂_j; s² = Σ (θ̂_j − θ̄)²/(k − 1), on k − 1 degrees of freedom; excess over
     measurement error e² = max(0, s² − (1/k)·Σ v_j); posterior spread
     σ_u² = (ν₀·σ₀² + (k − 1)·e²)/(ν₀ + k − 1), with `spread_dof = k − 1`; class mean
     μ̂ = Σ w_j·θ̂_j/Σ w_j with w_j = 1/(v_j + σ_u²), and `class_mean_sd`² = 1/Σ w_j.
   - Predictive for a unit not yet measured: value μ̂, uncertainty² = σ_u² + class_mean_sd².
   Correlations between fields are carried the same way on the covariance block: the between-unit sample
   covariance of the field vector, on k − 1 degrees of freedom, with the same shrinkage toward the prior.
5. **Which card a model binds.** A model of a named, measured unit binds that unit's admitted versions. A
   model of an unmeasured unit, or of the design in general (most simulation), binds the class card. Reports
   say which: `cards: unit(unit-07)` or `cards: class(k=3)`.
6. **Status.** A class card version is derived: it is `admitted` when every contributing unit version is
   admitted in its own cell, and it is rebuilt (a new version) when a unit is added, or when a contributing
   cell is retired, in which case that unit drops out. It never confers a Reality status on anything: a class
   card is a better prior, and reports of an unmeasured unit still print `reality: no-claim`.
7. **Not pooling.** Each unit was fitted from its own dataset in its own cell; the class update combines k
   posteriors, each a summary with its own uncertainty. No raw rows from different cells meet, so the
   no-pooling refusal (814) does not apply and is not weakened.

## Acceptance criteria

- [ ] k = 1: `unit_spread` equals the prior spread exactly and `spread_dof = 0`. Worked case on a generic
      prior (μ₀ = 1.0, σ₀ = 0.15) with θ̂₁ = 1.2, v₁ = 0.01: class mean 1.0818, `class_mean_sd`² = 0.013295,
      predictive uncertainty √0.035795 = 0.1892.
- [ ] k = 3 with θ̂ = (1.0, 1.2, 1.4), v_j = 0.01, σ₀ = 0.15: θ̄ = 1.2, s² = 0.04, e² = 0.03,
      σ_u² = (0.0225 + 2·0.03)/3 = 0.0275 (σ_u = 0.166), `class_mean_sd`² = (0.01 + 0.0275)/3 = 0.0125,
      predictive uncertainty √0.04 = 0.20, `spread_dof = 2`.
- [ ] Three units with identical estimates give e² = 0 and a spread shrunk toward, and not below,
      √(ν₀·σ₀²/(ν₀ + 2)) (the prior still counts for one degree of freedom).
- [ ] Binding unit-07's knee version into a model of unit-08, or into unit-07's other knee, is refused.
- [ ] A model of an unmeasured unit binds the class card and its report prints `cards: class(k=…)` and
      `reality: no-claim`.
- [ ] Retiring one contributing cell rebuilds the class card from the remaining units.

### End-to-end script and logging

Part of `scripts/e2e/ground_identify.sh` (N30a-26): three rigs of population A are declared to be three units
of one part class with planted unit-to-unit spread; after their versions are admitted the script runs
`frob actuator show <class card>` and logs k, the spread, its degrees of freedom, the class mean with its
standard deviation and the predictive uncertainty against the planted spread.

### Known answers and negative controls

The worked case above. Negative controls: a class update that copies the single unit's posterior uncertainty
to the class (at k = 1 the predictive uncertainty would be √v₁ = 0.10 in place of √(0.0225 + …), and the test
fails); a spread estimated with divisor k in place of k − 1 (0.0267 against 0.04 in the worked case). Related
counterexample CX-330 (pooling hides a failing regime) for the rule that raw data from different cells never
meets. Determinism: exact rational arithmetic is not required; double precision, bitwise twice.

## Considerations

- ν₀ = 1 is a DESIGN choice that keeps the k = 2 estimate from collapsing onto a two-point sample variance; it
  is recorded on the card so that a different prior weight is visible.
- "Unit" must mean the same thing here as in the cell key and in the band rules: a serial-level identity.
  Two joints of one robot that use the same part number are two instances, not two units of evidence about the
  class's spread across builds; whether instances within one robot may count toward the class spread is left
  to the Ground lead (default: no; they share a build lot and an assembler).
- With no bench hardware (the default), no unit version exists and class cards stay at their generic priors;
  the share of guessed fields printed on reports says so.
- Recorded alternative from the superseded bead N30b-04: no prior weight on the spread (ν₀ = 0),
  ŝ² = max(0, Σ (θ̂_u − μ̂)²/(k − 1) − mean(v_u)) with μ̂ the precision-weighted mean, and predictive variance
  ŝ² + var(μ̂). It is the ν₀ → 0 limit of the update above; ν₀ = 1 is kept so that two units do not fix the
  spread from one squared difference.
- A class card built from two units has one degree of freedom for its spread; the interval is wide and is
  printed, and every report says how many units stand behind a class card.
