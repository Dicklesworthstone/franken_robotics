## Background

Ground is the subsystem that compares simulation with measured reality (crate `frob-ground`, layer 5). The
program has no real data, and it may never have any. Whether Ground's machinery is correct is nevertheless
decidable without hardware: a **truth simulator** plays the part of reality. It is the referee (the
double-precision reference tier) run with planted parameters and one planted difference of model form, and it
emits logs through the sensor models with planted clock skew and offset. The fitting side is then asked to
recover what was planted, to refuse what cannot be recovered, and to notice the model-form difference on sealed
data. Every gate of the subsystem from GATE-GROUND-02 to -09 and -11 is decided on this rehearsal.

Two rules bound what the rehearsal means. First, everything it produces has `origin = "synthetic"`, for life:
recovering planted values shows that a bounded loop is sound and nothing more, and the Reality claim stays
`no-claim` (invariant INV-GROUND-06: data of origin `synthetic` never yields a status other than `synthetic`).
Second, the fitting code must not be able to see the truth: a rehearsal in which the estimator can read the
planted values proves nothing.

Rejected alternatives: waiting for real data before testing (the subsystem would land untested, and the first
real dataset would be debugged against an unknown estimator); testing each mechanism on its own ad hoc
fixture (the stages alias into each other: a clock error becomes a delay error becomes a friction error, and
only one pipeline over one dataset family exposes that); a truth simulator of another vendor (it would add a
foreign tool to a production path and make the planted truth unknowable).

Tier: Frontier, with the rest of the subsystem. It serves the bet that calibration bands reach their stated
coverage inside one calibrated robot and task family, by giving that bet a place to fail.

## Scope

In: the truth simulator configuration; the fixture catalogue with planted values; dataset bundles with complete
manifests, splits and sealed parts; the truth sidecar and its isolation; the reference computations for the
closed-form rows; the generator entry points; the script that generates and admits the catalogue
(`scripts/e2e/ground_rehearsal_gen.sh`). Out: the mechanisms that consume the fixtures (BD-389 to BD-396);
the end-to-end run of the whole procedure over them (N30b-31); the eight structural-alias analyses themselves
(BD-390).

## Technical approach

1. **Layout.** `crates/frob-ground/src/rehearsal/`: `truth.rs` (truth simulator), `fixtures.rs` (catalogue),
   `emit.rs` (bundles), `reference.rs` (closed-form values). Entry points, with no new verb and no new binary
   (the conformance crate has test and example targets only): the library function
   `frob_ground::rehearsal::generate(fixtures, seed, out)`; the example target
   `cargo run -p frob-conformance --example ground_rehearsal -- gen --fixture <id|all> --seed <u64> --out <dir>`,
   which calls it and writes the truth sidecars of step 4 (a script or bead that writes
   `frob-conformance gen ground.rehearsal …` means this command); and the kit builder, which embeds the same
   generator recipe. Schema of the generator receipt: `frob.ground.rehearsal/1`.
2. **Truth simulator.** The referee with: a planted parameter vector per fixture; the planted model-form
   difference (stated per fixture; for whole-robot fixtures a contact dissipation variant the fitting side's
   model class lacks, so that a non-zero reality gap exists); logs emitted through the sensor models (noise,
   bias, quantization, the declared timestamp instant) on a device clock t_src with t_ref = a + (1 + s)·t_src;
   two shared hardware marks unless the fixture removes them.
3. **Bundles.** Each fixture is one or more `.frun` episode bundles with a `frob.ground.dataset/1` manifest:
   `origin = "synthetic"`, `license = "CC0-1.0"`, `acquired = { by = "frob-ground::rehearsal@<version>", on =
   "<generator date>", rights = "generated" }`, a full `[rig]` (units `sim-unit-01` …, controller identity,
   firmware `sim-1.0`, surface class, envelope), instruments with `sigma`, `bias_bound`, `instant`, `clock` and
   `calibration`, clocks with raw mark timestamps, and a split by synthetic day: calibration, validation,
   holdout, with validation and holdout sealed. `attempts = "all"`; two fixtures contain planted aborted trials
   so that the denominator check has something to count.
4. **Truth isolation.** Planted values are written to `truth/<fixture>.toml` under
   `crates/frob-conformance/fixtures/ground/`, never into a bundle. The generator receipt stores only the
   BLAKE3 hash of each truth file. `frob-ground` has no dependency on `frob-conformance` and no read path to
   that directory; only the assertion harness reads it. The catalogue's planted values live in
   `rehearsal/fixtures.rs` of the same crate as the estimators, so the same source lint also forbids any
   module of `frob-ground` outside `rehearsal/` and `kit.rs` from naming `crate::rehearsal`: the fitting
   code cannot import the truth it is asked to recover.
5. **Catalogue** (planted values are DESIGN, registered with the generator version; tolerances are those of the
   known-answer rows).

6. **Exact rows.** R-03, R-11, R-12 and R-15 are evaluated in exact rational arithmetic and converted to floating
   point once (R-15: v·δ + b = 1/25 m exactly in both explanations; evaluated naively in double precision as
   L − v·(t + δ) − b, the two explanations agree bit for bit on 96 of the 101 samples with t_k = k/100, and on
   97 with t_k = k·0.01, not on all, so the fixture defines the reading as L − v·t − (v·δ + b) with the
   bracket computed in rationals). `reference.rs` exposes these and the
   Beta-law figures (mean 19/21, standard deviation 0.0626, P(coverage < 0.80) = 0.0692 at n = 20; standard
   deviation 0.0211 at n = 200).
7. **Evidence.** Every verb output computed on a rehearsal dataset carries `evidence.reality = "synthetic"` and
   the line `reality: synthetic [dataset=<hash prefix>]`; every log line of every script that touches the
   rehearsal carries `synthetic: true`. Every chunk hash the generator writes is recorded in the
   `synthetic_chunk` table, so no later dataset can relabel it.

Determinism: the generator is class D2 on one platform (same seed, same bytes, across worker counts and in debug
and release); across platforms the bundles are compared in class D3, because the referee's cross-platform bit
equality is an open upstream item. The kit ships bundles by content hash for that reason.

## Acceptance criteria

- [ ] The fifteen fixtures generate from one command with one seed; each bundle is admitted by `ground.ingest`
      and its sealed parts are sealed.
- [ ] The known answers of the rehearsal reproduce (seed done-condition), as far as this bead and its
      dependencies can show it: the closed-form rows R-03, R-11, R-12, R-15 and the Beta figures match
      `reference.rs` to the printed digits here, and every fixture's planted truth round-trips through its
      bundle generator (the unit tests below). The rows that need a consumer (R-01, R-02, R-04 to R-10, R-13,
      R-14) are asserted by those consumers' gate scripts and, as one pipeline, by the end-to-end run N30b-31;
      those beads depend on this one, and this bead's close does not wait for them.
- [ ] Every output of the rehearsal prints `synthetic` in its evidence (seed done-condition): the generator
      receipt and every `ground.ingest` envelope on every rehearsal bundle carry `evidence.reality =
      "synthetic"` and the line `reality: synthetic [dataset=…]` (this bead's script). The sweep over all seven
      `ground` verbs is the last step of N30b-31, which exists because six of those verbs land after this bead.
- [ ] A rehearsal manifest edited to `origin = "real"` fails its hash; with the id recomputed it is refused by
      chunk hash (FROB-REF-814).
- [ ] No file under `crates/frob-ground/` reads the truth directory, and no module outside `rehearsal/` and
      `kit.rs` names `crate::rehearsal` (one source lint; a planted `use crate::rehearsal::fixtures` in
      `identify/` makes it fail); the crate graph has no edge from `frob-ground` to `frob-conformance`.
- [ ] Two generations with one seed give identical dataset ids; a different seed gives different ids.
- [ ] Cancellation during generation leaves no partial bundle in the store.

### Unit tests

`crates/frob-ground/tests/rehearsal.rs`: `fifteen_fixtures_listed`; `manifests_complete_and_synthetic`;
`clock_planted_values_roundtrip` (the raw marks in R-01 reproduce skew 100 ppm and offset 3.7 ms when jitter is

`beta_figures` (0.9048, 0.0626, 0.0692); `drift_fixture_power_registered` (R-10's registered post-drift miss
probability is at least 0.8, and the exact power of the miss monitor after its ten clean episodes, computed by
enumeration over miss counts and averaged over the calibration draw, is 0.980, above 0.97; at 0.7 it is 0.86,
which the test prints as the reason for the floor); `exposure_alias_bit_equal` (X and Y: 101 of 101 samples equal);
`exposure_alias_naive_form_is_not` (the naive double form differs on some samples: documents the hazard);
`truth_not_in_bundle` (no planted value appears in any bundle file); `aborted_trials_counted`;
`rig_population_by_address` (rig 17 has the same parameters in any generation order);
`same_seed_same_ids`; `relabel_fails_hash`.

### End-to-end script and logging

This bead's own script is `scripts/e2e/ground_rehearsal_gen.sh` (header `bead=BD-388 milestone=M5
labels=ground,e2e seed=1 needs=cpu plants=truth-in-bundle,label-real`), built on the generator and on
`ground.ingest` only. It sources `scripts/e2e/lib.sh` and runs in the run's own state root. Steps: (1)
`generate`: the example target of item 1 with `--fixture all --seed 1 --out $D`, asserting fifteen fixtures
and that no file of any bundle contains a planted value (the truth sidecars are read by the harness, never by
`frob`); (2) `ingest`: `frob ground ingest <bundle> --design <d> --task-family <tf> --key "$(e2e_key
ingest-<fixture>-<n>)" --json` for every bundle (`tf:none` for the bench and scan bundles), asserting
`origin = "synthetic"`, the sealed parts, `evidence.reality == "synthetic"` and the line `reality: synthetic
[dataset=…]` in the human rendering; (3) `regenerate`: a second generation with seed 1 gives the same dataset
ids, and seed 2 gives different ones; (4) `relabel`: a manifest edited to `origin = "real"` is refused
(`e2e_expect_refusal FROB-REF-873 3`), and with its id recomputed it is refused by chunk hash
(`e2e_expect_refusal FROB-REF-814 3`); (5) `cancel`: generation interrupted mid-run leaves no partial bundle in
the store (store digest equal before and after). The two plants: a generator build that writes truth into a
bundle (step 1 fails), and one that labels its output `real` (step 2 fails). Log:
`target/e2e-logs/ground_rehearsal_gen/<utc>.ndjson` with a transcript; every line has `ts`, `script`, `bead`,
`step`, `event`, the exact command, exit code, wall time and the envelope's evidence block; per fixture the
dataset id, the truth file's hash, the split counts and `synthetic: true`; each refusal with code, pointer and
repairs; on failure the first differing value and the bundle path; a final `summary` with assertions passed and
failed and `gates: []`.

`scripts/e2e/ground_rehearsal.sh` (bead N30b-31, which depends on this bead) then drives the ten-step procedure
over the catalogue and asserts every consumer row. It logs, per fixture, the dataset id, the truth hash, the
consumer's result against the planted value with its tolerance, and `synthetic: true`.

### Known answers and negative controls

KA-721 to KA-734 and KA-736 with the values in the catalogue; CX-326 to CX-334. Planted failures the rehearsal
itself must catch: a generator build that writes truth into the bundle (the lint and `truth_not_in_bundle`
fail); a generator that labels its output `real` (admission of the pair real-and-synthetic is refused).
Metamorphic relations: scaling every time by a constant leaves the recovered skew unchanged; shifting the
reference clock origin shifts the offset by the same amount and changes nothing else; permuting the rig order
changes no rig. Determinism lanes: twice on one machine; worker counts 1 and 8; debug and release; macOS and
Linux in class D3.

## Considerations

- The drift fixture's power depends on its registered noise: armed fresh (e-value 1), the miss monitor retires
  within 20 episodes with probability 0.70, 0.92 and 0.99 when the post-drift miss probability is 0.5, 0.6 and
  0.7 (computed for p₀ = 0.22, p₁ = 0.5, threshold 20). R-10's ten clean episodes come first and shrink the
  e-value (a pure likelihood-ratio product, N30a-42, falls by 0.641 per covered episode), so at the change the
  power is lower: 0.58, 0.86, 0.94 and 0.98 at 0.6, 0.7, 0.75 and 0.8 (averaged over the calibration draw).
  The fixture therefore registers at least 0.8 before the gate is run; a 30% friction
  change that does not move residuals that far would make the gate unreachable, and that must be seen at
  registration, not after.
- The rig's planted values and prior errors are chosen so that the 30% held-out improvement of the
  identification gate is achievable; they are part of the generator version and are not tuned after a run.
- The rehearsal cannot show that real friction follows the fitted law. Its omitted-law fixture exists to keep
  that limitation visible.
- Size: the catalogue is a few hundred megabytes with the 100-rig population (TARGET: under 1 GB); the
  population is generated on demand and only the ids are pinned.
- If no dataset is ever admitted, this rehearsal is the only exercise the subsystem gets, and work beyond it
  waits.
