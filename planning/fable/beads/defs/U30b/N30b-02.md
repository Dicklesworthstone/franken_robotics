## Background

Ground's identification of an actuator runs in three passes. Pass A is a linear regression and pass B an
output-error fit by an iterated Gauss–Newton update (both in BD-391). Three parameters of the joint model do not
suit either. The joint model is (I(q) + J_a)·q̈ + b·q̇ + τ_f(q̇) + g(q) = N·η·k_t·i(t − d) with friction
τ_f(q̇) = [τ_c + (τ_s − τ_c)·exp(−(q̇/v_s)²)]·sgn(q̇) while moving and a stiction row holding q̇ = 0 while the
applied torque is inside ±τ_s (d actuator delay, τ_s static torque, v_s Stribeck speed, τ_c Coulomb torque).

- **Delay** enters through the instant at which a command is latched, which lies on a rational clock. The misfit
  is not a smooth function of d: it is flat between grid values and jumps at them. A derivative is zero or
  undefined, so delay is profiled, not differentiated.
- **Static friction and the Stribeck speed** act only around breakaway, a threshold event. The stick–slip
  likelihood has no useful Jacobian, so they are estimated by an ensemble.

Sibling facts (FACT, FrankenSim `crates/fs-assimilate`): a deterministic serial ensemble square-root filter with
forecast, correlated blocks and a fixed-lag smoother (`nonlinear::ensemble`, behind feature `ensemble`). The
lane is feature-gated and claims no determinism across instruction-set architectures. Posteriors are Gaussian
or ensemble only: a stick–slip likelihood is handled only as far as an ensemble approximates it.

Rejected alternatives: smoothing the delay into a continuous lag and differentiating (it identifies a lag, and
delay and lag are different card fields with different effects on a sampled loop); a smoothed friction law so
that a Jacobian exists (the smoothing width becomes a hidden parameter that aliases with v_s).

## Scope

In: the delay grid, profile and likelihood-ratio set; the ensemble estimate of τ_s and v_s from ramp
experiments; the refusals when the data cannot carry either; what is handed to the calibration record.
Out: passes A and B and the verb (BD-391); the record's layout and energy check (N30b-03); card writing
(N30b-04); clock rules for clocks without a shared mark (BD-389).

## Technical approach

1. **Delay grid.** d_k = k·T_c/G for k = 0 … K, with T_c the control period (a rational number of seconds), G = 8
   (TARGET) and K chosen so that d_K covers the card's prior delay plus four prior standard deviations (TARGET).
   Grid values are exact rationals; a "grid step" is T_c/G.
2. **Profile.** For each d_k, pass B is run for the remaining parameters with the delay held at d_k
   (warm-started from the neighbouring grid value, in increasing k, so the path is deterministic). The profile
   value is ℓ_k = ½·rᵀ·R⁻¹·r at the optimum, with r the feature residuals and R the instrument covariance.
3. **Result.** The profile {(d_k, ℓ_k)}, its minimizer d̂, and the set of delays inside the 95%
   likelihood-ratio bound, {d_k : 2·(ℓ_k − ℓ_min) ≤ 3.841} (3.841 is the 0.95 quantile of χ² with one degree of
   freedom; TARGET). The posterior for delay is this set and the profile, not a mean and a variance.
4. **Refusals.** If the set is the whole grid the profile is flat: delay is unidentified in this experiment and
   a delay value is refused with FROB-REF-879, repair "a step command with a shared hardware mark". If the
   command clock has no shared mark with the encoder clock, the profiled quantity is "delay plus offset", it is
   reported under that name, and the card's delay is not updated.
5. **Ensemble for τ_s and v_s.** Data: slow torque ramps from rest in both directions (the experiment of the
   excitation grammar that informs static friction). A run that never dwells at zero velocity carries no
   information on breakaway: with no ramp data a value for τ_s is refused with FROB-REF-879 (structural alias 7,
   repair "slow torque ramps from rest, both directions").
   1. Draw M = 256 members (TARGET) of (τ_s, v_s) from the prior by world address.
   2. Run them as one batched rollout with per-world parameter variants: each member is a world whose parameter
      row carries its (τ_s, v_s), on the strict double-precision profile of the CPU batch tier (event-located
      steps, so breakaway is located and not smeared).
   3. Observations per ramp: the torque at first motion in each direction; the velocity at three fixed times
      after breakaway (TARGET set, stored in the record).
   4. Update with the serial ensemble square-root filter; at most three assimilation cycles (TARGET), each
      re-running the rollouts from the updated members.
   5. Report the ensemble mean, covariance with the pass-B parameters' block left untouched, the ensemble
      skewness of each parameter (a posterior that is visibly non-Gaussian is flagged `ensemble-nongaussian`),
      and the machine fingerprint.
6. **Handed on.** `Pass::C { delay_profile, delay_set, tau_s, v_s, ensemble_size, cycles, fingerprint }` to the
   calibration record; the card receives d̂ with the bounds of the set as its uncertainty and the profile by
   reference.

Determinism: the profile is class D2. The ensemble is class D2 on one machine fingerprint and is not compared
across machines; a second machine's result is recorded beside the first, not asserted equal.

## Acceptance criteria

- [ ] On the nominal rig of the rehearsal (planted d = 2.625 ms on a 1/8 ms grid) the minimizer is the planted
      grid value or an adjacent one, and the 95% set contains the truth.
- [ ] Planted τ_s = 0.45 N·m and v_s = 0.10 rad/s are recovered within 10% from the ramp experiments.
- [ ] A dataset with no dwell at zero velocity refuses τ_s with FROB-REF-879 and names the ramp experiment.
- [ ] A dataset with no shared mark reports "delay plus offset" and leaves the card's delay unchanged.
- [ ] A flat profile is refused, not resolved by picking the prior.
- [ ] Member i of the ensemble has the same parameters and the same rollout digest whatever the batch
      composition; the record carries the fingerprint.
- [ ] Contributes its rows to GATE-GROUND-04 (delay within one grid step; τ_s and v_s within 10%).

## Test plan

### Unit tests

`crates/frob-ground/tests/pass_c.rs`: `grid_is_rational` (T_c = 1 ms, G = 8: step 1/8000 s exactly);
`profile_minimum_at_planted_delay` (index 21); `lr_set_contains_truth`; `lr_threshold_is_3_841`;
`flat_profile_refused_879`; `no_shared_mark_profiles_the_sum` (delay 8 ms with offset −8 ms: sum 0);
`ensemble_recovers_static_and_stribeck`; `no_dwell_refused_879`; `ensemble_members_by_address`;
`three_cycles_at_most`; `nongaussian_flag_on_bimodal_fixture` (a `synthetic` ramp set mixing two breakaway
levels); `fingerprint_in_record`.

### End-to-end script and logging

`scripts/e2e/ground_identify.sh` (bead N30b-32) logs, per rig, the delay minimizer, the bounds of the 95% set in
grid steps, τ_s and v_s against truth with their relative errors, the ensemble size and the fingerprint.

### Known answers and negative controls

KA-724 (delay within one grid step; τ_s and v_s within 10%); KA-725 (delay against offset: reported as a sum).
CX-327; structural aliases 5 and 7 of CX-328. Planted failures: a profile that interpolates between grid values
and reports a delay off the grid; an ensemble seeded by batch slot instead of by address (members change under
permutation); an estimator that returns the prior for τ_s when no ramp exists. Determinism lanes: twice on one
machine and across worker counts for both parts; debug and release; across machines recorded, not asserted.

## Considerations

- Upstream work item FD-FSIM-24 asks the sibling for a cross-architecture statement on the ensemble lane.
  Interim posture: ensemble results carry the machine fingerprint and are not compared across machines;
  switch-over: re-run the rehearsal's known answers on a second machine and record the comparison in the
  calibration record.
- Cost: K + 1 output-error fits per joint for the profile (about 80 at G = 8 over 10 ms) and three batched
  rollouts of 256 worlds for the ensemble; minutes of CPU per joint.
- Delay and lag are separated only by a step command with a shared mark; where the identifiability report shows
  them aliased, the lag is held at its prior and the profile is reported for the pair.
- A finer grid than T_c/8 is not supported by the sampled loop's information; the grid resolution is the stated
  resolution of the card's delay.
