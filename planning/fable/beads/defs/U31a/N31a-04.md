## Background

Foundry's own code is the robotics and the glue: load extraction, interface tractions, gauge placement, feature
measurement, the loop, the packet. The mechanics come from sibling libraries, reached through the airlock crate
`frob-fsim`, which is the only crate allowed to name FrankenSim types. This bead builds the thin typed layer
`frob-foundry::sib` over the airlock traits and, for each sibling fact the chapter relies on, a probe test that
fails when the fact stops being true at the pinned commit.

FACT throughout, read at FrankenSim commit `483d09c682`; paths are under `frankensim/crates/` unless stated.
Five gaps are upstream work items in the sibling repository (FD-FSIM-26 to -30). This bead does not wait for
them: each has an interim posture that ships now and a switch-over rule for when the upstream change lands.

Foundry jobs are whole jobs of seconds to minutes, so the worker-process mode suits them.

## Scope

In: `src/sib/{solid,topopt,topols,mesh,geocon,fab,toleralloc,io,material,massprops}.rs`; one probe test per
row above; the gap table with interim postures; the switch-over tests for the five upstream items.
Out: the airlock traits themselves and INT-FSIM-15 (unit U33b); the upstream changes (beads FD-FSIM-26 to -30);
probes for `fs-contact`, `fs-orbit`, `fs-phs` and `fln-verdict` used only by the Moonshots are written here but
run in the lanes of N31a-45 and N31a-47.

## Technical approach

1. **Wrappers.** Each `sib/*.rs` file exposes functions in Foundry's vocabulary (quantities as
   `frob_core::qty` types, results as `FoundryValue`) and calls the airlock trait. A sibling refusal is
   converted, never reinterpreted: it becomes a Foundry refusal carrying the upstream reason, and is never
   retried with weakened inputs. Every wrapper result records the stack-lock digest.
2. **Job shape.** A wrapper call is one job: geometry, mesh parameters, materials, load cases in, fields and
   scalars out. No wrapper is called per element or per sample. In worker mode the job crosses the process
   boundary with its canonical-bytes hash; in-process mode gives the same bytes back.
3. **Probes** (`tests/sibling_facts.rs`, lane `--features structure`). One named test per fact that a mechanism
   relies on. Examples: `rainflow_residue_persists_across_blocks` (history 0, 10, 0 fed as [0, 10] then
   [10, 0] with one `finish` counts one full cycle of range 10); `faceted_export_requires_decoded_solid`;
   `faceted_export_refuses_nonreplaying_solid`; `step_default_limit_is_1e6_instances`;
   `fab_check_all_returns_repair_target`; `toleralloc_requires_positive_sensitivity`;
   `correlated_stack_limit_128_terms`; `topols_is_two_dimensional`; `sdf3_is_feature_gated`;
   `mesh_audit_available`; `massprops_returns_sources`; `geocon_has_no_overhang_measure`.
   A probe that fails means a FACT of this chapter changed: the gap table and the bead that relied on it are
   revised before the pin moves.
4. **Gap table with interim posture and switch-over rule** (`docs/foundry/sibling_gaps.md`):

   | Upstream item | Gap | Interim posture | Switch-over rule |
   |---|---|---|---|
   | FD-FSIM-26 | `fs-io`: no mesh entry point to the faceted STEP exporter | Faceted export under a stated triangle bound, with decimation and re-check or refusal (bead N31a-35) | Re-export the packet fixtures and compare hashes |
   | FD-FSIM-27 | `fs-topols`: no plane-stress option | Plates are shaped in two dimensions under plane strain, no two-dimensional stress or compliance is used as evidence, and every number comes from the three-dimensional check of the extruded part (N31a-16) | Add the plane-stress known answer |
   | FD-FSIM-28 | `fs-topopt::sdf3`: no stable, ungated surface | Reached behind its feature through the airlock, pinned by commit (N31a-15) | Remove the feature gate from the airlock entry |
   | FD-FSIM-29 | `fs-fab`: no geometric evaluators for overhang and tool access | `frob-foundry` owns the evaluators and reports `review: no-claim` (N31a-28) | Differential test, then delete the local evaluators |
   | FD-FSIM-30 | `fs-mesh`: no statement of boundary conformity | Conformity is measured per mesh and recorded with the structural evidence (N31a-17) | Replace the measurement with the stated bound where it applies |
5. **Switch-over tests** exist from the start and are marked `ignored` with the FD identifier; un-ignoring one is
   the first step of the switch.

## Acceptance criteria

- [ ] Every wrapper compiles in `inproc` and `remote` airlock modes and returns identical result bytes for the probe fixtures in both.
- [ ] Each of the fourteen rows has at least one probe; the probe list is printed by `cargo test -p frob-foundry sibling_facts -- --list` and matches `docs/foundry/sibling_gaps.md`.
- [ ] A sibling refusal surfaces as a Foundry refusal with `upstream_reason` filled, verified on three planted invalid inputs (inverted tetrahedron, negative sensitivity, open shell).
- [ ] The five switch-over tests exist, are ignored, and name their FD identifier.
- [ ] Without the `structure` group, every wrapper returns the group-absent refusal (`FROB-REF-790`, exit 5) and nothing panics.

## Test plan

### Unit tests
The probes of step 3, plus: `wrapper_records_stack_digest`; `refusal_is_converted_not_retried` (a counter in
the test adapter shows one upstream call); `remote_and_inproc_bytes_equal`; `group_absent_refuses_790`.
Planted defects, each caught: `retry-with-relaxed-tolerance` (the wrapper retries a refused mesh with a looser
quality bound), `drop-upstream-reason`.

### End-to-end script and logging
`scripts/e2e/foundry_sibling_facts.sh` (this bead's own, built only on its dependencies; it sources the
STD-E2E helper library). Steps: (1) `cargo test -p frob-foundry --features structure --test sibling_facts`
through `e2e_cmd`: every probe passes, each logged with its name, its gap-table row and the stack-lock digest
it recorded; (2) the same with `-- --list`: the sorted probe names equal those named in
`docs/foundry/sibling_gaps.md` (`e2e_assert_eq`), and a `metric` line counts the rows with at least one probe
against 14; (3) the same with `-- --ignored --list`: the five switch-over tests are listed (not run), each
named with its FD identifier, FD-FSIM-26 to -30; (4) `cargo test -p frob-foundry --features structure -- sib`:
the wrapper tests, `remote_and_inproc_bytes_equal` (the airlock-mode comparison), the three planted invalid
inputs with `upstream_reason` filled, and the two planted defects caught; (5) `cargo test -p frob-foundry --
sib::group_absent_refuses_790` in the build without the `structure` group: the 790 refusal with exit 5 and no
panic. No `frob` verb is called, so the evidence block is recorded as absent with reason `no-verb`. Logs to
`target/e2e-logs/foundry_sibling_facts/<utc>.ndjson` with a transcript: per line `ts`, `script`, `bead` =
N31a-04, `step`, `event`, the command, exit code and wall time; on failure the failing probe and the FACT it
guards; a final `summary`. The verb-level check is a step of `scripts/e2e/foundry_check.sh` (N31a-55), which
runs this script as a stage: at start it logs the stack-lock digest and the airlock mode from `frob doctor
--json`, and asserts they equal those in every result's evidence block.

### Known answers and negative controls
The residue probe is known answer KA-170 (history 0, 10, 0 in two windows: one full cycle of range 10; a
counter that drops residues counts none). The tetrahedron STEP document has 18 instances (KA-748). Controls:
the two planted defects. Determinism: probe outputs are compared bitwise between two runs and between airlock
modes on one machine.

## Considerations

- The whole chapter leans on feature-gated or Frontier-tagged upstream code (`sdf3`). The pin protects against
  drift; the probes say when a move of the pin changes a fact.
- The compile cost of the `structure` group is about 412 thousand lines; if it does not fit the build envelope,
  Foundry reaches the group only through the worker, and the wrappers already allow that.
- `fln-verdict` belongs to another sibling repository at another commit; its probe records that commit too.
