## Background

A part that passes every structural check can still be impossible to make: a wall thinner than the process can
hold, an internal corner sharper than any cutter, a pocket no tool can reach, a ceiling a printer cannot
bridge, a cavity full of trapped powder. Topology optimization produces such features freely. Manufacturability
is the set of checks that says which features of a geometry a declared process cannot produce, where they are,
and what value would be acceptable.

**Each made part declares a process: `cnc-3axis`, `cnc-5axis`, `sheet`, `fdm`, `sls` or `slm`.** The
fabrication sibling holds the limits; the geometry-constraint sibling measures some features; the rest is
measured by `frob-foundry`:

| Feature | Measured by | Limit from | Process |
|---|---|---|---|
| Minimum wall and member thickness | `fs-geocon::min_thickness_soft` | `fs-fab::min_feature_size` | All |
| Internal corner radius | Curvature of the distance field (ours) | `fs-fab::cnc_tool_radius` | Milling |
| Tool access | Visibility of each surface point along the declared setup directions for the stated tool radius and reach (ours) | Setup list on the process card | Milling |
| Overhang angle | Angle between surface normal and build direction (ours) | `fs-fab::overhang_angle` | Additive |
| Draft and undercut | `fs-geocon::draft_violations` | `fs-fab::draft_angle` | Moulded |
| Enclosed voids | Connected components of the complement (ours) | None for milling; drain holes for powder processes | All |
| Keep-in and keep-out | `fs-geocon::envelope_violation` | The design region | All |

The division follows a fact about the siblings: the fabrication sibling "compares a supplied number with a
limit. It does not measure geometry", and has no process-capability data, machine models or prices; the
geometry-constraint sibling has no overhang, tool-access or corner-radius measure, and its thickness and
envelope values carry estimate authority.

Cost and embodied carbon are parametric estimates with a relative uncertainty, class Estimated, and are
printed only when a process card supplies the unit rates.

Foundry fabricates nothing: a manufacturability pass is a statement about a geometric model against declared
limits, with `review: no-claim` until a person or a shop says otherwise.

## Scope

In: the process card; the dispatcher from process to checks; adapters for the three sibling-measured features;
the findings record with location and repair; the gating and advisory modes; cost and carbon; the `fab.json`
section; the manufacturability half of the verb `foundry.check`.
Out: the four Foundry-owned evaluators (corner radius and enclosed voids in N31a-27; tool access and overhang
in N31a-28); constraints active inside the optimization and the repair re-run (N31a-29); the fixture battery of
GATE-FOUNDRY-07 (N31a-30).

## Technical approach

1. **Process card** (`fab/process.rs`; card kind `process`, DESIGN):
   ```toml
   process = "cnc-3axis"
   min_feature_size_m = { value = 0.0015, provenance = "datasheet" }
   tool_radii_m = [0.0015, 0.003, 0.005]          # available cutters; the smallest bounds corner radius
   tool_reach_m = 0.040; tool_type = "flat"       # or "ball"
   setups = [[0, 0, 1], [0, 0, -1]]               # directions the tool comes from, part frame
   cone_half_angle_deg = 0                        # 5-axis: tilt allowed about each setup
   overhang_max_deg = 45; build_directions = [[0, 0, 1]]; max_bridge_m = 0     # additive
   drain_hole_min_m = 0.003                       # powder processes
   draft_min_deg = 0; demould_direction = []      # only on a card that declares a moulded process
   stock_thickness_m = []; kerf_radius_m = 0      # sheet
   [rates]                                        # optional; cost and carbon print only if present
   material_per_kg = …; machine_per_hour = …; removal_rate_m3_per_h = …; carbon_per_kg = …; rel_uncertainty = 0.3
   ```
2. **Dispatcher** (`fab/dispatch.rs`):

   | Process | Checks run |
   |---|---|
   | `cnc-3axis`, `cnc-5axis` | thickness; corner radius; tool access (5-axis samples the tilt cone); enclosed voids (any void is a violation); envelope |
   | `sheet` | constant stock thickness; thickness of in-plane features; corner radius against kerf; envelope |
   | `fdm` | thickness; overhang; enclosed voids reported; envelope |
   | `sls` | thickness; enclosed voids need a drain; envelope (powder is self-supporting: no overhang limit) |
   | `slm` | thickness; overhang; enclosed voids need a drain; envelope |
   | any card with `draft_min_deg > 0` | draft and undercut along the demould direction |
3. **Adapters.** Thickness: the sibling's soft minimum thickness on the part's distance field, with the
   location of the minimum. Draft: the sibling's draft violations with undercuts flagged. Envelope: its
   envelope violation against the region record of the part's class. Each returns a measured value with
   estimate authority.
4. **Limits and repairs.** Every measured value is handed to the fabrication sibling's `check_all` with the
   card's limits; a violation comes back with a repair target (the value that would pass) and the difference.
5. **Finding** (`frob.foundry.fab.finding/1`):
   `{ part, process, feature, location: {point, region}, measured, limit, difference, unit, repair:
   {target, edit_hint}, severity, evaluator: {name, version}, class: "Estimated" }`. Locations are points in
   the part frame plus the connected surface region that violates, with its area.
6. **Report and modes.** `fab.json` per packet and per check: for each made part, process, card hash, checks
   run, findings, `pass: true|false`, and `review: "no-claim"`. Mode `gating` (default): `pass` is recorded
   and the structure loop reacts to violations (N31a-29). Mode `advisory` (the KILL-FAB fallback): findings
   are lints, and the packet records `manufacturability: not assessed as pass` with no `pass` field at all.
7. **Cost and embodied carbon.** Only when `[rates]` is present: material cost = stock mass × rate; machine
   cost from removed volume ÷ removal rate (milling) or build volume and height (additive) × hourly rate;
   carbon = mass × factor. Each printed as value ± relative uncertainty from the sibling's parametric
   estimators, class Estimated, with the card as the weakest input. Without rates the fields are absent, not
   zero.
8. **Verb.** `foundry.check <geometry | design part> --fab [--process <card>]`: kind `run`; findings give
   exit 2; a part with no declared process is a refusal of the request's schema (the declaration is required).

## Acceptance criteria

- [ ] Each of the six processes dispatches exactly the checks of the table above (a table-driven test).
- [ ] A plate fixture 1.0 mm thick against `min_feature_size` 1.5 mm yields a thickness finding with measured 1.0 mm, limit 1.5 mm, difference 0.5 mm, a location on the plate, and the repair target 1.5 mm.
- [ ] A clean part yields `pass: true` and no findings for its process.
- [ ] A part outside its keep-in by 2 mm yields an envelope finding with that distance.
- [ ] Cost and carbon fields are absent without `[rates]` and present with value and relative uncertainty when rates exist.
- [ ] In advisory mode the report has no `pass` field and the packet text says no manufacturability pass is recorded.
- [ ] Every finding carries class Estimated and the evaluator's name and version; `review` reads `no-claim`.
- [ ] A made part without a process declaration cannot be checked or packed.

## Test plan

### Unit tests
`cargo test -p frob-foundry fab::process fab::dispatch fab::cost`:
- `dispatch_table_matches_spec` (six processes plus the draft rule).
- `thin_plate_finding_with_repair`: measured 1.0 mm; target 1.5 mm; difference 0.5 mm.
- `envelope_violation_distance`.
- `draft_and_undercut_on_moulded_card`: a wall at 0.5° draft against a 2° minimum is flagged with difference 1.5°; a face tilted 5° the wrong way is flagged as an undercut.
- `sls_has_no_overhang_check`; `milling_void_is_violation`; `fdm_void_is_reported_not_violated`.
- `cost_absent_without_rates`; `cost_with_rates_and_uncertainty`: 0.2 kg stock at 8 per kg plus 1.0 × 10⁻⁵ m³ removed at 2.0 × 10⁻⁴ m³/h and 60 per hour gives 1.6 + 3.0 = 4.6, printed ± 30%.
- `advisory_mode_has_no_pass_field`.
- `finding_schema_valid`.
- `process_declaration_required`.
- Planted defects, each caught: `compare-in-wrong-units` (millimetres against metres; caught by dimension typing at compile time), `pass-true-when-no-checks-ran`, `cost-printed-with-default-rates`.

### End-to-end script and logging
`scripts/e2e/foundry_check.sh` (bead N31a-55): `frob foundry check --fixture thin-plate --fab --process
cnc-3axis --json` (assert exit 2, the finding and its repair), the clean bracket fixture (exit 0,
`pass: true`), and the same with a rates card (cost present with uncertainty). Logged: process, card hash,
checks run, findings count by feature, each finding's measured value, limit and difference.

### Known answers and negative controls
Hand values in the tests above. Negative controls: the three planted defects. Metamorphic: tightening any
limit never removes a finding; scaling the part and all limits by the same factor leaves the set of findings
unchanged. Determinism: adapters and dispatcher are deterministic; findings are sorted by part, feature and
location.

## Considerations

- KILL-FAB (M5): trigger GATE-FOUNDRY-07 fails. Fallback: manufacturability findings become advisory lints and
  a packet records no manufacturability pass. The mode switch above is that fallback.
- The plan's table names a "Moulded" row, but no moulded process is among the six a part can declare. The row
  is implemented and stays dormant until a process card declares a demould direction and a draft minimum.
- Limits on a generic card are typical values, not a shop's capability. The first import of a real quotation
  or first-article inspection is where they meet reality; until then `review: no-claim`.
- Geometric measures have estimate authority: a part 1% above a limit is not certified to be makeable.
