## Background

A *method experiment* asks whether a mechanism of FrankenRobotics (a rung of the evaluation ladder, a family
policy, an adversarial search, a runtime shield, a kernel specialization) does better than doing without it. The
planning pilots of this program showed how such experiments fail quietly: a speed test was run whose largest
possible result was below its success threshold; every pilot's strong baseline tied or won; a decision rule could
not return one of its own verdicts at its planned sample size; and a draft rule "the point estimate is at least
10 on every brief" would have confirmed a true ratio of 10 in at most 18% of simulated campaigns (FACT, planning
pilot). The draft rule was replaced, before any measurement, by a pooled ratio with a paired lower bound and a
power analysis.

The Gauntlet (the verification subsystem, crate `frob-conformance`) therefore registers every method experiment
in the ledger before it runs, in a fixed form of six parts. An experiment that lacks one part is not admitted,
and a result from it cannot be cited by a gate (GATE-GAUNT-09). Rejected alternative: a review checklist; the
decision must be made before the data can argue, and only a record written and hashed beforehand shows that.

## Scope

In: the record, the admission check, the three further rules, the refusals, the link from a gate row to an
admitted experiment. Out: the statistics themselves (N38a-08); the design corpus that serves as potency control
for analyses and screens (N38a-22); the ten-fold test's own protocol.

## Technical approach

**The six parts, each written down before the first run.**

| Part | What is recorded | Why |
|---|---|---|
| Ceiling | The largest effect the experiment could show, computed from a phase breakdown measured on the baseline arm | A test whose ceiling is below its success threshold cannot confirm anything |
| Competing arms | The mechanism; the strongest conventional alternative at equal resources; the mechanism's own fallback; and, where an incumbent could host the same method, a composed-incumbent arm | Every planning pilot's strong baseline tied or won; an arm against a weak baseline measures the baseline |
| Potency control | A planted effect of the declared size that the experiment must detect, and an A/A arm that it must not | An experiment that cannot see a planted effect is silent about a real one; an A/A campaign that clears 1.02 has a broken harness |
| Paired lower bound | Arms paired by world address and seed; the reported quantity is a lower confidence bound on the paired ratio or difference, never a ratio of means. Ten pairs of constant ratio r must return the bound r | Pairing removes world variance; a bound, not a point estimate, is what a kill rule reads |
| Pre-declared fallback | What ships if the falsifier holds, named with its kill gate | The decision is made before the data can argue |
| Reachability pre-analysis | Fixed-n study: every verdict the rule can return at the planned n and level, and the power at declared alternatives. Anytime-valid study: the budget at which the e-process can cross its threshold under the declared alternative | At 64 pairs one frozen rule cannot return one of its four verdicts (FACT); a verdict that cannot be reached must not be promised |

**Record (`crates/frob-conformance/registry/experiments.toml`; schema `frob.gauntlet.experiment/1`).**
```toml
[[experiment]]
id = "EXP-0001"                      # append-only
mechanism = "…"; question = "…"; claim = "design-comparison"   # or "performance"
study_type = "fixed-n"               # fixed-n | anytime-valid ; never both
success = { quantity = "paired-ratio-lower-bound", op = ">=", value = "1.25", level = "0.05" }
[experiment.ceiling]      baseline_ledger = "seq:…"; phases = [{ name = "solve", wall_s = "…" }]
                          f = "…"; r = "…"; h = "…"; value = "…"; computed = "…"
[experiment.arms]         mechanism = "…"; conventional = "…"; resources = "equal: …"; fallback = "…"
                          composed_incumbent = "…"       # or "not-applicable: <reason>"
[experiment.potency]      planted_effect = "…"; must_detect = true; aa_arm = true; aa_threshold = "1.02"
[experiment.pairing]      unit = "world-address+seed"; cluster = "…"; determinism_class = "D2"
[experiment.fallback]     ships = "…"; kill_gate = "KILL-…"
[experiment.reachability] n = 64; verdicts = ["prefer", "inferior", "inconclusive"]; unreachable = []
                          power = [{ alternative = "…", value = "…" }]   # or budget_to_cross for anytime-valid
registered = { ledger_seq = "…", date = "…", protocol_blake3 = "…" }
runs = []                            # appended by the harness; each cites the protocol hash
```

**Admission check (`experiments::admit`).**
1. All six tables present and non-empty, else `not-admitted: missing <part>`.
2. `registered.ledger_seq` precedes the first entry of `runs`; a run recorded before registration voids the
   experiment.
3. `ceiling.value` recomputed from `f`, `r`, `h` equals the stored value; if `ceiling.value < success.value` for
   a speed or efficiency claim the experiment is refused with `FROB-REF-866` (a speed experiment requested
   without its computed ceiling, or with a ceiling below its goal).
4. `success.quantity` must be a paired lower bound; a ratio of means or a point estimate is refused with
   `FROB-REF-863` (a performance ratio without a paired lower bound).
5. Fixed-n: the pre-analysis is re-enumerated; if `success` or any promised verdict is in `unreachable`, the
   experiment is refused with `FROB-REF-532` (a fixed-n study has no pre-analysis, or names a verdict it cannot
   reach).
6. `study_type` is single-valued; a record that states a fixed-n verdict and an e-process threshold for the same
   question is refused with `FROB-REF-552` (a request mixes study types).
7. `pairing.determinism_class` must be D2 on one device family (or D1 across families) for `paired-exact`; D3 is
   admitted as `paired-by-address`, labelled; D4 or an unrecorded class is refused with `FROB-REF-561`.
8. `arms.conventional` names a baseline with `resources = "equal: …"`; an experiment with only a weak or absent
   conventional arm is `not-admitted: no strong baseline`.

**Three further rules.** (a) The two study types are never mixed inside one experiment. (b) Paired statistics are
refused under an uncontrolled determinism class. (c) A confirmatory experiment about a design or a policy runs in
the blinded qualification lane at the level of its request; the development batch that suggested it keeps its
original analysis and is not counted again (the record carries `suggested_by = "<study id>"` and the check
refuses a confirmatory result whose units overlap the suggesting batch).

**Link to gates.** A gate row may cite a method-experiment result only when the experiment's `id` is admitted and
the result's `protocol_blake3` equals the registered one. The recorder refuses otherwise.

## Acceptance criteria

- [ ] GATE-GAUNT-09 (TARGET): every registered method experiment has the six parts; a planted experiment with an
      unreachable verdict is refused; the harness passes its exactness obligation (N38a-08).
- [ ] Each of the eight admission steps has a planted record it refuses, with the stated code or reason.
- [ ] A run dated before registration voids the experiment.
- [ ] A gate row citing a non-admitted experiment, or a result with a different protocol hash, is refused.
- [ ] The worked case is reproduced: a speed experiment with ceiling 1.46 and success threshold 2.0 is refused
      with `FROB-REF-866`.

## Test plan

### Unit tests

`crates/frob-conformance/tests/experiment_register.rs`:
- `six_parts_required`: six planted records, each missing one part, each `not-admitted` naming the part.
- `ceiling_below_threshold_refused`: f = 0.3169, r → ∞, h = 0 gives ceiling 1.464; threshold 2.0 → `FROB-REF-866`.
- `ratio_of_means_refused`: `FROB-REF-863`.
- `unreachable_verdict_refused`: a fixed-n rule at n = 64 that promises `tie` (first reachable at n = 86) →
  `FROB-REF-532`; the same rule at n = 86 is admitted.
- `mixed_study_types_refused`: `FROB-REF-552`.
- `uncontrolled_class_refused`: class D4 → `FROB-REF-561`; class D3 admitted with label `paired-by-address`.
- `weak_baseline_not_admitted`.
- `run_before_registration_voids`.
- `confirmatory_units_disjoint`: overlap of one world cluster with the suggesting batch is refused.
- `gate_cites_only_admitted`.

### End-to-end script and logging

`scripts/e2e/experiment_form.sh` (header: `bead=N38a-07 milestone=M1 labels=gauntlet,gate
gates=GATE-GAUNT-09 plants=unreachable-verdict,missing-ceiling`). It registers a complete experiment in a scratch
registry, admits it, then plants each defect and requires the refusal; with the `frob` binary present it calls
`frob eval preanalyze` for the fixed-n rule and compares the reachable verdicts with the record. Log at
`target/e2e-logs/experiment_form/<utc>.ndjson`: commands with exit codes and wall time, one `refusal` line per
planted record (code, message, repairs), the count of admitted and refused records as `metric` lines, the
assertions tagged GATE-GAUNT-09, and the `summary`.

### Known answers and negative controls

Known answers: the enumeration of the frozen rule at n = 64 gives 2,145 count pairs (521 prefer, 521 inferior,
0 ties, 1,103 inconclusive) and a tie is first reachable at n = 86; the peeking counterexample for mixing types
(an exact one-sided sign test at nominal 5% looked at after every pair rejects falsely with probability
13/256 = 5.08% after 8 looks, 8.76% after 16, 12.9% after 32, 17.4% after 64). Negative controls: the eight
planted records. Determinism lane: admission is class D0; identical twice and on both platforms.

## Considerations

- Kill gates are named per experiment in its `fallback` table; this bead has none of its own.
- The 2% tolerance of an A/A arm (1.02) is a TARGET of the performance program and is shared with it.
- An experiment whose run exceeds the default machine envelope names its budget and waits for the owner's
  approval; the record carries the approval reference.
- Risk: the register becomes ceremony. It exists because a gate reads it; an experiment no gate or funding
  decision cites is not registered.
