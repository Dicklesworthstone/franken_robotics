## Background

Two components of FrankenRobotics turn raw episodes into verdicts at M1, and the verification subsystem (the
Gauntlet, crate `frob-conformance`) self-tests each as a *certifier* in tier G0 under gate GATE-GAUNT-04. (A
third, the rare-event bounds, is self-tested as CERT-13 by N38bp1-03 at M3, where its estimators land; it was
first carried here, in an M1 bead that could not depend on them.)

- *Requirement monitors.* A task's requirement is a formula over signals with temporal operators; its verdict
  and margin are computed by three independent evaluators of the requirement language (among them a streaming
  past-time monitor and an offline evaluator). If they disagree, a verdict depends on which code path ran.
- *The fixed-n pre-analysis.* A study with a fixed number of pairs uses a frozen decision rule. Before sampling,
  every verdict the rule can return at the planned n is enumerated; a verdict that cannot be reached must not
  be promised. A planning pilot found that at 64 pairs the frozen rule can return three of its four verdicts
  and that a tie is first reachable at 86 pairs (FACT, to be re-run here).

## Scope

In: the two self-tests with thresholds, inputs and broken-certifier controls. Out: the monitors and the study
runner; the monitors' refusal battery; the rare-event bounds' self-test, CERT-13, with its estimators
(N38bp1-03, M3); attribution and conformal bands (N38b-15); the M1 end-to-end run (N38bp1-02).

## Technical approach

**CERT-11 Requirement monitors.** For each operator of the language (the Boolean connectives, the bounded
past-time and future-time windows, `until`, and the unit-normalized atoms), draw 10⁶ random traces (address-keyed
generator; lengths 1 to 4,096 samples; multi-rate signals; window bounds that need the declared rounding to a
clock period) and evaluate verdict and margin with all three evaluators. Threshold: agreement bit for bit on
every trace, for verdict and for margin. Relations checked on the way: streaming past-time robustness equals
offline evaluation; "globally over [0, T]" evaluated at 0 equals "historically over [0, T]" evaluated at T.
Broken certifier (control): a monitor that pads a short window with the neutral element instead of refusing or
shortening as declared; it disagrees with the other two on traces shorter than the window.

**CERT-12 Fixed-n pre-analysis.** The frozen rule: for paired binary outcomes with a counts of A-only successes
and b counts of B-only successes among n pairs, the effect estimate is (b − a)/n. Form two-sided 97.5% exact
Clopper–Pearson intervals [L_b, U_b] for b of n and [L_a, U_a] for a of n (each tail 0.0125: L_k is the 0.0125
quantile of Beta(k, n − k + 1), 0 when k = 0; U_k the 0.9875 quantile of Beta(k + 1, n − k), 1 when k = n); the
interval [L_b − U_a, U_b − L_a] covers the difference with probability at least 95%. Verdicts with the ±5 point
indifference band: *prefer B* when L_b − U_a > +0.05 (and B violates no hard limit where A does not; not
exercised by the enumeration); *B inferior* when U_b − L_a < −0.05; *practical tie* when the interval lies inside
[−0.05, +0.05]; *inconclusive* otherwise. Regenerate, by exact enumeration of all (a, b) with a + b ≤ n (there
are (n + 1)(n + 2)/2 such pairs; every count below follows from the statement above):

| n | Count pairs | Prefer B | B inferior | Practical tie | Inconclusive |
|---|---|---|---|---|---|
| 64 | 2,145 | 521 | 521 | 0 | 1,103 |
| 86 | 3,828 | 1,031 | 1,031 | 1 | 1,765 |
| 128 | 8,385 | 2,517 | 2,517 | 4 | 3,347 |
| 256 | 33,153 | 11,384 | 11,384 | 39 | 10,346 |

Further exact facts to reproduce: perfect concordance at n = 64 gives the interval [−0.0662, +0.0662]
(1 − 0.0125^(1/64) = 0.0662), so no outcome returns a tie; a tie is first reachable at n = 86 and only for
(0, 0), with chance 0.9⁸⁶ = 0.0116% at 5% discordance each way; with no A-only pair a preference needs 15
B-only pairs of 64, and 17, 19, 21, 23 with one to four A-only pairs. Threshold: exact equality with the table,
and a request that declares the tie verdict at n = 64 is refused (existing refusal FROB-REF-532): at M1 by the
pre-analysis verb itself (`eval.preanalyze` with `declared_verdicts`, N24b-06), which this bead measures; study
admission refuses it too (`study.plan` through `study::admit`, N24b-14, answering at M1 in the CPU form of
N33b-19), but that path is not among this bead's dependencies and is not measured here.
Broken certifier (control): a pre-analysis that uses a normal approximation reports a reachable tie at n = 64.

**Evidence.** Class `Tested`, kind known answer; tier G0, site `host`; D0 for CERT-12, D0 given the seed for
CERT-11.

## Acceptance criteria

- [ ] CERT-11: zero disagreements over 10⁶ traces per operator; the padding monitor is caught.
- [ ] CERT-12: the four table rows and the three further facts reproduce exactly; the tie request at n = 64 is
      refused; the normal-approximation variant is caught.
- [ ] The two rows are in the certifier register with controls and are read by GATE-GAUNT-04 at M1.

## Test plan

### Unit tests

`crates/frob-conformance/tests/cert_evaluators.rs`:
- `monitors_agree_per_operator` (count from `FROB_PROP_CASES`; the gate run passes 10⁶ explicitly).
- `monitors_edge_traces`: empty window, window equal to trace length, a window bound of 2.5 clock periods with
  declared rounding.
- `preanalysis_table_64_86_128_256`: the sixteen counts above.
- `pair_counts`: 65·66/2 = 2,145; 87·88/2 = 3,828; 129·130/2 = 8,385; 257·258/2 = 33,153.
- `concordance_interval_64`: 0.0662 to four decimals; `first_tie_at_86`; `tie_chance`: 0.9⁸⁶ = 1.16 × 10⁻⁴.
- `preference_needs_15_17_19_21_23`.
- `tie_at_64_refused`: a pre-analysis request at n = 64 declaring `practical-tie` → FROB-REF-532, with the
  reachable set and the first n (86) attached.
- `padding_monitor_control`: the padding monitor disagrees on a trace shorter than its window and is caught.
- `normal_approximation_control`: the normal-approximation pre-analysis reports a reachable tie at n = 64 and
  is caught.

### End-to-end script and logging

Measured at M1 by `scripts/e2e/certifiers.sh M1` (bead N38bp1-02; re-run at later exits through N38b-17):
`frob task verdict` on recorded traces through each evaluator, `frob eval preanalyze --rule
paired-clopper-pearson/1 --n 64|86|128|256 --margin 0.05 --level 0.05 --json`, and the same at `--n 64` with
`--declared-verdicts practical-tie` (refused, FROB-REF-532). Logged: disagreements per operator (threshold 0), the table as
measured against the expected counts, the refusal code, and each broken certifier's outcome.

### Known answers and negative controls

Known answers: the enumeration table (KA-612); the reachable-verdict fact (KA-002). Negative controls: the
padding monitor; the normal-approximation pre-analysis. Metamorphic relation: a change of units leaves normalized margins unchanged.
Determinism: enumeration is exact (D0); trace generation is address-keyed.

## Considerations

- The interval [−0.0662, +0.0662] reconciles only with two-sided 97.5% intervals; at 95% the bound is 0.0560
  and the first tie is at n = 72. The level is part of the rule and must be stated wherever the numbers are
  (N38b-59).
- 10⁶ traces per operator on three evaluators is a nightly run inside the default envelope when traces are
  short; the count is printed if reduced.
