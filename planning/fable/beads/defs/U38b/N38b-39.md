## Background

FrankenRobotics integrates rigid-body motion with the *Cayley map*, a rational map from a velocity (an element
x of the Lie algebra) to a group element: cay(x) = (I − x/2)⁻¹·(I + x/2). It is used instead of the matrix
exponential because it is rational, lands on the group exactly and agrees with the exponential to second
order. On rotations it gives R = I + 4/(4 + ‖ω‖²)·(ω̂ + ω̂²/2), where ω̂ is the skew matrix of ω. On rigid
motions (rotation and translation together) the pair (ω, v) maps to rotation cay(ω̂) and translation
(I − ω̂/2)⁻¹·v.

The tempting shortcut is to compute the rotation correctly and carry the translation v across unchanged. It is
right for pure translation and for small steps to first order, so ordinary tests miss it. The verification
subsystem (the Gauntlet) adopts the smallest case that separates the two as a known answer under gate
GATE-GAUNT-11 (claim kind: known answer; every adopted row reproduced at its tolerance, rational rows exact,
and every negative control failing; each row lands at the milestone of its owner section, here M0 with the
Lie-group core).

## Technical approach

**The row (KA-845).** Input ω = (0, 0, 2), v = (1, 0, 0).
1. ω̂/2 = [[0, −1, 0], [1, 0, 0], [0, 0, 0]].
2. (I − ω̂/2) = [[1, 1, 0], [−1, 1, 0], [0, 0, 1]]; its inverse is ½·[[1, −1, 0], [1, 1, 0], [0, 0, 2]].
3. Rotation: (I − ω̂/2)⁻¹·(I + ω̂/2) = [[0, −1, 0], [1, 0, 0], [0, 0, 1]], a quarter turn about z.
4. Translation: (I − ω̂/2)⁻¹·v = (1/2, 1/2, 0).
Truth is exact in rationals. Check also: the step rotates by 2·atan(‖ω‖/2) = 2·atan(1) = π/2, not by ‖ω‖ = 2 rad,
which is the known second-order difference from the exponential.

**Tests.**
1. *Exact*: evaluate the crate's Cayley map over a rational scalar type (or the host's big-rational test
   scalar) and compare all twelve entries exactly.
2. *Double precision*: the same through the `f64` path; entries equal to within one unit in the last place
   (the values 0, ±1, ½ are exactly representable; the test asserts bit equality).
3. *Group membership*: RᵀR = I and det R = 1 exactly in rationals.
4. *Differential test*: for the left-trivialized differential Dcay_x defined by cay(x)⁻¹·δcay(x) = Dcay_x(δx),
   compare Dcay_x(δx) with the central finite difference of cay at x along each of the six basis directions,
   step 10⁻⁶, tolerance 10⁻⁸, at x = (ω, v) above and at 100 seeded points with ‖ω‖ ≤ 0.2.
5. *Refusal boundary noted, not used as a control*: the product refuses the Cayley step when ‖ω‖·h exceeds its
   admitted bound per step; the known answer is evaluated through the mathematical function, outside a step.

**Negative control (seed: the catalogue entry on the unpaired translation; kind `mutation`; gate
GATE-GAUNT-11).** Feature `nc-<id>` in the Lie-group crate replaces the translation part by v unchanged. Under
the mutant: the row returns (1, 0, 0) and fails test 1; the differential test fails in the translation block
for every direction with a rotational component. The control is `caught` only if both failures are observed
for those reasons.

**Evidence.** Kind known answer, class `Tested`, tier G1, site `host`, determinism D0.

### Known answers and negative controls

Known answer: quarter turn about z and (1/2, 1/2, 0). Negative control: the unpaired translation, (1, 0, 0).
Metamorphic relations: conjugating (ω, v) by a rotation conjugates the result; scaling lengths by a power of
two scales the translation by the same factor and changes no rotation bit. Determinism lanes: `twice`,
`profiles` and `platforms`, class D0.
