## Background

FrankenRobotics calibrates the mounting of a robot's sensors by weighted least squares on a graph: nodes are
sensor frames and the base, unknowns are small corrections δ (twists, six numbers each: an angular and a
linear part) to each sensor's mount transform, and edges are pairwise relative-pose measurements. Linearized,
an edge from sensor 1 to sensor 2 has residual r₁₂ = log(T̂₁₂⁻¹·T₁₂) ≈ δ₂ − Ad(T̂₂₁)·δ₁, where T̂₁₂ is the
predicted and T₁₂ the measured pose of sensor 2 in the frame of sensor 1, T̂₂₁ = T̂₁₂⁻¹, and Ad is the adjoint
map that re-expresses a twist in another frame: for a pose (R, p) and a twist (ω, v),
Ad(R, p)·(ω, v) = (R·ω, p × R·ω + R·v). Corrections are applied on the right of each mount transform.

The tempting shortcut is to use the adjoint of the predicted pose itself, Ad(T̂₁₂), on the tail of the edge.
For a pure rotation between sensors the two agree in the angular part and the error hides; with a lever arm
the linear part comes out with the wrong sign. The verification subsystem (the Gauntlet) adopts the smallest
case that separates them under gate GATE-GAUNT-11 (known answer; rational rows exact; every negative control
fails), landing at M3 with sensor calibration.

## Technical approach

**The row (KA-849).** Predicted pose of sensor 2 in sensor 1: a translation of (1, 0, 0) m, no rotation.
Sensor 1's mount is off by a rotation of 0.01 rad about z: δ₁ = (ω = (0, 0, 0.01), v = 0). Sensor 2's mount is
exact: δ₂ = 0.
1. T̂₂₁ is the translation (−1, 0, 0).
2. Ad(T̂₂₁)·δ₁ = (ω, p₂₁ × ω) = ((0, 0, 0.01), (−1, 0, 0) × (0, 0, 0.01)) = ((0, 0, 0.01), (0, 0.01, 0)).
3. r₁₂ = δ₂ − Ad(T̂₂₁)·δ₁: angular part (0, 0, −0.01) rad; linear part (0, −0.01, 0) m.
4. Reading: sensor 2 appears at (1, −0.01, 0) m in sensor 1's frame, as it must when sensor 1's frame is
   turned counter-clockwise by 0.01 rad.
Truth is exact to first order in rationals (1/100). The full nonlinear relative transform T̂₁₂⁻¹·T₁₂ has
rotation −0.01 rad about z and translation (cos 0.01 − 1, −sin 0.01, 0) = (−0.00005, −0.0099998, 0) m; its
logarithm differs from the row only at second order. The test checks first-order agreement to 10⁻⁴ m and the
linearized block exactly.

**Tests.**
1. *Host, exact*: build the edge's Jacobian block for the tail node and multiply by δ₁ in rationals; compare
   with (0, 0, −1/100; 0, −1/100, 0).
2. *Through the verb*: a two-sensor rig description with the planted mount error; `sense.calibrate` reports
   the edge residual before the solve (equal to the row within 10⁻⁴ m and 10⁻⁶ rad) and recovers δ₁ after the
   solve (0.01 rad about z within the verb's stated uncertainty), attributing it to sensor 1.
3. *Sign sanity by simulation*: on the referee, place a marker at sensor 2's true position and read it from
   the rotated sensor 1; the measured y coordinate is negative.

**Negative control (seed: the catalogue entry on the wrong adjoint; kind `mutation`; gate GATE-GAUNT-11).**
A feature in the sensing crate uses Ad(T̂₁₂) on the tail: (1, 0, 0) × (0, 0, 0.01) = (0, −0.01, 0), so the
residual's linear part is (0, +0.01, 0) m. Under the mutant test 1 fails in the linear block, and the solve of
test 2 either fails to converge to the planted error or attributes it with the wrong sign. `caught` requires
the linear-part sign failure.

**Evidence.** Known answer, class `Tested`, tier G1, sites `host` and `referee`; determinism D0 on the host.

## Acceptance criteria

- [ ] The linearized residual is (0, 0, −0.01) rad and (0, −0.01, 0) m exactly on the host.
- [ ] `sense.calibrate` prints the same residual for the edge and recovers the planted 0.01 rad on sensor 1.
- [ ] The wrong-adjoint mutant yields a linear part of (0, +0.01, 0) m and is caught.
- [ ] The `ka: KA-849` metric lines of the latest `sense_calibrate.sh` log (N20b-07) agree with the host values
      within 10⁻⁴ m and 10⁻⁶ rad.
- [ ] The row is recorded as the M3 part of GATE-GAUNT-11 from the receipt of `adopted_known_answers.sh M3`
      by a session that did not implement the solver.

Conformance entries `ka:KA-849@host`, `@referee`, and `crates/frob-conformance/tests/adopted_rows_m3.rs`:
- `ka_849_tail_block_exact`: rationals, six components.
- `ka_849_adjoint_definition`: Ad(R, p)·(ω, v) = (R·ω, p × R·ω + R·v) checked against conjugation of the

- `ka_849_marker_sign_on_referee`: y < 0.

### End-to-end script and logging

`scripts/e2e/adopted_known_answers.sh M3` (bead N38b-46): `frob --json sense calibrate` on the two-sensor rig,
then this bead's tier entries and control; logs, with the fields of STD-E2E (`ts`, `script`, `bead`, `step`,
`event`; exact command, exit code, wall time; the envelope's evidence block), the six residual components with
units against the truth and tolerance, the recovered correction with its uncertainty, the attributed node, the
control's outcome with the observed linear part (0, +0.01, 0) m, and on failure the first differing component
with observed and expected values and the rig and feature flags to reproduce it. The verb's own script
`scripts/e2e/sense_calibrate.sh` (N20b-07) logs the same edge as `metric` lines tagged `ka: KA-849`; this
bead's acceptance compares them with the host values.

### Known answers and negative controls

Known answer: (0, 0, −0.01; 0, −0.01, 0). Negative control: Ad(T̂₁₂) on the tail, (0, +0.01, 0). Metamorphic
relations: re-expressing the rig in another base frame leaves the residual's norm and the attributed node
unchanged; doubling the lever arm doubles the linear part. Determinism lanes: `twice`, `profiles`.

## Considerations

- With a pure rotation between the sensors (zero lever arm) the mutant is invisible; the fixture must keep the
  1 m translation.
- On a tree-shaped graph the consistency residual is identically zero and nothing can be localized; the row
  uses a single edge with one node anchored, which is the smallest well-posed case.
