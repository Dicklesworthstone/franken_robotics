## Background

The known-answer suite of FrankenRobotics requires, for every row, a derivation on file: the model, the
derivation, the numeric value with its digits and the error budget of the test. The suite's own account of its
gaps lists a kind of row that cannot even be compared: *truths named and not written*. Three chapters name
closed forms for the pendulum period, the precession of a top, the pole of the two-wheeled balancer and the
hydraulic cylinder, and do not write them; one construction names the rolling disk and the Chaplygin sleigh
and gives no values; and one rejection fixture (a tracked base turning in place at zero scrub work on a
frictional floor) is said to be "caught by the belt-law known answer" of the contact chapter, which lists no
row under that name (the nearest is the skid-steer base under exact no-slip, with yaw rate zero).

Rows that cite such truths carry no value until the derivation files exist; they are obligations and cannot
support a gate. This bead writes the six derivation files. Every formula below is a DESIGN proposal from
standard mechanics, stated in full so that it can be checked by hand and confirmed by the row's owner; none
is a measurement.

## Scope

In: six derivation files with closed forms, numeric fixtures, error budgets and a negative control each; the
registry updates; host tests of the closed forms. Out: the simulations that are compared with them (the
dynamics and contact batteries); tolerances and controls of other rows. For the balancer this bead writes the
derivation file and its host test only: the template whose default parameters are the fixture is N14b-03, and
the comparison of the closed form with the linearized compiled model and with the referee's free response,
with the modal block structure and the sensitivity fixtures, is the zoo golden ZOO-balancer-2w; both depend on
this bead and keep the row `blocked: derivation` until the file is on record.

## Technical approach

**1. Pendulum period (row KA-356; gate of the dynamics battery; tolerance 10⁻⁶ relative at a 1 ms step).**
The fixture is the one the dynamics battery simulates (BD-088, `pendulum-60`), so that the file and the test
that compares with it state one value. A rigid link on one revolute joint with a horizontal axis: mass m,
distance ℓ from pivot to centre of mass, inertia I_p about the pivot (I_p = I_com + m·ℓ²), amplitude θ₀,
gravity g. ω₀ = √(m·g·ℓ/I_p); small-angle period T₀ = 2π/ω₀. Exact period T = (4/ω₀)·K(sin(θ₀/2)) with
K(k) = π/(2·AGM(1, √(1 − k²))), that is T = T₀/AGM(1, cos(θ₀/2)), where AGM is the arithmetic–geometric mean
(iterate a ← (a + b)/2, b ← √(a·b) until equal). Series check of the formula: T = T₀·(1 + θ₀²/16 +
11·θ₀⁴/3072 + …), which at θ₀ = 0.5 rad gives 1.0158488 against the AGM ratio 1.0158525. Fixture (BD-088): a
solid sphere of mass 1 kg and radius 0.05 m at ℓ = 1 m, so I_p = 1.001 kg·m²; g = 9.81 m/s²; θ₀ = 60°,
k = ½, K(½) = 1.685750354812596: ω₀ = 3.130527 rad/s, T₀ = 2.007069 s, T = 2.153951 s (ratio 1.0731820; the
file carries 15 digits). Control: the small-angle period used as truth at 60° is 6.82% short (T/T₀ − 1 =
7.3%).

**2. Symmetric-top precession (row KA-357; tolerance 10⁻⁴).** A heavy symmetric top with a fixed point: mass m,
distance ℓ from the pivot to the centre of mass, axial inertia I₃, transverse inertia I₁ about the pivot, spin
ω₃ about the symmetry axis, tilt θ from the vertical. Steady precession at rate Ω satisfies
I₁·Ω²·cos θ − I₃·ω₃·Ω + m·g·ℓ = 0. Slow root:
Ω = [I₃·ω₃ − √(I₃²·ω₃² − 4·I₁·m·g·ℓ·cos θ)]/(2·I₁·cos θ); for a fast top Ω ≈ m·g·ℓ/(I₃·ω₃); at θ = 90° the
relation is exactly Ω = m·g·ℓ/(I₃·ω₃). Fixture (BD-088, `top_precession_horizontal`): m = 1 kg, ℓ = 0.1 m,
I₃ = 2.0 × 10⁻³ kg·m², I₁ = 1.1 × 10⁻² kg·m², ω₃ = 100 rad/s, θ = 90°, started on the steady solution:
Ω = 0.981/0.2 = 4.905 rad/s, precession period 1.2810 s. Control: the gyroscopic term dropped gives no steady
precession (the top falls). A tilted case (this file's first fixture: I₃ = 0.002, I₁ = 0.012 kg·m², d = 0.1 m,
ω₃ = 200 rad/s, θ = π/3, slow root 2.5500 rad/s, the fast-top value 2.4525 being 3.8% low) enters the file as a
second case only if BD-088 adds its simulation test; until then it is not part of the row, and the host test
uses it only to check the slow-root formula.

**3. Two-wheeled balancer, open-loop pole (row KA-269).** Planar model: body of mass m_b, centre of mass at
height l above the axle, pitch inertia I_b about its centre of mass; two wheels of total mass m_w, total spin
inertia I_w and radius r, rolling without slip; no motor torque. Linearized about upright with pitch θ and
wheel travel x: (m_b + m_w + I_w/r²)·ẍ + m_b·l·θ̈ = 0 and m_b·l·ẍ + (I_b + m_b·l²)·θ̈ − m_b·g·l·θ = 0.
Eliminating ẍ with M_e = m_b + m_w + I_w/r²: the unstable pole is
p = √(m_b·g·l/(I_b + m_b·l² − (m_b·l)²/M_e)). The file is `docs/derivations/balancer-2w-pole.md`, the path the
archetype's template (N14b-03) and its zoo golden (ZOO-balancer-2w) cite. The archetype's own parameters give
the number, and the fixture is the template's defaults: m_b = 10 kg, l = 0.30 m, I_b = 0.20 kg·m², m_w = 2 kg,
I_w = 0.01 kg·m², r = 0.10 m: M_e = 13 kg, I_b + m_b·l² = 1.1 kg·m², denominator 1.1 − 9/13 = 0.407692,
p² = 29.43/0.407692 = 72.1868 s⁻², p = 8.49628 s⁻¹. Control: wheel inertia omitted (M_e = 12 kg, denominator
1.1 − 0.75 = 0.35) gives 9.1698 s⁻¹. DESIGN: the plan gives no parameters for the balancer, so one fixture has
to be chosen; the template's defaults govern, because the row's value is "the archetype's own parameters" and
N14b-03 and ZOO-balancer-2w test against them (rejected: a separate illustrative fixture with
I_b = 0.3 kg·m², 7.614 s⁻¹ and control 8.087 s⁻¹, which would give KA-269 two values). The template writes the same
expression as λ² = (M + m_b)·m_b·g·l/((M + m_b)·(I_b + m_b·l²) − m_b²·l²) with M = m_w + I_w/r² = M_e − m_b;
the poles are ±p plus a double pole at zero (free rolling). The file also states what counts in I_w: rotor
inertia reflected through the gear ratio belongs in it.

**4. Hydraulic cylinder through an orifice (row KA-336; a Moonshot item).** Supply pressure p_s, piston area
A, opposing load F, orifice area A_o with discharge coefficient C_d, fluid density ρ. Orifice flow
Q = C_d·A_o·√(2·Δp/ρ) with Δp = p_s − F/A; steady speed v = Q/A = (C_d·A_o/A)·√(2·(p_s − F/A)/ρ). Fixture:
p_s = 10 MPa, A = 10⁻³ m², F = 5 kN, A_o = 10⁻⁶ m², C_d = 0.6, ρ = 850 kg/m³: Δp = 5 MPa, v = 0.06508 m/s.
The port balance must close: p_s·Q = F·v + Δp·Q (650.8 W = 325.4 W + 325.4 W). Control: a flow law linear in
pressure, calibrated to the orifice law at Δp = 10 MPa, halves the flow when Δp halves where the orifice law
keeps 1/√2 of it: 0.0460 m/s.

**5. Rolling disk and Chaplygin sleigh (row KA-061).** *Sleigh*: mass m, yaw inertia I about the centre of
mass, knife edge a behind the centre of mass, forward speed v, yaw rate ω, no lateral slip at the edge:
v̇ = a·ω², ω̇ = −c·v·ω with c = m·a/(I + m·a²). Energy ½·m·v² + ½·(I + m·a²)·ω² is constant; with
V² = v² + (a/c)·ω²: v(t) = V·tanh(c·V·(t − t₀)) and ω(t) = V·√(c/a)·sech(c·V·(t − t₀)). The total heading
change over all time is π·√(1 + I/(m·a²)). Fixture: m = 1 kg, I = 0.03 kg·m², a = 0.1 m: total turn 2π rad.
*Disk*: an upright disk of radius r rolling without slip at spin rate ω_r and yaw rate Ω follows a circle of
radius r·ω_r/Ω; over a step Δt its displacement is the constant-twist chord
v·Δt·sinc(δ/2)·(cos(θ + δ/2), sin(θ + δ/2)) with δ = Ω·Δt, so a unit-speed half turn in one second gives
(0, 2/π) m. Control: the lateral no-slip row dropped (the sleigh's heading change is then ω₀·t, unbounded).

**6. Track turning in place (row KA-282, the rejection fixture, and the contact chapter's missing "belt-law"
row).** A tracked base of weight W on two tracks of contact length L under uniform pressure, friction μ,
turning in place at yaw rate Ω. Under ideal no-slip lateral rows the base cannot yaw: Ω = 0 (the existing
skid-steer rows). With cone-bounded rows it turns, and the lateral slip speed at distance s from the track
centre is Ω·s, so the scrub power is μ·W·Ω·L/4 and the scrub work per full turn is π·μ·W·L/2 (turning
resistance moment μ·W·L/4). Fixture: W = 500 N, L = 0.5 m, μ = 0.6: moment 37.5 N·m, 235.6 J per turn. The
rejection fixture's planted failure is "turning in place at zero scrub work"; the row that catches it is this
one, registered as a new row of the contact chapter (appended number) and cited by KA-282. Control: lateral
friction rows omitted for tracks, giving zero scrub work.

**Registry mechanics.** Each derivation file is `docs/derivations/<fixture>.md` with front matter listing the
rows it serves; rows change from "obligation: derivation" to eligible once the file, a tolerance and a control
are registered. The belt-law row is appended (never renumbered into the contact chapter's block).

**Controls of these rows: values here, records elsewhere.** The NC records of five of the rows are registered
by the control beads and their owners, and this bead registers none of them a second time: KA-061 (first
control N10-KA1's, the disk's longitudinal no-slip row removed; the sleigh's lateral row dropped is N38b-29's
alternate), KA-269 (first control N14-KA's, gravity reversed; wheel inertia omitted is N38b-30's second record),
KA-336 (N38b-31's proposal, the linear orifice law), KA-356 and KA-357 (first controls BD-088's: the
small-angle period used as truth and a stepper at h = 10 ms; the coadjoint taken with the wrong sign; N38b-31's
proposals, the small-angle period and the gyroscopic term dropped, are linked or second records by its rule).
What this bead adds is the number each control gives, written into the derivation file under "what the control
gives" (unbounded heading ω₀·t against 2π; 9.1698 against 8.49628 s⁻¹; 0.0460 against 0.06508 m/s; 2.007069
against 2.153951 s, 6.82% short; no steady precession), which those beads read. The
one record this bead registers is the control of the new track-scrub row (lateral friction rows omitted, zero
scrub work), which KA-282 also cites.

## Test plan

### Unit tests

`crates/frob-conformance/tests/derivations_owed.rs` (double precision; rationals where exact):
- `pendulum_period_agm`: BD-088's fixture, 2.007069 s and 2.153951 s (ratio 1.0731820); series agreement to
  10⁻⁵ at θ₀ = 0.5 rad with three terms.
- `top_precession_roots`: BD-088's fixture, 4.905 rad/s at θ = 90°; the slow-root formula at θ = π/3 (2.5500
  rad/s) with the quadratic's residual below 10⁻¹² and its limit m·g·ℓ/(I₃·ω₃) as θ → 90°.
- `balancer_pole`: 8.49628 s⁻¹ (p² = 72.1868 s⁻²) to 10⁻⁹ relative; control 9.1698 s⁻¹; the two written forms
  of the expression (with M_e and with M) agree to 10⁻¹².
- `orifice_cylinder_speed`: 0.06508 m/s; power balance closes to 10⁻¹².
- `sleigh_solution`: the tanh and sech forms satisfy both differential equations (checked by symbolic
  substitution at 100 seeded times); total turn 2π for the fixture.
- `track_scrub`: 37.5 N·m and 235.6 J; zero under the planted omission.
- `derivation_front_matter`: each of the six files lists the rows it serves and has the five sections (model,
  derivation, numeric fixture, error budget, what the control gives); a planted file without its error budget
  keeps its row "obligation: derivation".

### End-to-end script and logging

`scripts/e2e/ka_derivations_owed.sh` (header: `bead=N38b-47 milestone=M1 labels=gauntlet,registry
gates=GATE-GAUNT-02 plants=budgetless-derivation,zero-scrub`; sources the STD-E2E helper; scratch copy of the
registries). Steps: (1) `closed-forms`: `cargo test -p frob-conformance --test derivations_owed`, one `metric`
per fixture value (value, unit, truth, tolerance); (2) `registry`: the burn-down's `derivation` column read from
`target/gauntlet/obligations.json` (N38b-49's `ka_obligations.sh` regenerates it), one `assert` per row that it
has left "obligation: derivation", KA-336 logged `not-due`; (3) `simulate`: when the dynamics battery exists,
`frob sim run <fixture> --tier referee --profile referee --step 1ms --key kdo-<fixture>-<n> --json` (BD-088's
form; `sim.run` is a run verb) on the pendulum, top and sleigh fixtures, each simulated value against its
closed form with the row's tolerance; before that, `skip` with the reason (`battery not available`), never
counted as a pass; (4) plants: a derivation file with its error budget removed (its row must stay an
obligation) and the track-scrub control (zero scrub work, which the new row must catch). Log at
`target/e2e-logs/ka_derivations_owed/<utc>.ndjson` with the transcript; every line has `ts`, `script`, `bead`,
`step`, `event`; `cmd` lines the exact command, exit code and wall time (and the envelope's evidence block for
`sim run`); failed assertions the first differing value or row with observed and expected values and the
scratch paths; the `summary` with rows released, rows still owed and GATE-GAUNT-02.

### Known answers and negative controls

Known answers: the six fixtures. Negative controls (values written here, records as above): small-angle
period; gyroscopic term dropped; wheel inertia omitted; linear orifice law; lateral row dropped; zero scrub work
(registered here); and, for this bead's own check, a derivation file without its error budget. Metamorphic
relations: scaling every length of the pendulum by 4 doubles its period; scaling lengths by 4, times by 2 and masses by 2 reproduces the sleigh solution
bit for bit in the simulation. Determinism: D0 on the host.

## Considerations

- These are proposals: where an owner prefers another closed form (for example a top with nutation), the
  owner's form replaces the proposal and the row's fixture is re-derived.
- The pendulum row is stated "at h = 1 ms" with a 10⁻⁶ tolerance; the error budget must show the integrator's
  order makes that reachable, or the tolerance is amended by a dated note before the measurement.
