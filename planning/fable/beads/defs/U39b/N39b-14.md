## Background

Both program gates of the ten-fold test pass on a record, "whatever the ratio": the partial gate when every cell
has its ratio, interval, verdict, completion, coverage, tie test and phase ledgers; the tournament when the same
record is published with its ledgers and its kit. The report is that record in a fixed form. Its discipline is
that a number never travels alone: every reported ratio carries its regime, m, n, H, [L, U], the adjudication
label and the freeze hashes, and a warm ratio also carries S and N* (invariant INV-TENFOLD-08). A report that
would lack one of these is not written. The report is a harness record with the schema name
`frob.tenfold.report/1`; it is not a product format and it travels in the replication kit.

Terms. *Cell*: a stratum and a regime. *m*: mission families in the cell; *n*: paired campaigns; *H*: the
deadline. *R̂*: the pooled ratio of restricted times, rival over ours. *[L, U]*: one-sided 95% bounds. *S*: the
measured build cost of a standing asset (anything an arm built for a mission class before a clock started).
*N\**: the crossover reuse count, the smallest number of amendments at which our total time is no larger than
the rival's. *Freeze hash*: the content address of an arm's published freeze manifest.

## Scope

In: the generator; the JSON schema; the rendered form; the label vocabulary; the completeness check; the
deterministic-bytes property. Out: computing the numbers (the scorer N39b-19 and the three-arm statistics
N39b-43); sentences (N39b-05); the wording lint and limits block (N39b-15); publication and the kit.

## Technical approach

Module `crates/frob-conformance/src/tenfold/report.rs`; command `frob-tenfold report --gate <id>` (DESIGN). The
generator reads only the scorer's output, the outcome engine's output and the gate directory; it computes
nothing statistical itself and prints nothing it cannot resolve to a record digest.

**Per-cell table (DESIGN sketch of the record).**

```json
{ "schema": "frob.tenfold.report/1", "gate": "M3-partial", "params_hash": "b3:…", "suite_hash": "b3:…",
  "protocol_hash": "b3:…", "labels": ["self-adjudicated", "rival: internally advocated", "reality: no-claim"],
  "cells": [ { "stratum": "legged-quad", "regime": "cold", "confirmatory": true, "result_type": "finite-suite",
    "m": 24, "c": 1, "n": 24, "deadline_s": "14400", "ratio": "45/17", "ratio_decimal": "2.647",
    "bounds": {"L": "…", "U": "…", "method": "family-bootstrap-bc/10000", "seed": "…"},
    "guard": {"above_5": 20, "needs": 18, "level": "1/80"}, "verdict": "withdrawn",
    "completion": {"A": "20/24", "B": "20/24", "noninferiority_lower": "…", "margin": "1/20"},
    "coverage": null, "tie_test": {"rmt_c_over_a": "…", "lower": "…", "same_scope": true, "reading": "…"},
    "recovery": {"r_T": "…", "r_T_interval": ["…", "…"], "r_C": "…", "r_C_interval": ["…", "…"], "case": "…"},
    "warm": null, "excluded_pairs": 0, "censored": {"A": 4, "B": 4, "C": 0}, "ledger_open": {"A": 0, "B": 1, "C": 0},
    "adjudication": "neutral", "freeze": {"A": "b3:…", "B": "b3:…", "C": "b3:…"},
    "ceilings_on_rival": {"remove_train": "…", "unremovable": "…", "completion": "…", "horizon": "…",
                          "binding": "…"},
    "phase_ledgers": {"A": {"author": "…", "…": "…"}, "B": {}, "C": {}}, "costs": {"A": {}, "B": {}, "C": {}},
    "rate_ratio": {"value": "…", "note": "different estimand"}, "outcomes": ["…"], "sentences": ["…"],
    "evidence": ["b3:…"] } ],
  "portfolio": {"ratio": "…", "label": "descriptive"}, "limits": ["…"],
  "authorization": {"execution_authorized": false, "hardware_safety_signoff": false, "sim_to_real_certified": false} }
```
For a warm cell `warm` holds `{"N": 10, "ratios": {"1": "…", "10": "…", "100": "…", "limit": "…"},
"S": {"A": "…", "B": "…"}, "N_star": 5}` and `ratio` is R_warm(10). Exact values are strings (rationals or
decimal strings), never binary floats.

**Phase ledgers.** One per arm per cell: pooled exclusive seconds and share per phase over closed runs (`author`,
`propose`, `check`, `synthesize`, `compile`, `screen`, `train`, `evaluate`, `qualify`, `certify`, `diagnose`,
`wait`, `adjudicate`, `unattributed`), the resource table (device-seconds and core-seconds per phase, the
learner's share of `train`), the per-phase ratio of the rival's ledger to ours, agent turns and tokens, designs
decided per hour, trainings, and the count of certificates that changed a decision.

**Labels (closed vocabulary).** `self-adjudicated` (no external adjudicator); `rival: internally advocated` (the
rival's advocates are sessions of the project); `adjudication: cross-home` (no neutral simulator for the
stratum); `unreplicated` (the kit has not been re-run externally); `reality: no-claim` (always, unless a
measured reality band covers the mission); `unavailable` (a platform an arm cannot use); `not run` (a stratum or
row with its reason); `descriptive`; `void` (with its event); `ledger-open`; `deadline: envelope-limited`;
`synthetic` (rehearsals).

**Completeness check.** Before writing, every cell is checked against INV-TENFOLD-08 (regime, m, n, H, [L, U],
adjudication label, freeze hashes; S and N* for warm cells) and against two product refusals: a ratio without a
paired lower bound (FROB-REF-863) and a summary that omits what it excluded (FROB-REF-865: excluded pairs,
censored runs and `ledger-open` runs are always counted and printed). A missing item refuses generation and
names the cell and field. A void cell prints its event and no ratio.

**Rendered form.** `report.md` and a static HTML page generated from the JSON with a fixed template: per cell
the table, the sentences, the ledgers, the ceilings; then the descriptive section (time-to-acceptance curves,
completion by H, conditional times, every false positive, false negative and abstention, the fastest qualifying
baseline, all arms with raw pairings; a per-mission best-of-rivals ensemble only as an extra lower bound,
labelled as one); then the protocol section and the limits block. Deterministic: the same gate directory yields
the same bytes (class D0); the report's digest is what the gate record cites.

## Acceptance criteria

- [ ] For the rehearsal gate the generator writes JSON, Markdown and HTML whose bytes are equal on two runs.
- [ ] Removing any single INV-TENFOLD-08 field from the scorer output refuses generation with the field named.
- [ ] A warm cell without S or N* is refused; a void cell prints no ratio; a `descriptive` cell prints its
      reason.
- [ ] Every number in the JSON has an evidence digest that resolves in the gate directory.
- [ ] The labels in force are computed from the gate's records (adjudicator kind, advocate kind, simulator
      kind, kit status), not typed by hand; a planted hand-edited label fails the check.
- [ ] The no-authorization flags are present and all false; a build that emits a true flag does not compile
      (the flags are one type with a single value).

## Test plan

### Unit tests

`cargo test -p frob-conformance tenfold::report`: `inv08_each_field_required` (eight variants);
`warm_requires_s_and_nstar`; `void_cell_has_no_ratio`; `labels_derived_from_records`;
`excluded_and_censored_counts_printed`; `rate_ratio_labelled_different_estimand`; `bytes_deterministic`;
`six_family_card_table` (golden: ratio "45/17", decimal "2.647", verdict "no verdict: n below 10");
`warm_card_table` (ratios 0.272, 2.120, 6.596, limit 8.617, N* = 5, S_A = 14,400 s).

### End-to-end script and logging

Step `report` of `scripts/e2e/tenfold_partial_gate.sh` (N39b-12): generates the report for the rehearsal gate,
compares with the golden report, and logs the report digest, the label set and each completeness assertion.

### Known answers and negative controls

Known answers: the two card tables above. Negative controls: a ratio with its interval stripped (FROB-REF-863);
a table that hides two excluded pairs (FROB-REF-865); a warm ratio printed as the limit 8.617 without N.

## Considerations

- The report is the source for every public statement; no document may restate a ratio except by citing it.
- Cost columns are reported and no cost claim is made; energy is a named gap where no credible meter exists.
- Privacy: transcripts are referenced by digest; a private input cannot appear, since a kit built from one is
  refused.
