## Background

The published numbers of the ten-fold test are computed by one program, the scorer, from ledgers and receipts
alone. The replication kit carries it, and the kit's first level of replication is that the scorer reproduces
every published ratio, interval, count and verdict, bit for bit, on a clean machine. For that the scorer, like
the offline certificate auditor, depends on nothing outside the standard library: a third party must be able to
read it, build it with a bare compiler and trust that no dependency changed its arithmetic. The scorer is also
where two classic mistakes would silently inflate the result (averaging per-family ratios; dropping a run that
never finished), so it is tested against planted wrong scorers.

Symbols. H: the stratum's deadline. T_X,j: the clock of arm X on pair j (A this system, B the rival, C the
ablation arm). A campaign not accepted by H is censored and contributes H. Cell: a stratum and a regime; m
families, c campaigns per family, n = m·c pairs. S_X: build cost of arm X's standing assets. ā, b̄: pooled
restricted mean times per amendment.

Rejected alternatives. Floating-point sums (rejected: order-dependent). The platform's `ln`, `exp` and normal
quantile for the bootstrap (rejected: library results differ across platforms in the last bit, which can move a
selected order statistic). A scorer inside the harness crate's dependency graph only (rejected: a clean machine
would have to build the whole workspace).

## Scope

In: the binary, its input and output schemas, exact arithmetic rules, the deterministic bootstrap, the
standard-library-only constraint and its test, the comparison mode. Out: the statistical design itself (the
statistics beads); the contrast test's definition (N39b-35); three-arm statistics (N39b-43), which call the same
primitives; the report (N39b-14).

## Technical approach

**Layout (DESIGN).** Sources in `crates/frob-conformance/src/tenfold/score/` (`main.rs`, `input.rs`, `exact.rs`,
`bootstrap.rs`, `normal.rs`, `verdict.rs`, `warm.rs`), using only `std` and the three auditor source files
included by path. The harness crate compiles the same files as a module, so there is one implementation. Build
recipe in the kit: `rustc --edition 2021 -O scorer/main.rs -o tenfold-score`.

**Command.** `tenfold-score --gate-dir <dir> --out score.json [--check report.json]`. Exit 0 on success; 3 on a
typed refusal; 1 when `--check` finds a difference (the first differing field is printed).

**Inputs.** The registration (parameter block; cells with m, c, H, regime, result type; the confirmatory list
and the number of confirmatory cells; the bootstrap seed), every ledger and receipt, the event log. Each
record's digest is recomputed and compared with the event log before use. There is no input field for a
monitor's output, and the scorer refuses to run on a cell whose planned campaigns are not all closed or
recorded as excluded (the fixed-n verdict is computed once, at n).

**Exact arithmetic.** Times are parsed from decimal strings into integer microseconds; sums are integers
(128-bit); ratios are reduced rationals; a decimal is printed from the rational by exact long division, rounded
half to even at the stated number of digits. Binomial tails are exact: P(X ≥ x) = Σ_{k≥x} C(m, k) ÷ 2^m.

**Statistics computed (formulas restated so the binary is self-describing).**
1. Pooled ratio, cold: R̂ = Σ_j min(T_B,j, H) ÷ Σ_j min(T_A,j, H). Per family i: ρ_i on that family's pairs; when
   arm B is censored ρ_i is a lower bound, flagged; when arm A is censored ρ_i ≤ 1.
2. Censoring and exclusions: both-censored pairs stay in both sums; a pair excluded for a second harness fault
   is excluded for every arm and counted; over 5% excluded makes the cell `descriptive`. A cap breach censors
   at the instant of the breach and costs H. A mission whose accepted answer was later shown wrong costs H.
3. Warm: R_warm(N) = (S_B + N·b̄) ÷ (S_A + N·ā) at N = 1, 10, 100 and the limit b̄ ÷ ā; N* = the smallest N with
   S_A + N·ā ≤ S_B + N·b̄ (none if ā ≥ b̄ and S_A > S_B); the cell's R̂ is R_warm(10).
4. Bounds L and U (one-sided 95%): bias-corrected bootstrap, B = 10,000 replicates, families resampled with
   replacement and each family's pairs kept together. Replicate r draws m family indices from a counter-based
   generator keyed by (seed, cell, r, draw) (DESIGN: SplitMix64 on that tuple, index = high bits modulo m by
   rejection). Each replicate's ratio R*_r is an exact rational. z₀ = Φ⁻¹(#{R*_r < R̂} ÷ B); the lower bound is
   the order statistic at ⌈B·Φ(2·z₀ + z_0.05)⌉ and the upper at ⌈B·Φ(2·z₀ + z_0.95)⌉. Because order statistics
   commute with the logarithm, selecting on R* equals selecting on ln R* and no logarithm of data is needed.
   Φ and Φ⁻¹ are evaluated by fixed algorithms written in this crate from additions, multiplications,
   divisions and square roots only (which IEEE arithmetic rounds identically everywhere), with their own
   `exp` and `ln` by argument reduction and fixed polynomials; if B·Φ(…) lies within 10⁻⁶ of an integer the
   more conservative index is taken and `index_tie: true` is recorded.
5. Guard: X = #{i : ρ_i > 5} (a lower-bound ρ_i counts when the bound itself exceeds 5); critical count from the
   exact tail at the cell's Holm-adjusted level (step-down across the confirmatory cells at family level 0.05).
6. Completion by H per arm, and on family strata the share of mandatory obligations discharged, with the exact
   non-inferiority bound against margin 0.05; a zero-count rate is given the bound 1 − α^(1/n), never a
   bootstrap.
7. Verdict, first row that applies: `disqualified`; `descriptive`; `withdrawn` (R̂ < 3); `ten-fold`; `measured`.
8. The rate ratio R_rate = (accepted_A ÷ makespan_A) ÷ (accepted_B ÷ makespan_B), printed as a different
   estimand; the bounded paired contrast where a population result was declared.
9. Phase tables: pooled exclusive seconds and shares per arm over closed runs; `ledger-open` runs counted and
   excluded from ceilings but kept in ratios.

**Output.** `score.json` in canonical JSON with every value as a string (rational and decimal), every input
digest, the seed, the scorer's own source digest and the compiler version. Two runs give equal bytes (class D0)
on any conforming platform.

## Acceptance criteria

- [ ] The scorer builds with a bare compiler and no external crate; a test fails if any `extern crate` or
      non-`std` path appears in its sources.
- [ ] On the six-family card it prints R̂ = 45/17 (2.647), the six per-family ratios, the ceiling 3.75 and "no
      verdict: n below 10"; on the warm card 0.272, 2.120, 6.596, limit 8.617 and N* = 5.
- [ ] The planted wrong scorers (average of ratios: 6.23; dropping the censored family: 7.05) differ from it on
      the card and are caught by `--check`.
- [ ] Output bytes are equal on arm64 macOS and x86-64 Linux, in debug and release, for the rehearsal gate.
- [ ] A cell with an open campaign, and any attempt to pass a monitor output, are refused.
- [ ] `--check` against a published report passes on the unmodified gate directory and fails on any edited
      ledger, naming the first differing field.

## Considerations

- The bootstrap interval is approximate and descriptive and does not decide the word; it is printed with every
  ratio. On a 24-family suite from a population whose true ratio is 1.82, a percentile bootstrap can report 20.
- Integer microseconds bound a sum of 10⁶ runs of 10⁵ s well inside 128 bits.
- The scorer must stay small enough to read in an afternoon (TARGET: under 2,500 lines with tests).
