## Background

**The row.** WP-17: Scene packs and terrain. Crates: `frob-scene`. Milestone: M2. Key gates: GATE-HAB-01, -13. Waits
for: WP-02.

A world is a compiled field, not a mesh handed to the step. The package delivers the `.fscene` scene-pack format with
bricks, interpolation bounds and truncated fields with a stated range, the scene compiler through the airlock with
analytic overlays (`scene.compile`, `scene.show`, `scene.list`), the brick pool with one dense directory per scene
variant, and terrain generators with a difficulty parameter (`scene.gen`).

It is one unit of work because the format, the compiler and the pool are tested by one comparison: the compiled field
against its source geometry, and the pooled field against the dense field bit for bit.

**Order.** It waits for WP-02 only: the compiler reaches FrankenSim's scene and query crates through the airlock. It
does not wait for the batched step, so it can start early in M2 and unblock WP-16. (The order between packages is
recorded in `related`, never in `deps`: a blocked epic would block every child, so the child beads carry the real
dependencies.)

## Test plan

### Unit tests
None of its own: the children's tests run beside the code with `cargo test -p <crate>`, without mocks. The package's
structural tests are in N44-04 (`wp_children_have_one_parent`, `wp_gate_ids_exist`, `wp_tier_tag_has_pilot`).
### End-to-end script and logging
The children's scripts under `scripts/e2e/` demonstrate the package through the real `frob` binary, with the
structured logs of STD-E2E. `scripts/e2e/wp_table.sh` (N44-05) prints this row with its children, the open count and
each gate's status, and fails if a gate above has no record when the package is declared complete.
### Known answers and negative controls
Carried by the children and their chapter registries. A gate above counts only when its registered negative control
has been shown to fail (GATE-GAUNT-01).

## Considerations

- **Envelope.** No request above the default E0 (16 GiB, 8 cores, one hour, one device) is registered. A run that
  needs more is refused (`FROB-REF-761`) until a request with its class and its not-approved fallback is registered
  and approved (N44-01).
- **KILL-POOL** (decided M2). Trigger: Measured deduplication on the archetype battery below 1.5. Fallback, named in
  advance: Dense per-variant fields behind the same directory interface.
- Compiled-field error must be at most half a fine voxel at 10⁶ surface samples and never above the brick bound;
  analytic shapes are exact to the interpolation bound and overlays to round-off.
- Quantization ripple on a resting 10 kg block must stay at or below 1% of weight on every tier, or contact forces
  inherit the grid.
- Generators must be reproducible across platforms: one seed gives one `SceneId` on Linux and macOS, which is tested
  on the interiors at M3 (GATE-HAB-02, in WP-23).
