## Background

**The row.** WP-51: Replay, teleport and forks. Crates: `frob-chronicle`. Milestone: M2. Key gates: GATE-CHRON-05,
-06, -07, -12; GATE-AUTOPSY-01, -02, -07. Waits for: WP-22, WP-43.

Debugging and adversarial search both need to go back to an instant and change one thing. The package delivers forks
from snapshots by indexed copy with their classification into five classes (`run.fork`), the first-divergence search
over the digest chain in exact and tolerance modes (`telemetry.divergence`), telemetry on devices (the reservoir by
address, deterministic integer histograms through `K-x-hist` and `telemetry.histogram`, the measured cost of T0 to
T2), and retention and collection with tombstones (`store.status`, `store.collect`).

It is one unit of work because a fork is only useful if it is exact, classified and kept: a null fork must replay with
identical digests, a change set must be assigned its class, and a pinned object must survive collection.

**Order.** It waits for WP-22 (digests, snapshots and replay) and WP-43 (the chunk store the snapshots live in). (The
order between packages is recorded in `related`, never in `deps`: a blocked epic would block every child, so the child
beads carry the real dependencies.)

acceptance is read. Each bead has one package (the owner of its crate at its milestone, or of the crate where its gate

## Test plan

### Unit tests
None of its own: the children's tests run beside the code with `cargo test -p <crate>`, without mocks. The package's
structural tests are in N44-04 (`wp_children_have_one_parent`, `wp_gate_ids_exist`, `wp_tier_tag_has_pilot`).
### End-to-end script and logging
The children's scripts under `scripts/e2e/` demonstrate the package through the real `frob` binary, with the
structured logs of STD-E2E. `scripts/e2e/wp_table.sh` (N44-05) prints this row with its children, the open count and
each gate's status, and fails if a gate above has no record when the package is declared complete.
### Known answers and negative controls
Carried by the children and their chapter registries. A gate above counts only when its registered negative control
has been shown to fail (GATE-GAUNT-01).

## Considerations

- **Envelope.** No request above the default E0 (16 GiB, 8 cores, one hour, one device) is registered. A run that
  needs more is refused (`FROB-REF-761`) until a request with its class and its not-approved fallback is registered
  and approved (N44-01).
- **One set of five fork classes** and one refusal for a warm-start graft (`FROB-REF-582`): GATE-AUTOPSY-02 and
  GATE-CHRON-05 are the two chapters' readings of one mechanism.
- **OPEN-CHRON-4**: retention windows for failure captures and the default store budget on each machine. Default: 30
  days and 64 GB.
- A world forked alone and in a batch of 512 children must give identical digests; in tolerance mode the divergence
  search must report gaps instead of guessing across missing samples.
