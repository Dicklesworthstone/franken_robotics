## Background

Autopsy explains a failed episode by intervention: fork the failing world from a snapshot, change one declared
mechanism (remove a torque limit, restore nominal friction), re-run, and see whether the failure goes away. In
a chaotic contact-rich system any touch changes some outcomes, so a rescue by itself proves nothing. The
placebo fork measures that floor: a fork with a keyed perturbation that changes no mechanism. A factor is named
as a cause only when its rescue rate beats the placebo flip rate by a tested margin (construction C-29,
decision core DC-06, invariant INV-AUTOPSY-05: no attribution without a placebo and a null fork that replays
the failure bit for bit). Kill gate KILL-AUTOPSY withdraws attribution labels if planted single causes are not
recovered; GATE-AUTOPSY-03 measures recovery. Attribution runs in double precision under determinism class D2.
Tier: Solid. Subsystem: Autopsy.

## Scope

In: `registries/cards/GB-34.toml`; test `gb_34`; controls. Out: forks and interventions (BD-279); contrasts and
labels (BD-280, N27b-05); coalitions, minimal rescuing coalitions and Shapley summaries, which lane B's
joint-against-alternative check reads (BD-281); the abstention rule (BD-282).

## Technical approach

**Equation.** Rescue rate of an intervention do(c): the fraction of replicates in which the requirement is not
violated. Placebo flip rate ρ₀: the same fraction under placebo forks. Contrast = rescue rate − ρ₀. A factor is
named only when its contrast is tested above zero against the placebo forks, at a level divided by the number
of factors. ρ₀ above 0.2 names nothing. Labels: `but-for` for a contrast of at least 0.5, `contributing` for a
tested positive contrast below it, `joint` when only a coalition rescues. Fork budget for F factors with
singles and pairs: F + C(F, 2) coalitions, each with r replicates, plus the placebo forks and one null fork.

**Substituted (illustrative), with goldens.** 200 failing worlds re-run from their forks.

**Intuition.** In a chaotic system any touch changes some outcomes. The placebo measures that floor, and a
cause is whatever beats it.

**Assumptions.** The null fork replays the failure bit for bit; each intervention changes one declared
mechanism; forks receive fresh keyed randomness; attribution runs in double precision under class D2. (How
the third is realized, so that it is not read as "a child draws new streams": a child reads its parent's
counter-based streams by address, so the intervention is the only difference; what is fresh is the keyed
draw of each replicate's perturbation, or the key of one named stream when a replicate is re-keyed. N27b-03.)

**Flip.** A placebo rate near a factor's rescue rate, 30 of 200 against 38, leaves nothing to attribute. If
only a pair rescues, the cause is `joint`, and a Shapley summary of (½, ½) cannot tell that case from two
alternative causes.

**Lane A.** Exact rationals for rates, contrasts and counts; the exact one-sided test (hypergeometric tail of
the 2 × 2 table) in rationals for both comparisons; Shapley values from the four-entry game tables.

**Lane B.** `frob-autopsy`'s contrast statistics on a `synthetic` outcome table with these counts returns the
same rates, contrasts, p-values and labels; with ρ₀ = 0.25 it abstains and names nothing; with the null fork's
digest altered by one bit it refuses to attribute at all, with FROB-REF-583 (the null fork does not reproduce
its parent; exit code 3) and no table; with no placebo forks (P = 0) it prints the placebo rate and every
contrast as `null`, tests nothing, names nothing and carries the flag `no-placebo` (BD-280); the fork planner
for 12 factors returns 689 forks;
for the joint and alternative games it returns labels `joint` and `alternative` with identical Shapley
summaries and different repair sets ({1, 2} against {1} or {2}).

## Acceptance criteria

- [ ] The card file validates with all five fields and the ten outputs.
- [ ] `gb_34` passes both lanes; the two p-values are recomputed exactly and stored by the test as rationals.
- [ ] No label is produced without a bit-exact null fork (FROB-REF-583 otherwise, and no table) and a placebo
      arm (flag `no-placebo` otherwise, every contrast `null`, nothing named).

## Test plan

### Unit tests

- `gb_34_reference_rates_contrasts`, `gb_34_reference_exact_tests`, `gb_34_reference_fork_budget`,
  `gb_34_reference_shapley`.
- `gb_34_mechanism_labels`, `gb_34_mechanism_abstains_above_020`, `gb_34_mechanism_null_fork_required`
  (FROB-REF-583), `gb_34_mechanism_no_placebo_names_nothing` (the card's counts with the placebo arm removed:
  flag `no-placebo`, no label, although the rescue rate 0.82 alone would name the torque limit),
  `gb_34_mechanism_planner_689`, `gb_34_mechanism_joint_vs_alternative`.
- `gb_34_negative_shapley`: v(∅) = 0, v({1}) = 1, v({2}) = 0, v({1, 2}) = 0 gives (½, −½), summing to 0.
- `gb_34_controls`: (a) attribution from rescue rates alone names friction at 0.19 even when the placebo is
  0.15, and must be rejected in the flip case; (b) a level not divided by the number of factors names a planted
  null factor in more than 5% of 10⁴ seeded tables with 12 factors; (c) a Shapley summary reported without the
  coalition table cannot distinguish `joint` from `alternative`, and the report schema rejects it.

### End-to-end script and logging

NEG-02 runs `frob autopsy attribute f:<fork> --json` (the verb takes a fork handle) on a `synthetic` fork whose
recorded intervention outcomes carry the card's counts (164, 38 and 12 of 200; a second fork with the placebo at
30 of 200), and compares rates, contrasts, p-values and labels (`but-for`, `contributing`; nothing named in the
flip case); logs the exact command lines, exit codes, counts per arm, ρ₀, the level per factor, p-values and the
labels. The fork count of 689 for 12 factors is the planner's unit test (`gb_34_mechanism_planner_689`), not
an e2e step, because `autopsy.intervene` would run the forks.

### Known answers and negative controls

KA-673 (joint and alternative pairs: labels `joint` and `alternative`; Shapley values (½, ½) in both; repair
sets differ); KA-674 (negative Shapley value (½, −½), summing to v(N) − v(∅) = 0 exactly). GATE-AUTOPSY-03
measures recovery of planted single causes with these statistics. Determinism: rational arithmetic D0; forks
keyed by address.

## Considerations

- A rescue shows that removing a mechanism prevents this failure in these worlds; it is a statement about the
  model under intervention, never about a real robot.
- The 0.5 threshold for `but-for` and the 0.2 abstention bound are registered constants of DC-06; the card's
  labels follow whatever is registered.
