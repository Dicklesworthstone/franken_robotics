# Component Card Registry (`registries/cards/`)

This directory holds versioned component cards (format `FMT-FCARD`, extension `.fcard`, schema `frob.card/1`, validated against `schemas/registries/card.schema.json`).

At the first commit (`BD-002`), the directory contains zero card entries; cards arrive with `frob-actuate`, `frob-terrain`, and `frob-sensor` beads.
